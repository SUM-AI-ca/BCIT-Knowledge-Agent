### Course Description
This course introduces the various transmission mediums and systems used in wireless, cellular, LOS and satellite telecommunications networks. Topics include transmission lines, waveguides, path calculations, antennas and configurations, microwave transmission devices, microwave interfaces and fiber-optic transmission systems.
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Analyze Transmission Line Parameters including loss, impedance, bandwidth and weight from commercial data sheets.
- Calculate the impedances, reflection parameters and matches using formulas and the Smith Chart.
- Calculate transmission parameters and dimensions in rectangular waveguides.
- Calculate performance of fiber optic systems in relationship to parameters such as loss and Numerical Aperture.
- Complete a manual splice of a multimode fiber optic cable.
- Calculate antenna parameters to apply them in path calculations.
- Calculate path flux budgets and clearances in design of simple links with specified carrier/noise and bit error performance.
- Calculate Fresnel and curvature clearances using the Huntington model.
- Reconcile flux budget and clearance calculation results with those of commercial path calculation design software.
- Describe common microwave devices and their applications.
- Test a variety of devices against theoretical calculations and specifications.
