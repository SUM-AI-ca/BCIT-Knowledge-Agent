### Course Description
Provides an overview of common computer applications used in the exploration and mining industry. Topics covered during the course include: resource estimates, block modeling techniques, 3D ore body modeling and 3D open-pit design. Industry standard mine design software is used throughout the course. Emphasis is placed on the theory and concepts behind mine design software and the utilisation of a specific software platform. The Gemcom Surpac TM computer mine design software is used during the course for hands on practice of mine modeling and design. The program provides mining solutions for: geology, engineering and operations. All applications operate in a 3D environment such that data can be viewed and edited in true three dimensions. Through a series of worked examples and term assignments, students will learn the basics of the program application. Exercises will include manipulating topographical and geological data, solids modeling of an ore body shape, mineral resource estimation using sectional and block modeling techniques, and open pit mine design.
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Operate the software application Gemcom Surpac.
- Manipulate the topographical and geological data.
- Create a 3D ore body solid using information from a geological database.
- Perform computer generated cross-sectional and polygonal resource estimates.
- Describe basic block modeling techniques and input requirements.
- Create a simple ore deposit computer block model and resource estimate.
- Develop waste dump and mine road models.
- Design a simple 3D open pit model.
