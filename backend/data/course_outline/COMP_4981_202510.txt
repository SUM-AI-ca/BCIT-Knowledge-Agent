## Course Description
Exploration of ideas of communication, concurrency, and asynchronous operation at the operating system level. Covers advanced Linux Systems software development for Data Communications and networking. TCP/IP Network applications development using the Berkeley socket interface. Design and implementation of Client-Server models on the Linux environment using IPC and TCP/IP. Coverage of selected topics such as Multicasting, Raw Sockets, and ICMP.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Use processes and threads in the implementation of advanced communications protocols for the Linux environment.
- Develop Client-Server models using interprocess Communication (IPC) and the TCP/IP Protocol suite.
- Use synchronization objects such as signals, semaphores, critical sections and mutexes in the design and implementation of applications.
- Design and develop programs for Internetworking applications using Internet Protocol Suite.
- Analyze and implement security measures on Linux servers using standard tools and packages.
- Design and develop highly specialized communications software within a project team.
- Use development tools such as standard debuggers (gdb, mtrace,strace, etc) and memory debuggers (valgrind).
