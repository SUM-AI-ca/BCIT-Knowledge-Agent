### Course Description
Descriptive data analysis also including run charts, Pareto, and process capability. Calculus of relevant probability distribution models. Applications to reliability and operating characteristic (OC) curves. Large and small sample estimation and hypothesis testing. Linear regression and correlation. Introduction to acceptance sampling and statistical process control (SPC) applications. Goodness of fit tests and one-way analysis of variance (ANOVA). A calculator and statistical software package will be utilized. This course provides a solid foundation in statistics and SPC for students challenging the American Society for Quality's Certified Quality Engineer Examination.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Prepare a complete statistical description of sampled data. [1, 2, 3]
- Use probability models to solve engineering sampling and reliability problems. [1, 2, 3]
- Apply the appropriate formulae and procedures for a given a statistical scenario. [1, 2, 3]
- Identify type I / II risks for hypothesis testing, sampling plans and control charts. [1, 2, 3]
- Construct and analyze Shewhart control charts for non-random patterns. [1, 2, 3]
- Calculate the line of best fit using Legendre's, and other methods. [1, 2, 3]
- Calculate the line of best fit using Legendre's, and other methods. [1, 2, 3]

### Course topics
Unit 1: Descriptive Statistics (Chapter 1 - 2)
- Measures of central tendency
- Measures of variation including standard deviation and CV
- Frequency distributions
- Chebyshev's Theorem and the Empirical Rule
- Introduction to process capability
- Histograms,frequency distributions, Pareto analysis
- Run charts
- Computer Applications
Unit 2: Probability Theory (Chapter 3)
- Basic probability rules
- Applications of addition and multiplication laws to sampling
- Bayesean probability
Unit 3: Discrete Probability Distributions (Chapter 4)
- Binomial probability distribution
- Poisson probability distribution
- Geometric and Hypergeometric distributions
- Sampling applications
- Discrete versus continuous probability distributions
Unit 4: Continuous Probability Distributions (Chapter 5)
- Continuous random variables
- Normal (Gaussian) probability distribution
- Exponential, Weibull and Gamma distributions
- t-distribution, Chi-Squared distribution, and F distribution
Unit 5: Reliability Theory (Chapter 16)
- Failure rate curve
- Application of probability distribution models
Unit 6: Sampling Distributions (Chapter 6)
- Central Limit Theorem
- Distribution of sample means
- Distribution of sample variance
Unit 7: Inferential Statistics (Chapter 7 - 10)
- Point and interval estimates for mean, variance, and proportions
- Hypothesis testing for mean, variance, and proportions
- Type I and Type II error
- Goodness of fit testing
Unit 8: Curve Fitting (Chapter 11)
- Correlation
- Legendre's Method of least squares
- Multiple regression
Unit 9: Analysis of Variance (Chapter 12)
- Randomized design
- One-way analysis of variance
Unit 10: Shewhart Control Charts and Sampling Principles (Chapter 15)
- General theory of control charts
- Variable charts (x-bar, R or s charts)
- Attribute charts (p or c charts)
- Control limits
- Attribute sampling plans
