### Course Description
​This course introduces the fundamental concepts of programming and problem solving. Students taking this course will design, implement, test, and debug programs that incorporate: variables, expressions, assignments, I/O, conditional and iterative control constructs, functions, and parameter passing. The course assumes no previous programming experience. Students will be assessed through quizzes, assignments, and exams.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Implement problem-solving strategies that employ the four pillars of computational thinking: decomposition, pattern matching and data representation, abstraction and generalization, algorithms and automation.
- Design, implement, test, and debug simple programs in a modern high-level programming language.
- Write programs using good software development processes including design before implementation, iterative development, responsibility-driven design, and encapsulation/information hiding.
- Apply the techniques of abstraction and functional decomposition to implement a program using small modules with well-defined interfaces.
- Use variables, IO, and fundamental control structures including sequence, selection, repetition, and indirection to write code that is modular and re-usable.
- Use error handling to manage exceptional circumstances.
- Write unit tests to verify the correctness of their code.
- Explain the representation and use of primitive data types and built-in data structures such as strings, lists (arrays), and associative arrays (maps/dictionaries).
- Analyze and explain the behaviour of simple programs that employ fundamental programming idioms and constructs.
- Explain the value of using existing application programming interfaces (APIs) in software development.
- Generate API documentation for their code.
- Gain experience using code quality and style checkers, build scripts.

### Course Schedule and Assignments
Week | Outcome/Material Covered
1- Sep04 | Programming language levels and paradigms. Intro to Javascript. Control statements. Types, Compiler and runtime. Using CLI and REPL.
2- Sep11 | Code Readability, coding standards, linting tools. Compiling vs interpreting. Typing (static vs dynamic). Javascript continued. Static methods on objects. (Math, Date). Debugging. Arrays, reptition: loops, nested loops
3- Sep18 | Functions and indirection. Functional decomposition. Strings: Ascii, Unicode, Mutability. Scope (functional vs block scope), switch statements.
4- Sep25 | Error handling in Javascript: Try, catch, throw vs null return. Synchronous File IO in node.
5- Oct02 | Node.js event loop. What it means for code to run on a single thread. CPU-bound operations blocking the event loop. Understanding Asynchronous code execution.
6- Oct09 | Build tools (npm), packaging. Alternative strategies for asynchronous code handling: Promises.
7- Oct16 | Midterm Exam Preperation/Review Class.
8- Oct23 | Midterm Exam Week
9- Oct30 | Processing large amounts of data efficiently through streams (Readable, Writable, Transform streams). Different kinds of APIs. Getting data from public APIs and using it.
10-Nov06 | Networking Primer. Understanding HTTP. HTTP Client library. Basic Intro to Server-Side Computing in Node. Serializing Data over the Wire.
11- Nov13 | Term Project Overview.
12- Nov20 | Term Project In-Class Work. Software Testing (Unit vs Integration).
13- Nov27 | Term Project In-Class Work. Code review and refactoring.
14- Dec04 | Preperation/Review Class for Final Exam.
15- Dec11 | Final Exam Week
