## Course Description
In this course, students learn how to cut internal and external threads using an engine lathe. They will work with multiple types of thread forms to achieve different thread designations.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Cut metric and imperial external and internal threads.
- Cut acme internal and external threads.
- Cut multiple start internal and external threads.
