## Course Description
​This course examines code techniques for analyzing large and diverse data sets. Course work requires students to develop and assess effective algorithms to gather, cleanse and prepare raw unstructured data for modeling. Students practice writing complex SQL queries and procedures for joins and aggregation with structured data from multiple sources. Analytics topics covered include techniques for conducting effective surveys, sentiment analysis and predictive methods for analyzing time series data. Cases studies in surveying, sentiment analysis and time series methods reinforce proper big data management practices.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Write complex procedures, joins, aggregate using SQL with various data sources.
- Gather and format data from RESTful services and other unstructured sources.
- Cleanse and prepare raw data for modeling.
- Evaluate and select code algorithms for efficiency.
- Apply language study techniques to gauge and understand sentiment.
- Recognize potential bias from sampling obtaining representative and stratified samples.
- Use conjoint analysis to simplify choice-based decisions, understand attribute interactions and understand respondent segments.
- Separate and analyze cyclical, seasonal and trend components from time series data.
- Create time series models for explaining predictions of averages and variance.
- Report on data exploration and model results in surveys, sentiment and time series studies with relevant statistical and visual summaries.
- Research and evaluate code libraries to complete data preparation and analysis tasks.
