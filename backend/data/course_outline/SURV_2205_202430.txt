## Course Description
Introduction to Autodesk Civil 3D software. Students will create and manage drawings; edit & create styles and settings; create, import, analyze, manipulate points; import and edit electronic data collection files; create point groups; create description keys; draw lines and curves; label points, lines and curves; subdivide land; create, edit and analyze terrain models; generate volumes between terrain models; create horizontal alignments; create existing and design profiles; create and use assemblies for corridor design.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, students will be able to:

- Create and manage Civil 3D drawings and projects.
- Create and manage Civil 3D object styles and object label styles.
- Import and export point files.
- Create, manage, edit and label points.
- Create description keys to extract and label point attribute data.
- Recognize similar point attributes points and create point groups.
- Create, modify and analyze surfaces.
- Create volume surfaces.
- Determine the volume between two surfaces.
- Subdivide parcels using a variety of methods.
- Create horizontal and vertical alignments.
- Create road design assemblies (templates).
- Create corridors and corridor surface models.

## Course Schedule and Assignments
Week: Material covered: Lab
Sept 10: Introduction to the AutoCAD Civil 3D Environment, Best Practices, including Drawing, Editing & Annotating a simple 2D drawing: Introduction to the Civil 3D environment
Sept 17: Civil 3D Object Styles and Settings, including Settings Hierarchy, Drawing Settings, Creating and Editing Point, Line and Label Styles: Settings and Styles
Sept 24: Civil 3D Template Files. Civil 3D Points, including Creating (by various methods), Importing (i.e. PNEZD, PNE, et al), Exporting, Printing, Editing and Analyzing: Points, Civil 3D Template File Creation
Oct 1: Point Groups including Creation, Properties, and their various uses. Introduction to Description Keys: Point Groups & Description Keys
Oct 8: Line and Curve Creation & Annotation: Lines & Curves
Oct 15: Parcels (including Sites). Creation of Parcels (i.e. Single Family, R/W, et al) based on various criteria (i.e. Area, Frontage, et al), from Objects, and the Editing, Renumbering, and Labelling of Parcels: Parcels, MT Practice Exam
Oct 22: Surface Models including their creation: Mid-Term Exam
Oct 29: Editing TIN Surfaces and Surface Breaklines: Surface Model Creation & Editing, Surface Breaklines
Nov 5: Surface Models, Contours and their Annotation, Surface Analysis, Catchment Areas, Slope Analysis, Elevation Banding, Slope Arrows, Visibility Check Tools (i.e. Zone of Visual Influence, Point to Point), and Volumes: Surface Model Contours & Analysis, Volumes
Nov 12: Civil 3D Survey Toolspace (Survey Database (SDB)). Importing data (i.e. FBK files) into a SDB, including a Co-ordinate Transformation and creating Imperial Drawings from Metric Drawings: Survey Toolspace, SDB Translation
Nov 19: Automating linework, using Survey Figures and Figure Line Codes: Survey Figures, Figure Line Codes
Nov 26: Final Exam
