## Course Description
​This course is built on the previous rigging courses. Students will create and utilize custom tools for a more efficient rigging process. In addition, students will create characters rigs that are captible across several characters to save time during the production work flow. By the end of this course, students will be able to create powerful scripts with UI's to build and support their rigs. Students will also be able to create fully rigged characters with user friendly systems for animators.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Setup the initial skeleton for 3D characters.
- Employ appropriate techniques in creating modular rigs.
- Setup joints and twist controls for flexible rigs.
- Script IK/FK blending and matching.
- Prepare tools and custom scripts for efficient workflow.
- Create scripts and tools that will aid animators.
- Apply appropriate limits to joints to avoid unwanted transformation during animation.
- Create a flexible and fully functional rig for a human and/or creature character.

## Course Goals
Upon completion of this course, students should be comfortable with:

-the basics of Python scripting (variables, data types, if/else statements, for loops, UI's, functions) to build tools in Maya

-improved deformations (corrective joints, muscle system, pose space deformers)

-advanced skinning techniques (painting techniques, NG skinning, copying and transferring weights)

-building a clean, functional rig for a character or creature
