## Course Description
​This course explores the practical application of measurement and automatic control theory to industrial processes. Application and appropriate selection of flow measurement systems, control strategies and final control elements (control valves, variable frequency drives) to common industrial processes is investigated. Students will evaluate single input (SISO) and multi-input, single output (MISO) control strategies including cascade, feedforward, ratio, selective and adaptive systems commonly found in industrial processes. Control system stability is analyzed based on a first order plus dead time model of processes using Bode plots. Industrial control computers, specifically a distributed control system (DCS), will be investigated and used to create models and controls that simulate an industrial process (heat exchanger). The configuration and simulation will be implemented in a DCS laboratory after investigating, parameterizing and optimizing the control of a heat exchanger process in the laboratory.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe common industrial control strategies, their requirements and objectives, recommend under what conditions an approach is suitable, and determine performance criteria for these strategies [1,2].
- Design a control system to meet objectives for closed loop performance as measured against established performance criteria and evaluate using frequency response analysis [4].
- Design multi-input control systems (cascade, feedforward and ratio) and document using industry-accepted standards (ISA S5.1, SAMA). Implement and optimize a cascade and/or feedforward strategy(ies) [4].
- Evaluate the performance of common industrial (flow) measurement devices, and formulate selection criteria for a given application [2,3].
- Investigate, select and size control valves for control applications [2.3].
- Investigate the variable frequency drive (VFD) as an alternative to the control valve for use as a final control element (as time permits) [3].
- Design, document and implement regulatory control (and interlock / sequence control as time permits) of a simulated process on an industrial distributed control system (DCS) using IEC-61131-3 compliant programming [4,5,7].
- Create mathematical and empirical models to simulate an industrial process [1,2].
- Design the graphical user interfaces required for complete testing of a simulated system [4,5].
