## Course Description
Photoshop mastery is essential to managing and producing a highly professional product. Students will create stunning images and composites for visual communication projects by exploring the Photoshop interface and an array of photo-editing techniques. The course focuses on fine image editing, retouching, and developing high-quality online and print image compositions. Students will learn how to create complex graphics that can be built in multiple layers for organization and independent manipulation. Students will come to understand the purpose of the application tools, work with layers, channels, paths, make selections, image manipulation/alteration, understand image size, canvas size and resolution, create masks, work with filters and layer styles, the pen, colourize, and create interesting type.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Navigate the Photoshop environment and efficiently apply the provided toolset
- Adjust the colour and tone of an image using Levels, Curves, Hue/Saturation and Colour Balance
- Demonstrate use of working with masks and channels through Layer Masks
- Describe the difference between raster and vector graphics
- Apply blending modes to layers with Filters, Adjustment Layers, and apply Layer Effects
- Learn the difference between destructive and non-destructive editing techniques
- Apply correction and enhancements to photographic images, such as using smart filters; straighten, crop and resize; use adjustment layers; correct the perspective of an image; restore an aged or damaged photo; and eliminate unwanted elements such as red-eye or blemishes
- Use of the Brush, Eraser, Selection Marquee, and Quick Mask tools
- Consider colour spaces, resolution, and file format based on final output for web or print production
- Create composite made out of multiple images in order to produce unique and original work​
