## Course Description
This course covers the configuration and administration of a Microsoft Windows Server environment. Students learn the core technologies and capabilities of a Windows Server. Topics include: local and remote server management; server storage; Active Directory (AD); managing organization units and AD accounts; configuring group policies; TCP/IP in Windows network; Domain Name System (DNS); and Dynamic Host Configuration Protocol (DHCP). Students configure a Windows Server to perform a variety of roles, including acting as a DNS server, DHCP server, and file server. During the course students will build a Windows domain consisting of three or more Windows and Linux virtual machines, and learn to troubleshoot and monitor a Windows domain environment.​

## Course Learning Outcomes/Competencies
Upon successful compleiton of this course, the student will be able to:

- Install and configure a Windows Server.
- Configure Windows Server to be a domain controller.
- Build a Windows domain consisting of three or more computers.
- Deploy and configure the DNS service.
- Deploy and configure the DHCP service.
- Create and manage Active Directory users, computers, groups and organization units.
- Create group policy objects.
- Configure security and account policies.
- Configure and manage group policy settings.
- Configure file and share access.
- Configure servers for remote management.
- Configure Windows firewall.
- Configure file server resource manager, file service and disk encryption.
- Configure VPN, routing and direct access.
- Configure IPv4 and IPv6 addressing.
- Monitoring server and domain activity.

## Course Specific Requirements
This course includes mandatory online learning activities. Lack of participation in the online portion of this class may result in failure of the course.

Course Website: The course will be managed through the BCIT Learning Hub. This platform will be used for announcements, electronic handouts, and assignment submissions. All course announcements will be posted on the Learning Hub. Students are responsible for regularly checking the site for updates.

Online Participation: Weekly online activities include required readings and discussions. These must be completed before the start of each class. Readings will be assigned from the textbook, and handouts will be available on the Learning Hub. To receive full participation marks, students must actively engage in these online activities.

In-Class Participation: During lab sessions, students are expected to engage in discussions, problem-solving exercises, or work on assignments. Students using class time for unrelated activities, such as checking emails or browsing social media, will be asked to leave.

In-Class Activities: Assignments typically involve reading, class discussions, responding to instructor-assigned questions, and completing pre-lab exercises. Completion of pre-lab exercises is required to participate effectively in lab work.

Quizzes: Quizzes will cover online learning materials, lecture content, and lab activities from the previous week. Missed quizzes will result in a grade of zero, as there will be no makeup opportunities.

Group Presentation: Each team will prepare a 10-15 minute presentation to be delivered after the midterm. Teams are responsible for forming themselves, selecting a team leader, and choosing a relevant topic with input from all members.

Assignments: Assignments must be completed individually unless otherwise specified by the instructor. Late assignments will not be accepted for grading. Plagiarism will result in a grade of zero for the affected assignment.
