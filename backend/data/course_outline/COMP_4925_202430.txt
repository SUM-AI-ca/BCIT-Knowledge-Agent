## Course Description
This course focuses on advanced topics in database technologies, database systems design and development tools, data management, enterprise servers and systems, and relevant related areas. Topics reflect on the current trends in the use of databases in the industry. Some of these topics include: business intelligence, data warehousing and OLAP, databases on the web, database applications based on 3-tier and n-tier models, development for enterprise systems, and connectivity and GUI development.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Discuss business decision-making and the need for business intelligence (BI) database applications.
- Explain the processes and issues in designing and populating a data warehouse / data mart for BI.
- Design and implement a data warehouse for BI.
- Design and develop analytic database applications for BI.
- Design and develop database-driven web applications using relevant tools and platforms.

## Learning Resources
Software: Microsoft Power BI, Unity Development Platform, Visual Studio C#.Net, MySQL.

## Course Goals
- Describe MS Power BI and its components.
- Explore different data connections to multiple sources, local, and online.
- Extract, Load & Transform Data into Power BI Desktop using Power Query.
- Create and understand different visualizations and dashboards in MS Power BI.
- Tell the data story to engage stakeholders to bring insights from data visualizations.
- Publish MS Power BI dashboards to a Power BI Service.
- Design and develop a database-powerd game using relevant tools and platforms, including C#, Unity and MySQL.

## Evaluation Criteria

Project 1 is individual * Project 2 work will be completed in groups of 2. Project will be given a project mark (PM). Group members will each receive an individual contribution grade (ICG1 and ICG2). Group marks will be adjusted based on individual contribution grades using Individual Adjustment Factors (IAF1 and IAF2). Individual adjustment factor (Student 1): IAF1= ICG1 / MAX (ICG1, ICG2) Individual adjustment factor (Student 1): IAF2= ICG2 / MAX (ICG1, ICG2) Individual group mark (IGM1) = PM * IAF1 Individual group mark (IGM2) = PM * IAF2

Students who contribute equally to a project will each receive a grade equal to the project grade. Students who contribute less than their other group member will have their grade adjusted down. Students who do not actively contribute to projects may receive a failing grade despite the project getting a high grade.

Any student that cannot be matched in a group of 2, can work individually (no adjustment needed)
