## Course Description
Provides a working knowledge of Part 9 of the 2024 B.C Building Code as it applies to single family dwellings. Gives students the basic skills required to check plans, inspect buildings and deal with questions relating to Part 9 at an elementary level. Covers acceptable materials, systems and methods used in housing construction. Students must bring B.C. Building Code (hardcopy) to the first class.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Check plans of single-family dwellings for compliance with the regulations in the BC Building Code, at an elementary level (provided the student has the ability to read plans).
- Inspect single-family dwellings relative to compliance with the regulations in the BC Building Code.
- Deal with questions relating to Building Code requirements for single-family dwellings.
- Have a basic understanding of acceptable materials, systems, and methods used in house construction.

## Other information
Communication: Please ensure you check your BCIT email regularly since this is the best means of communication by the instructor.

Course Format: This course is a lab / lecture combination.

Teaching Material: With the exception of the BC Building Code, course material is provided in the course portal, accessed by navigating through CONTENTS. The course material is written in easy to understand English. When reading the course material, the student must also cross reference the material with the BC Building Code to better understand the Building Code language, terminology as well as the Building Code layout. The instructor will be covering new material every class. The presentation will be in a PowerPoint format. Due to the large amount of material, only the significant material within the module will be presented. However, the student is responsible for all course material.

Evaluation: The students comprehension of the course will be evaluated through examinations and a term project. Examination writing will be in-class only; remote exam writing is not permitted. The examinations are in a hybrid format with multiple choice, fill in the blank and short answer questions. The examinations will be graded in the same manner; a hybrid of the computer system and the instructor. Each examination is assigned a separate, different weight. Once an exam is marked, the computer system incorporates the assigned weight and will then calculate the examination grade. The computer system calculates the final grade in the same way. Only this objective marking method will be used. Therefore, it is strongly recommended that students prepare for each class and engage and collaborates appropriately to get the most from this course.
