## Course Description
In this course students will install, create database and learn how to perform basic administration. Students will learn to configure the database to support different applications, perform tasks such as create users and schema objects, apply constraints, setup access control, assign memory, define storage structures and manipulate data. Since database administration does not end after the database is created, students will learn the importance of backup and recovery strategy. A good understanding of the DBMS architecture, performance monitoring and concurrency control are essential to ensure the database operates smoothly to support transaction processing.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Create database, configure and set initialization parameters
- Start and stop the database in different modes
- Connect clients to database instance
- Describe a basic database management system architecture
- Manage and use the DBMS’s process, memory and storage
- Apply database access control and administer user accounts, roles and privileges
- List and describe the different types of database objects
- Apply various types of table constraints using SQL DDL with some advanced features
- Access and manipulate data using SQL DML with some advanced features
- Explain performance monitoring with basic analysis
- Describe database transaction processing based on ACID property adherence
- Explain recovery concepts of using redo and undo of transaction data
- Describe concurrency control, locks application and resolution of lock conflicts
- Identify potential key causes of database failures
- Assess and evaluate suitable type of database for selected problem domain

## Course Goals
- Install, configure and administer a MySQL Server on Windows and Linux (edit config file, start/stop MySQL service).
- Optimize INSERTs, DELETEs, SELECTs and Aggregate queries in MySQL.
- Connect to and run queries against a MySQL Server on a CLI and GUI.
- Create users and assign privileges within MySQL to limit the potential threat of data loss due to accidental query execution. Analyze existing users and privileges to know who has access to what.
- Import SQL and non-SQL formatted (CSV style) data into MySQL.
- BEGIN, COMMIT and ROLLBACK a transaction.
- Add indexes to a table to speed up a set of queries.
- Create and manage summary tables to optimize aggregate SELECT statements (with GROUP BYs).
- Be able to perform a hot and cold backup of a database and restore partial or complete databases in response to a variety of database loss scenarios.
