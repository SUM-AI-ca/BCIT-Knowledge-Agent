## Course Description
​In this course, students will learn the principles and practices of React, one of the most prominent modern full-featured frontend JavaScript frameworks. They will learn to build modular components, and compose modular components into rich and featureful user interfaces. In this course, students build on core JavaScript development skills of Frontend Web Development with JavaScript.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Explain the basic concepts of the React Library, and how it interacts with the browser.
- Construct single-page applications using modern React and its supporting toolchain.
- Manage component state using both local state and shared state.
- Write code to transform nested serialized data into components.
- Implement components that can evolve as they asynchronously load, by displaying states such as loading, error, and success.
- Use third-party component libraries in their applications.
- Use third-party libraries such as Jest or Storybook to build and test components in isolation.
- Use a client side library to interact with HTTP APIs to send and receive data in JSON format.
- Extend React functionality with modern React libraries such as React Router.
- Conditionally render components using ternary and logical operators.
- Implement good programming practices for clear communication, such as comments and formatting style.
