## Course Description
​This course covers enterprise software development processes and systems integration with a focus on the mechanisms employed. Students will learn how to structure solutions using current technologies and protocols. The student will learn a series of Integration forms from simple to complex partner connections and everything in between. Current tools will be used to solve integration problems big and small.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Draw and understand models of an enterprise system development environment to the extent that they can communicate this information to and from others.
- Deploy and configure the tools needed to support an enterprise system development environment.
- Use schemas to construct solution structure and constraints.
- Create and configure solution schemas.
- Create and transform messages using maps.
- Manipulate data using advanced mapping.
- Enable integrations between tools.
- Create and configure CI/CD pipelines to process file data.
- Create orchestrations to automate enterprise system development processes.
- Automate Business Processes.
- Create Transactional Development Processes.
- Integrate Business Rules.

## Course Goals
This course looks at building and maintaining an environment for Enterprise Software Development.

Students will learn about the components that make up this environment, including the following topics:

- Software Source Code Management
- Work Management and Issue Tracking
- Knowledge Sharing and Communication
- Continuous Integration (CI)
- Automated Test
- Static Code Analysis
- Artefact Management
- Continuous Delivery (CD)

Students will incrementally deploy, configure and integrate the tools for an enterprise software development environment and exercise common software development and test workflows within this environment.

Students will also conduct tool assessments and trade-off analysis between cloud and on-premise tools and environments.
