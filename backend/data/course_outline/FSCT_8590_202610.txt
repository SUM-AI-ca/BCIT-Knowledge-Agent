### Course Description
​The course covers a wide range of topics from common vulnerabilities and tools that are used to exploit, to incident response and handling. Addresses theoretical and practical issues in malicious programs and scripts, ste​gano​graphy, worms and different types of network exploits and attacks.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Select exploit codes and hacker tools for the purposes of gaining an understanding of network vulnerabilities.
- Use monitoring and scanning tools to identify system vulnerabilities.
- Protect information and network systems using appropriate security tools.
- Evaluate available free tools and off-the-shelf hardware to sniff wireless traffic and compromise 802.11 networks.
- Test systems vulnerabilities using popular frameworks such as Metasploit to penetrate networks.
- Design and implement advanced defense mechanisms to secure artificial intelligence systems against sophisticated threats such as data poisoning, adversarial inputs, model inversion, and supply chain manipulation.​
### Learning Resources

### Course Goals
Upon successful completion, the student will be able to:
- Identify and use exploit code and security tools for the purposes of gaining an understanding of network vulnerabilities.
- Use monitoring and scanning tools to identify system vulnerabilities.
- Use security tools to protect information and systems.
- Use freely available tools and off-the-shelf hardware to sniff wireless traffic and compromise 802.11 networks.
- Use popular frameworks such as Metasploit to penetrate and test systems vulnerabilities.
- Use publicly available tools as well as commercial devices to carry out penetration testing of networks.
