## Course Description
​This course teaches the use of hospital administration software called Meditech. Meditech is a secure cloud-based electronic health record (EHR) software with standardized databases used by healthcare organizations of various sizes across the world. Meditech's EHR software provides healthcare providers with cost savings, efficiencies, flexibility, and timely access to patient information. Students will learn Meditech's software features, how to enter data, and how to navigate, retrieve and store patients' medical information. The management and security of private information is explained and demonstrated with case studies. Students will receive practical experience with Meditech software used at hospital and clinic sites and engage with software features that form an electronic record of the patient's healthcare journey.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Define Electronic Health Record (EHR).
- Use the healthcare database in a hospital setting.
- Explain how Meditech is used in healthcare environments.
- Identity Meditech’s software functions and components.
- Identify data entry location.
- Navigate software.
- Enter, maintain, retrieve and store patients administrative and clinical information.
- Recognize safety features and security protocols for data management.
- Explain when, why, and with whom the patients’ electronic chart is shared.
- Use software shortcuts and hospital protocols.
- Recognize the steps required for processing patient information from start to completion.
- Explain how Meditech information is used by the healthcare team.
- Adhere to safeguarding patient information and confidentiality requirements.
