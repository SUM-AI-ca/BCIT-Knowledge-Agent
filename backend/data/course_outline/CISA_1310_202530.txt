### Course Description
​This course introduces basic concepts involved in the electronic transmission of data from one computer system to another utilizing data networks. The major types of network topologies, protocols, and infrastructures are discussed, and students are presented with various networking models and standards. Topics covered will include the Open Systems Interconnection (OSI) model, TCP/IP, Ethernet, network topologies, IP addressing, sub-netting, IPv6, networking components, and basic network design. Students will gain the knowledge and skills necessary to implement, administer, and troubleshoot basic network systems and hardware, including configuring devices using command line tools.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Describe how devices communicate in data networks and the Internet
- Use network protocol models to explain the layers of communications in data networks
- Describe the protocols and services provided by the application layer in the OSI model
- Explain the operations and features of the transport layer protocols and services
- Describe the operations of network layer protocols including concepts of packet routing
- Convert decimal numbers to and from both binary and hexadecimal
- Design, calculate, and apply subnet masks and IPv4 addressing plans
- Design, calculate, and apply IPv6 addresses and prefixes to computers and router interfaces
- Explain fundamental Ethernet concepts and build a simple Ethernet network
- Describe structured data cabling and the differences between straight-through, crossover, and rollover patch cords
- Use router command-line-interface (CLI) commands to perform basic configuration and verification
- Configure static and default routes from the CLI for both IPv4 and IPv6
