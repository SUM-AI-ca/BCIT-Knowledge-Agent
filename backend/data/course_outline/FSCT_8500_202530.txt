## Course Description
This course will introduce students to forensic issues related to mobile devices that may use cloud resources. Students will learn what data can be retrieved from a mobile device, and they will get hands-on experience using current tools to perform the extraction. Students will analyze this data and align it with records from network security providers to inform an investigation. Cloud resources will also be addressed using industry standard software. Technical and legal issues will be considered.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe all steps required to collect and handle evidence from mobile devices.
- Create a forensic report detailing the data extracted from a mobile device.
- Analyze the data collected from a mobile device using existing hardware and software.
- Assess the impact of different cellular networks on forensic data.
- Use data from network service providers together with extracted data to improve forensic picture.
- Extract cloud data associated with a given mobile device.
- Explain the legal considerations associated with cloud extraction.

## Course topics
· Legal issues: The authority of a law enforcement agency in Canada to seize and search mobile evidence.

· Introduction to cell phone technology: History of mobile devices, mobile communication standards.

· Coping with non-responsive devices: Hardware inspection and repair of damaged devices (e.g., water damage, electrical damage, malicious destruction).

· Data extraction: Extracting data from logically failed mobile devices.

· Forensic practice: Applications of sound mobile device seizure procedures.

· Cell phone analysis: In-depth analysis of iOS and Android systems.

· Forensic software usage: Application of leading mobile extraction and analysis tools.

· Cloud issues: Techniques and approaches for accessing cloud data and artifacts.

· Best practices: Finding and identifying the best approach to properly process digital evidence from a mobile device – Choosing the best tool for the job.

· Working with storage media: Preserving and analyzing SIM cards and media cards.

· Manual method: Using manual approach to extract and verify data when traditional tools will not work.

· Mobile data: Processing and analyzing extracted mobile data – getting the artifacts and the evidence needed.

· Location of data: Interpreting geo-location data and applying it to the case.

· Documentation: Taking notes, creating and submitting a full forensic report describing all the steps taken during the analysis.
