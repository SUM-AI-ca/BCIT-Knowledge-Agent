### Course Description
This course is for students who have a special interest in database technology. Topics include: database transactions, concurrency control and recovery techniques in multi-user database systems, database security, distributed databases, and current trends in database technologies. Students will use common industry database software products such as Microsoft SQL Server and/or MySQL DBMSs.
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Identify the key requirements of a multi-user as well as a distributed database management system.
- Evaluate the role of transaction management, concurrency control and recovery in meeting these requirements.
- Discuss current trends in database technologies.
- Implement and administer a relational database system, such as MySQL and/or SQL Server DBMSs.
- Develop database applications that use a relational database to retrieve, store and modify data for data persistence.
### Learning Resources
Software: Microsoft Visual Studio Code, Google Chrome, Node.js, MongoDB and/or MySQL.
### Course Goals
- Apply concepts covered to progressively complex problems
- Solve course related problems under time pressure/constraint
- Design and develop multi-user web centered applications.
- Use industry best practices to secure databases and protect against Internet threats

* Project work will be completed in groups of 2. Projects will be given a project mark (PM). Group members will each receive an individual contribution grade (ICG1 and ICG2). Group marks will be adjusted based on individual contribution grades using Individual Adjustment Factors (IAF1 and IAF2). Individual adjustment factor (Student 1): IAF1= ICG1 / MAX (ICG1, ICG2) Individual adjustment factor (Student 2): IAF2= ICG2 / MAX (ICG1, ICG2) Individual group mark (IGM1) = PM * IAF1 Individual group mark (IGM2) = PM * IAF2
Students who contribute equally to a project will each receive a grade equal to the project grade. Students who contribute less than their other group member will have their grade adjusted down. Students who do not actively contribute to a project may receive a failing grade despite the project getting a high grade.
Any student that cannot be matched in a group of 2, can work individually (no adjustment needed). **Job interviews may be recorded and securely stored for review.
