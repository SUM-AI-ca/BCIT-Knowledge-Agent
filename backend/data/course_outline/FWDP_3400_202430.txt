## Course Description
The Web Scripting 3 course introduces students to JavaScript-based web application development. The course explores setting up and developing a web application using modern JavaScript build systems. Students will learn how to implement modern coding methodologies available in JavaScript such as modules and classes. Students will explore in detail application state management as well as routing, validating, and styling modules. Utilizing foundational JavaScript skills and modern JavaScript coding and build system techniques, students will explore developing and deploying practical interactive web modules and full-featured stand-alone web applications.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Explain common JavaScript frameworks and explain when to implement them on a web site or application.
- Set up a development environment for JavaScript application development.
- Explain application state management.
- Use an applications state to manipulate the DOM.
- Use routing to keep an application in sync with the URL address.
- Create and deploy stand-alone web applications.
