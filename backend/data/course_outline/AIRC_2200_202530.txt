## Course Description
​The Applied Project/Capstone course will continue to build on the multi-layered capstone project (dynamic assessment). Students will work with their teammates to revise the project plan they created in AIRC 1200, including incorporating feedback received from the faculty project leader and industry partner. The students will then carry out the tasks in the project plan assigned to Term 3. Student, faculty project leader and industry partner will communicate throughout the course to discuss progress. Students will contribute to 360-degree feedback, reflect on their leadership and teamwork skills, and create project status reports. Evaluation will include a project plan update, reflection paper, 360-degree feedback and project status reports.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Apply the skills developed in AIRC 1200 Applied Project 1/Capstone.
- Update the project plan for the applied/capstone project.
- Contribute to 360-degree feedback.
- Reflect on leadership and teamwork skills using information from the 360-degree feedback​.
- Create project status reports.​
