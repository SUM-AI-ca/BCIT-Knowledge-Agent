### Course Description
​In this course, students who have completed the program entry prerequisite are exposed to the fundamental programming structures of the main coding language(s) to be used within the Software Systems Developer program. Topics of this course include code environment setup, debugging, data structures, fundamental programming structures, string manipulation, and collections. Object-oriented content includes an in-depth focus on polymorphism, namespaces, access modifiers, virtual and abstract inheritance, generic types, interfaces, structs, delegates, anonymous functions, events, and call backs. Course content also focuses on object-relational mapping for creating, reading, updating, and deleting database content through code. Both code-first and database-first alternatives are examined for database implementations with exercises and projects. Labs and exercises focus on writing code for projects, assignments, and activities.​
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Install and set up a suitable development environment.
- Apply multiple techniques for effective debugging.
- Create simple algorithms with common programming structures for solving simple problems.
- Implement appropriate code structures for efficient storage and memory use.
- Organize code to optimize readability and reuse while reducing error vulnerability.
- Research and use features of the chosen programming language.
- Organize code in classes for encapsulation.
- Manage database content through code.
- Implement object-relational mapping for interaction with database content through code.
- Write an extensive range of database queries in code for querying, joining, summarizing, creating, updating and deleting data.
- Create custom events and call backs for event handling.​

### Course Goals
This course develops foundational and intermediate skills in object-oriented programming using C# and the .NET platform. Students will build an understanding of data types, control flow, memory management, and error handling while applying best practices for debugging and coding conventions.
The course emphasizes object-oriented principles, encapsulation, inheritance, polymorphism, and abstraction, together with generics, collections, and LINQ.
By the end of the course, students will be able to design, implement, and test .NET applications that integrate multiple object-oriented features and process real-world datasets.
