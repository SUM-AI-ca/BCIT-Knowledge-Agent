## Course Description
In this course, students will build on their programming and scripting skills within industry standard 3D applications. Programming with Python, students will apply standard coding practices used by technical artists in developing expressions, user interfaces, tools, and functions. In addition, students will learn the essential elements of user-centric design and user experience. ​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Write Python scripts in 3D applications.
- Design user-friendly interfaces.
- Develop a user interface within industry standard 3D applications.
- Create expressions for node attributes.
- Program procedural shader animation.
- Animate textures through expressions.
- Create connections between nodes through expressions.
- Build simple tools inside 3D applications.

## Course Goals
This course focuses on teaching the ways of scripting for 3D applications in technical production environments. The main goal is to get students to understand what a DCC (Digital Content Creation) package is, how it relates to the operating system it runs on, and how it fits within a larger pipeline. Students will learn about different scopes that a DCC shares (and doesn’t share) with its environment. They will also study how to write tools and workflows that integrate with Maya and other DCCs in multiple paradigms—such as control, automation, visualization, and wrappers. By the end of this class, students should be able to understand the role of a DCC in a VFX/game production environment, how to script for it, and how to integrate it into any type of pipeline and workflow. The scope of each topic will be designed to scale with each student’s ability as to make sure it’s challenging and pushing on an individual level.

By the end of this module, students will be able to:

- Define and describe what a DCC is and how it interacts with an operating system and external pipelines.
- Explain various scopes (OS level, pipeline level, DCC level, system level) and their influence on tool development.
- Develop Python scripts to control, automate, and extend functionality within Maya and similar 3D software.
- Discuss and implement data handling strategies (local vs. on-disk I/O, referencing, USD, database integration).
- Use Maya’s API (MEL, Python, OpenMaya) effectively and understand when to use each.
- Create custom solutions (plugins, nodes, automation callbacks) and package them for deployment.
- Design user interfaces within Maya using its Qt infrastructure.
- Plan and execute a final scripting project from concept to deployment, integrating best practices.
