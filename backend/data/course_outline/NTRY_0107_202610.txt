### Course Description
This course uses computer lab time and online learning (utilizing task-oriented assessment software) to give students an understanding of basic computer terminology, hardware components and software applications used in their technology. Practical exercises using the Microsoft Office Suite focus on file management, word-processing, spreadsheets, presentations, and World Wide Web access.
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Use correct terminology when discussing hardware components and software applications.
### MS Windows Operating System*
- Use a mouse to start and close a program, move and resize windows.
- Use menus, keyboard shortcuts, toolbars, dialog boxes and scroll bars.
- Customize a desktop and create shortcuts.
- View, move, copy, delete and restore files, manage files and create folders with Windows Explorer and My Computer.
### MS Internet Explorer*
- Use MS Internet Explorer, the Internet and the World Wide Web.
- Explore features of the browser window, open and save URLs, search for information on the Internet , print and navigate Web pages.
### MS Word*
- Start Word, type text in a document, save a document, print a document, close a document and exit Word.
- Select and replace, cut, copy and paste text using the system Clipboard and Office Clipboard.
- Use Spelling and Grammar and Thesaurus features and use the Word Help system.
- Use the Find and Replace feature.
- Create a document using Wizards and templates.
- Use fonts, font styles and effects to format text.
- Change format of paragraphs by aligning them, changing line and paragraph spacing and applying bullets and numbering.
- Work with tabs and indents.
- Divide a document into sections, format documents and sections with page layout option.
- Insert page breaks, change margins, create and modify headers and footers, add page numbers and format text in columns.
### MS PowerPoint*
- Learn about the basic elements of the PowerPoint window.
- Save, print and close a presentation.
- Plan and create a basic presentation, enter slide footer text, spell check and evaluate a presentation.
- Open an existing presentation and modify it, apply different text formatting techniques, draw and modify PowerPoint shapes, import text from MS Word and change a presentation colour scheme.
- Enhance a presentation with clip art, charts and tables.
- Annotate slides in slide show view.
- Set slide show timings, transitions and animation effects.
### MS Excel*
- Identify the difference between a worksheet and a workbook.
- Enter labels and values, open and save a workbook, name, move, preview and print worksheets.
- Build a worksheet by entering and editing text, numbers, mathematical formulas and Excel functions with relative and absolute cell references.
- Change the contents of a cell, insert, delete and adjust columns and rows, copy and paste information, move cell contents, format values, use conditional formatting, apply colour, pattern and borders.
- Plan and create charts, change chart types, as well as move, resize and enhance charts.
- Directed Projects
- Explore and demonstrate by way of directed projects: application programs at an advanced level and/or computer-related topics relevant to the student's subsequent technology program.

### Course Specific Requirements
- Please note that the course meets online and having access to reliable internet, a working webcam, and a scanner or a camera (cellphone or otherwise) to scan or take pictures of your written work are required. Having a printer would be great, but not required.
- Having a working version of Microsoft office 365 is a requirement of this course. Please make sure you have Microsoft word, Excel, and Powerpoint up and running on your device before the course starts.
- iOS users are responsible for finding compatible commands and shortkeys mentioned in the course. However, differences are minor in most cases.
- All students must provide their own current PC desktop or laptop with a microphone and webcam and have high speed internet access. BCIT does not provide support for student devices.
- All students must be computer literate to the extent of being able to log in during regular scheduled hours in order to participate and complete this course.
- All tests are online and will be invigilated via Zoom and/or BCIT recommended proctoring tools. The students are expected to share video as required by the instructor during tests.
