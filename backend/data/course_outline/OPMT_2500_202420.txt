## Course Description
For any project to be successful, it is essential to define the project scope and effectively manage it throughout the project. With proper scope definition, project activities can be defined and scheduled. The scheduling process involves assigning duration and resources to each activity and requires a plan to control them during the life cycle of the project. This course will provide the tools and techniques to create and manage the scope of the project and schedule project activities.

## Course Learning Outcomes/Competencies
Upon successful completion of the course, the student will be able to:

- Explain why scope definition and project management are important.
- Evaluate stakeholder needs through applying methodologies and tools.
- Define and document a project’s scope based on stakeholders’ needs.
- Develop the elements of a project scope statement.
- Develop a plan to receive the information needed to evaluate and implement possible changes to the project scope.
- Create a project work breakdown structure.
- Sequence activities based on estimates of the resources needed for each activity and their duration.
- Construct a project schedule using computer software.
- Create a plan to manage a project schedule.
- Apply appropriate tools and techniques to manage a project schedule.

## Course Specific Requirements
Note: This is an Asynchronous Learning Course and there are no scheduled live interactive sessions. Asynchronous learning means that students learn independently at their own pace at different times from different locations. The instructor provides students with a sequence of date-released modules which students move through as their schedules permit throughout the week. Course material will align with the in-class version of OPMT 2500 to maintain consistency. Assignments are completed individually.

In order to get the most from this course, learners will be required to engage in all activities, discussions and assignment completion. Remember that active participation in discussions is weighted into the overall grade. Actively immerse yourself, both in the module content, but also the optional resources, as you work through your assignments. This will help you prepare for the mid term and final exams.

Content in subsequent modules builds upon the knowledge and skills gained in previous modules; therefore, learners should complete them in sequence. The course schedule will provide learners with an overview to keep them on track and allow for preparation for upcoming modules. Each module will outline the topic covered, optional readings, and assignments where applicable. In addition, links to external websites will be suggested that will expand on the knowledge area.

There will be opportunities to “Test your Understanding” by interactively making your way through module content. Read the question, and click on the icon to check if your answer matches the required response.

## Course topics
After successfully completing the course, the student will be able to:

1. Describe the necessity of scope definition and management

2. Apply methodologies and tools to identify and evaluate stakeholder needs

3. Define and document Project Scope based on stakeholders needs

4. Describe and develop the elements of Project Scope Statement

5. Develop a plan to receive, evaluate and implement possible changes to the Project Scope

6. Define project activities and create project WBS (Work Breakdown Structure)

7. Apply methodologies and tools to sequence activities and estimate activity duration

8. Develop and control project schedule and create a plan to manage it during the project

9. Use MS-Project to construct the project schedule and explain available reports

10. Develop a plan to control and manage project schedule
