## Course Description
In this advanced course students will select intricate image elements, such as hair, eliminate background colours around selection edges, and automatically vary selection edges to create perfect masks using Photoshop’s different refinement tools. Students will learn advanced non-destructive raster procedures and techniques such as Smart Objects. Projects will engage the understanding of advanced compositing skills, color correction, asset creation, file management and graphic design.

## Course Learning Outcomes/Competencies
Upon successful completion of the course, the student will be able to:

- Apply a non-destructive raster workflow.
- Use color editing tools to make non-destructive tonal/value and color adjustments.
- Interpret histograms for photo colour editing.
- Use selection and masking tools.
- Select intricate image elements, such as hair, eliminate background colours around selection edges, and automatically vary selection edges to create perfect masks.
- Apply a non-destructive application of filters and effects.
- Use tools to retouch a photo non-destructively.
- Apply blending modes and opacity, in a creative and functional capacity.
- Process Raw images, JPEGs, TIFFs, or PNG images with Camera Raw.
- Use creative brush work to generate content.
- Use creative raster techniques for design generation.
- Perform asset exporting for various applications.
- Differentiate between pixel dimensions and file resolution when applying to digital and print mediums.
- Place vector content into a raster document.
