## Course Description
The first step in using computer aided design (CAD) software requires a solid foundation of the user interface, commands and features of the CAD software. This intensive, hands-on course prepares the student with the knowledge and skills necessary for creating a basic 2D working drawing using AutoCAD. Topics include CAD concepts, file management, the viewing, drawing, and editing of drawings as well the placement of text and dimensions onto a drawing layout in preparation for plotting. The expectation is that students are proficient in the use of a computer including file and folder management. Students should also be familiar with the fundamentals of technical drawing.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Use the AutoCAD interface to access commands and files.
- Discuss the importance of file management when using CAD software.
- Access the on-line help system and user documentation.
- Setup drawings and establish initial drawing settings.
- Change the drawing display using View commands.
- Use layers effectively to manage object properties.
- Establish CAD standards.
- Create a new drawing using a template file.
- Create 2D drawings using the Draw commands.
- Edit drawings with the Modify commands.
- Use effective CAD construction techniques to ensure data accuracy and integrity.
- Use Inquiry tools to verify accuracy of CAD constructions.
- Define text styles and create text to accepted standards.
- Layout a single viewport drawing using a standard scale.
- Place basic dimensions using annotative scale.
- Insert blocks to place complex objects as a single entity.
- Place hatch patterns.
- Print or plot a 2D drawing.

## Course topics
Getting Started

- AutoCAD User Interface
- On-line help and user documentation
- Command entry; Dynamic Input
- Cartesian workspace
- Opening and saving drawing files; File Management
- View commands: Pan and Zoom

Basic Drawing and Editing

- Line, Circle, Rectangle commands
- Using Polar Tracking
- Erasing objects; Undo and Redo actions

Other Fundamental Objects

- Arc command
- Drawing Polylines
- Polygon command
- Ellipse command*

Drawing with Precision

- Running Object Snaps
- Object Snap Overrides
- Polar Tracking at Angles
- Using Snap and Grid
- Coordinate Entry

Editing Objects

- Object selection fundamentals
- Copy and Move commands
- Rotate command
- Scale command
- Mirror command
- Trim and Extend commands
- Stretch command
- Fillet and Chamfer commands
- Offset command
- Creating Rectangular and Polar arrays
- Polyline editing
- Grip editing fundamentals

Using Layers

- Creating drawings from templates
- Layer concepts
- Using layers to organize a drawing

Object Properties

- Properties command
- List command
- Measure tools

Complex Objects

- Block concepts
- Insert command

Drawing Layout

- Model Space / Paper Space concepts
- Layout creation

Text and Annotations

- Annotative text concepts
- Text styles
- Multiline text
- Notes with leaders

Hatching

- Place and edit hatches

Dimensioning

- Dimensioning concepts
- Dimension styles
- Placing linear, radial and angular dimensions
- Modifying dimensions

Printing / Plotting

- Page setup
- Print preview
- Print a layout
