## Course Description
​This course introduces students to Windows Servers and includes configuration and management of components relating to Installation, Storage systems, Networking including DHCP and DNS, HyperV, Domain Controllers, Active Directory, Permissions, Securing Servers, and other items supporting a large enterprise environment. ​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Install and configure servers and domain controllers.
- Configure Windows server licensing and activation.
- Manage Windows servers remotely.
- Configure Windows clients to securely connect to Windows servers.
- Configure hard drives and storage.
- Configure SMB shares in Windows server.
- Configure basic and advanced NTFS and share permissions.
- Install and configure HyperV.
- Configure and manage HyperV Storage and networking.
- Install and configure images (guests) using HyperV.
- Install and configure DHCP, DNS, and implement an IP Addressing strategy.
- Configure Virtual Private Networking and Remote Access.
- Install and configure forests, domains, and child domains.
- Create, manage, and maintain Active Directory.
- Create and manage Active Directory users, computers, groups, organizational units (OUs), and many other Active Directory objects.
- Configure global catalog servers and operations masters.
- Configure service authentication and account policies.
- Create and configure password policies, account lockout policies, and Kerberos authentication policies.
- Create and configure various trust relationships in enterprise environments.
- Monitor, manage and recover Widows Servers and AD DS.
- Configure and manage Active Directory in a complex enterprise environment using Active Directory sites and services.
- Configure and manage Active Directory replication.
- Use PowerShell to install, configure, and manage many of the components learned in this course.​

## Course Schedule and Assignments
Session1: Introduction to Windows Server & Virtualization

- Introduction to Windows Server.
- HyperV.
- Lab-Create and configure virtual machines in HyperV.

Session2: Network Addressing and DHCP

- Network Addressing (IPv4 and IPv6).
- Implementing and Managing DHCP.
- Lab-IP Addressing and DHCP Configuration.

Session3: Storage and File Management

- Configuring Drives and Storage for Windows Server.
- Configuring File Permissions, Sharing and Auditing.
- Lab-Disk Management and File Server role.

Session4: Domain Name System (DNS)

- DNS Configuration
- Lab-Implementing and Managing DNS in Windows Server.

Session5: Routing and Remote Access

- Implementing Routing and Remote Access (RRAS) in Windows Server.
- Lab-Routing and Remote Access Configuration-NAT-VPN.

Session6: Active Directory Domain Services (ADDS) & Midterm Exam

- ADDS Introduction.
- Active Directory Objects (OU, Users, Groups, Computers).
- Lab-Active Directory Installation and Managing Organizational Units, Users, Groups, Computers.
- Midterm Exam (Covers lesson01 to lesson08).

Session7: Group Policy Implementation (Part 1)

- Implementing Group Policy - Part1.
- Lab-Account Policies, PSO, Security Policies, Managing User and Computer Settings with Group Policy.

Session8: Group Policy Implementation (Part 2)

- Implementing Group Policy - Part2.
- Lab-Group Policy Administrative Tools Central Store, Preferences Policies, BitLocker Policies.

Session9: Active Directory Operations Master Roles and Global Catalog

- Operations Master Roles and Global Catalog.
- Lab-Additional DC Installation, Managing Operations Master Roles in Active Directory.

Session10: Advanced Active Directory Infrastructure Management

- Advanced Active Directory Infrastructure Management.
- Active Directory Sites and Replication.
- Lab-Creating Sites, Subnets, Site Links, Read-Only Domain Controllers.

Session11: Skills Exam

- Practical Skills Assessment-Installing and configuring Active Directory, DNS, DHCP and Routing and Remote Access Services on Windows Server.

Session12 Final Exam & Open Lab

- Final Exam (Covers all lessons)
- Open Lab: Students have access to lab resources for final course review and hands-on practice.
