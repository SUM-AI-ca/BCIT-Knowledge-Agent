## Course Description
Revit for MEP (mechanical, electrical and plumbing) uses 3D parametric models for both design and construction documentation. This course introduces the basic HVAC, electrical and plumbing components of the software. Architectural models are linked. The expectation is that students have current training/experience with Computer Aided Design. Students should also have exposure to building systems.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Link architectural files.
- Create and modify views.
- Create spaces and zones.
- Analyze heating and cooling loads.
- Use the HVAC module to add HVAC systems.
- Add piping and plumbing components.
- Add electrical circuits and conduits.
- Create and annotate construction documents.

## Course Goals
This on-campus Computer-Aided Design (CAD) course at the British Columbia Institute of Technology (BCIT) introduces students to Building Information Modeling (BIM) with Autodesk Revit MEP. Students will gain hands-on skills in designing, analyzing, and documenting HVAC, plumbing, fire protection, and electrical systems, while learning to coordinate these systems within a complete building model. By combining technical Revit proficiency with essential building services concepts, this course prepares students to apply BIM workflows in real-world projects. Learning Revit MEP with BCIT will enhance your education and provide the in-demand skills needed to excel in your career in the architecture, engineering, and construction (AEC) industry.

## Course Schedule and Assignments
Course overview & objectives

Introduction to Building Information Modeling (BIM) and its integration with Revit MEP

Revit GUI Overview: Refresher on Revit’s graphical user interface—Ribbon, Project Browser, Properties Palette, navigation tools and MEP-specific object types

Revit Architecture Refresher: Review of basic architectural elements like walls, floors, and roofs to establish a solid foundation for MEP integration.

Start a New Project (Imperial/Metric): Set up an MEP project with correct units and parameters.

Spaces and Zones: Create Spaces for load analysis and organize them into Zones for HVAC systems.

Heating & Cooling Loads Analysis: Perform load calculations based on building geometry and space requirements, essential for HVAC sizing.

Draw Ducting: Use the HVAC panel in the Systems tab to design duct systems.

Place Air Handling Unit (AHU): Add AHUs for airflow management in the HVAC system.

Place Air Terminals: Add and configure air registers, diffusers, and grilles.

Place Ducting Accessories: Place dampers, filters, and detectors to complete the system.

Views: Work with 3D Views, Elevations, and Sections for comprehensive system analysis.

View Control: Adjust visibility and graphic display settings of elements in views using Visibility/Graphics (VG) and Detail Level.

​View Filters: Control visibility and selection in a view; use the View tab, Graphics panel, and select Filters. Create Rule-based and Selection filters to manage what is displayed.

Assignment 1 (to be submitted before Day 5)

Check Connections and Systems: Verify the connections and configurations of your HVAC systems.

Ducting Systems (Manual and Automatic): Create duct systems manually or let Revit generate the layout for you.

System Access Tools: Use the Project Browser, System Editor, and System Browser to manage systems.

Hover and Tab Method: Use the Hover and Tab keys to select specific elements in complex models.

Duct Sizing Tool: Use sizing tools to determine the correct size for ducts based on flow rates and pressure.

Generate Layout Tool (Base Option): Automatically generate duct layouts based on defined parameters.

System Inspector: Inspect the system’s integrity to ensure all components are configured properly.

Copy and paste to multiple levels

Tagging & Documentation: Tag components, duplicate views, create legends, and use color schemes for identification.

Piping and Plumbing Overview: General overview of plumbing and piping systems in fire suppression.

Piping Methodology: Techniques for designing piping systems for water-based fire suppression (e.g., sprinklers).

Fire Suppression Systems: Set up and configure fire suppression systems using the Plumbing and Piping panel.

Hosted and Non-hosted Component Types: Understand the difference between hosted and non-hosted components.

Types of Fire Suppression Systems: Review various systems like wet, dry, and pre-action systems.

Tagging & Documentation: Tag components, duplicate views, create legends, and use color schemes for identification.

Assignment 2 (to be submitted before Day 6)

Designing Water Supply Systems: Create the infrastructure for cold and hot water delivery in residential buildings.

Check Plumbing Settings: Set up parameters for water flow, pipe types, and material specifications.

Point of Connection (POC): Establish the connection between the plumbing system and external water supply.

Pipe Sizing Tool: Use sizing tools to determine the correct pipe size based on flow rates and pressure.

Generate Layout Tool (Base Option): Automatically generate pipe layouts based on defined parameters.

Tagging & Documentation: Tag components, duplicate views, create legends, and use color schemes for identification.

Assignment 3 (to be submitted before Day 8)

Set Up the Project: Enable MEP systems and define waste and vent plumbing types.

Design Waste Systems: Design drainage (sanitary and vent) systems for residential buildings.

Check Plumbing Settings: Ensure correct pipe sizing, flow rates, and materials.

Point of Connection (POC): Establish connection to the external waste or sewer system.

Pipe Sizing & Layout: Use sizing tools and auto-generate pipe layouts based on system parameters.

Apply Slope & Route Pipes: Apply slope to pipes for proper drainage and route them to the main stack.

Place Fixtures & Add Components: Place plumbing fixtures and necessary fittings like cleanouts.

Tagging & Documentation: Tag components, duplicate views, create legends, and use color schemes for identification.

Electrical Settings: Configure electrical parameters, including load calculations, circuiting methods, and distribution panels.

Lighting: Place and configure lighting fixtures in your model.

Editing Commands for Lighting: Modify properties like wattage, color, and intensity for lighting fixtures.

Place Light Switches: Use Electrical Panels to place switches and connect them to circuits.

Lighting Systems: Organize lighting components into systems for better management and scheduling.

Electrical Panels: Configure electrical panels and route circuits.

Wiring (Automatic and Manual): Automatically or manually route electrical wiring in the model.

Project Templates and Transfer Project Standards: Use project templates for consistency and transfer standards from other Revit files.

Linking Revit Files together: Link external Revit models (architecture, structure and MEP) into a central coordination file for coordination and clash detection.

View Templates: Save and apply consistent settings across multiple views.

Copy/Monitor Tool: Copy elements from linked models and monitor changes to stay updated.

Interference Tool: Detect and resolve conflicts between MEP components and other building elements (e.g., ducting clashing with pipes).

Introduction to the Interference Tool

Running Interference Checks

Analyzing and Resolving Clashes

Managing Interference Reports

Preventing Future Clashes in Linked Models

2D Drafting in Revit MEP; Exploring 2D drafting techniques for MEP systems to create accurate and detailed drawings.

Detailing Tools in Revit MEP; Using Revit's detailing tools, including custom components and system-specific details, for efficient drafting.

Creating and Managing Detailed Views; Step-by-step methods for creating, organizing, and managing 2D detail views of MEP systems.

Annotation Techniques; Adding dimensions, tags, labels, and text to MEP components for clear and informative detail views.

Organizing MEP Details for Documentation; Best practices for arranging 2D MEP details for easy integration onto sheets in the next session.

Customizing 2D MEP Details; Customizing line styles, weights, and enhancing 2D MEP details for clarity and consistency.

Finalizing MEP Detail Drawings; Reviewing and refining MEP details to ensure accuracy and completeness before the next session on sheet setup and printing.

Assignment 4 (to be submitted before Day 12)

Creating and Managing Schedules in Revit: Types of schedules (Schedule/Quantities, Material Takeoff, Sheet List, Note Block, View List); Creating and customizing schedules with fields, filters, sorting, and formatting.

Sheets and Printing Sheets: Place views onto sheets and set up print layouts for physical or PDF distribution.

Dry Run for Final Exam (Mini Project Simulation)

Rendering Process: Create realistic renderings by adjusting lighting, materials, and camera settings.

Editing Materials of Components: Modify materials for components to control their appearance in rendered views.

Other Presentation Tools: Use Camera Views and Walkthroughs to create engaging visual presentations of the project.
