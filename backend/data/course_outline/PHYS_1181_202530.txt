## Course Description
This is the first of a pair of one-term calculus-based physics courses designed to acquaint the student with fundamental concepts in physics relating to chemical and environmental technology. PHYS 1181 deals mostly with concepts in classical mechanics, such as linear and rotational kinematics and dynamics, energy and power, wave motion and fluid statics and dynamics. The laboratory component which accompanies the lectures is designed to illustrate specific scientific concepts as well as teach proper laboratory technique and methods of data acquisition and analysis.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Define basic terms relating to the concepts covered in the course.
- Correctly choose, manipulate and apply formulae to the solution of typical physics problems.
- Apply a logical problem-solving technique to arrive at correct solutions to single and double concept physics problems.
- Demonstrate correct measurement and data acquisition skills in a laboratory environment.
- Write a laboratory report in accordance with commonly accepted formats.

## Course topics
The topics of the course are intended to help the student develop the following skills:

- Units and Measurement Convert between units given conversion factors Describe and differentiate random/systematic uncertainties Calculate discrepancy and uncertainty, and propagate uncertainties through a calculation Draw a 1D comparison graph
- Convert between units given conversion factors
- Describe and differentiate random/systematic uncertainties
- Calculate discrepancy and uncertainty, and propagate uncertainties through a calculation
- Draw a 1D comparison graph
- Graphical and Equation Analysis Make a graph from a set of data Read graphs to determine value, slope, and area Use a model fit to a set of data and assess appropriateness of a particular fit Manipulate equations to solve for a desired parameter / relationship
- Make a graph from a set of data
- Read graphs to determine value, slope, and area
- Use a model fit to a set of data and assess appropriateness of a particular fit
- Manipulate equations to solve for a desired parameter / relationship
- Vectors Decompose a vector, or convert x-y components into length and direction Add vectors graphically and algebraically Calculate the dot product of two vectors Give the cross product of two vectors lying in the x-y plane, including using the right hand rule
- Decompose a vector, or convert x-y components into length and direction
- Add vectors graphically and algebraically
- Calculate the dot product of two vectors
- Give the cross product of two vectors lying in the x-y plane, including using the right hand rule
- Kinematics Given one of {x, v, a} vs. t plots, estimate the other two Given an x(t) function, differentiate to find v(t) and a(t) functions Solve for x, v, a, or t using kinematics equations in a 1D problem Solve a projectile motion problem
- Given one of {x, v, a} vs. t plots, estimate the other two
- Given an x(t) function, differentiate to find v(t) and a(t) functions
- Solve for x, v, a, or t using kinematics equations in a 1D problem
- Solve a projectile motion problem
- Forces and Dynamics Draw a free body diagram for an object or group of objects Use Newton’s 2nd Law to find net force or acceleration in a problem Characterize force types and calculate values for specific force types, including gravity and frction Distinguish Newton’s 3rd Law force pairs Calculate parameters for an object undergoing uniform circular motion Define sources of centripetal and centrifugal force
- Draw a free body diagram for an object or group of objects
- Use Newton’s 2nd Law to find net force or acceleration in a problem
- Characterize force types and calculate values for specific force types, including gravity and frction
- Distinguish Newton’s 3rd Law force pairs
- Calculate parameters for an object undergoing uniform circular motion
- Define sources of centripetal and centrifugal force
- Statics Define equilibrium, and use equilibrium conditions to solve statics problem Describe and define stress and strain, and distinguish different types Calculate the stress and strain due to a force on an object Calculate the modulus of an object under stress
- Define equilibrium, and use equilibrium conditions to solve statics problem
- Describe and define stress and strain, and distinguish different types
- Calculate the stress and strain due to a force on an object
- Calculate the modulus of an object under stress
- Work, Energy, Power Calculate work done by a force on an object Explain dissipation, and describe where energy conservation does/doesn’t apply Characterize energy types and calculate values for specific energy types Explain system choice and convert between two systems for studying same problem Explain connection between energy and power and calculate power for a process
- Calculate work done by a force on an object
- Explain dissipation, and describe where energy conservation does/doesn’t apply
- Characterize energy types and calculate values for specific energy types
- Explain system choice and convert between two systems for studying same problem
- Explain connection between energy and power and calculate power for a process
- Momentum Define and calculate linear momentum, and explain when momentum conservation applies Classify and describe collision types Solve 1D collision problems using momentum conservation Solve 2D collision problems using momentum conservation and additional info
- Define and calculate linear momentum, and explain when momentum conservation applies
- Classify and describe collision types
- Solve 1D collision problems using momentum conservation
- Solve 2D collision problems using momentum conservation and additional info
- Rotation Explain the meaning of torque and calculate its value by a force about an axis Draw an extended free body diagram Define and use angular kinematics variables Explain connection between torque and rotation and use rotational analogue of 2nd Law Describe moment of inertia (MoI) and calculate rotation parameters using MoI values Define angular momentum, and calculate angular momentum given motion description Use conservation of angular momentum to solve rotational motion problems Describe rolling motion
- Explain the meaning of torque and calculate its value by a force about an axis
- Draw an extended free body diagram
- Define and use angular kinematics variables
- Explain connection between torque and rotation and use rotational analogue of 2nd Law
- Describe moment of inertia (MoI) and calculate rotation parameters using MoI values
- Define angular momentum, and calculate angular momentum given motion description
- Use conservation of angular momentum to solve rotational motion problems
- Describe rolling motion
