## Course Description
This course covers relational database technology, including basic concepts, relational algebra, enhanced entity-relationship data modeling, functional dependencies and normalization, design methodology, SQL query language (DDL and DML), views, access control and transaction management. Students design and implement a database application using RDBMS. Also covers some current database trends such as data warehousing and OLAP and use of databases through web technology.

## Course Learning Outcomes/Competencies
At the end of this course, the student will be able to:

- Describe the functions and characteristics of the relational database model.
- Apply techniques of database design including:
- Enhanced entity-relationship modeling.
- Functional dependencies and normalization.
- Derivation of relations schema from EER models.
- Apply database design process to design and implement a database application.
- Use SQL to implement and query a relational database including:
- Data definition language (DDL) and constraints.
- Data manipulation language (DML) for data insert, update and delete.
- Data manipulation language (DML) for data queries, including subqueries and views.
- Data control language (DCL) for access control.
- Discuss techniques for transaction management and concurrency control.
- Describe the use of databases in data warehousing and OLAP.

## Evaluation Criteria
Evaluation Method: Weight (%): Comments
Midterm Exam: 20%: Focused on relational concepts, EER modeling, normalization, and introductory SQL.
Final Exam: 25%: Applied exam covering advanced SQL (queries, subqueries, views, DCL), transaction management, and data warehousing/OLAP.
Database Design Project: 30%: Major applied project: full design and implementation of a database application, including ER modeling, relational schema derivation, normalization, implementation in an RDBMS, and demonstration of SQL queries.
Labs & SQL Assignments: 20%: 10 Hands-on labs and SQL coding assignments, graded for correctness and completion. (Subject to Change)
Participation & In-class Activities: 5%: Peer reviews, problem-solving sessions, and active contribution in class.

- A minimum of 50% in the combined exams + project is required to pass the course.
- All submitted work must adhere to BCIT’s academic integrity policies.

The grading in this course is meant to give you a fair balance between theory and practice. Exams check that you’ve mastered the key ideas about databases, while labs and assignments give you practice writing SQL and solving problems step by step. The project is where you put it all together, showing that you can design and build a working database. Participation is also rewarded because learning happens best when we share ideas and solve problems together.

## Course Schedule and Assignments
Instructional Week: Topic: Notes
1 – Sep 1: Introduction to Relational Databases: functions, characteristics, and relational model basics: No labs on the first week of classes
2 – Sep 8: Enhanced Entity–Relationship (EER) Modeling: entities, attributes, relationships, diagrams
3 – Sep 15: From EER to Relational Schema: mapping EER models into relational schemas
4 – Sep 22: Functional Dependencies & Normalization: 1NF to BCNF, ensuring consistency and integrity
5 – Sep 29: SQL – Data Definition Language (DDL): creating tables, keys, and constraints
6 – Oct 6: SQL – Data Manipulation Language (DML): insert, update, delete
7 – Oct 13: SQL – Queries and Views: SELECT, subqueries, joins, and views
Oct 20: Midterm Exam Week – Non-Instructional Week
8 – Oct 27: SQL – Access Control (DCL): GRANT, REVOKE, roles; Integrating SQL topics into project work
9 – Nov 3: Database Design Process & Implementation: case study and database project development
10 – Nov 10: Transaction Management & Concurrency Control: ACID properties, locks, schedules
11 – Nov 17: Databases in Analytics: Data Warehousing and OLAP concepts
12 – Nov 24: Current Trends & Project Integration: databases and web technology, wrap-up discussions
Dec 1: Study / Makeup / Review / Project Presentations (per CSTDiplomaWeek14Guidelines)
Dec 8: Final Exam Week – Non-Instructional Week
