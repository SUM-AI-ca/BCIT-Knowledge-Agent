## Course Description
This course introduces the mechanisms and protocols of electronic prepress production through the workflow application ‘Prinergy.’ It focuses on the requirements for setting work up in Prinergy and exposes the student to the refine and trapping functions that produce single page PDFs. Fundamentals of imposed form work for printing production is also covered through industry standard application Kodak Preps and the connection to Prinergy. Raster Image Processor (RIP) technologies will be contrasted and compared. Other pre-imaging page production systems will be reviewed and analyzed for their strengths and weaknesses. Students will have an opportunity to process a project from input through to plate ready status with close alignment to Kodak’s hands-on training program.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Articulate the primary components and functional modules of the Prinergy application in the context of the modern electronic prepress workflow.
- Create a job and the requisite supporting file organization structure in the Prinergy workflow.
- Construct a master process template job for recurring parameters.
- Differentiate between acceptable and unacceptable file formats for input to Prinergy.
- Effectively navigate the online help system that is built into the application.
- Transform files with the refine function into PDF format required for all subsequent actions in Prinergy.
- Adjust trapping settings in Prinergy for various output intents.
- Process a job from input to single page output.
- Describe differences in Raster Image Processor technologies.
- Create jobs in the application Preps to provide imposition instructions to Prinergy.
- Import the Preps job and its associated marks PDF into the appropriate location in Prinergy.
- Manipulate page sets for correct linking to imposition plans.
- Describe options for a colour managed PDF workflow.
- Process a multi-page project from input through to the output of correctly imposed forms
- Describe the strengths and weaknesses of other prepress workflows in the marketplace.​

## Course Goals
Upon successful completion, the student will be able to:

- Select the most appropriate imaging process (digital, sheet-fed, web, silk or flexo) based on the print project requirements (quantity, substrate, usage, and cost).
- Create press-ready PDF files that meet the technical requirements of different print processes.
- Communicate specifications, processes, and intent using standard prepress vocabulary.
- Prepare files that accommodate binding options: creep, drop down, gutters, etc.
- Describe the different colour modes, and their limitations to a client.
- Set up a colour management system on a work station.
- Maximize accuracy and colour gamut when converting RGB images to CMYK.
- Prepare files that accommodate special finishes: metallic and spot inks, varnishes, etc.
- Evaluate the success of trapping in printed products.
- Create digital die lines.
- Create digital codes (UPC, QRC)
- Identify different substrate and ink requirements and limitations: white plates, maximum ink coverage, rich black, etc.
- Create printer marks within a file that indicate folds, foldouts, pockets, trim, bleeds, etc.
- Select the appropriate proofing method for the various stages in a print project.
- Describe what and how to evaluate at a press check.
