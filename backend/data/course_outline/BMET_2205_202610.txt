### Course Description
This course provides an introduction to the fundamentals of data communication and networking. The Open System Interconnect (OSI) model is used to discuss network architectures, protocols, topologies, networking hardware and software. Topics include network media, access control, Transmission Control Protocol/Internet Protocol (TCP/IP), switching and routing, Ethernet Standards, IP addressing, wireless LAN Standards, and network security. Analog and digital data communications, transmission methods, coding schemes are also discussed. During the laboratory sessions, local area networks will be designed, built and managed to enhance understanding of the theoretical concepts, and to gain hands-on and troubleshooting experience with computer networks.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Describe physical, logical and virtual network topologies and their components.
- Describe the functions of network appliances such as, network interface cards, switches, bridges, routers, firewalls and gateways.
- Configure manageable switches, routers and access points.
- Describe the characteristics of conductive media, fiber-optic cables and wireless transmission media including their connectors.
- Perform a wiring task, such as, using the appropriate tools to build and test the network connections.
- Explain basic concepts in data communication including coding schemes, transmission methods, digital signal encoding, error detection methods, signal modulation and multiplexing.
- Characterize and differentiate data communication standards.
- Build, configure and test wired and wireless peer to peer and client-server networks.
- Discuss the OSI model in terms of its layers and their functions, and compare with TCP/IP Model.
- Describe the role of IP addresses, Ports and MAC addresses.
- Specify the main features of the IEEE802 standard including both Ethernet and Wireless.
- Describe the Ethernet and wireless applications (includes Bluetooth), access methods and frame format.
- Use network statistics, diagnostic utilities and tools to monitor network performance and trouble shoot network problems.
- Identify network security risks and discuss methods of mitigation.
- Identify the cause for a given simple network troubleshooting scenario involving hardware or software.

Laboratory works or assessments (such as lab exams, mid-term exam, or final exam) must be completed within the scheduled period, otherwise zero mark will be assigned.
