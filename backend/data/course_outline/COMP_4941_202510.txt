## Course Description
This course is an extension to COMP 3940 and provides in-depth knowledge of the principles and practice of client/server & distributed systems design. The focus is on examining strategies and algorithms to achieve design goals such as performance, reliability, scalability, consistency, and security in a distributed system. Some of the topics that will be covered include: Concurrency Control, Recovery and Performance considerations in multi-user and distributed data servers; Replication, Security and Fault Tolerance in distributed systems & the design and development of client/server based database applications.

## Course Learning Outcomes/Competencies
At the end of this course, the student will be able to:

- Identify and review key requirements of client/server and distributed systems.
- Examine strategies and algorithms to achieve design goals such as performance, reliability,scalability, consistency, and security in a distributed system.
- Evaluate various algorithms and protocols associated with transaction management, con-currency control and recovery.
- Evaluate existing client/server based systems such as relational database management systems (RDBMS) to assess how user requirements are being met.
- Develop client/server based and distributed database applications using these too.
