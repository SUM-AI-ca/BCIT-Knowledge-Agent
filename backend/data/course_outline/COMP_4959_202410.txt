## Course Description
In this course, students will apply functional and concurrent programming techniques to develop selected applications. Applications may include implementing a compiler or interpreter for a DSL (domain-specific language), implementing Web applications using a functional language, designing scalable and fault-tolerant network applications and system programming using a safe language.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Apply functional programming techniques to real-world applications.
- Apply concurrent programming techniques to real-word applications.
- Design and develop an application in a project team.
- Plan and manage a project using an iterative and incremental approach.
- Create and maintain a development environment.
