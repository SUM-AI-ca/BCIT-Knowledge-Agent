## Course Description
This course provides an introduction to organizing and formatting information with spreadsheet software including the use of macros.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Apply (iii) basic Excel functionality to: [1, 5]
- write formulas,
- draw charts,
- use functions, and
- apply formatting.
- Make (ii) Excel macros by using macro recorder, and by coding using Visual Basic for Application (VBA). [1, 5]

## Learning Resources
Required: Required learning resources, such as course notes and lab computers, and are provided. There is no required textbook.

Recommended: Students should bring a tablet (e.g iPad) or laptop pc to lab sessions. This will allow the use of the lab computers solely for spreadsheet work.

Supplementary: A growing list of supplementary learning resources is provided with the course documents.

## Course Goals
This course provides an introduction to spreadsheets that places an emphasis on using Excel in engineering laboratories. Beyond basic spreadsheet functionality, students will be introduced to features including complex number functions, user-defined functions, advanced graphing and VBA scripting.
