## Course Description
This hands-on course is designed for those who are already familiar with an Object Oriented programming language such as Java or C++. Students are introduced to web application development using C# and the Microsoft ASP.NET Framework. The course provides an overview of the Microsoft .NET framework as well as an introduction to the C# programming language. Topics include: ASP.NET Server controls, Data Binding, LINQ, Entity Framework, Code First development, Web API, Odata, ASP.NET MVC, SignalR, ASP.NET State management, Data Validation, and Single Page Applications.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Develop web applications with Visual Studio.
- Describe the Microsoft .NET Framework as it applies to a web application.
- Define the architecture of a .NET Web application.
- Use basic C# syntax including data types, operators, control structures, looping structures, inheritance, defining classes, collections, and namespaces.
- Create dynamic web pages using ASP.NET Web Forms and ASP.NET MVC.
- Produce and consume RESTful Services with C# and ASP.NET.
- Use the web controls and the event handling process from the .NET framework.
- Design and develop User Interfaces using ASP.NET Web Forms themes and navigation controls.
- Design and develop an ASP.NET application that interfaces with SQL Server database using Entity Framework and LINQ.
- Develop web applications that incorporate ASP.NET Security and OpenAuth authentication mechanisms.
- Test, debug and handle errors and exceptions in an ASP.NET Web application.
- Deploy an ASP.NET Web applications into IIS web server and the cloud.
