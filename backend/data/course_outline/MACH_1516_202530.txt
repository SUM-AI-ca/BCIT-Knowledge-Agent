## Course Description
In this course, students will learn to use rotary tables and indexing devices to perform milling machine operations. They will learn to set up accessories for the milling machine to cut radii, hexagonal and pentagonal shapes according to specifications.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Set up rotary tables and indexing devices in preparation for cutting operations.
- Utilize rotary tables to cut radii in given shapes.
- Utilize indexing devices to cut hexagonal and pentagonal shapes according to given specifications.
- Perform calculations to operate indexing devices.
