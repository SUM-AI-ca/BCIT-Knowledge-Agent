## Course Description
​This course develops an understanding of the fundamental underpinnings of client-server interaction within the context of Web Applications. Topics covered include using modern javascript, building asynchronous non-blocking web servers, working with databases to persist data, creating RESTful Web Services, and application deployment.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe client-server interaction as it applies to a web application.
- Develop server-side web applications.
- Use modern techniques for handling asynchronous IO in a web application.
- Deploy web applications.
- Access a database from a web site.
- Load and manipulate JSON documents.
- Create dynamic web pages.
- Develop web services.

## Course Schedule and Assignments
Week: Date: Topics
Week 01: Jan 06: Node.js setup, Understanding Runtime Environments, Javascript Review. Quiz 1 Assigned.
Week 02: Jan 13: Using third party libraries, continuing with JS Review. Lab 1 Assigned.
Week 03: Jan 20: Node.js Modules, creating your own libraries. Quiz 2 Lab 2 Assigned
Week 04: Jan 27: Node.js user input, working with Asynchronous and Synchronous Code, understanding Asynchronous IO handling. Quiz 2 Lab 2 Assigned.
Week 05: Feb 03: Common pitfalls when dealing with asynchronous code. Utilizing promises and async await to simplify async control flow. Quiz 3 Lab 3 Assigned
Week 06: Feb 10: Networking and HTTP overview. Building custom HTTP servers. Using third-party packages to ease Web Server management. Quiz 4 Lab 4 Assigned
Week 07: Feb 17: Midterm Exam Review Class.
Week 08: Feb 24: Midterm Week.
Week 09: Mar 03: Sessions, Cookies, and Authentication over the Web. Creating secure authentication systems through Node.js. Quiz 5 Lab 5 Assigned
Week 10: Mar 10: Implementing fine-grained access to resources through Roles/Claims based authorization in Node.js. Quiz 6 Lab 6 Assigned
Week 11: Mar 17: Introduction to enterprise-grade web application development through Typescript. Quiz 7 Lab 7 Assigned. Term Project Begins.
Week 12: Mar 24: Exploring E2E type-safety options from Database to the Application Layer. Term Project Cont'd.
Week 13: Mar 31: Different approaches for deploying Web Applications. CDNs, Cacheing (Client-Side/Server-Side). Term Project Wrap Up.
Week 14: Apr 07: (reserved for Makeup, Reviews, or Presentations)
Week 15: Apr 11- Apr 17: Final
