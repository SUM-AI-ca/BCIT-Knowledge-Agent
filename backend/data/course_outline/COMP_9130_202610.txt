### Course Description
​This course introduces student to concepts, topics, issues, and methodologies related to Artificial Intelligence. Students will develop the skills required to evaluate, design, develop and improve Artificial Intelligence (AI) algorithms through hands-on projects and problem solving. Participants are expected to develop a portfolio of Al projects during this course.​
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Explain representations, algorithms, and techniques used in artificial intelligence.
- Apply/evaluate and design new AI techniques for a given computing problem.
- Articulate the basic processes that a machine learning agent must perform – from perceiving its environment to making decisions on how to act and perform those actions.
- Apply machine learning techniques, in particular to draw inferences from data and help automate the development of AI systems and components.
- Design, implement and test the AI-based software.
- Work productively as a member of a team in an applied computing setting.

### Course Goals
This course aims to provide students with comprehensive, hands-on experience in modern artificial intelligence techniques and their practical applications. Through a combination of weekly class preparation materials and intensive classroom activities, students will progress from foundational machine learning concepts through advanced deep learning applications.
The course emphasizes computer vision as a primary application domain, with substantial coverage of convolutional neural networks, transfer learning, object detection, and semantic segmentation. Students will gain experience with state-of-the-art AI frameworks and tools, learning to select appropriate techniques for specific problems, implement solutions effectively, and evaluate results rigorously.
Working consistently in pairs, students will develop collaborative skills essential for professional AI development while building a comprehensive portfolio demonstrating mastery across multiple AI domains. The capstone project provides an opportunity to integrate learned techniques in addressing a substantial real-world problem, preparing students for AI leadership roles in industry or further academic research.

### Attendance Requirements
In addition to BCIT's Student Regulations Policy 5101 – Attendance Policy, the following course-specific requirements apply:
- Classroom Activities (Weeks 2-11): Attendance is mandatory. Each week includes three graded tasks that must be completed during the 3-hour session. Students who miss a class forfeit the opportunity to earn those participation points unless prior arrangements are made with the instructor for documented medical or emergency reasons.
- Quiz Administration (Weeks 2-11): Weekly quizzes are administered at the beginning of each class session. Students arriving more than 15 minutes late will not be permitted to write the quiz. Make-up quizzes are not available except in cases of documented medical emergencies or other exceptional circumstances approved by the instructor.
- Pair Programming: Since all projects are completed in pairs, students are expected to coordinate with their partners and maintain consistent collaboration. If one partner is absent, the other should still attend and continue working on the project, documenting the work independently.
- Final Project Presentations (Week 15): Attendance is mandatory for all final project presentations. All team members must be present to deliver their presentation. Absence from the presentation session will result in a grade of zero for the presentation component unless the instructor approves it in advance.
- Communication: Students unable to attend class must notify the instructor as early as possible via email and provide appropriate documentation for absences exceeding one class session.
### Course Specific Requirements
- Mini projects (Weeks 2-11) are completed in pairs that are randomly assigned at the beginning of each class
- New pairs are formed weekly to ensure students work with diverse partners
- Both partners are expected to contribute equally during the 3-hour session
- Each project README must include a section documenting individual contributions
- Students should be prepared to work effectively with any classmate
- In cases of team conflict during a session, students should contact the instructor immediately
- Final capstone project (Weeks 12-15) is completed in groups of 3-4 students
- Groups will be student-selected or instructor-assigned)
- Groups remain consistent throughout the final project period
- All group members are expected to contribute equally
- Final project documentation must include a detailed breakdown of individual contributions
- Group contracts and peer evaluations may be required
- All projects must be submitted via GitHub with public repositories
- Repositories must include proper .gitignore, README.md, and requirements.txt files
- For mini projects: Both partners' names must be in the README with contribution details
- For the final project: Commit history should demonstrate contributions from all group members
- Code must be well-commented and follow Python style guidelines (PEP 8)
- All coding activities will utilize Google Colab for consistency and accessibility
- Students are responsible for saving their work and managing Colab sessions
- Projects should include instructions for running code in the Colab environment
- All project reports must be submitted through the Learning Hub by the specified deadline
- Reports must be in PDF format
- Mini projects file naming: COMP9130_ProjectX_LastName1_LastName2.pdf
- Final project file naming: COMP9130_Final_GroupName.pdf
- Late submissions are subject to a 10% penalty per day unless prior arrangement is made
- Students are expected to write their own code and understand all implementations
- While AI assistants (ChatGPT, GitHub Copilot, etc.) may be used for learning, students must be able to explain every line of code they submit
- Direct copying of code from online sources without understanding and attribution is considered academic dishonesty
- All external code sources must be properly cited in comments and documentation
- Reliable internet connection for accessing Google Colab and participating in class
- A personal computer capable of running modern web browsers
- Webcam and microphone for potential remote presentations
- No local GPU required (Colab provides free GPU access/possible access to Pro tier via BCIT resources)
- Primary communication via BCIT email and Learning Hub announcements
- Response time: Instructor will respond to emails within 24-48 hours (weekdays)
