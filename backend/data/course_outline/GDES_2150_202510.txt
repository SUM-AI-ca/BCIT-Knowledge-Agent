## Course Description
Empathizing with users, defining pain points, and designing wireframes to plan products are integral parts in the foundation of UI and UX. This course introduces students to research, interface design, and user experience, which are fundamental fields required to create compelling human-centric designs in physical and digital mediums including packaging, desktop and mobile. This course will provide students with the knowledge required to research, plan, and deploy effective prototypes. In addition, students will learn how UX agency projects differ from consultancy projects in terms of complexity and expectations.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Examine UX and UI history.
- Distinguish between user experience and user interface design.
- Identify various methods of user research.
- Demonstrate user interface usability heuristics.
- Explain usability, accessibility, and layout design as fundamental areas of study of UX design.
- Summarize psychological principles that help understand human interactions with technology.
- Create personas to support the user experience research process.
- Design user stories, user story mapping and user flows.
- Develop user journey maps to visualize task processes.
- Construct wireframes by hand and online tools.
- Assemble low-fidelity prototypes to map the functioning of interactive systems.
- Prepare and perform usability evaluations.
- Recognize the expectations, scope, and complexity of small and large UX projects.
- Differentiate agency projects from client-side projects.​
