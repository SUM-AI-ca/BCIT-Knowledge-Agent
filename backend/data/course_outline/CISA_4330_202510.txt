## Course Description
This course covers Microsoft Windows System Center products: Operations Manager, Service Manager, and Configuration Manager. Microsoft SharePoint and advanced Microsoft Azure Cloud Administration topics will also be covered.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the capabilities of each of the Microsoft System Center suite of products
- Install and configure the Microsoft System Center suite of products
- Describe the capabilities of Microsoft SharePoint services as a collaboration platform
- Install SharePoint on the Microsoft Server platform
- Explain how to use SharePoint Lists and Libraries, Users and Permissions, and user profiles
- Configure SharePoint user profiles and policies
- Manage documents within a SharePoint environment
- Create and manage SharePoint content types, term stores, and term sets
- Configure SharePoint Search and its parameters
- Monitor, optimize, and maintain a SharePoint environment
- Design and implement cloud governance strategies for resource organization, security and compliance.
- Select and deploy compute services based on workload requirements and cost considerations.
- Design and configure networks for cloud and hybrid environments.
- Design data storage solutions.
- Plan and execute workload migrations using Azure Migrate.
