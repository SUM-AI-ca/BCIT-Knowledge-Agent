## Course Description
​This course continues from the CISA 1330 course and introduces students to Group Policies and Certificate Services running on Windows Servers (on-premises). The course then moves to cloud services and introduces students to Azure fundamentals and administration. Fundamental topics include an introduction to cloud services, Azure core services, networking with Azure, security, compliance, privacy and trust, pricing, service levels, lifecycle, and managing Azure resources. Azure administration topics include Azure Active Directory, virtual networking, intersite connectivity, network traffic management, storage, automation, deployment and configuration of resources, PaaS compute options, data protection, and monitoring resources. ​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Install, configure, and manage Group Policies on Windows Servers
- Install, configure, and manage Certificate Services on Windows Servers
- Understand cloud services
- Configure and manage Azure:
- Core services
- Networking services
- Security, compliance, privacy, and trusts
- Pricing, service levels, and lifecycle
- Resources
- Active Directory services
- Virtual networking
- Intersite connectivity
- Network traffic management
- Storage and automation
- Deployment and resources
- PaaS compute options
- Data protection
- Monitoring resources ​
