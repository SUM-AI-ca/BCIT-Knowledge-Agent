### Course Description
The course presents an introduction to the functions and use of AutoCAD and AutoCAD 3D Civil for solving different mining problems. Mining design software for engineering, surveying, and reclamation will be introduced. AutoCAD serves as a graphic engine and drawing editor. Mine design software that can be considered as an extension of AutoCAD will be used to add commands and enhancements for earthmoving and engineering.
### Course Learning Outcomes/Competencies
Upon successful completion of the course, the student will be able to:
- Determine the pros and cons of choosing and using the software based on the nature of the problem to be solved [2,5].
- Identify file types [5].
- Determine proper inputs from field data [3].
- Define drawings and setup options [5].
- Manage drawing layers [5].
- Experiment with 3D landform viewing and contouring [5].
- Produce cross sections, profiles and cut and fill volume calculation [1,5].
- Create simple layout plans for both surfaces mine and underground mine [1,5].
- Create 3D projection drawings [1, 5]
- Undertake navigation in the field. [1, 5]
