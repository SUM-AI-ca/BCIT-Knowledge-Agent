## Course Description
After a review of Ethernet, IP communications and the TCP/IP stack, students will be introduced to several ICS protocols that run over Ethernet and TCP/IP. Students will use tools like Wireshark to examine the details of how ICS protocols differ from regular IT protocols. Various attacks on ICS systems will be presented.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Identify the difference between Industrial Ethernet and IP Ethernet
- Identify the difference between Industrial Protocol and Internet Protocol
- Discuss possible network attacks on Industrial Networks
- Perform an attack on an industrial network​

## Course Schedule and Assignments
Introduction & Safety Briefing - Overview of PLC/HMI lab objectives - Safety procedures for electrical components

Part 1: Power Cable Construction - Create and connect a power cable to a Click PLC - Instructor inspection of wiring

Part 2: Software Installation - Install Automation Direct software from V: Drive - Connect to PLC using USB rollover cable

Part 3: First PLC Program - Understand STOP/RUN states - Add “End” instruction and write program to PLC

Part 3 Continued: Ladder Logic Programming - Add inputs (X001, X002) and outputs (Y001) - Use Monitor/Data View to test input/output behavior

Part 3: Latches and Logic Development - Create and test latch logic with momentary inputs - Program: button press toggles output state

Part 4: Multicolor Light Control - Program buttons and outputs for RED, AMBER, GREEN lights - Assign nicknames (Y001 = RED, etc.)

Q&A and Review - Troubleshooting common errors - Save all projects with your name/version
