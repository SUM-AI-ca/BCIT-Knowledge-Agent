## Course Description
This course provides students with the knowledge and skills necessary to provision, configure and deploy computer systems and software used in an enterprise network. Students will learn how to use clustering to deliver and monitor highly available network services for an enterprise network infrastructure. Students will also gain the skills necessary to allow secure remote access to server-hosted applications and desktops. The course will also explore network management tools used for IT tasks such as configuration management, application deployment, and provisioning. Topics covered include hardware and software configuration, data service configuration, system operation, device discovery, device monitoring and management.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Configure and monitor network interfaces.
- Discuss server monitoring options for network services.
- Describe highly available network services.
- Configure cluster hardware and software.
- Administer global properties, quorum, disk paths, and interconnect components using cluster commands.
- Manage the public network with IP multipathing and link aggregation.
- Manage resources and resource groups, including a failover data service, and a scalable data service.
- Implement a secure remote access solution.
- Manage secure access to enterprise applications and network services running on Windows and Linux servers.
- Discuss network management concepts.
- Install and configure a network service management platfom.
- Automate configuration management and application deployment tasks on managed hosts.
