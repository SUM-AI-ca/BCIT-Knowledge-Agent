## Course Description
Examines HVAC and smoke control systems with an emphasis on understanding components and their function; Building Code requirements for smoke control systems; procedures for completing commissioning tests; testing and inspection requirements of the Fire Code.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the function of the components of a smoke control system.
- Identify the appropriate smoke control system for a facility based on the BC building Code.
- Document the procedures for commissioning an installed system.

## Learning Resources
All material will be supplied via the BCIT D2L website for the assigned course

## Course Goals
Upon successful completion of this course, the student will be able to:

1) Conduct inspection and testing in conformance with applicable codes. 2) Conduct Fire Alarm testing in High Buildings. 3) Determine the smoke measure that applies to the building being tested. 4) Determine which testing procedures are required as per Building Code. 5) Conduct the appropriate testing procedures as required. 6) Locate and identify the necessary components requiring test/inspect. 7) Choose and operate the correct testing equipment. 8) Provide clear and accurate inspection and test reports. 9) Communicate with owner/authorized agent and Authority Having Jurisdiction deficiencies and require repairs.
