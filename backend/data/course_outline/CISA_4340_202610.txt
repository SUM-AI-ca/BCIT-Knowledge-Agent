### Course Description
Students will learn to design, implement and manage Microsoft 365 services, manage user identity and roles, manage access and authentication, and plan Office 365 workloads and applications. Students will also learn to configure, deploy, and manage Office 365 workloads for Microsoft Teams that focus on efficient and effective collaboration and communication in an enterprise environment. This course will introduce the students to plan, deploy, and manage Teams chat, apps, channels, meetings, audio conferencing, live events, and calling. This course includes topics such as Microsoft 365 tenant management tasks for an enterprise, including its identities, security, compliance, and supporting technologies.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Design and implement Microsoft 365 services
- Manage user identity and roles
- Manage access and authentication
- Plan Office 365 workloads and applications
- Configuring Microsoft Office 365 Tenant
- Manage Exchange Online
- Manage Microsoft Teams
- Plan and Configure a Microsoft Teams Environment
- Manage Chat, Calling, and Meetings
- Manage Teams and App Policies
- Implement modern device services
- Implement Microsoft 365 security and threat management

### Course Specific Requirements
- Internal SATA SSD or External USB Type-C SSD(Recommended minimum capacity: 500GB).
- A Registered Internet Domain.
- A credit card is required to create a Microsoft 365 subscription and access the Microsoft 365 licenses. Students may need to order a Microsoft 365 Business Premium license for four months and a Microsoft Teams Phone with a Calling Plan license for one month. All Microsoft 365 configuration and licensing procedures will be explained and guided by the instructor during classroom and lab sessions .
### Course Schedule and Assignments
Session1,2,3
- Discussion of the required learning resources for the course.
- Verify the public domains and ensure that the DNS records created in the previous course have been deleted.
- Set up the on-premises networking servers and services, including Active Directory, DNS, Routing and Remote Access, and other relevant systems.
Session4,5,6
- Create a new Microsoft 365 subscription and configure a custom domain for your Microsoft 365 deployment.
- In order to create a Microsoft 365 subscription, a credit card is required. Please note that a credit card is also needed to access the Microsoft 365 licenses .
- Introduction to Microsoft Entra ID (formerly known as Azure Active Directory).
- Configure a hybrid Active Directory environment using Microsoft Entra Connect Sync (formerly known as Azure AD Connect).
- Configure Microsoft Entra Connect Health for Active Directory Domain Services (AD DS).
- Lab Checkpoint1(Late submissions will not count for marks).
Session7,8
- Managing Exchange Online.
Session9,10,11,12
- Working with MS365 Apps (SharePoint, OneDrive, Power Automate, Sway, and Planner).
- Set up and configure Microsoft Intune.
- Lab Checkpoint2(Late submissions will not count for marks).
Session13,14,15
- Microsoft Teams: Manage Teams, Channels, Chats, Meetings, and Shifts.
- Manage and configure Microsoft Teams Phone, including phone numbers, call queue and auto attendant settings.
- Lab Checkpoint3(Late submissions will not count for marks).
Session16,17,18
- Skills Project Phase1: This is the hands-on practical component of the course, where students will set up a complete network along with core services (Active Directory, DNS, DHCP, RRAS) from scratch, in preparation of Phas2 of the Skills Project.
Session19,20,21,22
- Skills Project Phase2: In this phase, students will configure Microsoft Entra Connect to synchronize their on-premises Active Directory with the Microsoft Entra ID cloud service to simulate a real-word environment.
Session23,24
- Disconnect the on-premises Active Directory from Entra ID.
- Cancel the Microsoft 365 subscriptions to prevent any future charges from Microsoft.
- Perform cleanup of the Microsoft 365 subscription and the Internet Domain.
- Students are required to complete the MS365 cleanup procedure as outlined by the instructor and must present confirmation of the cleanup procedure completion to the instructor.
- Lab Checkpoint4(Late submissions will not count for marks).
