## Course Description
Investigates programming and operating procedures of Computer Numerical Control (CNC) machine tools. Part and machine setup procedures will be examined and proved on BCIT's CNC equipment. Computer Aided Manufacturing (CAM) techniques for programming will be studied in depth.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Set up and operate a Computer Numerical Control (CNC) milling machine.
- Perform CNC process planning.
- Create programs for CNC machine tools using manual G-code programming methods.
- Create and simulate milling toolpaths using Computer Aided Manufacturing software.

## Course topics
Manual CNC Programming

Write programs that include the following elements:

- Machine initialization
- Tool changes
- Work coordinate systems
- Point-to-point, linear, and circular moves
- Canned cycles
- Cutter compensation
- Subprograms

Machine Operation

- Observe the setup and operation of a CNC milling machine.
- Describe how to set up a machine including setting work coordinate system and tool offsets.

CNC Programming using CAM

- Create and edit 3D CAD geometry
- Generate toolpaths for contours, pockets, facing, and hole making operations
- Use CAM Simulation to verify a program.
- Generate the code for a specific machine.
