## Course Description
This course will build on student’s previous construction drawing knowledge to complete a set of commercial construction drawings based on their design solutions, using the current release of AutoCAD for Windows.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, students will be able to:

- Produce a space plan based on tenant requirements for an office space.
- Select freestanding and system furniture appropriate to an office environment.
- Produce a set of construction drawings for a commercial interior space including a site plan, a demolition plan, furniture plan, a construction plan, a power and communication plan, a finishes plan, a reflected ceiling plan and elevations wall and door details using the current release of AutoCAD.
- Incorporate partition types that convey an understanding of light steel stud construction such as fire rating, demising and acoustics.
- Select appropriate door types, frames and hardware for specific functional consideration.
- Maintain a well-organized file system and block library while creating a set of working drawings.
- Recognize construction details required for a commercial interior space.
- Select appropriate scales and organize millwork and detail drawings using Layout.
- Prepare a set of commercial construction drawings with accurate referencing.
- Create appropriate schedules and/or legends for the drawing set.
- Create a set of drawings using External Referencing commands and other advanced commands in AutoCAD.
- Produce a set of drawings with appropriate line weights, scales and conventions.
