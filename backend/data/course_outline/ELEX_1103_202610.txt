### Course Description
This course is an introduction to the fundamentals of data communication and networking. Topics include the physical characteristics of wired, fiber-optic and wireless media, basic Local Area Network (LAN) topologies, network interface controllers, Internet Protocol (IP) addressing, basic switches and routers and the Open Systems Interconnection (OSI) model for communication systems. Students will also learn basic troubleshooting techniques.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Explain the motivation and advantages for networking intelligent devices. [2]
- Describe the basic physical characteristics of wired (cable categories, shielding, color codes, connectors, propagation delay and crosstalk), fiber-optic (single and multimode) and wireless (802.11) media. [1, 2,3,6]
- Describe basic LAN topologies (star, bus, ring and mesh with a focus on star). [4]
- Explain the role of a Network Interface Controller (NIC) as a connection to the network. [1, 2,3,4]
- Describe an IP address scheme, including subnet masks. [2,4]
- Describe the difference between static and dynamic addresses and the role of Dynamic Host Configuration Protocol (DHCP). [2]
- Change an IP network address using IPCONFIG. [2,3,5]
- Use PING and TRACEROUT for basic troubleshooting. [2,3,5]
- Explain the basic functions of a switch and a router. [2,3,6]
- Describe common application layer services. [2,3]
- Explain the purpose of the OSI model and the functions belonging to each of its layers.[5]
- Compare the OSI model to the Transmission Control Protocol/Internet Protocol (TCP/IP) model. [2,3]

### Course Schedule and Assignments
Tentative Schedule: (Reading assignment discussed in class)
Week 1: Introduction, History, Hubs, Switches, Simplex. half duplex, Full duplex, Basic commands: IPConfig, Netstat, Ping
Week 2: OSI Introduction, TCP/IP, Routers, Gateways, NIC card, ARP, RARP, LAN, WAN, MAN.
Week 3: Introduction to IP Addressing, subnetting, ethernet, Token-Ring Overview, Bus, Star, Ring, Mesh Topologies, Cables Types
Week 4: Multiplexing, and DeMultiplexing, Circuit and Packet Switching, Bandwidth, Frequency, Data rate, Signal to Noise Ratio
