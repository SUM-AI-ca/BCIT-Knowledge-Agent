### Course Description
This course shifts focus from client-side to server-side programming, utilizing open source tools PHP and MySQL. An introduction to PHP fundamentals and the role it plays in generating dynamic websites will be covered. Exploring the C.R.U.D. model of development, students will complete a series of documents to facilitate the management of an online database. Content Management System (CMS) methods for form creation and user input will be reviewed. Students will be evaluated by quizzes, in –class assignments and term project.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Identify syntax and structures of PHP.
- Code and apply PHP to create web based applications.
- Identify syntax and structures of MySQL.
- Store and retrieve content within a PHP and MySQL.
- Provides methods of updating and removing data from a MySQL database
- Validate and style forms using JavaScript and PHP.
- Build a secure login system and dynamic component for a website.
- Integrate web service APIs (Application Programming Interface) to pull content from external sources.
- Analyze and model requirements and constraints for the design of databases, and other applications.
- Describe the difference between client-side scripting and server-side scripting.
