### Course Description
FNAM 3460 introduces students to GIS and data analysis tools relevant for both typical program project requirements, and entry level technologist positions in industry. Digital themes and models will be created from a combination of field data, imagery, and existing data typically found on online government sources. Students will also be introduced to both supervised and unsupervised image classification related to creating thematic maps. ArcGIS is the primary tool used to illustrate the GIS and analysis principles throughout the course, although other software products may be discussed and used in labs as well.
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Create a geodatabase with feature datasets and feature classes
- Import existing data from various sources
- Set map projection, datum, and coordinate systems
- Create and edit point, line and polygon features that include z coordinates
- Georeference scanned map and digital images
- Create topologically correct polygon map layers
- Create and edit feature attribute tables
- Use geoprocessing tools such as buffer, clip, union, and merge
- Perform attribute and location queries

### Course Goals
Upon successful completion, the student will be able to:
- Describe a photogrammetric stereo model
- Identify elements of a photogrammetric softcopy workstation
- Construct a digital elevation model (DEM) from stereo air photos
- Classify a LiDAR dataset
- Identify important elements in a digital hydrological model
- Generate a normalized difference vegetation index (NDVI)
- Describe the various applications to natural resources of RPAS
- Plan a project based on matching equipment with data objectives
