## Course Description
Web design is, at its essence, creating information user experiences to communicate a message to an online audience. This course focuses on a critical step for designers and developers when they make decisions related to creating and developing a website: considering the people who use the website. In preparation for the Web Portfolio and the Capstone Project courses, students will integrate the learned web design and user experience (UX) fundamentals from previous courses to develop the mindset of considering the end user in the web design process. Evaluation will include team and individual assignments.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the goal of designing a website.
- Apply knowledge gained in the discovery/information-gathering phase.
- Identify key design messages.
- Organize content and create sitemaps.
- Design information architecture and layout for a collaborative web or mobile project.
- Create user workflows based on different user personas in relation to a website goal.
- Create a style guide.
- Develop guidelines for creating UI elements for web, mobile, and interactive projects.
- Develop skills in the use of prototyping tools for wireframes, mockups, or interactive functional prototypes for different devices and screen sizes.
- Apply fundamental web design principles.

## Course Goals
Upon successful completion of this course, the student will be able to:

- Apply knowledge gained from the web design fundamentals and principles
- Integrate principles of visual design into the creation of mockups and prototypes
- Discuss the different stages of web design: Discovery, Planning, Design, Development, Testing, Launch, and Maintenance
- Organize content and create sitemaps
- Create wireframes using various wireframe applications
- Create and manage interactive content using new media development tools
- Develop guidelines for making UI elements for web, mobile, and interactive projects
- Develop skills in using various prototyping tools for wireframes, mockups, or interactive functional prototypes for different devices and screen sizes
