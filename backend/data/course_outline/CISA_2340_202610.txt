### Course Description
​In this course students learn how to administer Linux operating systems. Topics include installation, boot process configuration, partitions, file systems, network settings, logging services, user account policies, and host security. Additional topics include Apache web server, scripting, and Structured Query Language (SQL). Lab exercises reinforce the theory and provide opportunities for troubleshooting.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Describe the Linux file system, operating system structure, boot process, and tools
- Perform interactive and automated installations of Linux
- Configure and troubleshoot the boot process
- Configure services, networking settings, and system logging
- Configure account policies, access control lists, and host security
- Create and manage partitions and file systems
- Describe the importance of system time settings
- Manage software packages
- Install and configure Apache web server
- Configure advanced shell features
- Customize the user’s shell environment
- Use shell scripts to automate functions
- Create SQL statements to query a database
- Use the VI editor for editing files
