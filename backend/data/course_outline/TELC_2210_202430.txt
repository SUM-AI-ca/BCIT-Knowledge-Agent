## Course Description
This is a mostly hands-on course in installing and programming popular alarm systems. Students will learn to install common detectors such as passive infrared, glass break, smoke and heat detectors. Lab sessions will be spent on programming and working with common control panels, such as the DSC Power Series and the Honeywell Vista series panels. Special emphasis is placed on monitoring alarm systems and students will work directly with our monitoring station.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Describe detection loop operation
- Install intrusion detectors
- Operate and program control panels
- Monitor alarm systems
