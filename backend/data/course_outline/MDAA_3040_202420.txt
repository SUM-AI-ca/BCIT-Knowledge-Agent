## Course Description
In this course, students are introduced to many aspects of a game engine editor. This includes importing models, creating master materials, lighting scenes, assigning animations, controlling characters, creating landscapes, using the foliage tool, and using the blueprinting system. Throughout the course, individual projects will be created through the help of in-class demonstrations. Each student will use both marketplace assets, as well as their own viewpoint, therefore only minimal blueprint coding will be required. Students will learn the technical constraints of modeling, texturing, lighting, and animating for games and how to overcome those challenges. Optimization techniques will be discussed to ensure high frame rates are maintained.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Optimize 3D models based on the game engine requirements.
- Create animation state machines for game characters.
- Optimize textures based on game engine requirements.
- Create master materials that have useful controls for materials instances.
- Import 3D props and models into the engine and setup an environment.
- Use the landscape and foliage tools to create open world environments.
- Create atmosphere and mood for the game with lights and effects.
- Apply basic physics and dynamics to characters and props.

## Course Goals
The goal of this course is to introduce students to all aspects of the Unreal Engine Editor. The focus of this course is to tackle using the engine from an Artist's viewpoint, therefore coding will be done through Unreal's Blueprinting system.

## Course Specific Requirements
Students should sign up for an Epic Games account. If you already have one, you do not need to create a new one. The free monthly asset packs and games will remain in your account forever, so it is a good idea to sign up with an email address or account that you will be able to access after the course ends.

For some assignments, you will be required to create a recording of your project. OBS is a screen recording software that is available on AppsAnywhere or to download for free that you can use. You may use any software you like to capture your screen, but files must be an .mp4 file using the h.264 codec. The instructions for what I will want captured will be clearly put into the Assignments page so if your capture does not allow for me to see what was requested, you will not get marks for it.
