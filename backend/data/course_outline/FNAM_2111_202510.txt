### Course Description
FNAM 2111 introduces students to important field data collection tasks they will be typically be expected to complete during summer field employment, and incorporate into course projects during the second year of the program. Data collected in the field using a combination of equipment such as field data loggers or tablets, GIS grade GNSS equipment, and laser range finders will be imported into various software tools, and imported into GIS software to produce maps. Project planning tasks and common mapping strategies will be discussed before students are sent out in the field to collect data. Data will be collected in various vegetation and terrain conditions so students have experience in determining which combination of field equipment is most suitable for different project objectives. The course includes a mapping project that incorporates the skills introduced throughout the term.
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Use existing information to review the site characteristics for a given work site or project area
- Create a data collection and mapping plan based on matching equipment and methodology to project objectives and site characteristics
- Complete equipment calibration routines
- Adjust equipment settings to match project objectives
- Transfer necessary maps, images, attribute tables, and GNSS data dictionaries to digital field equipment
- Input field observations and data in industry standard note or form formats
- Produce digital plots and maps based on traverse field data collected with both traditional and digital field equipment
- Use planning software to determine the most appropriate times for field data collection with GNSS equipment
- Capture point, line and polygon features with corresponding attribute information using GIS grade GNSS equipment
- Collect carrier phase data for important field ties or features
- Describe the process for collecting real time differentially corrected data
- Post process GNSS data
- Create a geodatabase with feature datasets and feature classes for field data
- Set map projection, datum, and coordinate systems
- Create and edit point, line and polygon feature
- Create maps that include information such as scale, legends, north arrow information, coordinate grid ticks and labels
