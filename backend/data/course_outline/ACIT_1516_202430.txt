## Course Description
This course introduces the skills necessary to articulate the solution to a technical problem within the bounds of the Python programming language. The concepts developed in this course prepares students for the Linux Systems Administration for Industrial Network Cybersecurity course in term two. Students will learn how to design, implement, test, and debug programs that incorporate: variables, expressions, assignments, I/O, conditional and iterative control constructs, functions, and parameter passing. Programming related activities, assignments, and projects that are representative of tasks encounter in the IT workplace are used to facilitate the development of programming skills.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Create algorithms for solving simple problems. (4)
- Choose the appropriate Python data structure for modeling a given problem. (4)
- Choose appropriate conditional and iteration constructs for a given programming task in Python. (4)
- Apply the techniques of decomposition to break a program into smaller pieces. (3)
- Refactor a program in Python by identifying opportunities to apply procedural abstraction. (4)
- Write programs in Python that use primitive data types, variables, expressions, and command line I/O. (3)
- Write programs in Python that use conditional and iterative control structures, functions, and parameter passing. (3)
- Write programs in Python that use each of the following data structures: arrays, strings, sets, and maps. (3)
- Write programs in Python using the standard libraries available with a chosen programming language. (3)
- Write programs in Python that use file I/O to provide persistence across multiple executions. (3)
- Apply strategies to test and debug simple Python programs. (3)
- Conduct a personal code review on a Python program component. (4)
- Contribute to a small-team code walkthrough. (4)

## Course Specific Requirements
Online Participation Details:

- Weekly online activities involve completing online participation activities and writing Python programs in zyBooks.
- Participation is automatically tracked in the zyBook, with multiple Participation Activities in each chapter.
- Participation and Challenge Activities must be completed prior to the start of class.
- Students must complete a minimum of 75% of the Participation, Challenge Activity, and Pre-lab Exercises to pass this course.

Lab Exercise Details:

- Lab exercises are started in class each week. Some exercises will be due by end of class, and others are due before the next class. This will be announced in class and posted in D2L. Late submissions not accepted.
- Not all submissions are graded. The instructor will randomly sample submitted lab work for evaluation, choosing a minimum of two submissions over the course.
- Students must submit a minimum of 75% of lab exercises to pass the course.
