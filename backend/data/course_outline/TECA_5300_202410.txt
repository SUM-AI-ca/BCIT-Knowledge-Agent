## Course Description
This course looks at different art assets used in the production and development of a video game. Students will be introduced to standard game engines used in game studios. While exploring the game engine and its different panels and environments, students will be taught the dos and don’ts of creating 3D game models, lighting, textures, and shaders. Students will create a small game level using 3D assets, audio, and textures; visual scripting; and lights, camera, environment effects, and dynamics.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Navigate through different panels, windows, and menus inside an industry standard game engine.
- Create 3D props for game level.
- Sculpt and texture a terrain.
- Integrate foliage and props on game terrain.
- Optimize 3D props and assets for importing into the game engine.
- Import objects, animations, audio, and textures into the game engine .
- Develop shaders for 3D objects and connect textures.
- Plan and practice the position of lights and camera in a game environment.
- Create atmosphere and environment effects, and use post-processing techniques to create effects.
- Develop events and functions using visual scripting.

## Course Goals
The goal of this course is to provide an understanding of how to use a game engine with respect to efficiency and performance. The technical aspects of how the renderer is handling and processing the information in the scene will be discussed to provide an understanding of the impact each resource has so that the technical artist can optimize when necessary. Unreal Engine 5 will be taught in this course, but the lessons learned while using UE5 can be applied to other engines as well.
