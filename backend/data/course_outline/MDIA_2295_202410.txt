## Course Description
​In this course, students will learn how to use motion to visually present an idea or explain complex information. They will utilize text layers, vector artwork, and raster images into their projects, animating them across time and 2D or 3D space. The importance of proper pacing will be emphasized. Variant techniques, such as masking, effects, and color correction will be introduced as methods to enhance the animation. Students will work with Green Screens to add different backgrounds behind a commentator. They will showcase their understanding of the course's topics by completing individual assignments, as well as working in teams in a final project.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Utilize vector artwork and shapes in creating animation.
- Apply the principles of animated typography.
- Explain the importance of pacing and proper timing for animation.
- Utilize vector and raster-based masking.
- Perform basic compositing and Green-screen techniques.
- Use various colour-correction techniques.
- Explain how layers can be animated in 3D space.
- Explain how effects can be applied to layers.
- Describe the workflow for exporting an animation and placing it online.

## Course Schedule and Assignments
Note: All assignments are due a week from the day they are assigned. Missing two assignments (especially in a row) could result in failing the course.
Class: Topics: Assignments
Class 1:: Defining what is Motion Graphics. After Effect’s interface and shortcuts. Importing media and building compositions.: Creating a simple animation.
Class 2:: Creating motion: Animation, keyframes, Animation curves.: Creating a 15 second ad.
Class 3:: Using Shape layers (part 1).: Creating an animated car using shape layers.
Class 4:: Shape layers (part 2).: Creating an animated scene using shape layers.
Class 5:: Expressions. Exporting the result as a QuickTime movie.
Class 6:: Working with the Motion Path.: Animating elements on a map.
Class 7:: Raster versus Vector based masking. Masking using the Pen tool.: Utilizing vector-based masking in creating transitions.
Class 8:: Layer Track Matte.: Utilizing raster-based masking in a presentation.
Class 9:: Animating titles in After Effects. Text Animators and working with the Range selector.: Creating a public service announcement using text and shape layers.
Class 10:: 3D composition, lights, and Cameras.: Preparing concepts for the Final Project.
Class 11:: Advanced text animators. Discussing the proposals.: Preparing storyboards for the final project.
Class 12:: Keying. Final Project storyboards peer and instructor review.: Preparing ideas for their own Green Screen shots.
Class 13:: Keying (Production session in BCIT’s Green Screen Studio).: Keying their own Green Screen shots.
Class 14:: Puppet Pin tool. Useful effects for Motion Graphics.: Finishing 20% of the final project.
Class 15:: Introduction to 2D tracking (for motion graphics purposes) Review of project progress.: Finishing 40% of the final project.
Class 16:: Introduction to Rotoscoping and the Roto brush tool (for motion graphics purposes).: Finishing 60% of the final project.
Class 17:: Introduction to 3D tracking (for motion graphics purposes). Working session (Final Project).: Finishing 80% of the final project.
Class 18:: Final Project working session.: Finishing all the Final Project.
Class 19:: Final Project showcase. Course overview.
Class 20:: Exam week.
