## Course Description
Basic 2-D and 3-D tool path creation, tool path editing, post processing, job setup and part machining are covered.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Design and machine parts using G-code programs generated with CAD/CAM software such as Mastercam.
- Create profile turning, drilling, tapping, grooving, and threading for CNC turning centre using CAD/CAM.
- Create facing, contouring, and pocketing for machine centre using CAD/CAM.
- Understand the basic 3-D machining and basic solid modelling.
