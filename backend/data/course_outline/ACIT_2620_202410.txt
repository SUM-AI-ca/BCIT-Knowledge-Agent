## Course Description
This course introduces students to core networking concepts, terminologies, and their implementations. Topics are introduced and examined by implementing and configuring network services using contemporary technologies. The course includes a semester long hands-on practical networking project, as well a discussion of fundamental concepts such as network topologies, protocols, transmission media, switching techniques, access control and addressing. TCP/IP and the OSI Reference Model are used throughout the course.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Explain fundamental concepts and terminologies related to networking.
- Explain the techniques of switching, access control and addressing in networks.
- Describe common networking models, and employ them in network design, troubleshooting, and error reporting.
- Describe the operational characteristics of common network media.
- Describe the purpose, operation, and header elements of network protocols such as ARP, DHCP, DNS, HTTP, ICMP, ICMPv6, IEEE 802.11, IEEE 802.1Q, IEEE 802.3, IPv4, IPv6, OSPF, TCP, UDP.
- Configure network services (including domain name services, dynamic address allocation, dynamic routing, network address translation, packet filtering, static routing, switching, and web services).
- Use industry standard tools to configure, analyze, and troubleshoot network services.
- Analyze protocols at the physical, data link, network, transport and application layers.
- Discuss network security and network management principles.

## Course Goals
- Students will explore key networking concepts through hands-on practical activities
- Students will learn to use networking tools to configure network devices and services for a basic inter-network connectivity and analyze network traffic moving across the network

## Evaluation Criteria
Criteria: %: Comments
Quizzes: 40: Four equally weighted knowledge tests submitted online via the Learning Hub.
Project: 40: A cumulative project where students construct a virtual network throughout the term.
Final Exam: 20: A practical test where students configure a small network on top of the existing topology delivered through the project.

To pass the course, the student must deliver at least 60% of the project and achieve an overall grade of 50% or more.

## Course Schedule and Assignments
Week: Week Starting: Topics*: Objective: Evaluation
1: 8 Jan: Networking Overview: Understand the main networking concepts and terminology
2: 15 Jan: Network Devices and Topologies: Identify the main networking devices, their functions and how they are used to build networks
3: 22 Jan: Ethernet and Switching: Understand the shared medium model of information transfer and apply this knowledge to build a working Ethernet switch: Project: Switch Creation
4: 29 Jan: IPv4 Addressing: Examine the role of the network layer and the IPv4 header: Quiz 1
5: 5 Feb: IPv4 Routing: Explain routing tables and practice building a static IPv4 router: Project: IPv4 Static Router
6: 12 Feb: IPv4 Subnetting: Apply knowledge of IPv4 addressing to create subnets of different sizes
7: 19 Feb: IPv6 Addressing: Compare and contrast IPv6 and IPv4 and explain IPv6 packet processing: Quiz 2
8: 26 Feb: MIDTERM WEEK
9: 4 Mar: IPv6 Routing: Practice building a static IPv6 router: Project: IPv6 Static Router
10: 11 Mar: SPRING BREAK
11: 18 Mar: DHCP, Dynamic Routing: Understand the function of routing protocols and practice building a dynamic router and DHCP server: Quiz 3 Project: DHCP and Dynamic Router
12: 25 Mar: Transport – UDP, TCP, Sockets: Discuss the role of the transport layer and explain the differences between UDP and TCP
13: 1 Apr: Packet filtering and NAT: Apply knowledge of transport protocols and IP to implement a firewall and NAT: Quiz 4
