## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe national and international standards for aviation security.
- Interpret security regulations in the Aeronautics Act, Criminal Code, and Canadian Aviation Security Regulations (CASR).
- Describe the principles governing the selection and use of security systems and equipment.
- Identify the processes involved in the handling of a security threat at an airport or airline.
- Describe the elements and application of an air carrier security system.​

## Course topics
COURSE MODULES

- MODULE 1 - Development of National and International Aviation Security Regulations and Law
- MODULE 2 - Canadian Aviation Security Regulations
- MODULE 3 - U.S. Aviation Security Regulations
- MODULE 4 - European Aviation Security Regulations
- MODULE 5 - Ground Security Measures
- MODULE 6 - Airport Security Threats and Breaches
- MODULE 7 - Weapons and Sabotage Devices at Airports
- MODULE 8 - Detection and Handling of Illicit Narcotic Drugs
- MODULE 9 - Air Carrier Security and Security Measures
- MODULE 10 - Airport Security Planning
