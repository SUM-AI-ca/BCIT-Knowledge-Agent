## Course Description
​This course provides the student with hands-on skills using Microsoft Excel software as a management tool to store data, conduct data processing, solve problems, and display results in a variety of ways. It also provides students with an understanding of the fundamental concepts related to planning and scheduling a construction project using Microsoft Project software.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Create forms and documents in MS Excel.
- Conduct Elemental Cost Analysis.
- Apply MS Excel financial functions.
- Prepare a development proforma.
- Apply various MS Excel functions, formulas, charts, referencing, sorting and filtering to process and analyse data.
- Define project and construction management.
- Describe the basic steps in the construction scheduling process.
- Create a project schedule using MS Project software:
- Identify schedule activities that must be executed to produce project deliverables.
- Identify and describe the dependencies among schedule activities.
- Calculate the time required to perform an activity based on historical data.
- Determine the type and quantities of resources required to perform each construction activity.
- Perform project control based on simulated changes to a project schedule.
- Track project progress and update a project plan.
- Measure and analyse project performance.
