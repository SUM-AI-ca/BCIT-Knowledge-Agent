## Course Description
This course uses Python to introduce object-oriented programming principles and techniques to students who have completed ACIT 1515 or equivalent. Topics include: object-oriented programming concepts (classes, objects, methods, inheritance, encapsulation, and polymorphism), techniques for software design and reuse, use of typical Python libraries and modules, unit testing and debugging of Python programs, creation of HTTP APIs, creation of graphical user interfaces.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Create solutions to problems using object oriented design.
- Write object oriented programs that incorporate classes, methods, inheritance, encapsulation, and polymorphism.
- Develop programs that use large-scale APIs.
- Develop programs that implement common OO design patterns.
- Develop programs that have graphical user interfaces.
- Develop programs using Test-Driven-Development techniques.
- Create and run a public HTTP API.
- Use a modern integrated development environment and related tools to develop, package, and deploy applications.

- Use Python 3 to develop complete applications, using object oriented programming
- Model classes, attributes and relationships using diagrams
- Use best practices in writing and documenting code
- Build reusable software (design patterns, modular approach, packaging)
- Build and consume HTTP APIs in Python

## Course Schedule and Assignments
Week: Date (Monday): Topics
1: 2 Sep: ONLINE / ASYNCHRONOUS Python refresher: running a Python program, data types, control structures, functions, imports. Coding style, docstrings, variable names (PEP8).
2: 9 Sep: Installing and using additional packages (pip). Reading error messages and terminal output. Making sure the code does what it is supposed to do: debugging and unit testing.
3: 16 Sep: Object oriented programming: introduction to classes. Syntax, self, attributes, methods. Concepts: abstraction and encapsulation.
4: 23 Sep: EVALUATION 1
5: 30 Sep: ONLINE / ASYNCHRONOUS More object oriented programming: class diagrams, relationships, inheritance, dunder methods.
6: 7 Oct: Advanced unit testing: mocks, fixtures and patching. Project (part 1): web scraping in Python
7: 14 Oct: ONLINE / ASYNCHRONOUS Project (part 2): persisting data using JSON and CSV files
8: 21 Oct: MIDTERM EXAMS
9: 28 Oct: Project (part 3): persisting data using a relational database (SQLite)
10: 4 Nov: Project (part 4): many-to-many relationships
11: 11 Nov: ONLINE / ASYNCHRONOUS Web development in Python: Flask. Routes, URLs, views, parameters.
12: 18 Nov: Project (part 5): using a database with Flask
13: 25 Nov: Project (part 6): creating a REST HTTP API with Flask: HTTP methods and JSON payloads.
14: 2 Dec: REVIEW WEEK Demos and project presentations.
15: 9 Dec: FINAL EXAMS

Topics may be adjusted depending on class progress.
