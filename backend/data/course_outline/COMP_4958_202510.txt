## Course Description
​This course covers several paradigms for concurrent programming. Shared-state concurrency, channels (based on communicating sequential processes) and message-passing concurrency will be studied. The goal is to develop highly-concurrent applications.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Apply locks and conditions to synchronize threads.
- Develop concurrent applications using shared-state concurrency.
- Apply message-passing concurrency to build highly concurrent programs.
- Apply supervision trees to build fault-tolerant servers.
- Develop concurrent applications using communicating threads.
- Use a fault-tolerant data store in concurrent applications.
