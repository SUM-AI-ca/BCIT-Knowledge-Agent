### Course Description
This course introduces students to the application of Programmable Logic Controllers (PLCs) to industrial process automation. The course builds on logic and circuit analysis skills from previous courses and provides the background to design and implement automated sequence control systems. Topics covered are: PLC architecture, designing standard logic diagrams, ladder logic programing, I/O configuration and introductory Human Machine Interfaces (HMIs) design. The course is project based and involves design and implementation of few simplified industrial control projects using typical PLCs on real lab platforms.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Describe the architecture, main components, and scan sequence of typical industrial PLCs [2,3].
- Analyze and specify requirements for inputs, outputs, alarms and interlocks for building a sequential automation system [2, 3].
- Design and document instrument list, input/output tag list, interlocks and logics diagram for sequence control systems using ISA. S5.1 binary logic symbols [3, 4].
- Design interlock and sequence control to meet operating specifications and fail safe operation requirements for implementation on PLCs [4].
- Design HMIs to meet operating specifications for implementation on PLCs [4].
- Implement sequence, interlock, data manipulation functions and HMIs on a Programmable Logic Controller using industry norms and best practices [5, 6].
- Commission and verify the operation of an interlock control system to ascertain it meets its specifications and satisfies fail safe operating conditions [5, 6].

### Course Goals
1. Design and document interlock and sequence control systems using standard logic diagrams and contact symbols.
2. Implement interlock and sequence control systems on an industrial programmable logic controller.
3. Process and practice analog signals entries.
4. Develop operator HMI.
