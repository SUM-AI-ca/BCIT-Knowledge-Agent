## Course Description
This course is for students who have a special interest in database technology. Topics include: the importance of data in an organization; relational algebra and advanced SQL; conceptual, logical and physical data modeling; functional dependencies and normal forms; data integrity; data access methods including hashing and indexing; external sorting techniques; database design, implementation, administration and programming; performance tuning and optimization. Students will use common industry database software products such as Microsoft SQL Server and/or Oracle DBMSs.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Analyze business requirements, and translate them into database design and implementation.
- Apply conceptual, logical and physical modeling techniques to model data in database design.
- Apply functional dependency axioms and normal form synthesis algorithms in relational database design.
- Explain business rules and implement them as database integrity constraints.
- Implement and administer a relational database using a common industry DBMS.
- Apply relational algebra and advanced SQL to manipulate relational data.
- Develop stored procedures, functions and triggers using a DBMS procedural language, and using cursors.
- Describe physical data organization and access methods including dynamic hashing and multi-level indexing.
- Describe physical data access algorithms used by DBMSs to perform relational operations in query processing.
- Apply techniques to analyze and optimize SQL queries and database application performance.

## Course Goals
- Install a MySQL Server and a MS SQL Server
- Optimize SELECTs and Aggregate queries in MySQL and MS SQL.
- Connect to and run queries against MySQL and MS SQL Servers on a CLI and GUI.
- Create users and assign privileges within MySQL to limit the potential threat of data loss due to accidental query execution.
- Analyze existing users and privileges to know who has access to what.
- Import SQL and non-SQL formatted (CSV style) data into Relational Databases.
- BEGIN, COMMIT and ROLLBACK a transaction.
- Add indexes to a table to speed up a set of queries.
- Create and manage summary tables to optimize aggregate SELECT statements (with GROUP BYs).
- Be able to perform a backup of a database and restore in response to database loss.
- Use advanced SQL features for query processing.
- Identify SQL antipatterns to avoid frequently made missteps in SQL programming.
- Develop web applications with data persistence using SQL.
