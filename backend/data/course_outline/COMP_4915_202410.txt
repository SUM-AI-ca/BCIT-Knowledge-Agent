## Course Description
This course introduces 2 key technologies prominent in the Information Systems industry: 1) The Unix operating system. In the Unix portion of the course you will learn to work comfortably on a Unix platform, to be able to install and configure Unix services, and to create simple Shell scripts. Linux Fedora will be used for this part of the course. 2) The Windows Server Operating System. Students will learn the components and architecture of the Windows Server Operating System, as well as how to configure the operating system.

## Course Learning Outcomes/Competencies
At the end of the Unix portion of this course, the student will be able to:

- Explain how Unix came into existence, and its relevance in the workplace.
- Explain the Systems Administrator tasks.
- Manage a Unix file systems.
- Configure networks and file sharing.
- Program the Unix shell.
- Work comfortably in the bash-shell.
- Use Unix utilities such as awk, grep, sed, wc, or diff.
- Set up internet services.
- Set up firewalls.

At the end of the Windows portion of this course, the student will be able to:

- Perform the following tasks on a Windows Server Operating System:
- Configure
- Customize
- Optimize
- Integrate on a network
- Troubleshoot.
