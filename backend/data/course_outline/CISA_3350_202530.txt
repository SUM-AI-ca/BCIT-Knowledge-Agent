## Course Description
​Students will learn to install and configure a Microsoft Windows Active Directory Environment in preparation for messaging services deployment. Students will also learn to install, configure, and administer an enterprise messaging system that is integrated with Active Directory. The course will introduce the theory behind messaging systems, and provide students with hands-on activities to install, maintain, customize, and troubleshoot Microsoft Exchange Server and clients.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the functions of an enterprise messaging system
- Explain how messaging services integrate with Microsoft Active Directory services
- Install and configure Microsoft Exchange Servers
- Activate and configure Server roles
- Configure messaging recipient parameters including groups and mailboxes
- Implement bulk management of mail-enabled objects
- Describe the Microsoft Exchange Infrastructure components
- Configure Microsoft Exchange connectors, transport rules, certificate services, and e-mail policies
- Provide monitoring and reporting services on mail queues, system performance, and perform message tracking
- Describe high availability solutions for mailbox Servers

## Course Schedule and Assignments
Session 1 • Overview of required learning resources • Public domain registration (explained by the instructor)

Session 2 • Copying required software and images to SSDs • Hyper-V configuration (virtual networks and adapters) • Creating virtual machines

Session 3 & 4 • Installing Active Directory • Configuring Routing and Remote Access (RRAS) • Preparing for Exchange Server installation

• Checkpoint 1 Lab (Note: Late submissions will not be counted for marks.)

Session 5 • Installing Exchange Server

Session 6 • Certificate configuration • Creating and managing Mailbox Databases • Managing Exchange Recipients – Part 1

Session 7 • Managing Exchange Recipients – Part 2 • Configuring Internet domains • Setting up Send and Receive Connectors

Session 8 • Creating and applying Transport Rules • Compliance management • Configuring Roles and Permissions

Session 9 & 10 • Organization settings • Protection (Malware filters, Anti-spam) • Configuring Public Folders • Archiving

• Checkpoint 2 Lab (Note: Late submissions will not be counted for marks.)

Session 11 • Backup and restore of mailboxes and databases • Database Availability Group (DAG) – Part 1

Session 12 • Database Availability Group (DAG) – Part 2 • Checkpoint 3 Lab (Note: Late submissions will not be counted for marks.)

Final Skills Project

Sessions 13–15 (Phase 1: Infrastructure Setup) This is the hands-on practical component of the course, where students will set up a complete network along with core services (Active Directory, DNS, DHCP, RRAS) and Exchange Server from scratch, in preparation for Phase 2 of the skills project.

Sessions 16–19 (Phase 2: Exchange Server Configuration) In this phase, students will configure Mailbox Databases, recipient types, transport rules, address lists, and other key Exchange Server features to simulate a real-world environment.

Session 20 • Cleanup of Internet Zone DNS Records • Final review and preparation for Level 4
