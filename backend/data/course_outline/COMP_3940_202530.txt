## Course Description
This course provides in-depth understanding of developing and analyzing distributed systems. The focus is on developing distributed systems on desktop as well as mobile environments and analyzing the impact of networking technologies on their performance, reliability, scalability, consistency and security. Students will develop distributed applications using sockets / datagrams / multicast sockets, processes/threads/pipes/FIFOs; middleware that may include COM/DCOM or RPC; and web technologies.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Analyze requirements and design goals for client server and distributed system.
- Evaluate impact of Networking and Internetworking on the client/server and distributed systems.
- Identify structural and modeling issues.
- Analyze development methodologies for client/server based applications.
- Build GUI based client server systems using sockets, datagrams, multicasting, multithreading, multiprocessing; middleware that may include COM/DCOM, ODBC and web technologies.
