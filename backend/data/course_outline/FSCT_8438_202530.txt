## Course Description
This course will assist you in the visualization of large amounts of data to advance your organization's tactical and strategic mandates. The course builds upon FSCT 8431 by expanding your knowledge of spreadsheets to an intermediate level. You will learn how to build macros in spreadsheets for the purpose of building a dashboard. You will then learn how to use data visualization applications to develop basic graphs and maps, and to complete trend analysis.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Clean data in spreadsheets, such as Excel, for use in other data visualization applications.
- Create basic dashboards of simulated crime data in applications such as Excel and Tableau.
- Create graphics, figures, and tables in data visualization applications such as Tableau.
- Analyze data using graphics to identify trends.
- Create maps using data visualization applications such as Tableau.
- Create and present a dashboard.​

## Course Goals
Upon successful completion of this course, the student will be able to:

- Understand the data analytical life cycle.
- Understand the importance of data analytics and visualization.
- Define and understand key terminology as it relates to big data analytics.
- Explain and implement techniques for data extraction, preprocessing, transformations and visualization.
- Create and maintain both automated and manual processes for data extraction, data transformation and data reporting.
- Understand the importance of data visualization and best practices.
- Create graphics, figures, and tables in data visualization applications.
- Create and present a variety of data analytical product(s) both in a verbal format as well as visual. ​
- Understand and speak to ethical considerations in data analytics.
- Understand machine learning and predictive analysis implementation in forensics & crime
