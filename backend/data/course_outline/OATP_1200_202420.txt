## Course Description
This course has been designed to assist students in the application and development of business skills to function effectively in an administrative role. Topics covered include, but are not limited to financial reporting, document design, social media and presentation skills

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Create documents and convert existing documents to PDF format.
- Use traditional accounting procedures to interpret and compile financial statements.
- Use financial data to complete an accounting cycle.
- Create a LinkedIn profile.
- Manage stage fright and develop confident public speaking skills.
