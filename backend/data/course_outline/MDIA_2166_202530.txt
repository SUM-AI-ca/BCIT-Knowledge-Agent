## Course Description
This course introduces students to creating vector based graphics in Adobe Illustrator. Students will learn variant tools used in creating logos, icons, page layouts, and an introduction to building UI and UX elements. Topics covered include mastering the pen tool, merging and subtracting paths, organizing objects in groups and layers, selection techniques, patterns, symbols, brushes, rendering techniques for variant interface and design style, and exporting the results for print, web or mobile purposes.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Clearly articulate the nature of vector and a raster graphic.
- Demonstrate competent use of Illustrator’s tools and palettes
- Demonstrate the ability to navigate within an Illustrator document.
- Define a path and the differences between curved and linear anchor points.
- Demonstrate competence in selecting and organizing objects within a project.
- Create gradients and patterns to be applied to the fill or stroke of objects.
- Demonstrate how brushes and symbols are created.
- Demonstrate how illustrator files are exported for various purposes such as print or interface elements.

## Course Schedule and Assignments
Week 2025: Date: Topic: Assignments
1: Sept 5: Introduction to Illustrator interface, workspace and artboard. Organizing objects into groups. Selection methods. Navigation and shortcuts.
2: Sept 12: Introduction to basic shapes, using layers, brushes & methods for drawing.: Exercise 1
3: Sept 19: Object transformations, selecting and applying colors to fills/strokes, stroke properties.: Exercise 2
4: Sept 26: Type Tool, Character Palette, Type on Path options.: Exercise 3
5: Oct 3: Pen Tool Basics (lines, basic curves, editing points & direction handles).: Exercise 4
6: Oct 10: Pen Tool continued. Related pen tools (convert, adding/subtracting anchor points). Placing tracing image.
7: Oct 17: Rulers, grids, guidelines. Alignment and Grouping Options.: Assignment 1
8: Oct 24: Logo development process, blending modes, adding effects to a logo, working with variable stroke widths.
9: Oct 31: Typography tools, custom type & effects, font resources. Exploring appearance panel and graphic styles.: Exercise 5
10: Nov 7: Advanced Appearance panel, Paragraph and Character Styles, Optimizing Shapes, Working with Brushes, Patterns, Swatches: Exercise 6
11: Nov 14: Introduction to 3D elements in Illustrator: Emboss, Extrude and Revolve.
12: Nov 21: Drawing elements on a perspective grid, adjusting 3D perspectives, 3D render effects/settings.: Assignment 2
13: Nov 28: Asset creation: importing and exporting files for different mediums (print/web) and cross-compatibility with other Adobe programs
14: Dec 5: Advanced topics
15: Dec 12: Project presentations: Term Project Due
