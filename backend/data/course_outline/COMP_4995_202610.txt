### Course Description
Concentrates on gaming system architectures and provides an introduction to gaming graphics (DirectX/OpenGL/MFC etc.) and basic game design. Course materials cover the game system architectures and programming requirements for realtime graphics for gaming. Students develop small demonstration games or projects applying knowledge gained from previous option courses and their concurrent graphics programming courses.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Set up a DirectX application.
- Work with Direct3D surfaces.
- Track frame rates.
- Understand and build sprites.
- Add lighting, depth buffering, culling in a DirectX application.
- Apply textures, work with the camera, and animation matrices.
- Load external 3D models.
- Apply shadows and mirrors using the stencil buffer.
- Use the picking technique to select objects in a 3D space from the users perspective.
- Research a gaming topic, and demonstrate knowledge gained through a paper and project.
