## Course Description
​This course provides a comprehensive exploration of advanced Windows Server technologies, focusing on virtualization, deployment, and management. Areas of focus include Active Directory, Windows PowerShell, Windows Deployment Services (WDS), Azure Virtual Desktop (AVD), Hyper-Converged Infrastructure (HCI), and clustering. The course emphasizes hands-on experience with Windows Server Hyper-V, high availability solutions, and automated deployment techniques. This curriculum provides a strong foundation for leveraging modern Windows Server technologies in enterprise environments and prepares students for advanced roles in IT infrastructure management.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Demonstrate advanced knowledge of Active Directory services and management.
- Utilize PowerShell effectively for Windows Server administration and automation.
- Implement and manage Windows Deployment Services (WDS) for automated deployments of desktop and server operating systems.
- Configure and maintain Azure Virtual Desktop (AVD) for virtual desktop infrastructure and on-demand applications.
- Explain Microsoft's virtualization solutions and the Hyper-V architecture.
- Install, configure, and manage Windows Server Hyper-V.
- Create and manage virtual machines and virtual networks in Hyper-V.
- Implement high availability solutions using Windows Server Clustering.
- Design and deploy Hyper-Converged Infrastructure (HCI) solutions.
