### Course Description
​Lessons, labs, and practical assignments in this course examine cross-platform-enabled frameworks for developing mobile and tablet applications. The course will focus mainly on Android deployments but will address platform-neutral code, as well.​
### Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:
- Implement standard features that are found in mobile and tablet applications.
- Enable common screen inputs and outputs for data handling and presentation.
- Manage local data storage.
- Interactively exchange content with remote APIs.
- Handle gestures.
- Enable navigation between screens.
- Research and implement new features in the environment.
- Implement solutions with both native and cross-platform compatible development languages.
- Enable proper debugging in a mobile development environment.​
