## Course Description
This course is an overview of common project management concepts which will be applied to the collaborative projects in the later courses. The course includes the basic concepts of web project management, teamwork, and an introduction to popular project management software applications used in the web development field. Students will apply their knowledge and skills as well as appropriate tools and techniques to project activities to meet project requirements in later courses. Students will engage in project planning, identify project stakeholders, define the roles and responsibilities of the team, define project scope, devise risk and quality plans, map out schedules, and learn about time tracking and documentation. Evaluation will include in-class assignments.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Define fundamental project management terminology.
- Describe the main areas of managing web projects: scope, stakeholder, time/milestones, scheduling tasks and resources, budgeting, communications, risks, quality, and post-project evaluation.
- Manage project documentation.
- Identify appropriate project management tools to manage a web project.
