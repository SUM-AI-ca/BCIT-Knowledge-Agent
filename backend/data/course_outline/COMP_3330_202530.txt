### Course Description
​In this course, students will learn to use client-side JavaScript frameworks, such as React and MVC frameworks such as Angular, to create fast and modular applications. They will also learn to use server-side JavaScript using platforms such as Node.js, and build networked web applications. Labs and exercises focus on how to structure and develop web applications following current industry standards.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Implement HTTP servers and clients.
- Install and make use node modules to extend the capabilities of the Node.js platform.
- Use express web framework to build web applications.
- Build a RESTful API.
- Connect and retrieve data from a Data store.
- Access the file system to read and write files.
- Write Command-Line scripts.
- Explain transpilers in the Node.js environment.
- Add real time capabilities to the application by using socket.io module.
- Explain the use of a web stack as a way to build modern scalable web apps.
- Explain the basic concepts of the React Library, and how it interacts with the browser.
- Construct single-page applications using React and it’s supporting toolchain, including NPM, Webpack and Babel.
- Use features introduced with ECMAScript 6.
- Build feature-rich, interactive user interfaces with modular components.
- Implement extended React functionality with modern react libraries.
- Apply fundamental Software Development concepts to architect your web application.
- Develop one-page data-driven applications using the component-based architecture.
- Build custom components and services. Obtain and use suitable tools for developin
- Select and apply common directives for data binding, filtering, validation, and DOM manipulation.
- Use a client side library to interact with REST Services to send and receive data in JSON format.
- Automate unit-testing and end-to-end testing.

### Course Goals
This course will focus on building modern full-stack applications using a contemporary JavaScript toolchain. Students will learn to develop backends with Bun + Hono, create responsive frontends with React (Vite) + TailwindCSS + ShadCN UI, manage data with Neon/Postgres and Drizzle ORM, and integrate validation, authentication, file uploads, and deployment workflows. The emphasis is on hands-on, incremental learning through labs and projects that reflect real-world full-stack development practices.

### Course Schedule and Assignments

1 | Environment Setup : Bun runtime, Hono basics, Git workflow | Lab 1 – Kickoff & Hello API Deliverables: Bun server with 3 routes, logger middleware, curl outputs, Git repo init
2 | Routing & Validation : Hono routes, middleware, Zod schemas | Lab 2 – Routes, Middleware & Validation Deliverables: GET, POST, DELETE routes with Zod validation, custom timing middleware, curl tests & screenshots
3 | Full CRUD : PUT vs PATCH, standardized error handling | Lab 3 – CRUD & Error Handling Deliverables: PUT & PATCH routes, error helpers, curl tests (valid + invalid cases), Git commits
4 | Database Integration : Neon Postgres setup, Drizzle ORM migrations | Lab 4 – Database Setup Deliverables: Neon DB connected, Drizzle schema & migration applied, CRUD hooked into DB
5 | Frontend Setup : Vite React, TailwindCSS, ShadCN UI | Lab 5 – Frontend Initialization Deliverables: React app bootstrapped, Tailwind configured, ShadCN UI card displaying dummy data
6 | API → UI Bridge : Vite dev proxy, Hono RPC client | Lab 6 – Backend/Frontend Bridge Deliverables: Fetch API data into React via RPC client, display dynamic expenses list
7 | State Management : TanStack Query (caching, error/loading states) | Lab 7 – Query Integration Deliverables: React app using TanStack Query to fetch, cache, and refetch expenses with proper error/loading UI
