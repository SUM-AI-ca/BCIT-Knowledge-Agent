## Course Description
This focus of this course is on the application of the Canadian Electrical Code (CEC) and industrial electrical system design. This course builds from concepts learned in the circuit analysis courses, the CEC course in first year and the concurrent third term electrical equipment course and gives students the required background to design basic lighting and power distribution systems used in industry. Topics include lighting, feeder calculations and ratings, motor branch feeders, motor control centers, switchboards, unit substations, demand factors, voltage levels, grounding, fault calculations, protection and coordination, arc-flash calculations, appropriate sections of the Canadian Electrical Code and established engineering practices. Software tools will be used throughout this course.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Design feeders to meet the requirements of the Canadian Electrical Code and established engineering practices.
- Design cable tray layout including cables of different voltages.
- Design branch circuits for lighting and convenience receptacles to meet the requirements of the Canadian Electrical Code and established engineering practices.
- Design branch circuits and feeders for motors to meet the requirements of the Canadian Electrical Code and established engineering practices.
- Apply Canadian Electrical Code requirements to select the correct grounding and bonding conductor sizes for a specified system.
- Describe a grounding system design for a commercial or industrial system based on established engineering practices.
- Explain CSA voltage standards and terminology.
- Calculate fault current of typical industrial systems using established engineering practices and software tools.
- Design motor control centers (MCC) using the CEC and selected equipment manufacturers' application information.
- Select and coordinate primary fuse, secondary breaker, and motor overload relays for an MCC.
- Design lighting systems for commercial and industrial buildings based on Illumination Engineering Society recommended practices.
