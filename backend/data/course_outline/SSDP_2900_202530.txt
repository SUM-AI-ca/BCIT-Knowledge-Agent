### Course Description
​This course provides further practice and development perspective for skills covered in SSDP 2800 React Essentials but with competing frameworks. Content focuses on the benefits of the automation of features. Participants first learn development fundamentals and then practise building components, modules, and services for data-driven, client-side web applications. Exercises also include routing, asynchronous JSON transfer, validation, and automated testing.​
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Develop single-page, data-driven applications using component-based and MVC-like architectures.
- Use JavaScript to enable dynamic form entry and presentation of data.
- Build custom components and services.
- Obtain and use suitable tools for developing and debugging applications.
- Select and apply common directives for data binding, filtering, validation, and DOM manipulation.
- Asynchronously send and receive data in JSON format.
- Automate unit testing and end-to-end testing.
- Enable client-side applications to work with server-side applications while maintaining a proper separation of logic.
- ​Select architectures for reasons that include application speed, network bandwidth, development time and cost.​
