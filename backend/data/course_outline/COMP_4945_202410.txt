## Course Description
This course focuses on advanced topics in Client/Server Systems, Distributed Systems, and Network Computing. Topics reect state-of-the-art technologies being used to develop such systems and also current trends in this area. Some of these topics include: distributed objects, cloud computing, multimedia systems,web technologies and aspects of mobile computing. The emphasis is on architecting open and interoperable services.

## Course Learning Outcomes/Competencies
At the end of this course, the student will be able to:

- Design and develop components that could be distributed and accessed across platforms and operating systems.
- Develop Web applications employing platform-independent web technologies.
- Design and develop interoperable multimedia systems.
- Evaluate scalability, robustness and trust in distributed, mobile and cloud-based systems architectures.
