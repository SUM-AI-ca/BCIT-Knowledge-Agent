### Course Description
​In SSDP 1505, students learn and apply industry-standard development structures and methods for relational database design and development. The course first emphasizes structure and schema creation to ensure data accuracy and integrity. Then implementation of relational structures and management are examined through extensive coverage of Structured Query Language (SQL) for creating, reading, updating, and deleting data. A wide range of queries for joining, grouping, and aggregating data are practiced. Database objects studied also include stored procedures, views, functions, triggers, and cursors. Permissions and access management through the users and roles are examined. Common concurrency configurations are also studied. Upon successful completion, participants are able to design and build complete databases which can be integrated into other software systems.​
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Select appropriate database solutions for software systems.
- Design databases that preserve data integrity.
- Create and interpret entity relationship and Unified Modelling Language (UML) database schema diagrams.
- Implement keys, constraints, and other features of relational databases to ensure storage efficiency and accuracy.
- Manage permissions to prevent damage, theft, unwanted access, and loss of data.
- Apply the database-design process to implement a database application.
- Implement complex queries for joining, grouping, and summarizing data.
- Describe common features of concurrency control and explain why it is used.​

### Course Goals
This course provides a comprehensive foundation in relational database theory and practice. Students gain hands-on experience in schema design, data integrity enforcement, structured querying (SQL), and user access control.
By the end of the course, students will be able to construct robust, normalized databases, write complex queries, and integrate database systems into broader software solutions.

### Course topics
- Relational database fundamentals, conventions, and business requirements
- Entity-Relationship modeling (entities, attributes, cardinality, bridge tables, strong/weak relationships)
- SQL Server tools and SQL syntax
- Keys and constraints (internal/external)
- Querying: filtering, sorting, aggregates, joins, sub-selects, merges
- Temporary tables, stored procedures, and dynamic SQL
- Variables and control flow (IF–ELSE, CASE, WHILE)
- Views, cascading updates, and deletes
- Implementation best practices and database seeding
