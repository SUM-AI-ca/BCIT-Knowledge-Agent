## Course Description
This course will introduce students to the development of applications on mobile platforms. Android will be used as a basis for exploring the design and programming techniques associated with the development of standalone applications and mobile interfaces. Students will plan and design basic apps components. Students will be assessed by a combination of lab exercises, quizzes, group and individual projects.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Analyze and model requirements and constraints for the design of stand-alone mobile applications.
- Integrate content strategy with information architecture (IA), user experience (UX) and interface design (ID).
- Plan, and design user interface (UI) prototypes for usability, accessibility and user experience (UX) inspections and testing for the Android platform.
- Analyze and select appropriate evaluation methods, within an iterative design process, to improve user experience (UX) and user interface designs (UI) for the Android platform.
