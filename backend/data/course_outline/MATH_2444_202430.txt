## Course Description
(UBC BIOT 241) This is an introductory course on basic descriptive statistics and probability, and the application of computers and information technology in the field of biotechnology. The course covers the use of spreadsheets as tools for the manipulation, basic statistical analysis and presentation of biological data. The use of appropriate computer tools for more advanced analysis of data and to access biological databases is introduced in the latter half of the course.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Use software to create spreadsheets which analyze and present experimental data and values based on mathematical models of biological systems.
- Use statistical software for the presentation of biological data.
- Access biological databases and use biological database analysis tools, using R and/or Python.
- Construct class frequency and histograms.
- Compute measures of central tendency (mean, median, mode), explain the advantages and disadvantages of each.
- Compute measures of variation (standard deviation, range, interquartile range), explain the advantages and disadvantages of each.
- Compute five-number summaries and construct boxplots.
- Use regression and correlation to estimate trends in data.

## Course Goals
The course consists of statistical concepts and data analysis. Software tools for data analysis and bioinformatics applications are introduced, including Excel, Minitab, R, and the Python programming language. A series of assignments is designed to give the student experience with spreadsheets, statistical data analysis and programming for biological database access. The technical content of the assignments will vary. Software issues emphasized include

Spreadsheets:

- use of formulas, replication through copy/paste operations, built-in functions
- plotting
- programming in Excel

Programming with R and/or Python to acquiring and analyzing scientific data, R for bioinformatic searches (e.g. NCBI)
