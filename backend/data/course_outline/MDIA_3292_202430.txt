## Course Description
This course explores the new HTML5 and CSS3 standards as well as some of the peripheral technologies being put forth from the WC3. Focusing on the new semantic tags and media elements, this course will introduce students to the best practices for creating rich document structures and using advanced design patterns. This course will also focus on best practices for site development; from the planning phase to backup strategies. Students will be assessed by a combination of quizzes and individual projects.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Explain the meaning and proper usage of the semantic tags introduced in the HTML 5 standard.
- Create valid HTML documents based on the WC3 HTML5 doctype.
- Build, style and validate forms with HTML5 attributes and regular expressions.
- Add media elements to a web page using the audio and video tags.
- Walk through the steps professionals use to develop web sites.
- Implement an offline backup system for a web project.
- Use advanced workflow patterns and tools for larger project creation (Library / Frameworks)
- Execute the integration of advanced development tools (CSS Preprocessors, Dynamic Layouts)
- Demonstrate the use of Version Control and Team Integration (Git)

Unexcused absences in excess of 10% of the time prescribed for this course may result in the assignment of a failing grade. Attendance may be taken at any time during class.
