## Course Description
This course completes the overall Information Technology (IT) framework introduced in Comp 3910, and offers the student the opportunity to apply IT skills in a realistic work environment. In particular, this course will focus on: Information systems planning and management; Project management for medium and large teams; Software Development Lifecycle (SDLC) issues; Component technology using Enterprise Java Beans (EJBs); Advanced Java, Web component, Java EE, .NET, Visual Studio, Microsoft BackOffice and/or Microsoft Office Technologies, as appropriate.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Work in a structured, team environment.
- Use the Unified Process in a team environment.
- Produce the artifacts required by the Unified Process.
- Experience the principle roles defined by the Unified Process in a team environment.
- Make and keep commitments.
- Plan and track software development activities.
- Organize and operate day to day IS operations.
- Participate in peer assessments and structured performance reviews.
- Program effectively with advanced techniques such as:
- JSF, Facelets, JSP
- Java EE EJBs
- CDI
- Microsoft's .NET
- MySQL or SQL Server databases
- Incorporate multi-tier development strategies in transaction processing systems, such as:
- 2-tier, 3-tier, multi-tier
- Data access methodologies, Object to Relational Mapping
- Distributed Objects (Java EE)
