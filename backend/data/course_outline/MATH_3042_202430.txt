## Course Description
The course introduces descriptive and inferential statistics. The descriptive statistics will concentrate on using these methods for exploratory data analysis. Basic probability and probability distributions are used with an emphasis on their use in computer simulation methods. Inferential statistical methods and regression are introduced to lay the groundwork for decision making and prediction. In all parts of the course, current computer applications (i.e. R) will be used to perform statistical analyses and simulation programming.

## Course Learning Outcomes/Competencies
Upon successful compleltion of this course, the student will be able to:

- Summarize data using standard numerical statistical measures.
- Visualize data with statistical graphical methods.
- Apply the basic rules of probability and Bayes' theorem.
- Perform stochastic simulations using discrete and continuous probability distributions.
- Apply inferential techniques (e.g. hypothesis testing, confidence intervals) to make a decision.
- Assess data validity.
- Apply regression methods on data to make predictions.
- Use current computer tools to aid in statistical enquiries.
- Explain basic Bayesian statistical methods.

· Hardware: The midterm and final exam will be done in R and R Studio on your own device, so a computer with R and R Studio installed will be required.
