## Course Description
The course teaches User Interface Design (UI) and User Experience (UX) as a strategic area of development for new media. This involves assessing the technical needs of an interface and the appropriate delivery platform. By understanding the power and limitations of Interface Design and User Experience tools and how to work with them, students will create prototyping systems that effectively employ colour, layout, and typography to receive user feedback. The students will learn about design methods, design process, testing and inspections of user interfaces as well as prototyping in three levels of fidelity both on paper and digitally. Students will be assessed by a combination of quizzes, group and individual projects.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Integrate Information Architecture principles to user experience and interface design.
- Recognize the main disciplines of web usability, interface design and user experience.
- Evaluate and critique web site interfaces under industry standards.
- Demonstrate user and task analysis processes.
- Design and conduct usability testing and web evaluations.
- Design and implement app and website prototypes.
- Design low, medium and high-fidelity prototypes (paper and digital).
- Discuss ethical issues involved in testing interactive user interfaces.
