## Course Description
​This course covers advanced geospatial programming technologies. Topics include accessing the latest cloud and on premises geospatial datastores, working with the latest geospatial APIs, and comparing application patterns, responsive and reactive frameworks. Students will create various UI-based applications for the web and web-mobile realms. ​

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Create applications that display geospatial information.
- Integrate geospatial APIs that demonstrate encapsulation, inheritance, polymorphism, abstraction, and serialization.
- Implement structured error handling.
- Incorporate event driven architectures in geospatial solutions.
- Access and update geospatial datastores.
- Compare application patterns such as: MVC, MVP and MVVM.
- Create applications that integrate the latest web and web-mobile geospatial technologies.
- Compare COTS, MOTS, GOTS and NOTS solutions​.
