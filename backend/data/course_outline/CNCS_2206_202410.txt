## Course Description
This course is a practical application of machine centre setup and operation. Home position, work coordinates, tool offsets, screen reading, tool setup and job holding are covered.

## Course Learning Outcomes/Competencies
Upon successful completion, the student will be able to:

- Job set up on CNC machine centre.
- Safety operate the CNC machine centre.
- Inspect the 1st off part and correct adjust the offset.
- Create set up sheet and part inspection sheet.
- Produce the part on specification from the engineering drawing.
