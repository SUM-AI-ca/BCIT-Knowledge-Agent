## Course Description
This course focuses on the multiple platforms and solutions that can be used to create and launch an online store. These include open source and Software as a Service (SaaS) platforms to provide a foundation for work with e-commerce solutions Course topics include all stages of the preparation, configuration, and setup of a secure online store. Students will determine the appropriate tools necessary to configure and securely operate an online store for various products and services. Learners will then review tool features, configure settings for product samples, price options, and manage shipping options. Students will also learn and use the relevant templating or theming languages and methods to customize the design, layout, and functionality of their online store and further customize functionality using extensions. Once the store is set up, students will use best practices to secure the store, connect payment gateways, and test the payment process to complete the entire e-commerce purchasing process. Evaluation will include assignments.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Determine the appropriate e-commerce platform for a given product, service, or business.
- Set up and configure an online store using an open source platform or SaaS platform.
- Configure online stores for physical products (stock management, shipping) and digital products.
- Customize the design and layout of an online store using code and non-coding options.
- Customize and extend the functionality of an online store using plugins/extensions.
- Explain best practices for securing online stores.
- Use best practices for securing online stores to set up payment gateway accounts and connect payment gateways.
- Test the purchasing process for customers and store owners.
