## Course Description
​This course assists students enrolled in their Capstone Project course. Students conduct a systematic literature review including techniques for proper referencing of all sources. As they form their project report, students have opportunity for feedback on the logical flow and clarity of their written report, Topics include literature reviews, report organization, document design, editing techniques, and use of proper citation.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Analyse the audience and define the purpose for the Capstone Project report.
- Systematically review literature to select relevant information for the project.
- Critically evaluate information to determine if it is accurate, relevant, and complete and to use critical thinking to develop strong arguments.
- Write and edit a Capstone Project report which focuses on the reader; presents the material logically; uses concise, clear wording; uses direct pattern to get to the point; provides accurate information; satisfies the document specifications; and explains technical concepts to a non-technical audience.
- Use proper citation methods to reference sources and avoid plagiarism.
