## Course Description
Engage with one of the most powerful applications used in graphic design today. Students will explore the basics of the InDesign interface and its most used features in order to create an array of printed and digital layouts. Students will learn how to manipulate and position layout elements such as text, illustrations and photographs by applying design and typographic principles and terminology. You will work through a variety of print and digital media projects using the versatile InDesign tools and techniques to discover the possibilities for creative expression that come with mastering this application.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Set up multiple layouts structured by a modular and baseline grid.
- Analyze a publication using typesetting and layout terminology and vocabulary.
- Select typefaces for specific usage such as body copy, headings, and captions.
- Format type and paragraphs using typesetting conventions.
- Establish a hierarchy of information in a layout.
- Format various styles of lists including hanging indents, numbers, bullets, and lists within lists.
- Create, apply, and manage colour within a document.
- Understand the meaning and relevance behind hidden or special characters.
- Create basic master pages.
- Automate text formatting with basic paragraph and character styles.
- Organize content using the stacking order and layers.
- Integrate vector and raster graphics created in Adobe Illustrator and Photoshop.
- Develop creative layout solutions by means of a cumulative and conceptual design process.
