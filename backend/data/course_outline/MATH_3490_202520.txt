### Course Description
An online course in Numerical Methods. Topics include: numerical integration, solution of non-linear equations, linear programming, numerical differentiation, solution of systems of linear equations and differential equations.
### Learning Resources
- Internet connection to access the Learning Hub
- Web browser: Chrome , Firefox or Edge
- Scanner or camera: high enough quality so that hand-written assignments can be submitted electronically in pdf format
- Microsoft Excel
- Scientific Calculator (i.e. Sharp 520 or equivalent)
No textbook required as all learning resources will be available through the Learning Hub.

### Course topics
- Numerical Integration Rectangle Rule Trapezoid Rule Simpson's Rule Integration with unequal segments Error Analysis Applications of Numerical Integration
- Numerical Methods for solving Differential Equations Euler's Method Modified Euler's Method Runge-Kutta Applications of DE
- Numerical Differentiation Central Difference Formulas Forward and Backward Difference Formulas
- Numerical Methods for solving Non-Linear Equations Method of Bisection Newton's Method Secant Method Finding roots of polynomials Complex Conjugate Root Theorem Descartes Rule of Signs Cauchy's Bound Theorem
- Solution of Systems of Linear Equations Gauss-Jordan Elimination Consistency of Systems of Linear Equations
- Linear Programming (Simplex Method) Simplex method Applications
