### Course Description
​This course introduces current mainstream JavaScript frameworks for developing modularized single-page applications. Content focuses on the benefits of the automation of features. Participants first learn development fundamentals and then practise building components, modules, and services for data-driven, client-side web applications. Exercises also include routing, asynchronous JSON transfer, and validation. Automated testing is introduced as well. ​
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Develop single-page, data-driven applications using component-based and MVC-like architectures.
- Use JavaScript to enable dynamic form entry and presentation of data.
- Build custom components and services.
- Obtain and use suitable tools for developing and debugging applications.
- Select and apply common directives for data binding, filtering, validation, and DOM manipulation.
- Asynchronously send and receive data in JSON format.
- Automate unit testing and end-to-end testing.
- Enable client-side applications to work with server-side applications while maintaining a proper separation of logic.
- Select architectures for reasons that include application speed, network bandwidth, development time and cost.​

### Course Goals
Upon successful completion of this course, students will be able to use the React framework to build interactive, data-driven single-page applications. They will gain experience structuring projects with components, props, and state; handling form input and validation; and connecting client-side applications with server-side data through asynchronous JSON. Assignments such as a shopping cart, a quote-of-the-day app, and a calculator give students the chance to practice core patterns for managing state, routing, and UI updates in real-time. The course also introduces automated testing and emphasizes evaluating architectural choices for performance, scalability, and maintainability—skills that prepare students to confidently apply React in professional web development.
