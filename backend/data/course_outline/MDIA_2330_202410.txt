## Course Description
Apply best practices in user interface (UI) design and user experience (UX) to create a design prototype. Learn technical tips and tricks and to apply the technical workflow of UI and UX using current design tools such as Adobe XD, Photoshop, and Illustrator. Working on applied projects to identify key user needs, students work individually and in groups to develop design decisions that inform a web or app user interface prototype development. Students are assessed through a combination of individual assignments and a group project.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Demonstrate the use of Adobe XD, Photoshop and Illustrator integrated to plan, design and deploy a Web or App prototype.
- Demonstrate the use of Adobe XD, Spark and other Adobe tools to share safely and collaborate remotely.
- Recognize and apply the use of images, UI libraries (icons, control and navigation visuals packs) for the design of user interfaces for web and mobile.
- Follow principles and guidelines based on UX research, typography for interactive media and colour theory to select the most effective typefaces for a given prototype.
- Recognize and understand the limitations of the Adobe design applications' features against other UI and UX design tools used by industry.
