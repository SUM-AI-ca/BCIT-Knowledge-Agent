## Course Description
This course focuses on providing the skills and knowledge necessary to implement Cisco Collaboration and Unified Communication solutions. This course first explores the traditional telephone system, voice communications, codecs, and voice technology. Next, it moves to the fundamental of Voice over IP (VoIP), Cisco Unified Communications Manager (CUCME), as well as external communication with the Cisco Unified Communications Manager (CUCM) Express. This course describes telephony features supported in CUCME and CUCM, also covers the class of restriction, call handling features and quality of service. Other topics that are covered include phone restriction, device configuration, and user access to CUCM. Students will learn about the Cisco Unity Connection, Cisco Unified Presence, and troubleshooting. This course includes practical labs relating to the day to day administration using the Cisco Collaboration solution to complete the common tasks.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe Voice Technology & Communications
- Describe VoIP Terms And Technologies
- Describe Voice Codecs Technologies
- Identify the Basics Of Voice Ports
- Identify Network Requirements For VoIP
- Configure Cisco Unified Communications Manager Express (CUCME) Basic Configuration
- Configure Dial-Peer in CUCME
- Configure Class Of Restriction In CUCME
- Implement Call Handling Features In CUCME
- Describe Quality Of Service Models And Mechanisms
- Register Phones in Cisco Unified Communications Manager(CUCM)
- Configure DHCP For Device Registration in CUCM
- Register Devices In CUCM
- Configure LDAP Synchronization With CUCM
- Manage CUCM Dial Plan Administration
- Configure Telephony Features In CUCM
- Configure CUCM Connection To Cisco Unity Connection (CUC)
- Configure CUCM For Cisco Unified Presence (CUP)
- Troubleshooting Phone Registration Issues
- Troubleshooting Call Routing Issues
