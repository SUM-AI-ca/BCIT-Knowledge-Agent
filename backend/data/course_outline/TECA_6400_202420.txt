## Course Description
In this course students develop object-oriented scripts with Python. The focus is on problem-solving in scripts, proper object-oriented programming (OOP) techniques, and clear coding style. The fundamental principles of OOP (data abstraction, encapsulation, inheritance and polymorphism) are covered with emphasis on inheritance and polymorphism. Students will examine data structures such as linked lists, queues, stacks, trees and common search and sort algorithms. Students will also explore scripting in more depth, creating interfaces, tools, exception handling and user interfaces in Python.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Identify the appropriate data structure or container class for modeling a given problem.
- Implement user-defined data structures in Python, such as lists and trees.
- Apply the techniques of decomposition to break a program into smaller pieces.
- Design, implement, and test programs using the main principles of object-oriented programming: data abstraction, encapsulation, inheritance, and polymorphism.
- Report on the concept of recursion and give examples of its use.
- Design, code, and debug graphical user interfaces with event-driven programs that respond to user events.
- Build robust scripts using exception handling.
- Discuss the computational efficiency of the principal algorithms for sorting, searching, and hashing.
- Explain the execution environment.

## Course Goals
This course takes a deeper dive into the fundamentals of software design and development. Students will expand their knowledge of the Python programming language as they learn to read, design, and compose higher-level data types. They will learn to recognize common code patterns and how they can be applied effectively. Students will also learn industry-standard tools and workflows for writing code in high quality software projects.
