## Course Description
In this course, students will build on their programming and scripting skills within industry standard 3D applications. Programming with Python, students will apply standard coding practices used by technical artists in developing expressions, user interfaces, tools, and functions. In addition, students will learn the essential elements of user-centric design and user experience. ​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Write Python scripts in 3D applications.
- Design user-friendly interfaces.
- Develop a user interface within industry standard 3D applications.
- Create expressions for node attributes.
- Program procedural shader animation.
- Animate textures through expressions.
- Create connections between nodes through expressions.
- Build simple tools inside 3D applications.
