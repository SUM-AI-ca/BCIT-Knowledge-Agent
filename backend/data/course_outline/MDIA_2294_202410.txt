## Course Description
This course concentrates on introducing students to the fundamentals of coding, with an emphasis on JavaScript. Students will be instructed in the core principles and best practices of writing code. Students will move through the fundamentals of JavaScript to developing and extending with the JavaScript framework; jQuery. To fully understand how JavaScript works, students will be asked to write their code manually using a text editor. Students will be assessed by a combination of quizzes, group and individual projects.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Recognize ECMA structures and syntax.
- Identify logical, math, assignment and comparison operators.
- Code variables to store and retrieve data.
- Identify simple and complex JavaScript datatypes.
- Use conditionals to control the flow of a script.
- Use loops to repeat commands and iterate over objects.
- Define reusable commands with functions.
- Identify and apply programming best practices.
- Explain and apply jQuery to select and manipulate elements in the DOM (Document Object Model).
- Extend the functionality of jQuery through plug-ins.
