## Course Description
​This course focuses on the configuration and testing of real-world radio systems. Students will configure, modify, test and document digital radio systems using both conventional and trunked mode operation. Cellular system concepts are introduced, over several generations. Radio over IP (RoIP) technology, using TCP/IP networks, is investigated. Students will build and test advanced antenna systems and study radio site DC Uninterruptible Power Supply​ (UPS) power systems. Students will learn how to correctly use technical manuals and radio system documentation. Advanced troubleshooting methodologies are explored in the lab using logical fault-finding. Additional installation training will be provided in industry-specific hand skills related to rack mounting radio and network system equipment. General safety practices specifically related to the RF industry will also be reviewed.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Explain the basic components of a communications network.
- Configure and test an antenna network.
- Configure, test, modify, and document a digital radio system's conventional repeater.
- Describe and analyze a Radio over IP (RoIP) data communications system.
- Explain the operation of a cellular service communications network.
- Use technical manuals and system documentation for configuration and troubleshooting of radio systems.
- Demonstrate industry-standard radio rack mounting procedures using as-built drawings.
- Analyze and modify the configuration of an LMR trunked radio system.
- Operate and test a DC UPS.
- Demonstrate various troubleshooting methodologies.
- Demonstrate workplace safety practices.
