### Course Description
​This course immerses students in geospatial programming by developing various applications with well-known application programmable interfaces (API) and integrated development environments (IDE). The course expands into the automation of vector geospatial analysis and modelling. It concludes with publishing geospatial data sources such as maps and applications via the web/cloud.​
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Describe and distinguish between spatial concepts, structures, formats and sources of geospatial cloud and services.
- Use and evaluate desktop, web and mobile applications that access the geospatial cloud and services.
- Discuss the technical, organizational, social issues, policies, and standards related to geospatial mobile cloud.
- Compare and use tools for GIS queries, vector geoprocessing, network analysis, big data and NoSQL analytics.
- Evaluate and recommend the appropriate approach for analyzing the various attributes and geospatial data models for a given scenario.
- Demonstrate spatial analytical skills such as process modelling, enrichment, overlays, and proximity.
- Use tools that clean and prepare data for use with GIS, network, big data, and NoSQL.
- Describe concepts, current trends and choice for tooling, techniques and languages when building geospatial applications.
- Plan, design, build, test and deploy geospatial applications that integrate geospatial APIs.
- Create programs that clean and prepare data for use with GIS, network, big data and NoSQL tools.​
