## Course Description
In this course, students will explore Microsoft Windows network applications including: System Center Operations Manager, Service Manager, and Configuration Manager. Students will have the opportunity to deploy and configure Microsoft SharePoint. Microsoft Azure Cloud Administration will also be covered.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the capabilities of each of the Microsoft System Center suite of products
- Install and configure the Microsoft System Center suite of products
- Describe the capabilities of Microsoft SharePoint services as a collaboration platform
- Install SharePoint on the Microsoft Server platform
- Explain how to use SharePoint Lists and Libraries, Users and Permissions, and user profiles
- Configure SharePoint user profiles and policies
- Manage documents within a SharePoint environment
- Monitor, optimize, and maintain a SharePoint environment
- Demonstrate implementing Azure identities and governance
- Demonstrate managing Azure storage
- Demonstrate implementing virtual networking in Azure
- Demonstrate managing Azure resources
