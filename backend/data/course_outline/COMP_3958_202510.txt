## Course Description
This course introduces functional programming techniques and data structures. The course looks at the features that a functional language provides that allow developers to write expressive and concise programs. Topics covered include higher-order functions, algebraic data types, data abstraction and the implementation of selected data structures.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Apply the functional paradigm to create extensible programs.
- Analyze and explain the behaviour of programs involving functional design.
- Apply functional decomposition to break a program into multiple functions.
- Apply functional idioms and patterns.
- Build data structures in a clean and efficient way.
- Design and implement tests for functional programs.

## Course Specific Requirements
1) You must pass the exam component in order to be able to pass the course. The midterm exam will be calculated out of 10 marks, the final exam out of 15 marks. The total score of the two exams is thus 25 marks. Under this calculation, you must score a total of at least 12.5 marks on the exams.

2) You must pass the lab component in order to be able to pass the course, i.e., your total lab score must be at least 50% of the maximum total lab score.

If you do not meet the above 2 requirements, you will fail this course regardless of your overall score.
