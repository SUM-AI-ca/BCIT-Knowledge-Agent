## Course Description
This hands-on course is designed for students who are able to code medium sized applications in an Object-Oriented language. Students design and develop apps to Apple standards for the latest iOS platform. Participants will be required to specify, design and build a significant iOS application. The course starts with an overview of the Swift programming language, followed by an introduction to the iOS platform. Special attention is given to the user interface components of current popular iPhone and iPad applications.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Utilize the Objective-C or the Swift programming language including classes, protocols, properties, conditionals, instance variables, strings, arrays, loops, and methods.
- Employ basic Debugging and troubleshooting.
- Handle user touches, connect to the Internet, utilize accelerometer, timers, and location.
- Specify, design and build an iOS application.
- Creating a universal app that will run on both iPhone and iPad devices.
- Discuss the differences between designing an iPad vs iPhone application.
- Publish and submit an iOS application to the Apple App Store.
