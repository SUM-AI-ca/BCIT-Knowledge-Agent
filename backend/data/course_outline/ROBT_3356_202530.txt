## Course Description
Investigates the software and hardware involved in the real-time control of a microprocessor -based system. Topics include microprocessor architecture, assembly language programming, input/output operations, handshaking, protocols, timer system, interrupt handling, address decoding and interfacing techniques. Troubleshooting techniques used in a fault analysis are also taught. Throughout the course, a single board microcontroller system is used to facilitate a detailed analysis of hardware and software involved. An automated controller system is designed, built and tested.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Identify the various types of industrial controllers and their application to manufacturing automation.
- Recognize the main functional blocks of an embedded controller.
- Describe the programmer's model and memory map of an embedded controller.
- Design, debug and document software for control applications using development tools.
- Interface input/output devices.
- Use interrupts for interfacing.
- Apply timer/counter operations to real-time control applications.
- Analyze bus signals to troubleshoot digital control systems.
- Design and build address decoders for memory interfacing and port realization.

## Course topics
Week: Material Covered
1-2: Course overview. Comparative Introduction to microprocessors and microcontrollers. Architecture and hardware, SW/programming. Memory maps and I/O peripherals.
2: Memory Types (RAM, FLASH). Intro to MSP430F5529 HW architecture and operation.
3: Programming microcontrollers. Introduction to FW development with micro-controllers. Assembly Language versus C.
3-4: Assembly Language Programming: MSP430 Instruction Set and Programmers Model. Instruction Set Architecture (ISA), addressing modes
5-6: Assembly Language Programming: memory transfer operations, arithmetic/logical operations, branching instructions, emulated instructions
6: Assembly Language Programming: subroutines, the stack and parameter passing.
7: C programming: Functions, the stack and parameter passing. Pointers.
8-9: Principles of Digital I/O interfacing. GPIO, strobed parallel I/O, current drive/sink considerations, interface timing.
10-11: Interrupts, ISR development in assembler and C.
11-12: Timers. Output functions (PWM), Input timing (frequency, period). Real time interrupt processing in assembler and C.
12-13: Introduction to Digital Serial Communications. UART/RS-232, SPI, I2C
14: The final week will be devoted to review and possibly special topics
15: Final Exam Week
