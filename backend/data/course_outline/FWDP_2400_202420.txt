## Course Description
This course shifts the focus from client-side to server-side programming utilizing PHP and MySQL. An introduction to PHP fundamentals and the role it plays in generating dynamic websites will be covered. Students will review the differences between client-side scripting and server-side scripting and learn how to recognize where scripting solutions are necessary or useful. Students will also use basic scripting techniques, write and use functions, perform HTML form validation and process, and use regular expressions for string pattern matching. In addition, students will learn to manage cookies and session handling, construct basic SQL statements, use and manipulate databases, store and retrieve content, and work with open source scripts. Evaluation will include in-class participation and assignments.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the difference between client-side scripting and server-side scripting.
- Recognize where scripting solutions are required/desirable.
- Use fundamental scripting techniques: data types, variables, flow control structures, and Boolean logic.
- Write and use functions.
- Perform HTML form validation and processing.
- Use regular expressions for string pattern matching.
- Manage files and folders on the server side.
- Utilize cookie management and session handling to maintain state.
- Construct basic SQL statements.
- Perform database interactions and manipulation.
- Store and retrieve content using PHP and MySQL.
- Find, use, and customize open source scripts.
