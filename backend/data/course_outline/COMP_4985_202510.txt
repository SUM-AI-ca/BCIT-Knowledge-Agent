## Course Description
Covers advanced Windows Systems Programming for Data Communications. Develop TCP/IP Interneworking applications using the Windows Socket API. Develop Windows client-server models using Internet Protocol Suite. Design and implement Multimedia Communication Applications using the Internet Protocol Suite. Design and implementation of Mobile Network Applications on the Android platform.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Develop Client-Server models for the Windows environment using the TCP/IP protocol suite.
- Implement advanced communications protocols under the Windows environment.
- Design and implement TCP/IP and UDP/IP socket applications to transfer Multimedia content in a networked environment.
- Design and develop highly specialized communications software within a project team.
- Design and implement TCP/IP applications for mobile devices using the Android platform.
- Implement code to communicate with built-in sensors on a mobile device such as GPS, NFC, and audio devices.
