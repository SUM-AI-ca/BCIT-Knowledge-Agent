## Course Description
​This course will provide the student with an introduction to more advanced computing methods related to building a simple game engine. The course will focus on materials not covered in other programming courses and will include topics on advanced programming, optimization, multi-threading, real-time programming considerations and hardware interfaces. Students will be exposed to different technologies and programming environments. Students will also learn basic physics concepts and how to apply them when building a game engine. These concepts include basic physics and mathematics governing natural phenomena such as force, kinematics, inertia, and momentum.​ Students are recommended to have C++ knowledge.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Optimize code to consider speed and size constraints.
- Solve problems related to synchronization across threads and processes.
- Adapt and optimize code to different underlying hardware architectures.
- Design and create a simple multi-threaded game engine.
- Apply the concepts of mass, centre of mass, moment of inertia and calculate these for a collection of masses in a game engine.
- Apply the concepts of linear and angular displacement, velocity and acceleration in a game engine.
- Apply vector forces and the relationship between force and acceleration in a game engine.
- Apply rigid body collision response, linear and angular impulse and friction in a game engine.
- Apply the above concepts to solve problems related to movement, acceleration, friction and collision detection related to movement simulation in a game engine.​

## Course Goals
Students will design and implement their own game engine, and then use it to build a fully playable game. Along the way, they’ll explore core concepts in game programming, systems design, and interactive media.
