## Course Description
This course focuses on programming both front and back end for web application development using JavaScript on both front-end and back-end development. Topics include AJAX, DOM editing with JavaScript & jQuery, and JSON.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Create JavaScript classes and objects.
- Create JavaScript code that handles various types of events on the client side.
- Apply the standard three-tiered web architecture (data, application, presentation) and how to design a web app with that architecture.
- Utilize various storage mechanisms on both the client-side and server-side for session and app data requirements.
- Design and implement a Progressive Web Application (PWA).
- Apply core JavaScript concepts such as functions as objects, various different iterative and conditional control constructs, and how JSON is utilized.
- Install, configure, and use a web server.
- Create animation and transition effects within a web page.
- Utilize current CSS selector types in order to interact with the DOM.
- Utilize JavaScript functions as callbacks within an asynchronous design.

## Course Schedule and Assignments
Week Number: Week Of: Topics
Week 1: Jan. 6: Overview of the Web: * How the Web Works * Tools of the Trade: IDEs, Browsers, and Developer Tools * Introduction to HTML5: Structure of a Web Page Basics of HTML: * Elements, Tags, Attributes, Nesting, Comments * HTML Elements: Headings, Paragraphs, Text Formatting, Links and Images, Lists, Tables, Forms, Semantic Elements
Week 2: Jan. 13: Basics of CSS * Selectors, Properties, and Values * CSS Syntax, Selectors, Colors, Backgrounds, Borders, Margins, Padding, Height/Width, Text, Fonts, Tables, Display, Max-width, Overflow, Float, Inline-block, Align, Pseudo-class, Pseudo-element, Units, Specificity * Introduction to CSS Frameworks: Tailwind
Week 3: Jan. 20: CSS Part II * CSS Box Model: Margin, Border, Padding, Content * CSS Display: Block, Inline, Inline-block, None * CSS Positioning: Static, Relative, Absolute, Fixed * CSS Float and Clear * CSS Flexbox: Flex Container, Flex Items, Flex Direction, Justify Content, Align Items, Align Content, Flex Wrap, Flex Flow, Flex Grow, Flex Shrink, Flex Basis, Align Self
Week 4: Jan.27: Introduction to JavaScript * What is JavaScript, and where is it used? * JS Syntax: Understanding Statements, Expressions, and Code Blocks * JS Variables: Declaring Variables with var, let, and const * Data Types: Numbers, Strings, Booleans, Undefined, Null, and Symbol * JS Operators: Arithmetic, Assignment, Comparison, Logical, and String Operators * Control Structures: If-Else Statements, Switch Statements, and Loops (For, While) * Functions: Defining and Invoking Functions, Function Expressions, Arrow Functions * Arrays: Creating, Accessing, and Modifying Arrays, Common Array Methods * Objects: Creating Objects, Accessing Properties, Adding/Modifying Properties
Week 5: Feb. 3: JavaScript Part II * Advanced Functions: Callback Functions, Closures, Higher-Order Functions * Scope and Hoisting: Understanding Function Scope, Block Scope, and Variable Hoisting * JavaScript ES6+ Features: Destructuring, Spread/Rest Operators, Template Literals * Error Handling: Try/Catch Statements, Handling Errors Gracefully * JavaScript Modules: Import/Export, Module Patterns
Week 6: Feb. 1: jQuery * Master advanced techniques for traversing and modifying DOM elements, attributes, and styles. * Develop expertise in event handling, including interactions, propagation, and delegation. * Implement effective form handling and validation strategies. * Gain foundational knowledge of AJAX for asynchronous data requests. * Work with JSON for parsing, serializing, and interacting with API data. * Explore asynchronous programming concepts, including Promises, Async/Await, and the Fetch API. * Enhance skills in navigating and interacting with DOM elements efficiently. * Refine skills in manipulating the Document Object Model (DOM). * Strengthen understanding of event handling in web development. * Explore dynamic styling through JavaScript-driven CSS manipulation.
Week 7: Feb. 17: Midterm Practice
Week 8: Feb. 24: Midterm Exam Week
Week 9: Mar. 3: Vanilla JS
Week 10: Mar. 10: Node.js * Understand the fundamentals of Node.js, including server-side JavaScript and asynchronous programming. * Explore core Node.js capabilities, such as server-side scripting, file operations, and database interaction. * Differentiate between server-side and client-side JavaScript functionalities. Express.js * Gain an overview of Express.js and learn how to build and configure Express applications. * Manage routes and handle requests and responses effectively in Express.js. * Enhance application functionality using middleware and templating engines.
Week 11: Mar. 17: Express.js * Develop robust Express applications by managing routes for various HTTP methods. * Access and process request data effectively to handle client inputs. * Deliver dynamic responses using advanced response handling techniques. * Implement and utilize middleware to enhance application functionality. * Manage user sessions to support stateful interactions in web applications.
Week 12: Mar. 24: MongoDB * Explore the fundamentals and key features of MongoDB. * Learn how to set up and connect to a MongoDB database. * Master essential data operations in MongoDB, including creating, retrieving, updating, and deleting documents.
