## Course Description
​This course introduces geospatial data design, acquisition, and management used in the geomatics industry. Topics are focused on geographic information systems (GIS) and cover spatial databases and design (RDBMS), acquiring and working with spatial and aspatial data, and data management.​

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe different database systems, including hierarchical, network, relational and object-models.
- Explain GIS data-modelling through the abstraction levels of conceptual, logical, and physical.
- Explain how real-world features are modelled in a GIS using either the object model (vector) or the field model (raster).
- Explain the use of topology, dynamic segmentation, and linear referencing.
- Describe how spatial data is coded and stored in a relational geodatabase.
- Explain how GIS enterprise systems are connected to the geodatabase using the relational database model.
- Plan and create land information related datasets using knowledge of data integration methods and tools, ETL, and best practices.
- Apply relevant knowledge for inserting, updating, deleting and querying of data, using both SQL- and GUI-based tools.
- Explain what a data warehouse is and identify one for each of the following types: municipal, provincial, federal, and private sector.
- Discuss data-acquisition methods, best practices, and standards for field collection programs and data sharing.
- Plan an appropriate data quality strategy for a variety of geospatial data.
- Describe, contrast, and discuss the challenges with the five major steps in GIS project implementation.
- Explain the importance of data standards, security, confidentiality, and metadata for good data management.
