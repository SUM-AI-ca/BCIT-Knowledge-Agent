## Course Description
This course introduces students to the basic concepts and practices of web-based animation. Students will learn fundamental production and animation techniques, creating interactive presentations, managing timelines and site structures, importing graphics from other applications and basic scripting techniques. Students will be introduced to several web animation libraries and frameworks, after which they will be able to compare the features and shortcomings of each. Students will be assessed by a written evaluation and individual projects.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Create timeline animations using current CSS3 methods.
- Describe how key-frames operate to change and animate properties.
- Use easing functions to adjust the pacing of an animation.
- Demonstrate the use of multiple timelines in creating complex animation.
- Identify web animation workflows.
- Demonstrate the use of animation work environments.
- Demonstrate the use of HTML5 Canvas and SVG.
- Integrate JavaScript techniques such as timers to trigger actions
- Use current libraries and frameworks to develop HTML5 animations
