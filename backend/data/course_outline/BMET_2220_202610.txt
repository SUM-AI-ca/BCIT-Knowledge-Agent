### Course Description
​This is a hands-on workshop for biomedical engineering technology students. The workshop will introduce students to correct use of general hand tools and basic mechanical skills as employed in the profession. Safe working practice appropriate to shop activities will be emphasized.
### Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:
- Recognize and name common hand tools employed in biomedical engineering.
- Identify and select appropriate hand tools for mechanical tasks in the biomedical engineering profession.
- Safely and correctly use hand tools for mechanical tasks in the biomedical engineering profession.
- Perform basic metal working skills including layout, material identification, drilling, tapping, and thread repair, cutting and forming sheet metal, filing, clamping, etc.
- Apply safe working practice appropriate to shop activities.

### Course topics
Projects:
Aluminum Block
Students will use various procedures and tools to create a precisely sized aluminum block with threaded holes.
Fastener ID
Students will identify various fasteners and use the correct tool to thread the fasteners into a block.
Soft Jaws
Students will create a set of soft bench vise jaws for use in this course and in the future.
PC Board holder
Students will use a variety of materials, procedures, and tools to create a simple clamping device for holding printed circuit boards.
USB Phone Charger
Student will create an emergency phone charger which will run off of a 9V battery.
