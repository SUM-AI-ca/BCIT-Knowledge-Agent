## Course Description
​Students will learn to install and configure a Microsoft Windows Active Directory Environment in preparation for messaging services deployment. Students will also learn to install, configure, and administer an enterprise messaging system that is integrated with Active Directory. The course will introduce the theory behind messaging systems, and provide students with hands-on activities to install, maintain, customize, and troubleshoot Microsoft Exchange Server and clients.

## Course Learning Outcomes/Competencies
Upon successful completion of this course, the student will be able to:

- Describe the functions of an enterprise messaging system
- Explain how messaging services integrate with Microsoft Active Directory services
- Install and configure Microsoft Exchange Servers
- Activate and configure Server roles
- Configure messaging recipient parameters including groups and mailboxes
- Implement bulk management of mail-enabled objects
- Describe the Microsoft Exchange Infrastructure components
- Configure Microsoft Exchange connectors, transport rules, certificate services, and e-mail policies
- Provide monitoring and reporting services on mail queues, system performance, and perform message tracking
- Describe high availability solutions for mailbox Servers
