## Courses

Class hours

### Required Courses:

TSPP 1010 - Network Fundamentals

Outline URL: https://www.bcit.ca/outlines/tspp1010/

Credits: 5.5

Description: This course introduces students to the basic design, implementation, and terminology related to data communications and networking. Students learn the OSI model, as well as the TCP/IP protocol suite used throughout the course to demonstrate concepts and implementation. Topics include: network topology, protocols, transmission media, switching techniques, access control and addressing for wired and wireless networks.

Prerequisites: No prerequisites are required for this course.

TSPP 1020 - Network Operations/Security

Outline URL: https://www.bcit.ca/outlines/tspp1020/

Credits: 5.5

Description: This course focuses on developing skills in configuring and troubleshooting networking infrastructure components. Topics include virtualization, network security, firewall configuration, protocols, switching techniques, and addressing for wired and wireless networks. They will also study how computers exchange data over LANs and WANs. Labs and exercises will examine network protocol implementation, as well as show how to troubleshoot and improve network design.

Prerequisites: TSPP 1010

TSPP 1030 - Operating System (OS) Fundamentals for Admins

Outline URL: https://www.bcit.ca/outlines/tspp1030/

Credits: 5.0

Description: In this course, students will learn how to support and configure Windows and Linux desktops in an enterprise environment. Students will develop skills that include learning how to install, customize, and update operating systems. Students will learn how to manage storage, files, and devices as well as how to configure network connectivity for Windows and Linux. Students will learn how to manage and troubleshoot operating systems. Hands-on exercises and labs include desktop navigation and creating user accounts and folder structures. Discussions also include the technical aspects of using Windows in the set-up of a small PC network. Students will compare the primary functions of Windows, Linux and Mac OS.

Prerequisites: TSPP 1020

TSPP 1040 - Linux Troubleshooting Project

Outline URL: https://www.bcit.ca/outlines/tspp1040/

Credits: 4.0

Description: The purpose of the Linux Troubleshooting Project is for students to apply practical knowledge acquired during the program to a project involving the creation of an enterprise network in a realistic setting. During the project, students engage in the entire process of time management, critical thinking, troubleshooting and problem solving. The project deliverables originate from real-world environments similar to those that students might typically encounter within industry.

Prerequisites: TSPP 1030

TSPP 1060 - IT Career Readiness

Outline URL: https://www.bcit.ca/outlines/tspp1060/

Credits: 1.5

Description: This course focuses on preparing students to be competitive in the IT job market. Students will have practice in advanced problem solving, troubleshooting and presentation skills required to be successful in IT interviews.

Prerequisites: No prerequisites are required for this course.

TSPP 2015 - Windows/Linux Server Administration

Outline URL: https://www.bcit.ca/outlines/tspp2015/

Credits: 7.0

Description: This course covers the configuration and administration of a Microsoft Windows Server environment. Students learn the core technologies and capabilities of Windows Server. Students configure Windows Server to perform a variety of roles, including acting as a DNS server, DHCP server, and file server. During the course, students will build a Windows domain consisting of three or more Windows and Linux virtual machines, and learn to troubleshoot and monitor a Windows domain environment.

Prerequisites: TSPP 1010 and TSPP 1020 and TSPP 1030 and TSPP 1040

TSPP 2025 - Advanced Server Administration

Outline URL: https://www.bcit.ca/outlines/tspp2025/

Credits: 4.0

Description: This course will teach students how to provision and configure advanced services using Windows Server. This course provides the skills and knowledge necessary to implement a core Windows Server infrastructure in an existing enterprise environment. This course primarily covers advanced configuration of services necessary to deploy, manage and maintain a Windows Server infrastructure, such as advanced networking services, virtual machine movement, network load balancing, failover clustering, image automation, business continuity and disaster recovery.

Prerequisites: TSPP 2015

TSPP 2035 - Datacenter Administration and Automation

Outline URL: https://www.bcit.ca/outlines/tspp2035/

Credits: 2.0

Description: This course provides students with the knowledge and skills to use Windows PowerShell for administration of Windows servers. In addition, students learn how to build scripts to accomplish advanced tasks such as automating repetitive tasks. Students learn using hands-on training that focuses on installing, configuring, and managing an enterprise hypervisor. Students implement the underlying components employed in modern computer storage.

Prerequisites: TSPP 2025

TSPP 2045 - Microsoft 365 Administration

Outline URL: https://www.bcit.ca/outlines/tspp2045/

Credits: 1.5

Description: Cloud computing resources and environments are used extensively in business, industry, government, and education. This course provides foundational knowledge on the considerations and benefits of adopting cloud services and the Software as a Service (SaaS) cloud model, with a specific focus on Microsoft 365 cloud service offerings. Students begin by learning about cloud fundamentals, including an overview of cloud computing and specifically Microsoft cloud services in a hand-on approach.

Prerequisites: TSPP 2035

TSPP 2055 - Capstone Project

Outline URL: https://www.bcit.ca/outlines/tspp2055/

Credits: 4.0

Description: The purpose of the Capstone Project is for students to apply practical knowledge acquired during the program to a project involving the creation of an enterprise network in a realistic setting. During the project, students engage in the entire process of time management, critical thinking, troubleshooting and problem solving. The project deliverables originate from real-world environments similar to those that students might typically encounter within industry.

Prerequisites: TSPP 1010 and TSPP 1020 and TSPP 1030 and TSPP 1040 and TSPP 2015 and TSPP 2025 and TSPP 2035 and TSPP 2045

TSPP 3010 - Work Term

Outline URL: https://www.bcit.ca/outlines/tspp3010/

Credits: 10.0

Description: This work term provides students with the opportunity to augment their classroom training and demonstrate learned analytical and technical skills in an IT related position. Students will acquire and further refine their skills through real-world work experiences and potential mentor relationships with work term employers. Students will work in industry/government organizations and will complete 7 weeks full-time in an IT Help Desk related position. The practicum is a minimum of 35 hours per week for 7 weeks.

Prerequisites: TSPP 2055
