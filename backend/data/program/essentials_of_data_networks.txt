Title: Essentials of Data Networks

================================================================================

## Overview

Delivery

online

Overview text

The emphasis in this microcredential is on networking knowledge with several basic skills that are useful for a home or Small Office/Home Office (SOHO) network.



## Courses

### Required Courses:

XINC 1101 - Network Terminology and Protocols

Outline URL: https://www.bcit.ca/outlines/xinc1101/

Credits: 2.0

Description: In this course, students will learn about communications in a connected world. Students will identify network devices and connections then install a simulation tool to allow further exploration of networks. After building a simple network, students will examine network protocols and will delve into the concepts behind network design.

Prerequisites: Completion of Grade 10 or equivalent

XINC 1102 - Network Addressing and Services

Outline URL: https://www.bcit.ca/outlines/xinc1102/

Credits: 2.0

Description: In this course, students will learn about Internet Protocol (IP) and how routing works between networks. Students will create a fully connected network and will subnet an IP address. Students will learn about IP address management and how Dynamic Addressing occurs using Dynamic Host Configuration Protocol (DHCP). Finally, students will create Domain Name System (DNS) records in a Domain Name Server.

Prerequisites: 50% in XINC 1101

XINC 1103 - Network Connectivity

Outline URL: https://www.bcit.ca/outlines/xinc1103/

Credits: 2.0

Description: Building on previous work, this course will apply that learning to a home-office network. Students will set up a home router and add devices to a home network. They will implement security on the home network including a firewall and wireless authentication.

Prerequisites: 50% in XINC 1102
