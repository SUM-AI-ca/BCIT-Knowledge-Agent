Title: Advanced Topics in Networking

================================================================================

## Overview

Delivery

online

Overview text

This Microcredential will focus on Enterprise Networks and will expand on previous microcredentials in the Essentials of Data Networking and Switching and Routing . The focus will be on connecting the previously developed Local Area Networks together to form Wide Area Networks and understanding the associated technologies, equipment and configurations needed to implement Wide Area Networks. Configuration automation and software defined networks will also be discussed.



## Courses

### Required Courses:

XINC 2320 - Enterprise Configuration

Outline URL: https://www.bcit.ca/outlines/xinc2320/

Credits: 3.0

Description: Students taking Enterprise Configuration will learn how to configure a routed networking using Single Area Open Shortest Path First (OSPF) as a routing protocol for both IPv4 and IPv6 networks. Students will configure routers with OSPF to allow communication of routes between Networks and allow Wide Area Network communication. Students will build packet filtering firewalls using Access Control Lists (ACLs) to limit traffic between the Local Area Networks to only those devices and protocols that are defined by organizational policy. Network Address Translation will also be presented as a method used to mitigate IPv4 Address depletion by using private IPv4 addresses to conserve public IPv4 addresses.

Prerequisites: No prerequisites are required for this course.

XINC 2330 - Scalability and Troubleshooting

Outline URL: https://www.bcit.ca/outlines/xinc2330/

Credits: 3.0

Description: In Scalability and Troubleshooting students will extend the network scalability issues caused by IPv4 address depletion and consider campus designs that provide a scalable network architecture. Students will learn how to allow secure remote access to Wide Area Networks as well as how to monitor and troubleshoot a scalable network architecture. The different types of network traffic (for example: VoIP and Email), their network characteristics and the type of Quality of Service (QoS) needed for each of these categories of traffic will be discussed. Students will implement protocols used to monitor and manage the different types of network traffic. Virtualization, network automation and Software Defined Networking (SDN) will also be presented in this badge.

Prerequisites: No prerequisites are required for this course.

Recommended for success
