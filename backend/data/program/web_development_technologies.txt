## Web Development Technologies
### Over 25,000 students have learned web development at BCIT.
BCIT Computing Flexible Learning offers four separate web development credentials, course by course in the evenings, with online delivery options.
Start with just one course COMP 1850 to learn to write code with HTML, create web sites and move on to more advanced web development.
### Associate Certificate
Applied Web Development (AWD) is for s tudents with no prior background who want to focus on using industry-standard methods and scripting tools to plan, document, design and build commercial-quality web pages with the most popular technologies.
AWD begins with hand-coding in HTML5, CSS3, and JavaScript. Required courses include data modelling, database, SQL, and business analysis for systems design.
Elective options provide choices in: UX/UI, Mobile Apps, Angular and Vue, Node.js, React and PHP for advanced web applications.
Once you’ve completed AWD, you can develop and manage commercial-quality web pages to industry standards.
### Microcredentials*
Web Development Foundations (WDF) is for those with no web coding background and who want to learn to build web pages by hand. You’ll be introduced to web scripting languages and tools by industry experts. After WDF, you can continue to the next level.
Introduction to Full-Stack Web Development is for those with a solid understanding of web coding and scripting with HTML5 and CSS3. Advanced JavaScript libraries for Front-End and Back-end web development are taught with best practices for developing web pages.
Both web microcredentials are sub-sets of AWD .
*Badges and Microcredentials can only be earned on courses taken since September 2023.
Applied Software Development (ASD) covers best practices and industry standards in application development. You’ll begin with Python and move on to Java, business analysis, and systems design. Electives may include app development with C, Java, C#, and C++, plus agile scrum methods, quality assurance (QA) and software testing.
ASD is aimed at two audiences:
- Legacy programmers upgrading to current development environments in C, Java, C++ and C#.
- Those with post-secondary education in Computing and IT who want to learn programming languages for application development.
Web and Mobile Application Development (WMA) is built on top of ASD and aimed at Object-Oriented programmers who already know how to build software applications in Java and C# .
You’ll focus on JavaScript libraries, including Angular/Vue, back-end Node.js, and front-end React.js, in conjunction with web application development in both Java and .NET.
Electives include Android, mobile, iOS, quality assurance (QA), DevOps with Kubernetes, and advanced web apps with PHP.
WMA Students must have prior Java and C# programming language application development experience. Business analysis and systems design plus HTML5 and CSS3 before declaring WMA.
Once you’ve completed WMA, you can develop significant software applications on websites and mobile devices.
