## Essentials of Data Networks
Microcredential Part-time School of Energy
## Overview
The Essentials of Data Networks Microcredential provides a high-level understanding of networking for anyone interested in an IT or related Career. Network administrator, data centre or Web operator, or a computer network technician are entry level careers graduates of this program can choose to pursue.
Delivery: online. See details .
The emphasis in this microcredential is on networking knowledge with several basic skills that are useful for a home or Small Office/Home Office (SOHO) network.

## Courses
### Program matrix
Check current availability of courses for this program.
Required Courses: | Credits
XINC 1101 | Network Terminology and Protocols ​In this course, students will learn about communications in a connected world. Students will identify network devices and connections then install a simulation tool to allow further exploration of networks. After building a simple network, students will examine network protocols and will delve into the concepts behind network design. Prerequisite(s): Completion of Grade 10 or equivalent course outline | 2.0
XINC 1102 | Network Addressing and Services In this course, students will learn about Internet Protocol (IP) and how routing works between networks. Students will create a fully connected network and will subnet an IP address. Students will learn about IP address management and how Dynamic Addressing occurs using Dynamic Host Configuration Protocol (DHCP). Finally, students will create Domain Name System (DNS) records in a Domain Name Server.​ Prerequisite(s): 50% in XINC 1101 course outline | 2.0
XINC 1103 | Network Connectivity ​Building on previous work, this course will apply that learning to a home-office network. Students will set up a home router and add devices to a home network. They will implement security on the home network including a firewall and wireless authentication.​ Prerequisite(s): 50% in XINC 1102 course outline | 2.0
