## How to Apply


Flexible Learning Programs


Enrol in a Flexible Learning Program where students self-register on a course-by-course basis each term.

Apply to Flexible Learning Programs


Full-time Cohort Learning Programs


Applying to a full-time program requires you to first meet specific program entrance requirements. Please make sure to review the details on each program webpage.

Apply to a full-time program


International Student Entry Program


ISEP – Technical Academic English is an English language program that prepares students for success by helping them to meet English requirements for academic programs at BCIT.

Apply to ISEP
