## SPC for Plastics PLAS 2070
Plastics Course
## Course Overview
Introduces Statistical Process Control with an emphasis on plastics process examples. Topics include the need for a process control system, process variation, control charts, frequency curves, statistical calculations, and measures of variability. The course concludes with the use of a typical statistical process control software program in a computer laboratory setting. Skills are developed in handling variables data, charting variables data, creating histograms, charting cause and effect data, and charting Pareto data.
### Prerequisite(s)
- PLAS 1001 or PLAS 1010
