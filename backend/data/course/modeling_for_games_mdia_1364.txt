## Modeling for Games MDIA 1364
Media Communications Course
## Course Overview
This course will cover the process of designing and creating 3D models (characters, Props, vehicles) for the purposes of game production for platforms including Game consoles, Computers, Tablets and SmartPhones. Students will study the essentials and the methods behind modeling for game production. In addition students will study how to modify and optimized high-poly 3D models and prepare them for game engines. The process of creating a re-topology of high-poly models will also be discussed.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Create levels and details for the game.
- Create a basic mesh for Biped and Quadruped characters.
- Create base meshes for 3D props.
- Prepare and export models for detailing and sculpting.
- Study sculpting and detailing methods.
- Set up up UV maps.
- Stack and lay out UV shells.
- Extract normal maps, bumps, textures and displacement maps from high-poly models.
- Optimize materials and baking textures into one texture file.
- Integrate 3D models into a game engine.
- Test models and make necessary corrections.
