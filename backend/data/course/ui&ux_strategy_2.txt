## Overview

This course focuses on building UI elements using various design applications. Students will be introduced to the guidelines for building UI elements, utilize their knowledge in several design applications to create UI components and finally export them in the proper formats. Students will be evaluated by a series of assignments and term project.

## Credits

3.0

## Cost

$611.22

## Prerequisites

- MDIA 2540

## Learning Outcomes

- Develop guidelines for creating UI elements for web, mobile and interactive projects.
- Utilize online tools in building UI elements for web, mobile and interactive projects.
- Demonstrate the use of various design applications (such as Illustrator, Photoshop and InDesign) in creating UI elements.
- Export UI elements with proper size and transparency settings for multiple platforms.
- Plan and design effective ready to use interfaces.
- Plan and create UI component libraries and templates.
