## Microsoft Word and Converting Documents to Digital Media XBSY 1003
Business Systems Course
## Course Overview
In this course, participants take a deeper look at how to use Microsoft Word to create professional-looking documents and revise them easily. Participants will learn key functionality such as how to create documents using graphics, tables, hyperlinks and watermarks. Participants will also walk through the different ways to format a document depending on if you are printing a file or sending it electronically.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create, edit, arrange, and print documents
- Create and import graphics into documents; including picture files, SmartArt and WordArt
- Create documents with tables, images, hyperlinks, and watermarks
- Describe default settings for graphics in MS Word
