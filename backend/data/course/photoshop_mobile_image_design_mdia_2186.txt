## Photoshop Mobile Image Design MDIA 2186
Media Communications Course
## Course Overview
This course focuses on using Adobe Photoshop for Mobile Image Design. It has been designed specifically for the full time Mobile App Tools program. Students in this section must supply their own Mac notebook installed with the current OS X system plus subscribe to the Adobe Creative Cloud in order to participate. Students begin with studying the work flow of mobile UI/UX design and how the design process is involved from product concept to product release. Discussions include theoretical differences between UI /UX design and flowcharts and wireframes. There will be a focus on current industry best practices across IOS and Android platforms. Design topics include: Colour use, graphics, transitions, spacing and visual balance when designing for mobile devices as well as creating accurately pixel sized, correctly layered and placed designs for mobile content. By the end of this course, successful participants will be able to use Photoshop tools to visually create a functional mobile application with efficient user flow that would be ready for client approval and be used as a pre-production prototype.

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Explain the differences between UI/UX design.
- Study industry best practices and trends in mobile art & design.
- Retina and xHDpi, what they mean and how to design for them.
- Know iOS and Android screen resolutions to creates assets for.
- Design mobile screens based on user flows to match and convey the UX.
- Mood boards and product branding into mobile design.
- Demonstrate knowledge of driving user flow using colour and design.
- Define device fonts and localization of fonts with design.
- Design scalable and responsive mobile artwork in Photoshop.
- Iconography and how it drives user flow.
- Building mobile art files from Photoshop to iOS and Android.
- Build layered mobile screen examples in Photoshop.
- Export assets for iOS and Android ready for a developer.
- App icon and asset requirements for device online stores.
- Demonstrate correct use of typography, placement and colour use.
