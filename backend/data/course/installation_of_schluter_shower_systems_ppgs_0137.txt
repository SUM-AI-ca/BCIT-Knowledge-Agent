## Installation of Schluter Shower Systems PPGS 0137
Piping, Plumbing, Gas Course
## Course Overview
This course will provide you with the knowledge and hands on skills needed to install a Schluter shower system. You will install a shower base, Kerdi board, Kerdi membrane, and shower curbs. You will be provided with instructions on how to properly complete each step and receive feedback on the quality of your installation procedures. Students who successfully complete this course will receive a Schluter Training Card. The materials for this course have been donated by Schluter Systems and Custom Building Products.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Install a shower base.
- Install a Kerdi board.
- Install a Kerdi membrane.
- Install a shower curb.
