## Create Shop Drawings JOIN 1271
Joinery Course
## Course Overview
Students will create a series of shop drawings, cutting bills and cutting plans. Initially these shop drawings are created manually (using pencil and paper) and in the latter portion of the course they are produced using AutoCAD. Note: These shop drawings are then used to construct the required practical projects for this program ( JOIN 1276 ).
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
7.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Sketch simple objects.
- Manually create dimensioned shop drawings using pencil and paper.
- Create dimensioned shop drawings using AutoCAD.
- Produce cutting bills from dimensioned shop drawings.
- Produce cutting plans for sheet goods.
