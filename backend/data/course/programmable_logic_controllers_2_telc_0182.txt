## Programmable Logic Controllers 2 TELC 0182
Electrical Trades Course
## Course Overview
Provides hands-on training in the use of RSLogix5000 PLC programming software. Explores the power of the PLC through use of math functions, data comparison and manipulation instructions. A measure-and-sort application will illustrate how to interface a PLC to an optical shaft encoder and a Human Machine Interface (HMI) via Ethernet.
### Prerequisite(s)
- TELC 0186 - Programmable Logic Controllers 1 (recommended)

## Learning Outcomes
Upon successful completion of this course, the student will be familiar with the following, at an intermediate level:
- Reading schematic drawings for PLC control systems.
- PLC data types.
- Implementation of PLC routines to perform Math and Data Manipulation.
- Programming required for a sorting operation that includes a PLC (Programmable Logic Controller) connected to a HMI (Human Machine Interface) and a VFD (Variable Frequency Drive).
- Organizing a medium-sized project into subroutines.
- Documenting PLC applications.
- Preparation for the Level 3 (PAC) Programmable Automation Controller course.
