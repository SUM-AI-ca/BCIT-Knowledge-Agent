## Introduction to C Programming COMP 1515
Computer Systems Course
## Course Overview
COMP 1515 presents a core subset of the C language, including selected data types, input/output, logic control, and algorithm development. Many examples are presented, with small assignments directly built upon the examples. The follow-on course ( COMP 2510 ) fills out portions of C programming purposely omitted from this introduction.
### Prerequisite(s)
- No prerequisites are required for this course.
