## SNOW 101: Mac OS X Support Essentials 10.6 MDIA 1013
Media Communications Course
## Course Overview
Mac OS X Support Essentials is a hands-on course that provides an in-depth exploration of troubleshooting on Mac OS X. This course is designed to give you a tour of the breadth of functionality of Mac OS X and the best methods for effectively supporting users of Mac OS X systems. The course is a combination of lectures and hands-on case study exercises that provide practical real-world experience.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- OS X installation.
- Prepare and partition the drive.
- Setup user accounts.
- Work with command line and automation.
- Work with file systems.
- File management.
- Applications.
- Network configuration.
- Network services.
