## Adobe After Effects 1 MDIA 1171
Media Communications Course
## Course Overview
This course introduces students to the basics of Motion Graphics and Visual Effects using Adobe After Effects. The course covers a variety of post-production techniques that are essential for creating polished videos for online, TV or film productions. The course begins with reviewing the program interface, followed by an in-depth study of animation and curves. Variant vector and raster based masking techniques are introduced including rotoscoping and layer track-matting. This is followed by working with 3D cameras, lights and building virtual sets. Towards the end of the course text animators are explained with an emphasis on working the range selector tool.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create new projects, import and organize media files including images, illustrations, videos and audio files.
- Build, manage and nest composition.
- Animate variant transform properties for a layer as needed.
- Control the behaviour of an animation by adjusting its curve line.
- Demonstrate the use of vector and layer masking.
- Rotoscope or animate a layer mask.
- Demonstrate linking a raster based mask to a layer.
- Create basic virtual sets using 3D lights, cameras and layer alignment in a 3D space.
- Animate text layers using the Range Selector tool.
- Apply techniques learned in the course to create a QuickTime movie.
