## MS Access 3 Build Applications COMP 1272
Computer Systems Course
## Course Overview
Teaches non-programmers how to develop a small application using MS Access macros. Covers the advanced features of uses of macros, macro actions, events triggering macros, menu builder, toolbar modification, and advanced report design.
### Prerequisite(s)
- 50% in COMP 1271
