## Page Production & Workflow Management GTEC 3240
Graphic Communications Technology Course
## Course Overview
This course introduces the mechanisms and protocols of electronic prepress production through the workflow applications 'Prinergy' and 'Preps'. Students will have an opportunity to process a project from input through to plate ready status, and will progress from setting up basic imposition workflows, to creating more complex, multi page jobs.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
3.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Articulate the primary components and functional modules of the Prinergy application in the context of the modern electronic prepress workflow.
- Create a job and the requisite supporting folder structure in the Prinergy workflow.
- Construct a Master Template job for recurring parameters.
- Differentiate between acceptable and unacceptable file formats for input to Prinergy.
- Transform files with the Refine function into PDF required for subsequent actions in Prinergy.
- Describe the settings for Trapping in Prinergy.
- Create templates and jobs in the application Preps to provide imposition instructions to Prinergy.
- Import the Preps job and its associated marks pdf into the appropriate location in Prinergy.
- Manipulate page sets for correct linking to Imposition plans.
- Process a multi-page project from input through to the output of correctly imposed forms.
