## Photoshop for New Media MDIA 2185
Media Communications Course
## Course Overview
This course introduces students to the techniques used in digital image creation, manipulation and management. Students will learn how colour is defined in digital images, the differences between Raster and Vector based graphics and techniques, how to identify the correct resolutions and pixel dimensions for different purposes, destructive versus nondestructive editing techniques, how to isolate and edit a part of an image, how to colour correct images, and the proper workflow for creating a photo based project in Photoshop and exporting the result for variant platforms.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Recognize image resolution and its applications for web, mobile and print.
- Recognize the differences between Raster and Vector based graphics and techniques.
- Create, manage and manipulate raster images.
- Demonstrate how RGB, HSV and CMYK colour modes work.
- Determine how a part of an image is isolated and modified using non-destructive techniques.
- Demonstrate how colour correction principles are applied to layers and images.
- Create selections using different methods within Photoshop such as lasso tools, quick mask, pen tool or colour based selections.
- Organize content using layers, groups, and art-boards.
- Demonstrate the application of patterns and brushes.
- Optimize and export files for final deployment.
