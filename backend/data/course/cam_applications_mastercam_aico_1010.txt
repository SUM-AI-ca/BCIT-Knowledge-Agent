## CAM Applications - Mastercam AICO 1010
Computer Aided Design & Engineering Course
## Course Overview
Presents the use of CAM software for automatically generating toolpaths such as 2D contouring, pocketing and drilling operations. Some programs may be proved out on BCIT's machine tools. A brief introduction to G-code programming will be included.
### Prerequisite(s)
- Familiarity with Microsoft Windows.
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Understand CNC machine codes.
- Edit CNC machine codes.
- Use Vericut toolpath simulator.
- Define tools and operations using the Operations Manager.
- Establish job setup parameters using the Operations Manager.
- Use MasterCAM's working environment for contour machining, hole operations, pocketing, roughing and finishing operations.
- Transform toolpaths - move, rotate, mirror.
- Edit part geometry and regenerate toolpaths.
- Recognize important considerations for CAD model creation.
- Understand MasterCAM's CAD to CAM conversion process.
