## Database Applications BSYS 3100
Business Systems Course
## Course Overview
This course will continue the development of the skills and tools that are the basis to database applications and data analytics. Students will be using a mix of software, including MS Access and MS Excel, in order to build knowledge through practical hands-on development, and apply this knowledge by analyzing information in order to make business decisions.
### Prerequisite(s)
- BSYS 2060
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Evaluate the functions and components of a database.
- Process data sets using a business analytics system.
- Develop reports and support business decision making using various tools.
- Evaluate emerging trends in data analytics.
- Design easy to read, useful reports to present information.
- Import and export data between MS Access and MS Excel.
- Create and modify data in MS Access and MS Excel.
- Create and modify simple database applications to support business decision making.
