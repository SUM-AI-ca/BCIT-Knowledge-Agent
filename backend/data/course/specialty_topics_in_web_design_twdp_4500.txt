## Specialty Topics in Web Design TWDP 4500
Technical Web Designer Course
## Course Overview
This course was designed to meet the changes and trends in web site development. As more and more users turn to their smartphones instead of their computers for social networking, information, shopping, and entertainment, web designers must also learn to deliver practical design concepts for this new mobile web market. Student groups will be provided with mobile devices (such as an iPod Touch) to convert their client project sites for viewing on a smartphone. Increasingly, employers are asking for web designers with Content Management Systems (CMS) experience. This course will also provide students with an opportunity to explore the top two open source CMSs – Drupal and WordPress. In small groups, students will evaluate each product for ease of development, implementation, and training. Students will also add dynamic and exciting features to their web sites, using jQuery. Finally, students need to find work – whether employed or self-employed. This course will also include a module that provides practical help with resume writing, job interview skills, career planning, and starting up a consulting business.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Adapt (X)HTML- and CSS-coded web sites to mobile web design principles – fast-loading, optimized, and efficient.
- Design web sites that have the look and feel of a basic iPhone app.
- Add interactivity to mobile sites with jQTouch.
- Discuss, compare, and evaluate the most commonly used open-source Content Management Systems.
- Set up a basic administrative interface for a modular CMS, such as Drupal.
- Install, and setup WordPress, then learn content creation, work with themes and plug-ins.
- Explore site structures, security issues, and ease of customization and configuration for Drupal modules.
- Identify and plan a career path.
- Write an effective resume and cover letter.
- Through role-playing exercises, develop confident interview skills.
