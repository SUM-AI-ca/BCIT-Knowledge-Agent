## 5G Essentials TELX 1520
Electronics Technical Course
## Course Overview
​The 5G Essentials course offers an interactive online knowledge-based approach for individuals looking to learn about 5G wireless technologies. This course provides learners an overview of 5G technologies, network architecture and features that have been developed for both consumers and industry. If you are interested in exploring core technologies that have enhanced communications and will lead to digital convergence, then this course will open the door to 5G now and its possibilities moving forward.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe the basic subsystems of a Cellular Network
- Identify general characteristics of previous Cellular technologies
- Describe the key technologies in a 5G Network
- Identify the key features and applications of 5G technologies
- Identify various industries working with 5G networks
