## Managing Pre-Imaging Workflows 1 GTEC 2105
Graphic Communications Technology Course
## Course Overview
This course introduces the mechanisms and protocols of electronic prepress production through the workflow application ‘Prinergy.’ It focuses on the requirements for setting work up in Prinergy, and exposes the student to the Refine and Trapping functions that produce single page PDFs. Fundamentals of imposed form work for printing production is also covered through industry standard applications Preps and the connection to Prinergy. RIP technologies will be contrasted and compared. Other pre-imaging page production systems will be reviewed and analyzed for their strengths and weaknesses. Students will have an opportunity to process a project from input through to plate ready status with close alignment to Kodak’s hands-on training program.
### Prerequisite(s)
- GTEC 1100 and GTEC 2250 and GTEC 2280

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Articulate the primary components and functional modules of the Prinergy application in the context of the modern electronic prepress workflow.
- Create a job and the requisite supporting file organization structure in the Prinergy workflow.
- Construct a Master Process Template job for recurring parameters.
- Create and differentiate between acceptable and unacceptable file formats for input to Prinergy.
- Effectively navigate the online help system that is built into the application.
- Transform files with the Refine function into PDF format required for all subsequent actions in Prinergy.
- Describe the settings for Trapping in Prinergy.
- Process a job from input to single page output.
- Describe differences in RIP technologies.
- Create jobs in the application Preps to provide imposition instructions to Prinergy.
- Import the Preps job and its associated marks PDF into the appropriate location in Prinergy.
- Manipulate page sets for correct linking to Imposition plans.
- Describe options for a colour managed PDF workflow.
- Process a multi-page project from input through to the output of correctly imposed forms.
- Describe the strengths and weaknesses of other prepress workflows in the marketplace.
