## Planning and Designing Web Sites TWDP 1500
Technical Web Designer Course
## Course Overview
This course provides an intensive and comprehensive introduction to web site development and represents the first phase of the development life cycle. Students will use project management techniques to plan and prototype web sites that meet the needs of their project sponsors and the site’s end users. They will be introduced to commonly used web technologies, such as (X)HTML and CSS, web usability principles, and best practices for web graphic design. The course will also cover how to publish, manage and market a web site. Students will also compare and contrast the principles and differences between client-side and server-side technologies. Additional topics will include designing an effective homepage, planning web site navigation and layout, and content organization and architecture.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Identify an organization's primary business objectives and how they relate to the web.
- Identify and document web site requirements based on user tasks and goals.
- Plan and create mock-ups that demonstrate an understanding of a client's needs.
- Prepare a project schedule, project plan and project estimation.
- Design a user interface that follows established web accessibility and usability guidelines.
- Produce basic web sites using (X)HTML and CSS that meet current accessibility and cross-browser standards.
- Design style sheets to provide a common look and feel to all parts of a web site.
- Create visually appealing web graphics using software such as Adobe Photoshop and Illustrator.
- Based on the web site requirements, select the optimal location (client or server) and web technology for implementing web site functionality.
- Compare and contrast client-side versus server-side technologies.
- Examine different types of commonly used tools for web publishing and internet systems administration.
- Design and plan an individual student portfolio site.
