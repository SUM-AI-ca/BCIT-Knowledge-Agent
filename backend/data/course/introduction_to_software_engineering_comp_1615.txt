## Introduction to Software Engineering COMP 1615
Computer Systems Course
## Course Overview
This course presents students with the knowledge a software engineer needs to pass from requirements, to design, coding, testing and maintenance. It will discuss some of the challenges that software engineers face and the different techniques used.
### Prerequisite(s)
- 50% in COMP 1401
