## Distributed Control and Safety Instrumented Systems for Industrial Network Cybersecurity ELEX 4610
Electrical and Computer Engineering Course
## Course Overview
​This course develops a basic working knowledge of distributed control and safety instrumented systems to provide a deep appreciation as to their application in industry and the challenges associated with the networking and network security of them. Building on the concepts developed in the Process Measurement and Control Fundamentals for Industrial Network Cybersecurity course in term three, this course prepares students for the Culminating Project in the five-week term that follows. Topics include: programming languages conforming to the IEC-61131-3 (FBDs, SFCs and structured text), the theory of advanced control strategies including multivariable and statistical process controls (SPC), trips, interlocks, permissives, and sequence control. Laboratory activities involve the configuration and operation of a distributed control system platform (DeltaV), to implement and test control strategies on typical industrial processes.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Configure control loops using a DeltaV distributed control system. (3)
- Design interlock and sequence control systems using function block diagrams and sequential function charts. (4)
- Design and analyze multivariable control schemes. (3)
- Identify and analyse the use of control loop data in statistical process control. (4)
- Implement control loops and sequential control systems on the DeltaV Distributed Control System. (3)
- Test control simulations using graphical user interfaces. (3)
