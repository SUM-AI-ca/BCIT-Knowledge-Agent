## Exploring DOS COMP 1005
Computer Systems Course
## Course Overview
Gives the beginning student an in-depth knowledge of the PC/MS Disk Operating System (DOS). This course covers all the essential commands contained in DOS including formatting and copying disks. The course provides an understanding of how to use PC/MS DOS files, essentials of Hard Disk management, and Batch File creation.
### Prerequisite(s)
- 50% in COMP 0001
