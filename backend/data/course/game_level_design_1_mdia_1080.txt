## Game Level Design 1 MDIA 1080
Media Communications Course
## Course Overview
This course introduces the basics of Unity 3D gaming software. Course topics will include; setting up levels and environments for video games across multiple platforms, game design, project planning (for a low to intermediate scale game project), setup, design and create proper game levels and user interface based on a different game genre. Students who attend this course must have basic knowledge of Autodesk Maya, 3ds Max, or Blender.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Transform a game idea into a game project.
- Plan and manage a low-level game project.
- Design and describe a game-play story and workflow.
- Provide and execute proper assets for creating a game level environment.
- Layout and create a user friendly user interface.
- Refine and optimize assets already provided.
- Design and setup a proper and efficient game level.
- Test, refine and regress the designed game level in action.
- Create a working demo and prototype of the game concept.
