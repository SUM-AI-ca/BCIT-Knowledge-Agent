## Visio Workshop - Level 1 COMP 0160
Computer Systems Course
## Course Overview
This intensive, hands-on seminar covers drawing techniques used to create professional business diagrams using Visio 2007. Learn how to create a flow chart, office layout plan, a map and an organization chart using stencils, shapes, text, and, connectors; enhance diagrams with backgrounds, borders and colour schemes, and generate a chart from imported data.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
- Identify the various types of drawings.
- Drag shapes from stencils, resize, rotate, align, transform and duplicate them.
- Create a directional map.
- Locate master shapes within the stencil library.
- Create an organization chart and generate from imported data.
- Create a flowchart.
- Apply title, borders, backgrounds and colour schemes.
- Create an office floor plan to scale.
