## Custom Guitar Building JOIN 0010
Joinery Course
## Course Overview
This course teaches the student the skills required to build a custom electric guitar. The course covers basic to advanced woodworking techniques depending on the student’s prior experience. Students that successfully complete the course will have a custom electric guitar of their own design as well as woodworking skills that can open doors to many venues in the woodworking industry.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
## Use Safe Work Practices
- Apply Occupational Health and Safety Regulations.
- Use the Workplace Hazardous Materials Information System (WHMIS).
- Apply safe work practices.
## Use Tools and Equipment
- Use layout tools.
- Use hand tools.
- Use carving tools.
- Use portable power tools.
- Use stationary power tools.
- Use routers and router jigs.
## Select Materials
- Describe the properties of wood species used in guitar construction.
- Use solid wood breakout procedures.
- Use adhesives.
- Glue and clamp materials.
## Design and Layout Guitars
- Describe the parts of a guitar.
- Layout a guitar.
- Layout component locations.
- Locate the fret scale and the bridge.
## Build Guitar Bodies
- Rout a guitar blank.
- Rout guitar cavities for hardware and electronics.
- Rout the guitar body for binding.
- Rout the neck cavity.
## Build Guitar Necks
- Create a neck template.
- Machine solid wood for a neck.
- Install head stock veneer.
- Install a heel cap.
- Install a truss rod.
- Install a fret board.
- Install neck binding.
- Drill head-stock holes.
- Carve a neck blank.
## Create Inlay
- Design inlay.
- Build inlay.
- Rout inlay cavities.
- Install and level inlay.
## Install Fret Wire
- Choose fret wire
- Prepare a fret board for fret wire.
- Install fret wire.
- Level fret wire.
- Shape and polish fret wire
## Prepare for a Finish
- Sand for a finish
- Fill pores.
- Apply a stain.
- Apply graphics.
## Apply a Finish
- Select finish materials.
- Describe spray equipment.
- Describe spraying procedures.
- Describe cut polishing.
- Spray and polish a guitar.
## Install Hardware
- Attach the neck to the body.
- Create a nut for the neck.
- Install body hardware.
- Install neck hardware.
- Install electronics.
## Set-up and Adjust Guitars
- Adjust the nut.
- Adjust the truss rod.
- Describe basic guitar repair.
- Solder the electronics.
- Adjust the bridge.
- Adjust the nut
