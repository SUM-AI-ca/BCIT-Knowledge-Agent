## Framework III Level 1 COMP 1235
Computer Systems Course
## Course Overview
Covers the use of Framework III as a power tool to help in various real-life situations. Students learn to use Framework's database management, spreadsheet, word processing and dynamic outlining features, and apply them to solving problems. Includes: Common database structures, spreadsheet design techniques, word processing, report generation, graphical techniques, mailmerge, file and disk management;introduces the use of Framework's programming language. Students complete a major project.
### Prerequisite(s)
- No previous experience of computers is required but keyboard skills are desirable and access to Framework in the work environment is a considerable asset.
