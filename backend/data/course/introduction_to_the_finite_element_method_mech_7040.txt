## Introduction to the Finite Element Method MECH 7040
Mechanical Engineering Course
## Course Overview
Introduces the finite element method (FEM) for linear static analysis f structures and machine components. Topics include the displacement method, matrix solution techniques, stress interpretation, modeling with 3D elements and automatic mesh generation.
### Prerequisite(s)
- Diploma of Engineering Technology or equivalent.

3.0
