## Prop and Character Setup 2 MDIA 2085
Media Communications Course
## Course Overview
This course explores advanced techniques and methods in preparing and setting up characters and props for video games. Advanced topics include; building on to skills learned in MDIA 1085 Prop and Character Setup 1, optimizing, designing and creating proper game characters and props for a game project, different methods for creating and blending animation segments for different actions and interactions inside the game engine and working with the instructor to produce a final polished video game. Students who attend this course must have at least intermediate level knowledge of 3D modeling, animation and texturing in industry standard applications.
### Prerequisite(s)
- MDIA 1085

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Follow and explain the project plan.
- Design and execute a prop and character concept.
- Prepare and optimize images for importing realistic textures into the game props.
- Animate and execute game props inside the game engine.
- Create action-based animations for different characters inside the game engine.
- Use and demonstrate different game engine tools for blending animations.
- Create animated textures for crowd based elements.
- Create camera animations and assign different camera controls.
- Trigger prop and character animations based on user input.
- Create and demonstrate a working final prototype and demo to the instructor.
