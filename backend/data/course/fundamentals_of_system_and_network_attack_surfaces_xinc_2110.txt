## Fundamentals of System and Network Attack Surfaces XINC 2110
Cybersecurity Professionals Microcredentials Course
## Course Overview
This badge introduces students to the role a Cybersecurity Operations Analyst plays in a Security Operations Centre (SOC). Students will examine various network protocols and services and explore their function on modern networks. Students will also learn about different virtualization hypervisors that run on modern computers and will install a hypervisor and virtual machine to allow exploration of network protocols and network services. ​​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- ​Install and manage virtual machines to create a safe home-lab environment
- Explain the role of a Cybersecurity Operations Analyst in an enterprise
- Analyze the operation of network protocols and services
