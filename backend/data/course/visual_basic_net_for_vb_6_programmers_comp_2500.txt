## Visual Basic .NET for VB 6 Programmers COMP 2500
Computer Systems Course
## Course Overview
Intended for experienced VB6 programmers, this new "bridging" course provides an overview of the .NET framework. Topics include; the Common Language Runtime, the Common Language Specification, and Microsoft's Intermediate Language. Using Visual Basic.NET, the course also covers: GUI design with the Label, CommandButton, ListBox, ComboBox, Option Button controls; .NET syntax and data types, writing classes, creating objects, file I/O, and exception handling (.NET error handling). Upon completion of this course, students will have an intermediate level of proficiency in Visual Basic.NET.
