## File Construction and Page Layout GTEC 2150
Graphic Communications Technology Course
## Course Overview
This course teaches the fundamental principles of page layout design. Basic type measurement and terminology will be explained. Students will construct single and multi-page documents with imported text, graphics and images. Students will examine good and bad typography and learn prepress terminology. Using page layout software, students will prepare industry standard documents that incorporate the rules and practices of high quality typesetting. Files will then be exported to PDF format which bridges the gap between paper and the digital workflow.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Setup single and multi page documents with master pages and libraries.
- Work with different measurement systems including picas and points used the printing industry.
- Precisely position text graphics and images on a page based on an origin point.
- Edit text and change character and paragraph formatting.
- Create and apply paragraph and character style sheets.
- Create threaded and unthreaded text from column to column and page to page.
- Demonstrate the difference between good and bad typography.
- Create and work with tabular composition to build tables with coloured screens.
- Describe type terminology including: point size, leading, tracking, kerning, word spacing and copy fitting.
- Determine repurposing requirements for both a printed document and one that will be viewed on-screen.
- Create PDF files including electronic forms.
- Add navigation elements such as Bookmarks, Links and Articles.
