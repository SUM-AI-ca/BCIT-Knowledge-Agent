## Overview

Building on previous work, this course will apply that learning to a home-office network. Students will set up a home router and add devices to a home network. They will implement security on the home network including a firewall and wireless authentication.

## Credits

2.0

## Cost

$444.61

## Prerequisites

- 50% in XINC 1102

## Learning Outcomes

- Describe the components needed to build a home network
- Explain how Wi-Fi traffic is controlled
- Configure a wireless LAN device
- Describe different types of network security threats
- Explain how security tools can be used to mitigate network security threats
- Implement user authentication for wireless security
- Configure firewall settings​​
