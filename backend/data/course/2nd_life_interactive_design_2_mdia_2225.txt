## 2nd Life: Interactive Design 2 MDIA 2225
Media Communications Course
## Course Overview
This course builds on the skills learned in "designing Interactive Environments in a Virtual World 1" - through a practical hands-on building project. Students will work in teams to develop themed content which includes interactive components. The building process will be documented by each student. Final presentations will showcase the project and demonstrate student use in-world communication and presentation technologies. Evaluation and analysis will examine the projects and the application of the skills learned in the context of.
### Prerequisite(s)
- 50% in MDIA 1225

## Learning Outcomes
- Upon successful completion of this course, the student will be able to:
- Work effectively in teamsto create a themed build.
- Demonstrate building skills by developing content for the build, including interactive components.
- Create a working slide projector for a slideshow and demonstrate its use.
- Create a promotional notecard-giver poster and demonstrate its use.
- Evaluate building tools and their potential for use in developing virtual worlds.
