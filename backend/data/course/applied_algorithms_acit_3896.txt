## Applied Algorithms ACIT 3896
Computer Information Technology Course
## Course Overview
​In this course, students will develop the ability to analyze, select, and design computer algorithms. In particular, students will analyze the time and space complexity of programs, solve difficult programming problems using algorithmic techniques, and prove that their solution is correct. The emphasis will be on developing the practical skills to analyze various algorithms, select the optimal algorithm based on constraints, and implement solutions. Topics covered may vary each term
### Prerequisite(s)
- ACIT 2515 and ACIT 2831
### Credits
4.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe common algorithms.
- Analyze pseudo-code using the Big-O notation.
- Deduce the complexity of a program by running different experiments.
- Design new algorithms using several techniques and machine learning approaches.
- Implement the algorithms.
- Recognize different types of problems and select an appropriate algorithm.
- Argue the correctness of their algorithms
