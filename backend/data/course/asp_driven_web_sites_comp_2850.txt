## ASP Driven Web Sites COMP 2850
Computer Systems Course
## Course Overview
The purpose of this introductory course is to discuss the main elements in creating and deploying a dynamic data driven website using Active Server Pages (ASP) in conjunction with Microsoft Access or SQL Server.
### Prerequisite(s)
- 50% in COMP 1950
### Credits
3.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Build on existing knowledge of HTML and CSS.
- Understand web standards and their impact on web design.
- Learn to interpret client requirements into effective web development.
- Create a site using only CSS for layout control.
- Understand key interface concepts.
- Use concepts of information architecture and user experience to create site definition.
- Learn strategies for agile site design.
