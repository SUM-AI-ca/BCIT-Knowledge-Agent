## MS Word Workshop 2 COMP 0267
Computer Systems Course
## Course Overview
Following on from COMP 0266 , participants are shown how to use intermediate level topics for using Word in this intensive, hands-on seminar. Exercises in class include: efficient time saving techniques using quick parts, building blocks, mail merge, templates, and basic macros. Other topics include: multilevel lists; sorting lists and tables; performing calculations in tables; charts; creating and modifying styles; controlling text flow; columns; section breaks v. page breaks. Successful participants will be prepared to move on to MS Word Workshop 3, COMP 0268 .
### Prerequisite(s)
- COMP 0266 , or equivalent knowledge of MS Word.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create and customize a multilevel lists.
- Sort lists and table data; perform calculations in a table.
- Create and format charts.
- Format paragraphs by controlling text flow – widow /orphan, keep with next, keep lines together.
- Know when to use a section break v. a page break.
- Format text into multiple columns.
- Create and modify styles.
- Use a mail merge to create and personalize form letters, envelopes or mailing labels.
- Insert, create and modify Quick Parts; use Word’s Building Blocks.
- Use and create templates to automate document creation.
- Record, run and edit simple macros.
