## CNC Milling Essentials MACH 1160
Machinist Course
## Course Overview
This course provides secondary school teachers with an overview of Computer Numerical Control (CNC) milling operations. Topics include CNC applications and programming as well as the safe set-up and operation of a machining centre. Students will import geometry from CAD systems to create programs to manufacture simple parts using CNC machining centres. Quality control, troubleshooting, simulation and verification are also covered.
### Prerequisite(s)
- Students should have experience with Fusion 360 design software and be familiar with manual machining and precision measurement.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Discuss applications of CNC machines and programs
- Identify the components of a CNC machining centre
- Interpret CNC part programs
- Establish work coordinate systems
- Select and inspect tooling and tool holders
- Set up tooling and offsets
- Install and align work-holding devices and fixtures
- Create and simulate milling toolpaths
- Transfer programs to and from the machine control
- Verify the execution of CNC programs
- Troubleshoot CNC program errors
- Safely operate a CNC machining centre
- Conduct quality control measures
