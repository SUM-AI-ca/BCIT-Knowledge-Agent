## Construction Drawings 2 INTD 2460
Interior Design Course
## Course Overview
Using the current release of AutoCAD for the PC, this course will teach students to produce 2D architectural drawings, expanding on knowledge covered in previous courses. Students will create a set of commercial interior design construction drawings, including plans, elevations, section and details. Students will be introduced to more complex AutoCAD commands such as external references, attributes and setting up drawings for plotting.
### Prerequisite(s)
- 65% in INTD 2350 and 65% in INTD 2360
### Credits
3.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Produce a set of interior design drawings using AutoCAD commands.
- Demonstrate understanding of external referencing in drawings.
- Created attributed blocks for title blocks, room names, door symbols and finishes symbols.
- Create drawing sheets for a set of construction drawings including plans, elevations and details at varying scales.
- Generate construction plans with existing walls, new walls and walls to be Demolished.
- Plot drawings at a reprographic shop using appropriate line weights and scales for interior design purposes.
