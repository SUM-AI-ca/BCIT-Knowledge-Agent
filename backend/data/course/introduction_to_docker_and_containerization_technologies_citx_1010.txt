## Introduction to Docker and Containerization Technologies CITX 1010
Computer Information Technology Electronics Course
## Course Overview
​This introductory course demystifies containerization, focusing on practical Docker tools for modern application deployment. Participants will learn how to build, deploy, and manage containers, gaining hands-on skills in container creation and cluster management.​​ The course covers essential Docker skills including container lifecycle management, image deployment, Docker Swarm clustering, networking, load balancing, and scaling strategies. Designed for system administrators, developers, and IT professionals new to containerization, this training provides a direct path to understanding container technologies. Students will explore Docker's architecture, learning to transform traditional application ​deployment through practical, real-world techniques. The curriculum moves beyond theory, giving participants actionable skills to implement efficient and scalable containerized environments This hands-on training bridges the gap between theoretical knowledge and practical implementation, preparing professionals to leverage Docker technologies in their daily work.​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create and manage Docker containers
- Build and deploy container images
- Configure Docker Swarm clusters
- Implement container networking
- Scale and balance containerized applications
