## Texturing 2 MDAA 2183
3D Modelling, Art & Animation’ Course
## Course Overview
​In this course students will build upon the principles of texturing using specific techniques to create believable and stylized surfaces for props and environments. Texturing will be explored in more depth with an emphasis placed on details. 3D painting software will be explored to detail textures directly on the model. Procedural texturing software will also be explored to create seamless textures that can be easily modified to the project's needs. Students will learn to apply trim sheets to their work to speed up their environment texturing workflow.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Practice different techniques to create textures for props and environments.
- Apply dirt and wear and tear detailing through masks.
- Create realistic and stylized textures.
- Use a 3D texturing package to texture directly on a model.
- Use procedural texturing software to create seamless textures.
- Create and apply trim sheets.
