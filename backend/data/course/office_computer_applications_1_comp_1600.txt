## Office Computer Applications 1 COMP 1600
Computer Systems Course
## Course Overview
Learn to be proficient in Windows XP and MS Office 2003 all in one course. Practice using MS Word, Excel and PowerPoint along with Internet and Email. Start with basic Windows file management and become productive with documents, spreadsheets and presentations. Hands-on exercises reinforce features and shortcuts. Use Object Linking and Embedding (OLE) to integrate the various applications of MS Office. Learn to use the internet and MyBCIT as a resource. Each student receives an individual BCIT email account with storage,for long term use.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
3.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion of this course, students will:
- Become proficient in Microsoft Windows XP and MS Office 2003.
- Learn to use MS Word, Excel and PowerPoint as well as the Internet and Email all in one course.
- Learn the basics of Windows and file management, how to produce documents, spreadsheets and presentations.
- Learn MS Office features that allow you to become productive immediately.
- Use the internet as a resource for Microsoft products and obtain a permanent BCIT email address via the MyBCIT web portal.
