## Web Design Fundamentals FWDP 1100
Front-End Web Developer Course
## Course Overview
This course covers the theory and best practices of web design fundamentals. Topics include screen-design principles; web layout and design; digital colour theory; typography fundamentals; image and web graphics sourcing, handling and copyright. Students will learn the best practices in creating designs for responsive web sites that adapt to different screen sizes using the fundamental design and usability principles for layout, such as visual hierarchy, colours, fonts, readability, proportions, alignments, and white space. In this class, students will explore in detail the differences between raster and vector graphics and basic techniques suitable for digital image creation, manipulation, and management. Students will develop practical skills will be developed in how to colour correct, resize, and resample images as well as how to use transparency settings and automate the resizing and saving of large numbers of images for the web. Evaluation will include lab assignments.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Discuss the importance of fundamental design principles for web and mobile applications.
- Apply the learned design principles to the design of web pages.
- Explain the nature of vector and raster graphics.
- Manage, optimize, and export images and UI elements for web and application development.
- Automate repeatable graphic manipulation tasks by creating batch processes.
- Follow legal guidelines for the use of copyright images and web graphics in web projects.
