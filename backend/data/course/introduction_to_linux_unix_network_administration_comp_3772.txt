## Introduction to Linux/Unix Network Administration COMP 3772
Computer Systems Course
## Course Overview
This course is the fourth level in a series of core Linux/Unix courses, and is designed to cover basic Linux/Unix network administration concepts using the GNU/Linux operating system on the Intel platform. Topics include static and dynamic IP configuration, basic diagnostic tools, TELNET, FTP, Network File System (NFS), and network security concepts.
### Prerequisite(s)
- 50% in COMP 2770
