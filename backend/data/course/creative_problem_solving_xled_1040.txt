## Creative Problem-Solving XLED 1040
Building Capacity Course
## Course Overview
Psychologists and businesspeople alike have discovered that successful problem solvers tend to use a similar process to identify and implement solutions to their problems. This process works for any kind of problem, large or small. Research has consistently demonstrated that when clear goals are associated with learning, learning occurs more easily and rapidly. This workshop will give participants an overview of the entire creative problem-solving process, as well as key problem-solving tools that they can use every day.​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Understand the difference between a problem and a symptom.
- Define a problem correctly using problem definition tools.
- Use basic brainstorming tools to generate ideas for solutions and evaluate potential solutions against criteria​.
