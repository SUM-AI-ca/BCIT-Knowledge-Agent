## 1998 B.C. Building Code Update: Part 9 BLDG 0005
Building Course
## Course Overview
Covers changes and updates to the BC Building Code. Emphasis on part 9, single family dwellings, multi-unit and small buildings. Practical application of code will bo emphasized in lab.
### Prerequisite(s)
- BLDG 1805 or BLDG 1825 or working knowledge of part 9 of the BC Building Code.
