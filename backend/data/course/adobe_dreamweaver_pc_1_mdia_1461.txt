## Adobe Dreamweaver PC 1 MDIA 1461
Media Communications Course
## Course Overview
Learn to build Websites with Adobe Dreamweaver. Use the tools to creat an exciting site with tables, images, colours, layers, forms and other technologies. At the end of the course the student uploads the site on the net using the Adobe Dreamweaver FTP program. No previous experience required. Some computer knowledge recommended.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Set up a local site.
- Create a web layout using tables or layers.
- Use mostly intermediate tools (images, text, colour, behaviours, frames, etc.).
- Troubleshoot basic Dreamweaver MX problems.
- Understand the Dreamweaver MX interface and its functionality.
- Use FTP.
- Understand how to implement previously created images and other materials into Dreamweaver MX.
- Troubleshoot basic browser compatibility issues.
