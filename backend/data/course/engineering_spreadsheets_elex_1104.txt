## Engineering Spreadsheets ELEX 1104
Electrical and Computer Engineering Course
## Course Overview
This course provides an introduction to organizing and formatting information with spreadsheet software including the use of macros.​
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Apply (iii) basic Excel functionality to: [1, 5]
- write formulas,
- draw charts,
- use functions, and
- apply formatting.
- Make (ii) Excel macros by using macro recorder, and by coding using Visual Basic for Application (VBA). [1, 5]
