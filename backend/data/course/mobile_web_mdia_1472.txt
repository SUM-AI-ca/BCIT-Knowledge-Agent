## Mobile Web MDIA 1472
Media Communications Course
## Course Overview
In this course students will be introduced to mobile web interface design (websites for the small screen mobile device; tablets and cell phones). Development techniques of managing limitation and advantages of such devices will be explored, with a focus on popular mobile operating system/devices. Exploring CSS3 methods such as media queries, through to advanced frameworks will be covered. Students will be assessed by a combination of quizzes, and individual projects.
### Prerequisite(s)
- MDIA 1190
### Credits
1.5

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Identify current user experience standards and how they differ in the mobile environment.
- Apply different design strategies and tools when developing content for mobile devices.
- Create interfaces and functionality for both mobile and desktop devices using responsive design techniques.
- Use media queries to create dynamic layouts and cross platform websites
- Develop touch optimized interfaces.
- Apply current libraries / frameworks directed towards mobile use and interactivity.
