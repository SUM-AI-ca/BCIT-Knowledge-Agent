## SA-118 Fundamentals of Solaris Systems Administration CITX 1170
Computer Information Technology Electronics Course
## Course Overview
This course introduces new users to the Sun Solaris operating system environment. Students will learn basic Unix system administration including fundamental Solaris operating environment commands. Some topics covered include: file permissions, the vi text editor, command shells and file system navigation. The common Desktop Environment will also be discussed.
### Prerequisite(s)
- No prerequisites are required for this course.
