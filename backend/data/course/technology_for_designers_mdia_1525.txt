## Technology for Designers MDIA 1525
Media Communications Course
## Course Overview
This course covers the technical knowledge, including system administration, and elementary prepress skills you will need throughout the one-year Certificate in Communication Design Essentials program. Material covered in this course will be expanded upon in MDIA 2087 : Prepress.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
- Upon successful completion of this course the student will be able to:
- Navigate the computer interface.
- Develop a system to manage and organize files.
- Organize, open, and close fonts using a font management system.
- Transfer files using the BCIT and Emily Carr networks.
- Describe the appropriate use of common file formats.
- Create PDF files with Adobe Acrobat using a suitable preset for digital, press, and web output.
- Perform basic preflight operations in Acrobat, while checking for fonts, colours, and compatibility.
- Specify the correct resolution requirements for digital, press, and web output.
- Explain how ink is transferred to paper using offset lithography.
- Describe the main print methods, including digital, process, and spot.
- Describe the basic principles of RGB and CMY colour spaces.
- Create a PDF for print that includes transparency.
