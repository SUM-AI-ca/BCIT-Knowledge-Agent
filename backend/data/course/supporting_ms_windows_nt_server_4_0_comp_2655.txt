## Supporting MS Windows NT Server 4.0 COMP 2655
Computer Systems Course
## Course Overview
Provides a training solution for support professionals working in a NT Server 4.0 based enterprise environment. Presents designing, implementing and supporting the NT server network system in a multidomain enterprise environment. Covers implementing MS Windows NT 4.0 Server Directory Services, Analysis and Optimization, Network Analysis and Optimization, and troubleshooting MS Windows NT Server 4.0 in the Enterprise Environment. Prereq: Acceptance into the program.
### Prerequisite(s)
- No prerequisites are required for this course.
