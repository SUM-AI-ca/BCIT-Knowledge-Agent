## Adobe FrameMaker COMP 1287
Computer Systems Course
## Course Overview
Adobe FrameMaker for the PC is an enterprise-class authoring and publishing solution that combines the simplicity of word processing with the power of templates. Using WYSIWYG, students learn how to take advantage of long-document support that includes book management features, sophisticated templates and rich formatting options. Hands-on exercises start with basic formatting and document production and then move on to intermediate advanced functions and shortcuts, high-quality printing and exporting to Adobe Portable Document Format (PDF).

## Learning Outcomes
Upon successful completion of the course, students will be able to:
- Navigate the Framemaker user interface.
- Use Framemaker book building features to create and manage long or complex documents.
- Generate multiple document output formats, including print and PDF.
- Apply Character Formats, Paragraph Formats, List Formats and Master Pages.
- Import and format text files and Microsoft Word files.
- Apply tables formats, use table features and import Microsoft Excel files.
- Create drawings and import bitmap image layouts.
- Design master pages, table formats, character styles and paragraph styles.
- Define and import global template definitions in page layouts, table formats, paragraph formats and character formats.
- Modify and update document variables, autonumbered lists and cross-document page numbers.
- Generate multifile books and resolve common book updating problems.
- Create and update cross-references, tables of contents and indexes.
