## Utilizing Data Structures for Business Analytics BABI 1600
Business Analytics & Business Intelligence Course
## Course Overview
A good Business Analytics professional understands not only how to manipulate data and generate reports, but also how that data is organized within a Business Intelligence system. Internal data structures determine the capabilities and limitations of an analytical model. In this course, students will learn about the entire lifecycle of data as it flows through various stages and units in an organization. The course will explore: different types of storage schemas; the difference between a transactional structure and an analytical structure; how analytical database structures are defined including what cubes are and how to use them. An integral part of the course will be a project in which students will build and demonstrate a fully integrated analytical model – from entering data into an existing RDBMS system and using ETL (Extract Transform Load) tools to get relevent data into the analytical database (cube), to running analytical queries on the cube to provide meaningful insight into the data.

## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Select the right database structure for the right business need.
- Develop a simple data entry, manipulation and retrieval system for a business process.
- Explain how analytical models are designed using the star schema.
- Create and populate an analytics model using ETL tools to move data between systems.
- Design a cube to store analytical data.
- Use one or more analytics tools to query the cube data.
