## MS Word 2007 Transitional Workshop COMP 0265
Computer Systems Course
## Course Overview
MS Office has developed a new user interface for version 2007. It was created to make these applications simpler to use. The menus and toolbars from prior versions are gone! This intensive half-day transition workshop is targeted to students who have used previous versions of Word and will be upgrading to Word 2007. Topics include navigating within the new user interface: the Office Button, Quick Access Toolbar, Mini Toolbar, using the Ribbon, Dialog Box Launcher and Key Tip badges. Word 2007 saves your files with the new file format docx; compatibility mode and document conversion issues discussed. Students will gain hands on experience using many of the new features in Word: Live Preview, Quick Styles, Galleries, Document Themes, Smart Art, Building Blocks, Contextual Spelling and the new charting and diagramming features.
### Prerequisite(s)
- Working knowledge of MS Word and Windows PC and file management.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Navigate and identify the components within the new User Interface.
- Use the Ribbon, tabs and Dialog Box Launcher to find commonly used commands and features.
- Customize the Quick Access Toolbar.
- Display Key Tip badges and efficiency use keyboard shortcuts.
- Save time formatting using Live Preview, the Mini Toolbar, Quick Styles, Quick Parts, Quick Tables, Galleries, Document Themes.
- Use Building Blocks to add text, cover pages, headers and footers.
- Use new features such as Contextual Spelling, Smart Art, charting and diagramming.
- Save documents in the new file format.
- Work with older documents using compatibility mode and/or convert older documents.
