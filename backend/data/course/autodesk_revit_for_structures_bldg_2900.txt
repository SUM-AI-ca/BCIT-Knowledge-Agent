## Autodesk Revit For Structures BLDG 2900
Building Course
## Course Overview
This course covers the basics of Autodesk Revit in a Structural environment, from design through construction documentation. Students will be introduced to the tools and concepts of working with a fully parametric building modeller.
### Prerequisite(s)
- DRFT 1000 or Drafting skills in a structural Environment, AND familiarity with Windows.
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Understand the interface of Autodesk Revit Building in a Structural environment.
- Start a Structural Project using architectural underlay.
- Set up levels and grids.
- Create columns, walls, floors and foundations.
- Create beams, framing systems, and bracing.
- Work with views.
- Create a Title Block.
- Use the modify commands.
- Annotate and detail plans and sections.
- Create simple schedules.
- Set up sheets and Printing.
Effective as of Winter 2013
