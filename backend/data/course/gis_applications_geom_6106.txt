## GIS Applications GEOM 6106
Geomatics Course
## Course Overview
​This course covers concepts and techniques required for the application and implementation of GIS and provides a practical approach to solving geospatial problems. The course employs common spatial analysis and associated modelling techniques, widely used in GIS, through open-source and commercially available software. The course also discusses the PPDAC (Problem, Plan, Data, Analysis, and Conclusion) model used with spatial analysis and requires students to design GIS systems aimed at solving real-world geospatial challenges. In addition, geospatial information applications specific to geomatics engineering, LIS and BIM are examined. Topics include model progression and specifications, standardization, implementation procedures and tools, and how these topics integrate with GIS.​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the PPDAC model applied to solve spatial problems.
- Discuss how to set up a geospatial information system to solve a spatial problem.
- Review different open-source data (available at a global, national, provincial, and regional level).
- Recognize the role of metadata and standards.
- Identify problems associated with integrating data from different sources with different specifications and how to overcome them.
- Apply location-allocation analysis (for applications such as urban planning or disaster management).
- Create density maps to study and solve spatial problems (for applications such as service area or hot spots for crime, healthcare, vehicle accident determination, and so on).
- Implement surface analysis (for intervisibility determination, flood map compilation, and so on).
- Apply network analysis with different cost functions.
- Describe the concepts of LIS and BIM.
- Identify the advantages and limitations of LIS and BIM for surveying projects and geospatial applications.
- Demonstrate the need for LIS, BIM and GIS integration based on project requirements.​
