## Advanced Games Programming Techniques 2 COMP 8851
Computer Systems Course
## Course Overview
This course will provide the student with exposure to more advanced computing techniques used in games programming. The course will focus on materials not covered in other programming courses. In addition to reviewing basic data structures, the student will be introduced to data structures and algorithms used in games for rendering, sorting, animation, collision detection and handling, and basic optimization.
### Prerequisite(s)
- COMP 8551
### Credits
3.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Choose and implement appropriate data structures and algorithms for rendering in games programming.
- Choose and implement appropriate data structures and algorithms for sorting in games programming.
- Choose and implement appropriate data structures and algorithms for animation in games programming.
- Choose and implement appropriate data structures and algorithms for collision detection and handling in games programming.
- Choose and implement appropriate data structures and algorithms for basic optimization in games programming.
- Design and implement optimized applications on both mobile and desktop platforms.
