## Microsoft Windows 2000 Server CITX 2161
Computer Information Technology Electronics Course
## Course Overview
This hands-on class covers all the critical skills necessary to install, configure and implement Windows 2000 Server and help you manage your network more effectively. Students will learn to configure remote access services, integrate legacy software, and troubleshoot and tune Windows 2000 for optimal efficiency.
### Prerequisite(s)
- 70% in CITX 2160 or 70% in CITX 2165
### Credits
3.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Install and configure Microsoft Windows 2000 Server.
- Work with network protocols, routing, remote access and other application server functions; such as terminal services.
- Monitor and optimize Windows 2000 Server.
