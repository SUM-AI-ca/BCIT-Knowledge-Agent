## Server-Side Web Scripting with PHP COMP 4515
Computer Systems Course
## Course Overview
This hands-on course builds upon COMP 4514 in the Full Stack Web Development Diploma. Students are introduced to server-side scripting using PHP: a platform-independent, server-side web scripting language. Topics include: PHP theory and syntax, textfile manipulation, cookies, regular expressions, sessions, graphics, and database interactions. Labs and exercises focus on the major functions of PHP server-side scripting using a wide variety of open-source software tools and code libraries. Students practice how to write reusable classes and object-oriented scripts and use PHP frameworks such as Laravel in addition to unit-testing frameworks such as PHPUnit. Secure sessions, hashing and encryption techniques, and the use the PHP command line interface are also covered. By the end of this course successful participants will be able to create a back-end PHP service to power advanced web applications.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the theory behind server-side Web scripting.
- Write PHP Web scripts with and without HTML content.
- Identify, locate, download, and install free server-side Web scripting tools.
- Identify, locate, and download sample PHP scripts and resources relevant to PHP scripting.
- Install libraries that enable the use of resources such as compression, encryption, password security.
- Obtain, process, and store user input from Web pages.
- Develop PHP scripts that use cookies to remember users and user data.
- Develop PHP scripts that use regular expressions to find, process, and validate data.
- Develop PHP scripts that use server-side resources with their Web pages including files, databases, and images that are located on the server.
- Develop PHP scripts that use sessions to authorize users and keep session data persistent across multiple Web pages.
- Implement custom classes that generate PHP objects.
- Discuss advanced database issues that are relevant to utilizing databases with PHP.
- Discuss security issues that are relevant to PHP website construction.
- Write secure and robust PHP code that is resistant to errors and attacks.
- Use PHP to generate pdf documents dynamically.
- Use Object Oriented Programming techniques in authoring PHP scripts.
- Use PHP frameworks and templating engines such as Laravel blade or Smarty.
- Use unit-testing frameworks such as PHPUnit.
