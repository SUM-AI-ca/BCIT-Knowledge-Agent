## Selected Topics in Database Systems COMP 4925
Computer Systems Course
## Course Overview
This course focuses on advanced topics in database technologies, database systems design and development tools, data management, enterprise servers and systems, and relevant related areas. Topics reflect on the current trends in the use of databases in the industry. Some of these topics include: business intelligence, data warehousing and OLAP, databases on the web, database applications based on 3-tier and n-tier models, development for enterprise systems, and connectivity and GUI development.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Discuss business decision-making and the need for business intelligence (BI) database applications.
- Explain the processes and issues in designing and populating a data warehouse / data mart for BI.
- Design and implement a data warehouse for BI.
- Design and develop analytic database applications for BI.
- Design and develop database-driven web applications using relevant tools and platforms.
