## Pattern Development SMTL 1144
Sheet Metal Course
## Course Overview
Students will learn about basic lines used in drawings, sketch objects using orthographic projection, isometric, and sketch working drawings. Develop geometric constructions and patterns using Parallel Line Development, Radial Line Development and Triangulation.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
13.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Describe types of drawings.
- Identify types of drawings.
- Sketch a set of working drawings using common drawing practices.
- Develop geometric constructions.
- Use calculators to develop patterns to +/- 1/32.
- Develop patterns using parallel line development
- Develop patterns using radial line development.
- Calculate roof pitches.
- Develop patterns using triangulation.
- Develop patterns for duct fittings and calculate cut sizes.
