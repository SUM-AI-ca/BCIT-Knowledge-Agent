## Exploring Technical Aspects COMP 2610
Computer Systems Course
## Course Overview
Describes integrated circuit technology, logic design principles, memory and microprocessor design, peripherals, and software. Includes the evolution of IC technology, boolean logic and design, design and connection of microprocessor and support chips. Introduces microprocessor programming principles using a Z80-based single-board computer, an overview of system software, programming languages and application packages, and a discussion of communications methods and technologies.
### Prerequisite(s)
- 50% in COMP 1401
