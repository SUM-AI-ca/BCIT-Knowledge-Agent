## Lufthansa Technical Aviation English Course C AVIA 0126
Aviation Course
## Course Overview
The English Course which LTT offers concentrate on the language which is 'spoken' in the technical manuals. Course C is the Advanced Level. Each module comprises 10 lessons. The lessons contain a Grammar Section, a Vocabulary Section, a Read and Listen Part and an Assessment (normally 50 questions to be answered). Screen time: Appr. 25 hrs
### Prerequisite(s)
- AVIA 0124 and AVIA 0125
