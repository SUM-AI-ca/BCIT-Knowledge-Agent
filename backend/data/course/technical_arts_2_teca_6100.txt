## Technical Arts 2 TECA 6100
Technical Arts Course
## Course Overview
Building on knowledge and skills developed in Technical Arts 1, this course will focus on creating 3D-friendly shaders and materials for different projects used in the visual effects, animation, and game industries. In this course, students will use industry standard applications to develop materials and visual effects. In addition, students will create and optimize textures to be imported into 3D applications and game engines ​
### Prerequisite(s)
- TECA 5200
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain shader nodes in 3D applications and game engines.
- Export shader nodes to be used in different applications.
- Develop procedural materials and shaders.
- Create shading networks inside game engines and 3D applications.
- Formulate scripts and expressions for shading networks.
- Create seamless and tileable textures.
- Produce game engine friendly textures.
- Integrate and import textures into 3D applications and game engines.
Effective as of Fall 2019
