## 3D Animation for Games MDIA 1366
Media Communications Course
## Course Overview
This course will cover the process of designing and creating character and mechanics animation for the purposes of game production for platforms including; Game consoles, Computers, Tablets and SmartPhones. Students will learn the essentials and the methods behind efficient animation development for game production. In addition student’s will study how to work with the Maya Trax editor to composite, blend and modify animation clips for preparation into a game engine. Rigging essentials and animation baking will also be covered.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Create rigs for mechanical models.
- Create rigs for Biped characters.
- Create rigs for Quadruped characters.
- Skin Meshes over skeletons.
- Work with expressions and rig controls.
- Integrate generic animation including cycle design, walk and run.
- Create character sets in Maya.
- Provide referencing and animation.
- Create and export animation clips.
- Composite animation clips in a Trax Editor.
- Test animations and Baking key frames.
- Export animations ready to import into a game engine.
