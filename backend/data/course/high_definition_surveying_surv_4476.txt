## High Definition Surveying SURV 4476
Surveying Course
## Course Overview
SURV4476 presents a hands-on introduction to various CADD and high definition survey software packages that are used in the Geomatics industry. Students will work through labs using these different software packages so that they are introduced to the process of managing, manipulating, editing and modeling real world and complex datasets used in high definition surveying.
### Prerequisite(s)
- No prerequisites are required for this course.

2.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Review aerial LiDAR systems and uses.
- Manipulate aerial LiDAR data using the software.
- Create a filtered TIN surface and contours and building models.
- Discuss quality control issues in aerial LiDAR.
- View aerial LiDAR in Softcopy Workstation.
- Georeference and calibrate aerial LiDAR.
- Review terrestrial LiDAR and reference orient several point clouds.
- Register several point clouds using software.
- Create a 3D model of laser scan data.
