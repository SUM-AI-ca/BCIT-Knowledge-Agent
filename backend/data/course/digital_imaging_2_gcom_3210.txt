## Digital Imaging 2 GCOM 3210
Graphic Communications Course
## Course Overview
This course concentrates on checking that documents are set up properly before they are printed by application programs used for pre-flighting. Students will also set up colour management settings within the application programs using ICC profiles to help ensure consistent colour reproduction from the monitor to final digital output. Students will perform all the tasks using a high-capacity digital printer including setting up routines for running calibration and registrations tests. A database will be utilized to create a variable data print run for a personalized print marketing campaign. Students will impose a four-colour brochure with bleeds and trim marks and produce final output. The final exam will be to produce a complex job from creation through to completion.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Perform manual pre-flighting for identifying potential output problems.
- Build a job using various application files.
- Prepare pre-flight documents to create a report identifying potential problems.
- Modify native application files to correctly process through the raster image processor (RIP)
- Create PDF files from various applications.
- Implement ICC colour profile, colour management software, and RIP settings for colour management consistency.
- Use calibration software effectively to ensure consistent colour output.
- Recognize consistency, verification, calibration, characterization, and conversion issues.
- Troubleshoot a file and correct either on the fly or on demand.​
- Set up and prepare a digital printer for four-colour digital output.
- Assess PDF files to ensure they have been through the pre-flight process.
- Customize a print job with variable data, including variable customer specifications.
- Set up jobs to merge database for a personalized media campaign
- Run a variable data client job.
- Layout press runs for the printer.
