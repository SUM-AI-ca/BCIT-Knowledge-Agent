## AutoCAD for Interior Design 2 INTD 2335
Interior Design Course
## Course Overview
Using the current release of AutoCAD for the PC, students will produce 2D architectural drawings. The course emphasis is on using the AutoCAD commands learned in AutoCAD, Part A, and applying them to create a set of interior design drawings, including plans, elevations and sections. The students will also be introduced to the use of External References, Attributes and to setting up drawings for plotting.
### Prerequisite(s)
- 50% in INTD 1345 and 50% in INTD 1350 and 65% in AICO 1160

## Learning Outcomes
At the end of this course the student will be able to:
- Produce a set of interior design drawings using basic AutoCAD commands.
- Produce a set of interior design drawings using basic AutoCAD commands.
- Set up sheets composed of plans, elevations and details of varying scales.
- Produce a specified plan layout.
- Produce a set of interior design drawings including:
- A cover sheet.
- A furniture plan with furniture inserted as blocks.
- A construction plan that includes hatching, elevation and section symbols, north arrow.
- A reflected ceiling plan, and a power and communication plan or lighting/electrical plan.
- Plot drawings at a print shop using appropriate line weights, scales and so forth, for interior design purposes.
