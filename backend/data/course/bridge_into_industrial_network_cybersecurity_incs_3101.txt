## Bridge into Industrial Network Cybersecurity INCS 3101
Industrial Network Cybersecuri Course
## Course Overview
Students will engage in directed studies that will allow them to bridge into the Industrial Network Cybersecurity option from the Electrical Engineering and Technology program area. The studies will include Python programming and the Linux operating system. At the end of the course a final test will be administrated by the instructor of the course. This course when ​combined with INCS 1110 and INCS 2110 will allow direct entry into the second year of the Industrial Network Cybersecurity program (starting at the beginning of the third term).
### Prerequisite(s)
- Completion of the Electrical and Computer Engineering Technology Diploma program (any option).
### Credits
6.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Write programs in Python that use data types, conditional and interactive control structures, and functions.
- Write programs in Python that use arrays, strings, sets and maps.
- Write programs in Python that use standard python libraries.
- Use Python for file input and output to allow persistence of information.
- Access the Linux command line to access help and manage, create, edit and view files.
- Manage local users and groups on a Linux system.
- Manage and monitor processes on a Linux system.
- Manage system logs on a Linux system.
- Manage Linux software packages including installation and updating packages.
- Access Linux file systems.
