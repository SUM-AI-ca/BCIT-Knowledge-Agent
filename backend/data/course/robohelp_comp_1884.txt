## RoboHelp COMP 1884
Computer Systems Course
## Course Overview
Macromedia RoboHelp is the fastest, easiest way to create professional Help systems and documentation for desktop and web-based applications. Students learn to create Help systems that include: Help topics, Table of Contents, Index, Glossary, context-sensitive Help, and more. Hands-on lab exercises generate Help systems in an online Help format and press-ready printed documentation.
### Prerequisite(s)
- COMP 1002 and word processing experience or equivalent knowledge.
### Credits
1.5
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion of the course, students will be able to:
- Analyze user help requirements
- Design help systems for desktop or web-based applications
- Use standard and advanced Help features, including tables of content, indexes, glossaries, graphics and special effects
- Write and constellate context-specific help files
- Design, write and create tutor files and animations.
