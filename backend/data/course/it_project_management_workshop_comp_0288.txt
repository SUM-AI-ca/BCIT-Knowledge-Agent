## IT Project Management Workshop COMP 0288
Computer Systems Course
## Course Overview
This two day hands-on workshop provides a comprehensive introduction of project management (PM) terminology, techniques and best practices. Examples used are in the Information Technology (IT) field. Students learn to build and execute smaller IT Project Plans using Microsoft Project. Topics include: stakeholders, scope, deliverables, milestones, scheduling, estimates and budgets. Using theory and practical examples, participants will explore PM methodologies using MS Project software to apply their recently acquired knowledge. Successful students will be able to oversee building of a project plan and monitor delivery of an IT project to industry standards. By the end of this workshop participants will have a basic understanding of IT Project Management.
### Prerequisite(s)
- COMP 1002 or equivalent knowledge of a Windows PC, and file management.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Define project management.
- Describe fundamental project management terminology.
- Determine stakeholders.
- Outline the scope.
- Identify the deliverables.
- Plan phases and milestones.
- Perform scheduling of tasks and resources.
- Formulate estimates.
- Develop a budget.
- Perform a post project evaluation.
