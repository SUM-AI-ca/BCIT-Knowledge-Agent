## Wiring Methods TELC 1120
Electrical Trades Course
## Course Overview
This course covers practices and procedures of low-voltage wiring. Students will work with various wire and cable types and fasteners and connectors. Special emphasis is placed on working safely with 120-volt branch circuits and electrical metallic tubing (EMT).
### Prerequisite(s)
- TELC 1110
### Credits
10.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Interpret the Canadian Electrical Code and BC Amendments
- Install low-voltage cables
- Install branch circuit wiring
- Install electrical metallic tubing (EMT)
