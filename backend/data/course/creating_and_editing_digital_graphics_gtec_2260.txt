## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Use the pen tool fundamental drawing skills.
- Use direct selection tools for editing artwork.
- Recognize the importance of layers and sub-layers when creating artwork.
- Create balanced shapes by averaging points on horizontal and vertical axis paths.
- Use Illustrator’s transformation tools based on a centre origin point.
- Build new shapes using Illustrator’s Pathfinder tool.
- Incorporate artwork with transparency effects for changing an artwork’s opacity.
- Create and store from Illustrator’s colour libraries including Pantone and Trumatch.
- Demonstrate a colour managed PDF workflow in an Adobe Illustrator working file.
- Use Illustrator’s filters and live effects.
- Create gradients, blends and gradient meshes.
- Distinguish benefits of raster and vector elements in various file formats.
- Create artwork for 3 dimensional packages in two dimensional files.
