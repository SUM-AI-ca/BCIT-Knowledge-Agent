## HTML5 for Designers MDIA 2078
Media Communications Course
## Course Overview
This course explores design and construction of web pages using HTML5 and CSS3 authoring tools. HTML5 and CSS3 are the structural and presentational building blocks used to create websites. Students will interpret HTML5 scripting, design and layout web pages, combine videos, music and animation using tools and methods learned in the course. Successful completion of this course will include creating an HTML5 digital portfolio using tools and methods covered in the course.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Design and create content using HTML5 and CSS3.
- Describe and generate the structure of HTML5 including; headers, footers, articles and sections.
- Create a web interface and navigation system.
- Identify different resources for HTML5 and CSS3 scripting help.
- Demonstrate efficient use of HTML5 form elements and attributes.
- Combine and embed videos, music and animation using HTML5.
- Practice writing CSS3 scripts including; selectors, web fonts, text wraps, background colors, image placement, rounded corners, borders, gradients and shadows.
- Save, export and optimize content for the web.
- Explain different methods of uploading content to web servers.
- Embed Social Media feeds including; Linkedin, Facebook and Twitter into HTML5.
- Design and create an HTML5 digital portfolio using tools and methods covered in the course.
