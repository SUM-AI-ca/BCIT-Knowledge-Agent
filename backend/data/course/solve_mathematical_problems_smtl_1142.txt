## Solve Mathematical Problems SMTL 1142
Sheet Metal Course
## Course Overview
Students will solve mathematical problems from a trades perspective using whole numbers, fractions, decimals, metric and imperial measurements, ratio and proportion, percent, powers and roots, simple graphs, formulas, perimeters, areas, volumes, triangles, angles and geometric construction.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
2.5
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Solve problems using whole numbers.
- Solve problems using fractions.
- Solve problems using decimals.
- Convert metric and imperial measurements.
- Solve problems using ratio and proportion.
- Solve problems using percent.
- Solve problems using powers and roots.
- Interpret simple graphs.
- Solve problems using formulas.
- Solve problems using perimeters, areas and volumes.
- Solve problems using triangles, angles and geometric construction.
