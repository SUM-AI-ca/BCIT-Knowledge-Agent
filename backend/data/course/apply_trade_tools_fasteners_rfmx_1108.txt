## Apply Trade Tools/Fasteners RFMX 1108
Refrigeration Mechanic Course
## Course Overview
As in any trade activity, students must have a comprehensive knowledge about the different kinds of tools used within the Refrigeration field. This includes recognizing the proper application of any given tool along with safe practices and usage associated with it. In addition the course prepares students to increase their knowledge about the different kinds of fasteners and fittings used in piping trades. As a result, this course will identify the types and their application. Course activities include practical exercises on the proper use and fabrication of piping projects.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Identify various trade-related mechanical/electrical tools and equipment and describe their application.
- Describe all safety procedures to be followed while using tools and equipment.
- Select and use selected trade specialty tools, including:
- Gauge manifold set
- Vacuum gauges
- Charging stations
- Weight scales
- Temperature recorders
- Tube benders
- Swaging tools
- Flaring tools
