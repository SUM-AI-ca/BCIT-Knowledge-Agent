## Microsoft Excel Level 2 COMP 1262
Computer Systems Course
## Course Overview
COMP 1262 is no longer being offered. Please see COMP 2362 or COMP 2364 . Continuation from COMP 1261 - Level 1 and covers advanced MS Excel features. Expert topics include: charting, organization charts and diagrams, subtotaling data, linking worksheets, conditional formatting, importing data, templates, data validation, scenarios, goal seek and formula auditing. Learn advanced spreadsheet techniques and how to use MS Excel's advanced features such as pivot tables and acquire an insight into macros.
### Prerequisite(s)
- 50% in COMP 1261
### Credits
1.5
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Create, Edit and Format Charts.
- Create Combination Charts.
- Protect Workbooks, Worksheets and Ranges.
- Import and Export Data.
- More on Templates and Styles.
- Analyze Data.
- Use the Scenario Manager, Solver, Goal Seek.
- Link Worksheets and Workbooks.
- Consolidate Data by Position and Category.
- Create Pivot Tables.
- Trace Dependents, Precedents and Trace Errors.
- Use data validation techniques.
- Create and Modify Worksheet Outlines.
- Create and Customize Toolbars.
- Use Database Lists and Filters to Manage and Summarize Data.
