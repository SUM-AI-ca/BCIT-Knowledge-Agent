## Communication Graphics with CorelDRAW Workshop COMM 0110
Communication Course
## Course Overview
This two-day event is an intensive weekend workshop that focuses on key concepts for creating graphics that visually communicate various types of information. Instruction takes place in an up-to-date computer-lab using CorelDRAW and combines demonstrations with hands-on guided tutorials. The techniques discussed can typically be accomplished using any up-to-date graphics application. Intended Audience: This will be of interest to anyone who wishes to upgrade or learn new graphic communication skills. Material covered is geared toward practical business, marketing, and technical information graphics professionals who need to present eye-catching or detailed visual information.
### Prerequisite(s)
- Prior experience using CorelDRAW (or an equivalent graphics application) is recommended but not mandatory. Intermediate computer skills are required.

## Learning Outcomes
Upon completion of this course, the student will be able to:
- Improve the visual impact of presentation and information graphics.
- Discover quick ways to add interest to dull charts and diagrams.
- Learn how to add perspective and 3D effects.
- See how the experts use fountain fills/gradients to add depth effects.
- Discover how to harness graphic effects such as blending and contouring.
- Find out professional techniques for integrating vector and bitmap drawing elements.
- Create multi-purpose drawings using ordering, grouping, and layering strategies.
- Create text containers and fit text to shapes and paths.
- Use Lens Effects for quick diagram cut-aways.
- Discover advanced CorelDRAW user customization and tool tricks.
- Master the latest drawing tools, techniques, and effects.
- Discover fast image-masking strategies using the latest selection tools.
- Learn to choose the best retouching filters for maximum impact.
- Understand how to manipulate backgrounds and create multi-layer effects.
- Learn to manipulate photo objects and control photorealistic effects.
- Discover the Power of Advanced Bitmap-Manipulation Tools.
