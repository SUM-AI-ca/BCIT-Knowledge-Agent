## Digital Printing 2 GTEC 4363
Graphic Communications Technology Course
## Course Overview
This course concentrates on checking documents before they are printed by application programs used for preflighting including native application and PDF files. Students will also setup CMS settings within the application programs using ICC profiles to help ensure consistent colour reproduction from the monitor to final digital output. Students will perform all of the tasks using a high capacity digital printer including setting up routines for running calibration and registrations tests. Students will impose a four colour brochure with bleeds and trim marks and produce final output. The final exam will be to produce a complex job from creation through to completion.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Perform manual pre-flighting for identifying potential output problems.
- Prepare pre-flight documents to create a report identifying potential problems.
- Work with native application files.
- Create .pdf files from various applications.
- Implement ICC colour profiles for colour management consistency.
- Work with CMS and DTP applications together.
- Recognize consistency, verification, calibration, characterization and conversion issues.
- Troubleshoot a file and correct either on the fly or on demand.
- Use printing quick tips to maximize productivity and minimize waste.
- Setup and prepare a digital printer for four colour digital output.
- Use calibration software to ensure consistent colour output.
- Assess pdf files to ensure they have been through the pre-flight process.
- Customize the job with variable data, including variable date.
- Run a variable date client job.
- Build a job using various application files.
- Impose the job for the printer.
- Troubleshoot the job through the production process.
