## Introduction to Computers RWCD 1020
Railway Conductor Course
## Course Overview
This course is an introduction to computer fundamentals with emphasis on skills training. Theoretical components include computer concepts and terminology. Practical basic skills will be developed in Windows disk and file management procedures, keyboarding (speed and accuracy), word processing, spreadsheet applications, Internet and email.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Utilize basic keyboarding skills (recommended 30 Words per minute).
- Use the following computer fundamentals (including computer concepts and terminology):
- Basic windows disk and file management procedures
- Basic skills in Word processing
- Spreadsheet applications (Excel)
- Internet
- E-mail
