## Unix/Linux Administration CITX 2181
Computer Information Technology Electronics Course
## Course Overview
Basic, hands-on administering of a Linux system, and discusses basic system administration tasks related to Linux. Some topics covered include: package management, kernel, text editing, processing, printing, shells, scripting, programming, managing users, compiling and X MS Windows system. Course intended for Technicians.
### Prerequisite(s)
- CITX 2180
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Customize a shell environment.
- Use basic system administration commands in Linux.
- Create and manage user accounts.
- Manage processes using basic commands.
- Manage the power supply to your computer.
- Check the file system integrity.
- Manage system resources.
- Configure system logging.
- Create scripts and automated procedures.
- Set up, configure and manage printing.
- Back up system data.
