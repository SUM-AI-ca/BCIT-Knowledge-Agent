## Computer Systems Technology Foundations 1 COMP 2653
Computer Systems Course
## Course Overview
This intensive course is intended for applicants to the Bachelor of Technology degree in Computer Systems. The course covers, in one term, programming with C#, basic computer architecture concepts and principles. The material is presented in an integrated fashion and the goal is to provide the students with an introductory comprehension of computer systems technology and computer application development to continue in the Bachelor program. Topics include: 1) C# programming (Introduction to C# development environment, Basic Programming (Control Structures, Methods), Arrays, Files, Classes, Objects, Windows Forms Programming, Basic Debugging); 2) Architecture (Basic concepts, CPU, Primary Memory, Secondary Memory, I/O Devices, Boolean Algebra and Digital Logic Gates, Combinatorial Logic Design).
### Prerequisite(s)

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe the architecture of the main hardware components of a computer system, including peripheral devices, and inter-computer communications.
- Understand basic digital logic gates and combinatorial logic design.
- Work with Boolean algebra, truth tables and logic equations.
- Design and develop C# programs.
- Explain and use different C# structures like arrays, files, classes and objects.
- Create simple console and Windows forms applications.
- Use exception handling in code.
- Perform basic debugging in C#.
