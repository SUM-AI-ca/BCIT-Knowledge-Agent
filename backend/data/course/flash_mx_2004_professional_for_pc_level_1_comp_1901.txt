## Flash MX 2004 Professional for PC Level 1 COMP 1901
Computer Systems Course
## Course Overview
Learn to unlock the power of Macromedia's new Flash MX 2004 Pro on the PC platform by working through a series of hands-on exercises. Students are shown how to: utilize common toolbar tools, create and position graphics, movieclips and buttons, create keyframes, add simple sounds/text and import resources. Students will also learn to construct a simple animation, create and use layers and publish a movie destined for the web. A number of invaluable online resources will also be discussed.
### Prerequisite(s)
- COMP 1850 or equivalent HTML experience.
### Credits
1.0

## Learning Outcomes
Upon successful completion, students will be able to:
- Identify and utilize the more common toolbar tools
- Utilize the built in help and online resources for Flash
- Differentiate and utilize the timeline and stage
- Describe the difference between movieclips, graphics and buttons
- Create and position a graphic, movieclip and button
- Construct a simple motion tween animation
- Create a simple shape tween animation
- Create and interact with layers
- Publish a movie destined for the web
- Describe the difference between an FLA file and a SWF file
- Identify, create and remove frames and key frames
- Identify and utilize the symbol library
- Add simple sounds to their projects
- Add and work with text in their projects
- Implement frame by frame animation
- Recognize and use some basic ActionScript commands
- Import resources into the project
