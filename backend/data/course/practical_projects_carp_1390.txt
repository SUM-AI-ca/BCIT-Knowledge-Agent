## Learning Outcomes
Upon successful completion, the student will be able to:
- Use safe work practices.
- Read residential drawings.
- Draw simple plans.
- Select framing lumber.
- Select framing and finishing hardware.
- Calculate quantities of concrete.
- Use and maintain hand tools.
- Use and maintain portable power tools.
- Use and maintain shop equipment.
- Use optical levels.
- Use electronic levels.
- Use scaffolds and ladders.
- Tie knots, bends and hitches.
- Use hoisting equipment.
- Lay out locations on a building site.
- Build batter boards, set lines and square corners.
- Build footing and wall forms.
- Build foundations and floors.
- Build walls and partitions.
- Build gable roofs with ceiling joists.
- Build hip roofs.
- Build straight stairs.
- Install steel-stud framing and wallboard.
- Apply roofing materials.
- Install doors and windows.
- Apply exterior finishes.
- Apply wall finishes and trim.
- Build cabinets and apply plastic laminate.
