## Using New Media on the Web: Flash MDIA 3208
Media Communications Course
## Course Overview
Using 49 custom video tutorials, this course examines all of the skills necessary to create Flash animations. Starting with the basic drawing tools, we work our way through motion, classic, and shape tweens, to guided animations and masks. You will explore how to create animated buttons and apply simple button and frame actions, and add sound effects, music, and bitmap imagery to your animations. By the end of the course, you should be able to quickly and efficiently work with the Flash timeline, and create dynamic animations to make your Websites more interesting and more interactive.
### Prerequisite(s)
- MDIA 1205 and MDIA 2205

## Learning Outcomes
Upon successful completion, the student will be able to:
- Describe the Flash metaphor and interface
- Create graphics in Flash
- Describe the Flash tools and their functions
- Detail how to use layers in Flash
- Work with the Flash timeline
- Create motion, classic, and shape tweens
- Create guided animations and mask effects
- Control the Flash timeline with buttons and simple actions
- Use sound effects, music, and imagery to enhance their presentations
- Combine all of the tools covered in the course to create complete Flash websites, and animations
