## MS Project Workshop 2 COMP 0384
Computer Systems Course
## Course Overview
This intensive hands-on workshop follows on from COMP 0383 MS Project Workshop 1. Students are required to understand basic use of the MS Project application plus have a prior understanding of Project Management concepts. Topics include: splitting tasks, using the Organizer, sharing resources, multiple projects, macros, and custom templates. Successful participants will learn to use some of the intermediate topics in the MS Project software application for project management scheduling.
### Prerequisite(s)
- COMP 0383 or equivalent knowledge of using MS Project 2013.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create a custom template.
- Create multiple project files and to be able to link master and sub-projects.
- Share a resource pool.
- Import or export data to from MS Project.
- Create custom tables, views, and reports for your own purposes.
- Demonstrate the use of the “Organizer” to transfer customized calendars.
- Demonstrate the effective use of filters for views, tables, and reports.
- Define a project baseline for multiple project consolidation and to update tasks to reflect Baseline, Actual, and Current Costs.
- Demonstrate effective Levelling Techniques for single and multiple projects.
- Demonstrate effective Crashing Techniques for single and multiple projects.
