## Communications 2 NAUT 1810
Ocean Navigation Course
## Course Overview
This course covers communication by Morse code using flashing light or sound signals; the use of Standard Marine Navigational vocabulary as replaced by the International Maritime Organisation Standard Marine Communication Phrases; use English in written and oral form in communication with other ships and coast stations.
### Prerequisite(s)
- Students to be able to recognize and read by light the Morse symbols prior to taking this course.
### Credits
2.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Recognise morse code alphabets and numerals by flash light.
- Send and receive morse signals by flash light.
- Describe procedures for using morse signals as communication means.
- List single-letter signals which may be sounded in compliance with the Collision Regulations.
- Use the Standard Marine Navigational Vocabulary.
- Use charts and nautical publications.
- Interpret meteorological information.
