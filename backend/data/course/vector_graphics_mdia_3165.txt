## Vector Graphics MDIA 3165
Media Communications Course
## Course Overview
This course teaches students how to create crisp vector graphics and text with precise shape building tools, fluid painterly brushes and advanced path controls for digital printing, web and mobile devices. Students will create vector artwork with an array of sophisticated drawing tools to create resolution independent Bezier curves. Students will create their artwork on multiple art boards and use natural brushes, layers, shapes, colors, blends, alignments and transformations to develop their artwork. This course will also teach perspective drawing using perspective grids to draw shapes and scenes in accurate one, two or three point linear perspective, creating a look of realistic depth and distance.

## Learning Outcomes
At the end of this course the student will be able to:
- Create shapes with the shape builder tool.
- Produce vector graphics using different drawing modes including draw inside and draw behind modes.
- Apply different files and stroke weights to objects.
- Use pre-defined color groups to recolor artwork.
- Create precise typography with tracking and kerning techniques.
- Apply appearance effects to artwork on fills and strokes.
- Integrate different brush libraries to create artwork.
- Create and apply symbols with different symbol libraries.
- Create artwork with multiple art boards.
- Paint with vectors that resemble real-world brush strokes.
- Use perspective grids to draw shapes and scenes in accurate one, two or three point linear perspective.
- Create fully controllable variable width strokes, arrowheads, dashes and art brush scaling along a path.
