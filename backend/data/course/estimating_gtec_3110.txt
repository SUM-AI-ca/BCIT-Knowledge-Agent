## Estimating GTEC 3110
Graphic Communications Technology Course
## Course Overview
This course begins with the fundamentals of printing estimating, estimating processes and the development of production standards. Students will work with EFI Print Management Solution software to create printing project cost estimates. Topics covered in this course will include the scope and function of printing estimating; production standards; print order processing - sale through invoice; estimating paper, ink and buyouts; estimating prepress; estimating sheet fed offset; estimating post-press; and the completion of a number of basic estimates.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe the steps required to assign costs to a print project production plan.
- Recognize the differences between marketing, pricing and profit in the printing industry.
- Create a production standard with MIS software for one pre-press, press and post-press function.
- Estimate paper requirements for straight, stagger cutting and bookwork.
- Calculate the correct spoilage for press and bindery operations.
- Explain the different methods of bookwork impositions.
- Create basic layouts for sheet and bookwork.
- Estimate ink quantity and cost.
- Provide cost estimates for digital pre-press production.
- Estimate sheeted presswork and common post-press production methods.
- Construct requests for quote and produce cost estimates for basic jobs, using MIS software.
- Estimate digital press work.
- Estimate basic web press production.
- Explain the common methods used to estimate small commercial work.
- Establish tailored prices using cost estimating.
- Create a system for pricing digital work.
- Write more complicated RFQ's.
- Produce advanced level estimates up to 3 parts.
- Explain the principles of budgeted hourly rates and activity based costing.
- Explain how a production standard is developed.
- Perform an audit on a set of production data.
