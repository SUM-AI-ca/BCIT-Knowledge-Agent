## AutoCAD for Windows AICO 2010
Computer Aided Design & Engineering Course
## Course Overview
Students will be introduced to many of the productivity tools available in AutoCAD for windows. Topics include: interface customization, import/export using Clipboard, Dynamic Data Exchange, Object Linking and Embedding, render tools and development tools. For experienced AutoCAD users.
### Prerequisite(s)
- 50% in AICO 2000
