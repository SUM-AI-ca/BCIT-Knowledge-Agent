## Measuring and Layout Tools MILL 1202
Millwright Course
## Course Overview
This course prepares students to use metric and imperial measuring instruments and layout tools to a level equivalent to Level One of the Apprenticeship program. Students will learn the use, proper handling and storage of measuring tools along with gaining skills in laying out a workpiece. The content of the course is aligned with the SkilledTradesBC’s 2014 Competency Profile Chart and includes the following competencies: C1 and C2.
### Prerequisite(s)
- MILL 1200 and MILL 1201
### Credits
4.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Use measuring and layout tools and instruments
- Identify measuring tools (scales, calipers, micrometers) and describe their purpose
- Describe maintenance and storage procedures for measuring tools
- Adjust and use measuring tools
- Identify layout tools (calipers, scales and optical tools) and describe their purpose
- Describe maintenance and storage procedures for layout tools
- Adjust and use layout tools to perform the layout of a workpiece
Effective as of Spring/Summer 2015
