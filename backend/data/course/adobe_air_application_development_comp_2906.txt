## Adobe AIR Application Development COMP 2906
Computer Systems Course
## Course Overview
Adobe AIR allows you to use your current web scripting skills for Rapid Application Development. Web developers who know; HTML/JavaScript, Flash or Flex, can now build desktop applications. The Adobe AIR runtime lets scripters create cross platform (PC, MAC, Linux), rich internet applications (RIA's) which can run on the desktop. Topics include how to: work with existing web applications, utilize file and operating systems, create windows and menus, use existing HTML content and connect to an established SQL database.

## Learning Outcomes
Upon success completion of this course, the student will be able to:
- Customize an existing application.
- Utilize HTML and existing Flash content.
- Utilize and access an embedded SQL database.
- Construct simple SQL statements.
- Create and manipulate windows and menus.
- Work with the local file system and Operating System.
- Package and deploy an application with updates.
- Design, build and test a basic AIR application.
