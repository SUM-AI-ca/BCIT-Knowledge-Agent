## Computer Graphics Fundamentals COMP 7840
Computer Systems Course
## Course Overview
Introduces IRIX, X Windows and Motif on Indy Silicon Graphics Inc. (SGA) workstations; writing, compiling, linking and debugging C programs. Covers computer graphics primitives such as basic line drawing and curve drawing algorithms; 2D/3D transformations, clipping, viewing projections and wireframe modelling. Object hierarchy, PHIGS (Programmer's Hierarchical Interactive Graphics System), PHIGS+ and the GL (Graphics Library) are also covered.
### Prerequisite(s)
- Proficiency in C Programming, trigonometry and linear algebra.
