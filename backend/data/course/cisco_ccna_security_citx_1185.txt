## Cisco CCNA Security CITX 1185
Computer Information Technology Electronics Course
## Course Overview
CCNA Security provides a next step for individuals who want to enhance their CCNA skill set. The curriculum provides an introduction to the core security concepts and skills needed for the installation, troubleshooting, and monitoring of network devices to maintain the integrity, confidentiality, and availability of data and devices. Cisco CCNA Security helps prepare students for entry- level network security career opportunities as a first step in becoming network security professionals. This course aligns with the globally recognized Cisco CCNA Security certification.
### Prerequisite(s)
- CITX 2060 - Cisco CCNA Level 2, or a Valid CCENT Certification.
### Credits
6.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Identify network security threats.
- Secure Remote Access with Cisco Secure Access Control Server 2000 and Cisco IOS AAA feature.
- Protect internet access by configuring perimeter routers.
- Create security boundaries within a network.
- Configure the Cisco IOS Firewall Feature Set Context-Based Access Control.
- Configure Cisco IOS Firewall Authentication Proxy.
- Configure Cisco IOS Firewall Intrusion Detection System.
- Use IPSec features in Cisco IOS software to create a secure site-to-site VPN using pre-shared keys and digital certificates.
- Use Easy VPN features to create a secure remote access VPN solution.
- Use Cisco Security Device Manager to secure Cisco routers.
- Use Cisco Router Management Center to manage Cisco Router VPN implementations.
