## Web Scripting 3 FWDP 3400
Front-End Web Developer Course
## Course Overview
The Web Scripting 3 course introduces students to JavaScript-based web application development. The course explores setting up and developing a web application using modern JavaScript build systems. Students will learn how to implement modern coding methodologies available in JavaScript such as modules and classes. Application state management will be explored in detail along with routing, validating user data and styling modules. Utilizing foundational JavaScript skills and modern JavaScript coding and build system techniques, students will explore developing and deploying full-featured web applications.
### Prerequisite(s)
- FWDP 1000 and FWDP 1400
### Credits
4.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain common JavaScript frameworks and explain when to implement them on a web site or application
- Understand and Utilize Node.js in Web Application Development
- Set up a development environment for JavaScript application development
- Explain application state management
- Use an applications state to manipulate the DOM
- Use routing to keep an application in sync with the URL address
- Fetch and Use Data from APIs in Web Applications
- Create and deploy stand-alone web applications
