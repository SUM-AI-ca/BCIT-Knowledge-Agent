## Engineering Graphics 2 MECH 2202
Mechanical Engineering Course
## Course Overview
Covers topics in engineering graphics and computer aided design, with emphasis on the creation and management of models and drawings in a team environment. Topics include advanced part modeling, parametric models, dimensioning standards, tolerance and fits, geometric dimensioning and tolerancing (GD&T), 2D CAD drawings, blocks and attributes, external references, piping and HVAC drawings, and working drawing set creation.
### Prerequisite(s)
- 50% in MECH 1102

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create robust, moderately complex 3D part models. [1, 5]
- Describe drawing control systems. [1, 5]
- Document moderately complex CAD models. [1, 5]
- Use appropriate dimension techniques. [1, 5]
- Apply common engineering tolerance systems to technical drawings. [1, 5]
- Use standard drawing symbols for machining and welding drawings. [1, 5]
- Apply geometric dimensioning and tolerancing (GDT) in drawings. [1, 5]
- Create and edit 2D CAD geometric drawings. [1, 5]
- Use blocks and external references to share drawing information. [1, 5]
- Describe model space / paper space relationships in AutoCAD drawings. [1, 5]
- Create plotted drawings from AutoCAD. [1, 5]
- Create and interpret working drawings. [1, 5]
Effective as of Fall 2018
