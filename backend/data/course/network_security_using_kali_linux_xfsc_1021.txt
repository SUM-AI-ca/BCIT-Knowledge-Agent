## Network Security using Kali Linux XFSC 1021
Forensics Microcredentials Course
## Course Overview
This 2-day workshop introduces the usage of Kali Linux to provide security functions. It covers the basics of hacking, including the concept of penetration testing (also known as ethical hacking) and its value in combating cyber threats. This workshop will expose the attendees to the world of cyber crimes. It will also provide hands-on exercises to demonstrate network hacking and to evaluate the security of a network system. The attendee should have a basic understanding of computer network and Linux operating system. It is recommended that students take "Networking Foundation" prior to taking this workshop. This workshop is suitable for those people who are handling network administration tasks. This workshop is especially useful to those who are dealing with network security operations.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the concept computer crimes;
- Explain the concept of ethical hacking;
- Evaluate the security of a computer network;
- Use Kali Linux to provide security functions.
