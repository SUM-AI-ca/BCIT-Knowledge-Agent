## Advanced Web Design GDES 2190
Graphic Design Course
## Course Overview
​Building upon the foundational knowledge gained in the introductory web design course, this advanced-level course aims to further enhance the skills of graphic designers in creating visually appealing and functional websites. Students will explore responsive design principles, expand their knowledge of HTML and CSS3, and gain experience with industry-standard web development frameworks. Additionally, they will learn to utilize and customize templates, understand the distinction between static websites and dynamic web applications, and incorporate CSS animations and transitions to enhance user experience. ​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Apply responsive design principles to create websites that adapt effectively to different devices and screen sizes.
- Demonstrate advanced proficiency in HTML5 by utilizing complex elements, forms, and multimedia.
- Implement CSS3 features, such as flexbox and grid, to create sophisticated webpage layouts.
- Create detailed layouts, animations, and interactive components that enhance user experience and accessibility.
- Use contemporary design tools and frameworks to create dynamic and interactive websites, adapting to the latest industry standards and technologies.
- Customize templates and themes to align with specific design requirements and streamline the design process.
- Analyze and differentiate between static websites and dynamic web applications while gaining insight into the design considerations and functionality associated with web applications.
- Implement CSS animations and transitions to enhance user engagement and create visually appealing effects.
