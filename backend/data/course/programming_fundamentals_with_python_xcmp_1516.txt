## Programming Fundamentals with Python XCMP 1516
Computing Microcredential Course
## Course Overview
The entry point for this program (no prerequisites, no experience necessary). Learn to develop basic software-development skills using the Python programming language. Learn the language fundamentals, up to and including variables, functions, modules, branching, looping, and containers.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
2.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Install and set-up Python.
- Analyze and explain the behavior of simple programs.
- Create simple algorithms for solving simple problems.
- Choose appropriate conditional and iteration constructs for a given programming task.
- Apply the techniques of decomposition to break a program into smaller pieces.
- Write programs that use conditional and iterative control structures, functions, and parameter passing.
- Write programs using the standard libraries available with a chosen programming language.
- Conduct a personal code review on a program component.
- Move on to XCMP 1526 - Programming Practice with Python.
