## Computer Applications with Microsoft Office COMP 1200
Computer Systems Course
## Course Overview
COMP 1200 has been replaced by COMP 2007 . Become proficient with MS Office and learn how to use Word, Excel, Access, PowerPoint and Outlook. This hands-on lab course is combined with lectures and provides intermediate application skills. Students learn to be productive immediately in business computer applications. Exercises and assignments are designed to create and work with documents, spreadsheets, presentations, relational databases and e-mail. Learn how to master time-saving tips and techniques and shortcuts for daily use in these basic business software applications.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Create, Save, Open, Close, Edit and Print files using Microsoft Word, Excel, and PowerPoint.
- Navigate quickly and efficiently throughout documents, workbooks, presentations and in Outlook.
- Create headers and footers in documents, workbooks and presentations.
- Apply font, paragraph and page formats to documents including borders and shading.
- Insert and modify clipart and pictures.
- Create and set custom tab stops with line leaders.
- Create and format text into table and column layouts.
- Create formulas using addition, subtraction, division, multiplication, and common functions such as Sum, Average, Min, Max and Count.
- Use the Payment and Future Value functions.
- Format cells, rows, columns.
- Insert, view and print comments.
- Create a simple column chart and pie chart.
- Format and modify slide layouts in presentations.
- Apply bullets and numbering to a document or presentation.
- Apply an animation scheme.
- Run a slide show presentation.
- Copy and link data from one Microsoft Office application into another.
- Work with email messages and attachments.
- Create and manage contacts.
- Schedule calendar appointments and create tasks.
- Use the built-in wizards to quickly create an Access database, forms, reports and queries.
- Add, edit, modify and delete records in an Access table.
- Create and run a query in Access.
- Create forms and reports in Access.
