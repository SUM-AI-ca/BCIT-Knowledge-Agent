## Overview

This course utilizes Excel's PowerPivot and PowerBI functionality working on skills to model different types of data and how the data is synthesized into management information. In addition to these skills, this course will dive into the issues related to big data and analyze big data so information can be integrated into the strategic decision-making process by using data visualization tools. Students will be then able to build custom dashboards to answer management problems.

## Learning Outcomes

- Structure data gathering to a business need.
- Utilize systems to store, edit, and retrieve required data.
- Determine best practices in data use.
- Discuss and apply ethical and legal considerations in the use of data.
- Build effective data visualizations to communicate meaning through data.
- Determine correct visual tool to analyze multiple data types.
- Perform quantitative and qualitative analyses as appropriate.
- Select tools to effectively convey meaning.
- Perform basic application use.
- Describe Business Intelligence (e.g., Online Analytical Processing or OLAP).
- Perform data analysis using MS Power BI toolset.
- Perform time series analysis (forecasting techniques).
- Apply Power BI to Data Mining and Discovery methods and use single and multiple table data sources in Power BI.
