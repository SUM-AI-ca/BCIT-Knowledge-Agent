## Install Electrical / Mechanical Equipment RFMX 1120
Refrigeration Mechanic Course
## Course Overview
This course covers the proper installation procedures for electrical and mechanical components. These installation procedures will meet all electrical code requirements as well B-52 Mechanical Code conditions. Students will work on electrical control boards as well as actual operational equipment.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
4.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
## Connect Single-Phase Motors, including:
- CSR motors
- CSIR motors
- PSC motors
- shaded pole motors
## Install electrical controls, including:
- high pressure switch
- low pressure switch
- compressor motor
- defrost timers
- liquid line solenoid
- thermostats
- defrost termination switch
- oil failure control
- fan switch
- evaporator fan motors
- evaporator defrost heaters
- evaporator drain heaters
- Troubleshoot electrical control circuits.
- Install mechanical components and perform start-up procedures.
Effective as of Spring/Summer 2007
