## Network Protocol Design and Implementation COMP 3980
Computer Systems Course
## Course Overview
​This course is an introduction to protocol design and implementation using POSIX platforms such as Linux. Introduction of basic synchronous and asynchronous protocols and device interfaces. POSIX systems-level programming and multithreaded applications design and implementation. Interfacing to Communications hardware such as RFID transceivers, GPS devices, and wireless modems. Design and implementation of bit and character-oriented protocols. Introduction to wireless communication protocols and implementation of error detection/correction algorithms. Also covered will be embedded applications development using boards such as the Arduino, Raspberry Pi, and Beagle boards. Introduction to POSIX server services deployment and security.
### Prerequisite(s)
- Completion of first year CST and Admission into the Data Communications and Internetworking Option.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe communications hardware and its interface to communications software.
- Create POSIX programs and mobile applications.
- Create programs using threads, synchronization objects, and Overlapped I/O.
- Create communications software using TCP/IP in C.
- Create communication software for use on wireless channels.
- Analyze and apply basic error detection/correction techniques.
- Perform basic developer-oriented System Administration tasks on a POSIX system.
