## Geomatics Project Planning GEOM 7230
Geomatics Course
## Course Overview
Helps students prepare for a geomatics project. The student's primary task is to find an industry sponsor and topic. Students will review literature on the project topic, practice technical presentation skills, use project management software, and write a project proposal.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
2.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Identify a project topic.
- Conduct a search for industrysponsorship or equivalent.
- Perform a literature review and write a consice summary of related work.
- Write a scientific research proposal for project.
