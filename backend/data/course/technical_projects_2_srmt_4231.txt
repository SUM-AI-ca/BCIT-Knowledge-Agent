## Technical Projects 2 SRMT 4231
Sustainable Resource Mgt Course
## Course Overview
This course provides the student with the opportunity to become involved with an applied research project of particular interest in the field of Renewable Resources. Experience will be gained in planning a project, working productively with other individuals in a team environment, recording relevant information in a number of different formats (including journals), meeting the stated objectives of the project, and reporting on a renewable resource-related group project. Students follow the critical steps introduced in SRMT 3231 to see a resource- related research project through to completion.
### Prerequisite(s)
- SRMT 3231
### Credits
4.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Select a topic for a technical project.
- Formulate goals, objectives, and strategies for a technical project.
- Prepare and present a project proposal and work schedule.
- Write concise project progress reports.
- Determine appropriate data sources for a technical project.
- Prepare a literature review for a technical project.
- Conduct research in a manner consistent with accepted practices.
- Analyse the results of a research project in order to make conclusions and/or recommendations relevant to the project.
- Document research sources in a manner consistent with accepted practices.
