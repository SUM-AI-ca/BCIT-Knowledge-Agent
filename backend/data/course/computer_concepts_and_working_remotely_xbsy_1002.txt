## Computer Concepts & Working Remotely XBSY 1002
Business Systems Course
## Course Overview
In this course, participants learn how to work remotely and about the tools that allow for effective collaborations in a remote work environment. Throughout this course participants will learn how cloud computing works, file storage and management best practices as well as how to navigate and use Microsoft Teams. During our exploration of Microsoft Teams, participants will also learn how to create and use chats, channels, calendars and host virtual meetings.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe how a Personal Computer works, and the relationship amongst hardware, software, and operating systems.
- Explain how cloud computing works.
- Apply current data storage management models, file maintenance and file organization.
- Navigate and use MS Teams.
- Identify MS Teams features and capabilities using live interactive demonstrations.
- Create, use and manage Files, Chats, Channels and Calendar Meetings.
