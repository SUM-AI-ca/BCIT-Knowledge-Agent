## Lighting and Rendering 3 MDIA 3542
Media Communications Course
## Course Overview
This course is built on the foundations of its two predecessors and takes the lighting and rendering into the world of visual effects and run-time rendering for games. Students will experiment with different lighting techniques and methodologies, shading for games and VFX, cinematic camera movement and effects in a 3D environment to create a VFX lighting, shading or a real time rendering project.
### Prerequisite(s)
- Completion of all term 1 and 2 courses
### Credits
3.0

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Identify proper lighting methodology for 3D projects
- Setup optimized shading networks for animation and visual effects
- Create light animation through dynamic lighting
- Bake lights and shadows for faster and more efficient rendering
- Create textures with light baking for game engine
- Setup lights for real time rendering in a game engine
- Create optimized shaders inside a game engine
- Create a VFX lighting and shading final project
- Present a real time rendering final project
