## Adobe After Effects 2 MDIA 2171
Media Communications Course
## Course Overview
In this course students explore advanced animation techniques by using expressions and its applications in working with titles or 3D. The course will provide advanced colour correction techniques used for visual effects by using blending modes and keying blue/green shots. The course also examines use of filters and their applications in visual effects production with techniques that are widely applied within the visual effects industry.
### Prerequisite(s)
- MDIA 1171
### Credits
1.5

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Demonstrate use of expressions to loop and link animation between multiple layers.
- Create advanced animation clips using expressions and keyframes.
- Demonstrate tracking and stabilizing sign or screen replacements.
- Analyse different blending modes such as screen, multiply and overlay
- Illustrate 3D camera-tracking features when placing computer generated elements into live footage.
- Demonstrate video playback when using time remapping techniques.
- Apply and combine filters to a layer for creating a specific visual style.
- Illustrate the use of the keying process in video production.
- Create advanced text animation using path text and the wiggly selector tool.
- Use complex visual effects when shooting, tracking, keying, 3D camera and blending modes.
- Create a demo video reel.
