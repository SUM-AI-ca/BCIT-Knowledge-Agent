## Web Design for Journalists BCST 2215
Broadcast Communications Course
## Course Overview
In this hands-on, creative course, student journalists will explore aspects of web design. Throughout BCST 2215 , students will learn all the skills necessary to construct a personal portfolio website from the ground up. Using a variety of industry- standard digital tools and software, students will plan, design, and build an engaging personal website to showcase their work.
### Prerequisite(s)
- • Successful completion of all other Level 1, Level 2, and Level 3 courses in the Journalism program or Program Head's approval.
### Credits
2.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Identify the main characteristics of an engaging website.
- Identify different web-hosting options for a personal website.
- Purchase a domain name for use in a professional portfolio.
- Apply the principles of search engine optimization (SEO) to effective website design.
- Illustrate effective website layout and design principles through the creation of a personal portfolio website.
- Use photo editing software to conduct basic photo edits and create simple graphics for a personal website.
- Build an engaging personal portfolio website to effectively display student work.
- Use video editing software to create video content for a portfolio website.
Effective as of Winter 2025
