## SNOW 100: Introduction to Mac OS X 10.6 MDIA 0013
Media Communications Course
## Course Overview
Introduction to Mac OS X is a one-day preliminary course for those new to Mac OS X who need to prepare for the Mac OS X Support Essentials course, or other technical Mac OS X training courses. This course focuses on getting to know the foundation of Mac OS X, with topics ranging from efficient window and application management to system customization. You will also learn how to configure user accounts and manage files. This class is designed for those new to the Mac OS X platform who need to obtain the skills to support other Mac OS X users.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Get to know the Mac OS X user interface.
- Review Mac OS X basic functions.
- Customize system-wide preferences and user preferences.
- Demonstrate use of the Mac OS X help system.
- Review how common applications integrate with each other.
- Manage multiple applications and multiple windows within applications.
