## Adobe Photoshop 1 MDIA 1180
Media Communications Course
## Course Overview
This course introduces students to the creative world of photo editing using Adobe Photoshop. The course starts with an overview of raster based applications, including image resolution and the co-relation between pixel dimensions, color depth, and image quality. Students will customize the Photoshop workspace, use the quick selection tool, use the quick mask selection tool, manipulate selections, save selections to channels, and perform tonal corrections with the spot healing brush tool and the content-aware fill. Students will create point type, create a clipping mask from type, create vector paths, use layers and adjustment layers, and paint with the mixer brush tool.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Explain how resolution and pixel dimensions impact the quality of an image.
- Demonstrate the differences between RGB and CMYK color modes.
- Adjust the color and tone of an image using different tools and techniques.
- Demonstrate use of working with masks and channels.
- Develop a strategy for retouching images using different tools.
- Create and adjust vector paths to cut out parts of an image.
- Organize artwork on layers.
- Apply blending modes to layers.
- Rearrange layers to change the stacking order of artwork.
- Use guides to position text in a composition.
- Format text with fonts, leading, tracking, and kerning.
- Add text and layer effects to a layer.
- Paint an image with the mixer brush using different brush dynamics.
