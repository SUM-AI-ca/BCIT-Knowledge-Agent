## SharePoint Designer COMP 3969
Computer Systems Course
## Course Overview
SharePoint Designer 2007 is a dedicated tool for customizing, branding SharePoint sites/pages, and automating common SharePoint processes. This hands-on course is intended for web developers/designers or SharePoint developers who want to learn how to customize and brand SharePoint sites. It begins with an overview of the SharePoint Designer environment, creating sites and subsites. Topics include master pages, themes and custom page layouts; branding sites/subsites using XHTML/CSS; retrieving and displaying data using custom XSLT. Successful participants will also learn how to create basic dashboards and how to work with and customizing out-of-the-box web parts. By the end of this course, they will have a working knowledge of creating and managing Windows SharePoint Services (WSS) Designer workflows.
### Prerequisite(s)

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explore SharePoint Designer as a development environment.
- Create SharePoint Sites.
- Explain different methods to implement SharePoint branding.
- Modify master pages.
- Customize SharePoint pages, page layouts.
- Change site navigation, menus.
- Use and create SharePoint themes.
- Understand and use SharePoint Designer Workflows.
- Work with out-of-the-box web parts (content query, data view, content editor, page viewer, XML etc).
- Make use of SharePoint Designer Reports.
