## Shopwork Theory SMTL 1149
Sheet Metal Course
## Course Overview
This course provides students with the knowledge required when using shop tools and carrying out shop projects. Students will learn the theory involved in layout and hand tools, power tools, seams, edges, rivets, soldering and shop equipment.
### Prerequisite(s)
- 70% in SMTL 1142
### Credits
6.5
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Describe the types and uses of specified measurement and layout tools.
- Describe the types and uses of specified basic hand tools.
- Describe the types and uses of specified power tools.
- Describe the types, uses and calculations for various seams and edges.
- Identify types of rivets.
- Describe the application of rivets.
- Perform calculations for riveting.
- Identify soldering techniques.
- Identify types of soft solders.
- Describe the application of solder.
- Identify types of fluxes.
- Describe the application of fluxes.
- Identify types of soldering irons.
- Describe the application of soldering irons.
- Describe the types and uses of specified shop equipment.
