## Pro Tools 101- Introduction to Pro Tools MDIA 1151
Media Communications Course
## Course Overview
This course explores the basic Pro Tools software application for the audio enthusiast. Students will learn Pro Tools fundamentals and use a variety of recording techniques, processes and equipment. The course provides everything needed to complete a Pro Tools project from initial set up to final mix down. The course focuses on Pro Tools software and covers a multitude of new functions and feature enhancements. Students will experience recording live elements, MIDI sequencing of software synthesizers or audio editing or region looping. Pro Tools 101 is the first in a series of courses required to become an Avid Pro Tools Certified Operator.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Set up Pro Tools software preferences.
- Create a Pro Tools session.
- Make an audio recording.
- Combine different media into a session.
- Make an MIDI recording.
- Select and navigate the Pro Tools interface.
- Apply basic and mixed editing techniques.
- Create Music and a Post hands-on final project.
- Export different types of file formats.
