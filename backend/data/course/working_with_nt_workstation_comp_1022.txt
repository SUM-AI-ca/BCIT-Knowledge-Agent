## Working with NT Workstation COMP 1022
Computer Systems Course
## Course Overview
Provides a working knowledge of Windows NT Workstation operating system to those with a basic knowledge of personal computers. Covers working effectively with the new GUI interface. Introduces NT features including desktop, NT explorer, disk management, some administrative tools and control panel options. Discusses Windows NT basic functions for end users in a non-technical manner.
### Prerequisite(s)
- 50% in COMP 0001
- COMP 0001 or equivalent knowledge.
