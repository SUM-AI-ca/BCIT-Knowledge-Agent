## MS Excel 2007 Transitional Workshop COMP 0260
Computer Systems Course
## Course Overview
MS Office has a completely new interface for version 2007. It was developed to make these applications simpler to use. The menus and buttons from prior versions are gone. MS Excel 2007 uses a new ribbon environment with tabs to get to commands. This intensive half-day transition workshop is targeted for students who already know how to use MS Excel 2003 to create spreadsheets. Topics include navigating the Ribbon and using most typical commands: Cut, Copy, Paste, Insert Sheet Rows, Insert Sheet Columns, Sum and how to Save workbooks in the new Excel file formats. Gain hands-on experience to prepare spreadsheets using concepts and special techniques to increase efficiency.
### Prerequisite(s)
- COMP 0261 or working knowledge of MS Excel and Windows PC and file management.

## Learning Outcomes
Upon successful completion of this course, the student will be able to
- Use the Ribbon.
- Customize the Quick Access Toolbar.
- Use Page Layout view to fine-tune pages before printing.
- Apply, create, or remove a cell style.
- Add or change page headers and footers.
- Use new file name extensions and Office XML Formats.
