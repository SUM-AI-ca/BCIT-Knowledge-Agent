## i2 Analyst Notebook Training FSCT 0088
Forensic Investigation Course
## Course Overview
The course covers the basic to intermediate levels of i2 Analyst Notebook. Learn to develop charts from data sources, both manually and through using the import function. The course provides the basis for learning how to use the i2 Analyst Notebook software that will be used in other FSCT courses. The Social Network Analysis capability will be used to analyze the dynamics of groups and organizations. The course uses a combination of lecture, hands-on work, and exercises.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Develop from intelligence reports, statements, phone billing records, surveillance reports, and open source information.
- Know how to prepare DNR charts (Association, Frequency, Event-flow), Link Association charts, Organizational charts, Commodity / Money Flow charts, Event-flow (Timeline) charts, Activity flow charts, and Social Network charts.
- Understand how to utilize time and date information.
- Prepare and standardize import data.
- Import external structured data to produce charts.
- Modify import specifications.
- Import photos and videos.
- Update charts with new information.
- Remove irrelevant information from charts.
- Search charts.
- Find paths between entities.
- Merge charts together.
- Use the analytical tools of Filtering.
- Use Smart Matching and Label Matching to identify possible duplicates.
- Use the Social Network Analysis tool and evaluate the information on a chart.
- Arrange and change the styles of items on a chart, table, and histogram in preparation for briefing and dissemination.
- Create and Print Briefing charts.
- Restrict protected information.
- Use charts in other applications.
