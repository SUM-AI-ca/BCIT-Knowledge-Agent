## Surveying CAD Microstation SURV 4474
Surveying Course
## Course Overview
A hands-on course, which introduces students to Microstation, a powerful and popular software for digital mapping. Topics include Microstation basics, 2D element constructions and manipulations, data entry, data editing, reference file manipulation, and raster file manipulation.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Navigate the MicroStation interface.
- Create, manipulate and modify simple elements.
- Use Microstation’s precision input system to enter survey data.
- Create complex shapes and enclose their areas.
- Create cells and cell libraries.
- Place text, create text styles.
- Attach reference files and raster files within Microstation.
- Output files to plotter or printer.
- Collect raw data by heads up digitizing details from an orthophoto.
