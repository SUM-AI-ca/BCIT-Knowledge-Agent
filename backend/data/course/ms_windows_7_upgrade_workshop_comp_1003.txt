## MS Windows 7 Upgrade Workshop COMP 1003
Computer Systems Course
## Course Overview
In just 12 hours, students learn to upgrade to the Microsoft Windows 7 operating system from a prior version of Windows XP or Vista and become familiar using the new taskbar, interface and additional features. This fast paced, hands-on workshop continues on from COMP 1002 and is aimed to students who already understand PC concepts and who know how to properly use MS Windows XP and understand file management. Topics include what's new in MS Windows 7, comparisons of the different versions of Windows 7, improved security features, HomeGroup networking functions and how to access and use the Windows Live Essentials applications in day to day tasks. As an added bonus, BCIT School of Computing students on an approved credential program may be eligible to receive a copy of MS Windows 7 for their own personal use. This is a limited offer, please check the department website for details. Completion of this workshop provides students with the confidence to upgrade their home systems to Windows 7. Participants use many of the new features such as remote media streaming and Backup Centre, in MS Windows 7.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Examine the differences between the many versions of Windows 7.
- Understand the meaning and impact of running a 64bit Operating System.
- Review the different upgrade paths and methods to move to Windows 7 from previous versions of Windows.
- Compare the differences between the user interface in Windows 7 and the user interface in previous versions of Windows.
- Set-up and configure HomeGroup networking.
- Configure and access remote media streaming.
- Understand the concept of Libraries for improved file sharing .
- Use the indexed search functionality in Windows 7.
- Install, use and configure the Windows Live Essentials applications including Windows Live Mail, Windows Photo Gallery and Windows Live Writer.
- Understand the security model used by Windows 7.
- Configure Parental Controls.
- Use Backup Centre.
