## Microsoft Word Complete COMP 1169
Computer Systems Course
## Course Overview
COMP 1169 has been replaced by COMP 2369 . This hands-on course is the combination of MS Word Level 1 and 2. Students progress from a beginner to an expert in just 12 weeks. With a combination of lectures, labs and projects, this course provides students with the practical skills needed to create and manage all types of documents. As an added bonus, successful completion of this course prepares students to challenge a Microsoft Certification exam.
### Prerequisite(s)

## Learning Outcomes
Upon successful completion, the student will be able to:
- Create, Save, Open, Close, Edit and Print documents.
- Navigate quickly and efficiently throughout documents.
- Apply font, paragraph and page formats to documents including borders and shading.
- Create, edit and apply styles to text, paragraphs or tables.
- Insert section and page breaks.
- Create headers and footers.
- Insert and modify clipart and pictures.
- Create and set custom tab stops with line leaders.
- Create and format text into table and column layouts.
- Create charts and diagrams.
- Find and replace text and/or formatting.
- Sort lists.
- Use Word's collaborative features such as comments, track changes and compare and merge documents.
- Use, create, and edit templates and form templates.
- Customize the word environment.
- Record, edit and run simple Word macros.
- Insert document references such as footnotes, endnotes, bookmarks, and cross-references.
- Create an index and table of contents.
- Link data from other Office applications into a Word document.
- Perform a mail merge.
- Be familiar with XML concepts.
- Create a web page.
