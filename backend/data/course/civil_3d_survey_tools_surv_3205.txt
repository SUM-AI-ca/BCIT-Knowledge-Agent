## Civil 3D: Survey Tools SURV 3205
Surveying Course
## Course Overview
Introduction to the survey tools of Autodesk Civil 3D. Students will create and manage survey databases, import and edit survey data; perform control traverse adjustments using compass rule and least squares methods; translate survey data; code field data to create figures (auto line work); analyze figures; insert survey points and figures into drawings; create stepped offset figures; classify figures as surface breaklines.
### Prerequisite(s)
- SURV 2205

1.5

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Navigate the Civil 3D Tool space.
- Describe Civil 3D objects.
- Create a template file.
- Import points into a drawing.
- Export points from a drawing.
- Edit field data.
- Create a Survey database.
- Populate a survey database.
- Adjust control survey data.
- Translate a survey database.
- Create figure prefix codes for field crews.
- Create a figure prefix library.
- Create figures using field codes.
- Create breaklines from figures.
- Create stepped offsets from figures.
- Define the relationship between drawings and the Survey Database.
- Update a survey database by modifying figures in a drawing.
- Create point code look up tables for field crews.
- Create description keys.
- Organize survey database points and figures into groups.
