## XNA Games Development for PC COMP 0445
Computer Systems Course
## Course Overview
This course introduces Microsoft's newest game development platform for the PC and Xbox 360. This advanced course in XNA games development follows either prior summer games course; COMP 0417 or COMP 0440 . This hands-on course shows students how to create and program 3D games with Microsoft's freeware game developer suite. If you have already taken a prior games programming course, this is the next step. Students who complete this course may download the freeware developer suite to continue their learning and further develop their coding or games programming skills at home (Ages 13-15).
### Prerequisite(s)
- COMP 0417 or COMP 0440

## Learning Outcomes
Upon successful completion, students will be able to apply C# and DirectX for:
- Learn to make games that can be run on the Xbox 360 or PC.
- Setup PC for game development at home (requires XP or later and a suitable graphics card).
- Create 3D graphics effects.
- Create 3D models.
- Perform animations.
- Play audio.
- Use Microsoft's free XNA Game Studio Express.
- Create a simple game that starts with a basic game shell.
