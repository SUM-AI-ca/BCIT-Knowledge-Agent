## The Raiser's Edge FUND 4110
Fundraising Course
## Course Overview
Learn to utilize the world's #1 fundraising and donor management solution. Through instructor lead scenarios, class discussion and hands on practice using sample data, participants learn how to navigate through Raiser's Edge, create and maintain constituent records, enter and manage gift records, create mailings, evaluate data using reports and dashboards, execute queries, export information and globally add actions and appeals to constituent records.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
3.0

## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Log in to and navigate in The Raiser's Edge
- Enter and manage constituent information for individuals and organizations
- Enter and manage gift information
- Enter multiple records through batch entry
- Create mailings using Raiser's Edge data
- Generate reports to analyze Raiser's Edge data
- Group records in your database using queries
- Streamline navigation in The Raiser's Edge by customizing dashboards and the Home page
- Export data from The Raiser's Edge for use in other applications
- Update groups of records using the Globally Add Records function
