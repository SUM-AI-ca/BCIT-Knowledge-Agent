## Visual Scripting TECA 6300
Technical Arts Course
## Course Overview
This course focuses on creating and developing procedures and functions inside industry standard 3D applications and game engines using visual scripting methodology. Students will learn the fundamentals of visual scripting in several 3D applications and game engines through the creation of materials, blueprints, effects, dynamics and event controls. Topics also include creating events and triggers (including collision-based events), developing loops and conditions to execute functions, and performing the required mathematical calculations.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Discuss the logic and concept of visual scripting
- Describe the concept of blueprints in the game engine
- Navigate through visual scripting environments in different applications and game engines
- Assess the role of events and triggers in a game function
- Use visual scripting to trigger events based on actions and collisions in a game scene
- Change the environment atmosphere and appearance based on different parameters in a game environment
- Create a user interface with blueprints
- Develop procedural materials in a texture authoring tool
- Create dynamic elements for materials, objects, and atmosphere in 3D environments
- Build functions with visual scripting
- Develop loops and conditions to execute different functions
- Create procedural elements such as dynamic shaders, geometry, lights or scenery
