## Effects and Dynamics TECA 5400
Technical Arts Course
## Course Overview
This course introduces the concept of dynamics in 3D applications. Students will learn the fundamentals of physics and the essentials of several dynamic elements, such as rigid bodies, cloth, hair, particles, and pyro. Students will create different dynamic objects and experiment with various environmental elements and their effect on objects. An important component of this course is completion of various projects related to dynamic elements and environment, which contribute to students’ individual portfolios. ​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the fundamentals of physics as it relates to dynamic elements.
- Apply physics concepts to a dynamic environment.
- Describe different forces inside a dynamic environment.
- Create rigid body objects for dynamic animation.
- Build cloth material from 3D mesh.
- Setup a dynamic hair system on a 3D character.
- Create particle systems for fluid simulation.
- Build pyro effects.
- Apply dynamic rules in the game engine.
- Build effects inside a game level.
- Create several dynamic elements for objects .
