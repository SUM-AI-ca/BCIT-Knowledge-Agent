## DevOps Engineering COMP 4964
Computer Systems Course
## Course Overview
In this course students learn how to utilize automated software deployment, continuous integration, continuous delivery and continuous monitoring tools in cloud computing environments according to DevOps (development & operations) practices. This course is tightly integrated with COMP 4968 (Programming in the Cloud). Topics include software creation and distribution models, software release processes (source, build, test, production), cloud management tools, resource provisioning, software configuration management (SCM), continuous integration (source, build), continuous delivery, continuous (automated) deployment, and continuous monitoring. Students will build their skills by participating in in-class interactive lectures, hands-on lab activities, and working on comprehensive assignments.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain DevOps principles, methods and practices in terms of business unit operations and corporate culture.
- Identify cloud platforms, tools and techniques used to facilitate DevOps principles, methods and practices.
- Provision virtual development environments.
- Configure development, test and production environments on different public cloud platforms using automation tools.
- Install and configure tools used for continuous software integration within a variety of public cloud computing environments.
- Design and implement cloud-based environments for continuous software delivery and deployment.
- Implement resource monitoring tools available on different public cloud platforms.
- Design, build and deploy cloud-based software applications using DevOps tools and principles to facilitate the software release process.
