## Crystal Reports Level 3 COMP 1252
Computer Systems Course
## Course Overview
COMP 1252 has been replaced by COMP 1253 . Explore advanced features of Crystal Reports Version 10. Improve your reporting capabilities by designing a Business Intelligence Strategy and Reporting Standards that make use of Repository items, and Custom Functions. Work with advanced formulas in the Formula Workshop including Shared Variables, Arrays, Ranges, write SQL Expressions to talk directly to your database and many more advanced functions. Distribute your Crystal Reports using the Report Application Server (RAS) that is now included with Crystal Reports Version 10 and gain insight into Crystal Enterprise.
### Prerequisite(s)
- COMP 1250 and COMP 1251
### Credits
1.5

## Learning Outcomes
Upon successful completion, the student will be able to:
- Design multipass reports and use evaluation time functions.
- Create a manual running total.
- Use a dynamic array.
- Create unlinked and linked subreports.
- Create an on-demand subreport and use shared variables with subreports.
- Build complex formulas and use loop control structures with arrays.
- Use custom functions.
