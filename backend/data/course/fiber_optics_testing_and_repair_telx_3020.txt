## Fiber Optics: Testing and Repair TELX 3020
Electronics Technical Course
## Course Overview
​​​This cours​e introduces students to advanced fiber optic topics including optical network designs, fiber optic analysis using link budgets, Optical Loss Test Sets (OLTS) and Optical Time Domain Reflectometers (OTDR). Troubleshooting is emphasized for new installations as well as maintaining existing systems as students gain hands-on experience testing optical components installed in outside plant systems to current ANSI/TIA (American National Standards Institute / Telecommunications Industry Association​) standards. For their final exam, students will write the Fiber Optic Association (FOA) industry recognized exam for Certified Fiber Optic Technician (CFOT).​ Successful completion of the exam will result in certification; if students require further attempts, they may register with the FOA separately.​

## Learning Outcomes
​Upon successful completion of this course, the student will be able to:
- Identify modern day communication networks using fiber optics.
- Assemble outside plant fiber cable into an outdoor splice enclosure using a fusion splicer.
- Describe how to install fiber cables following industry and manufacture standards.
- Calculate a fiber optic link/power budget using current TIA standards.
- Demonstrate fiber optic connector end-face cleaning and inspection.
- Analyze a fiber optic system with an Optical Loss Test Set to current TIA standards
- Test a fiber optic system using an Optical Time Domain Reflectometer
- Test and troubleshoot a failed fiber optic link using current TIA standards
