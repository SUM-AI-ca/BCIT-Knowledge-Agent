## Computer Applications for Broadcasting BSYS 1620
Business Systems Course
## Course Overview
In this course, students will learn basic computer terminology, components of hardware, and software applications as used in the broadcasting industry. Students will learn concepts of spreadsheets and charting, word processing, presentations and graphics, the Internet, and current operating systems through practical exercises. The broadcast industry relies on computer files and networked environments to operate effectively, in all stages of production. Students will gain a n understanding of various file types, file management, moving files between systems, backing up data, and connecting to a network.​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- File Management
- Create efficient storage management, file maintenance and file organization on a local computer, a network drive, and the web / cloud platforms.
- Use specific media related file management (camera & audio recorder SD card file transfer and management)
- Save to various file types, understand file compression, backup device options, and sharing files.
- Computers and Troubleshooting
- Use and customize the PC operating system environment.
- Explain the differences between Microsoft Windows, and Apple computers, and address cross-platform issues.
- Discuss basic business technology issues that can arise.
- Describe a fundamental overview of cloud computing including Google Workspace, Microsoft 365, Microsoft One Drive, Apple iCloud, and Dropbox.
- Referring to current Microsoft and Apple Operating Systems, identify user interface components and explain their use.
- Explain basic PC security concepts and use the Operating System and additional software to enhance computer security.
- Effectively collaborate with computer professionals within the organization.
- Explain the need to backup data and demonstrate effective data backup and protection methods. e.g.: 3-2-1 backup strategy.
- Troubleshoot basic computer problems and use the resources provided by the Operating System.
- Networking
- Understand how to connect to a remote file server. Understand the ability to transfer files between computers using SMB file sharing.
- Understand the difference between DHCP and static IP addresses.
- Understand network protocols and learn how to transfer files using IP based file sharing.
- Digital Literacy
- Demonstrate industry-level digital literacy skills.
- Use social networks, collaboration tools, virtual desktops, and mobile devices for project work.
- Protect their privacy while using social media and be proactive with their online reputation. ​
- Microsoft Office Suite
- Integrate data and files within the current Microsoft Office Suite of software, given a business scenario.
- Work in a collaborative environment using Microsoft 365.
- Use help functions and Internet search engines to solve problems independently​.
- MS PowerPoint
- Create presentations, learning techniques integrated across the MS suite.
- Enhance, and refine PowerPoint Presentations.
- MS Word
- Produce effective business reports and documents based on company requirements.
- Use productivity tools to minimize time spent on producing business documents.
- Use Word's collaborative features: comments, track changes, compare and combine documents.
- MS Excel
- Use MS Excel and critical thinking to build business models, enabling "what-if'' analysis to aid in decision making.
- Enter and manage data within a single Excel spreadsheet or multiple spreadsheets.
- Use functions and formulae to manage the processes that transform inputs to outputs, given a business scenario. ​
