## Computer Applications RENR 1111
Renewable Resources Course
## Course Overview
Students will be introduced to word processing skills related to report writing, creating spreadsheets that include functions and formulas, and creating database files that include tables, forms, queries and reports. Introductory online digital mapping skills will also be introduced. An integrated field project will include a map and presentation component, and a brief report describing the procedures used to create the map. The intent of the course is to introduce students to various computer applications in resource management, and provide students with basic computer skills required in the program to complete project work.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, students will be able to:
- Complete file management tasks.
- Complete word processing tasks necessary for writing resumes, memos, and reports.
- Create spreadsheets to record, summarize, and chart data.
- Create a database that includes tables, forms, queries reports and macros.
- Import and export data between MS Word, Excel and Access.
- Create digital presentations and brochures.
- Use online mapping tools to draw new features, and present uploaded navigational grade GPS data.
- Use ArcMap to produce maps based on WMS links, downloaded topographic map files, and imported field data.
