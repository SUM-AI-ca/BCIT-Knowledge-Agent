## Adobe Dreamweaver MAC 1 MDIA 1470
Media Communications Course
## Course Overview
Adobe Dreamweaver is a professional visual editor for designing, developing and managing websites. Using industry standard methods for creating pages, the class will work with basic elements such as text, graphic and table layout structures. Methods of applying Cascading Style Sheets for more powerful control and layers to further enhance design layout will also be covered.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Set up a local site.
- Understand the dreamweaver interface and its functionality.
- Create a web layout using tables or layers.
- Insert multimedia elements such as images and rollovers.
- Demonstrate knowledge of intermediate tools (behaviours/JavaScript).
- Troubleshoot basic web design issues (User limitations, browser incompatibility).
- Use Dreamweaver's FTP (file transfer protocol).
