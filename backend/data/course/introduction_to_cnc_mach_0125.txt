## Introduction to CNC MACH 0125
Machinist Course
## Course Overview
Introduces the concepts of computer numerical control (CNC) programming. Haas simulators are used to prove programs using basic G code. Linear and circular interpolation, canned cycles are introduced to create a program to machine a project. Demonstration using Haas vertical milling machines to set up and complete a project. Intended for those with little or no CNC experience.
### Prerequisite(s)
- No prerequisites are required for this course.
