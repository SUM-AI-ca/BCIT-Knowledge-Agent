## Java and Flex for Web Development COMP 4629
Computer Systems Course
## Course Overview
Adobe FlexTM is a software development kit for building cross-platform, rich internet applications based on the Adobe Flash platform. Participants will learn to use Adobe FlexTM 4 and ActionScript 3 with Java Enterprise Edition (JEE) to create outstanding web applications. This hands-on workshop continues on from COMP 3641 and is aimed at students who already understand Java programming and Java web application development. Topics include: programming in ActionScript 3, writing declarative user interfaces in Flex 4, multi-tiered connectivity with JEE and Flex, and utilizing the remoting RPC services for connecting Java to Flex. By the end of this intense workshop, successful participants will be able to produce and deploy advanced server side and client side Web Applications with Java.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Apply JEE design patterns to both the client (FlexTM) and the server side (JavaTM).
- Demonstrate how to utilize validation, styling, and event handling within the FlexTM framework.
- Demonstrate how to write graphical user interface applications using AdobeTM FlexTM 4 Framework ActionScript 3 and MXML.
- Utilize AdobeTM BlazeDS for Remote Procedure Call (RPC) services between JavaTM and FlexTM.
