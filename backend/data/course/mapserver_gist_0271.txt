## MapServer GIST 0271
Geographic Information Systems Course
## Course Overview
MapServer is a very popular GIS web mapping application. Students will use the BCIT GIS Open Source web server and MapServer software, create Map and template files and write PHP scripts for a custom MapServer application using shapefiles or PostGIS/PostgreSQL database tables.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Draw a diagram showing the MapServer components.
- Create a MAP file that use shapefile data sets.
- Use the CLASS and EXPRESSION objects.
- Display and interact with a map image within a template HTML file.
- Customize a template with JavaScript.
