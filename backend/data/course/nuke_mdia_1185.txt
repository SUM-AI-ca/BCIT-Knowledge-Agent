## Nuke MDIA 1185
Media Communications Course
## Course Overview
This course introduces students to the principles and terminologies used in Digital Compositing and Visual Effects. Students will practice variant methods and techniques currently utilized in 3D productions. The course is taught using the NukeX leading application in node based compositing. Students explore different digital output formats (such as HD and film), create new compositions and import different types of media into a project. Students will animate layers across time and space, and utilize animation curves to control a layer’s movements. Students will use expressions to create dynamic camera-shakes as well as advanced animation with audio-sync and filters. Color correction will be explored in-depth with emphasis on levels and how levels impact lighting of a scene and the editing of the final demo reel. Students will also practice stabilizing, 2D tracking and Chroma keying.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Identify common terminology used in the Visual Effects and Compositing fields.
- State various movie formats used in production.
- Utilize shortcuts for layer timing controls and animation.
- Animate layers' properties in 2D & 3D space such as position or rotation.
- Utilize animation curves to fine tune animation.
- Create different types of text animation using Text Animators.
- Demonstrate the steps needed to Rotoscop an element in a video.
- Create random animation using expressions.
- Add camera shake in post-production.
- Utilize the 2D and 3D tracking tools within NukeX to track an element in a video.
- Demonstrate how a sign can be replaced using tracking.
- Utilize colour correction tools to alter the visual appearance of a video.
- Explain the role of colour correcting in editing a final demo reel.
- Demonstrate how video files are rendered and compressed.
