## Layout and InDesign 1 MDIA 1069
Media Communications Course
## Course Overview
In this course you will explore design and typographic principles that apply to page layout and typesetting. Using Adobe InDesign, a professional layout application, you will combine text and graphics to create full-colour page layouts.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
3.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion for this course, the student will be able to:
- Set up document dimensions.
- Describe type and layout using typesetting terminology and vocabulary.
- Select typefaces for specific usage such as body copy, headings, and captions.
- Position type and graphics precisely in a layout.
- Format type and paragraphs using typesetting conventions.
- Establish a hierarchy of information in a layout.
- Format various styles of lists including hanging indents, numbers, bullets, and lists within lists.
- Apply an organizational grid system over multiple layouts.
- Create, apply, and manage colour within a document.
- Correct a document by referring to proofreading symbols and Acrobat annotation tools.
- Create basic master pages.
- Automate text formatting with basic paragraph and character styles.
- Organize content using the stacking order and layers.
