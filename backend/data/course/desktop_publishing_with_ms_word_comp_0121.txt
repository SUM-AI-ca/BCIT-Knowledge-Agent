## Desktop Publishing with MS Word COMP 0121
Computer Systems Course
## Course Overview
From simple to elaborate, this half-day seminar will teach students how to produce professional-looking documents. Using MS Word's many built-in graphical features, students will learn how to design business-quality materials and enhance ordinary documents. Topics include: creating newsletters and business cards; inserting photos; using backgrounds, borders, and watermarks; animating text; and using graphics with text. In only half a day, learn how powerful a tool Microsoft Word really is.
### Prerequisite(s)
- Working knowledge of Microsoft Word.

## Learning Outcomes
Upon successful completion of this course, students should be able to:
- Add a watermark or background
- Create borders and shading effects on text, tables, and entire pages
- Animate text and create other graphical text effects
- Identify and insert a variety of graphic types that can be use in a document
- Resize, group, and rotate graphics
- Precisely position a graphic on the page and keep it in place
- Align a graphic with text, including wrapping text around it
- Arrange text in columns and create a simple newsletter
- Create a layout in Word for business cards
