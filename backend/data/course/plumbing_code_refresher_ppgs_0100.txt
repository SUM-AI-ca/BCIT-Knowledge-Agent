## Plumbing Code Refresher PPGS 0100
Piping, Plumbing, Gas Course
## Course Overview
The course is intended for Plumber Journey-persons as a refresher for the understanding and applying of codes relevant to their trade. Plumbing apprentices would also benefit from the course as they prepare to write their Red-Seal exam.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
0.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion of this course, the student will be able to
- The learner will be able to install potable water systems as per code requirements.
- The learner will be able to install sanitary drain, waste and vent systems as per code requirements.
- The learner will be able to install storm drainage systems as per code requirements.
- The learner will be able to test and commission sanitary and storm drainage systems as per the BC Building Code.
