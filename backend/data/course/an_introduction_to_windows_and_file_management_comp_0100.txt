## An Introduction to Windows and File Management COMP 0100
Computer Systems Course
## Course Overview
This intensive and informative one-day workshop is for any computer user who needs to learn or update their Windows PC and File Management skills. Gain hands-on experience to maintain a safe environment for data. Topics include how to: create, organize, locate files and folders, review virus protection, add and use external locations or devices such as Network Drives, USB keys and CDs for data backup. Learn best practices to prevent disaster, manage and protect your data, saving you both money and time. This workshop or equivalent knowledge is required prior to enrolling in any Microsoft Office application courses.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Use best practices for file management.
- Create, find and organize files and folders.
- Find and use network drives, external devices such as USB keys and CD.
- Protect your systems and data from Viruses, Spyware, Spam and Phishing.
- Apply Safe Computing Practices, Backups and have a disaster recovery plan.
