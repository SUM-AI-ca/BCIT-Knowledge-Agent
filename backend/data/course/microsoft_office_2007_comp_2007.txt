## Microsoft Office 2007 COMP 2007
Computer Systems Course
## Course Overview
COMP 2007 has been replaced by COMP 2010 MS Office 2010. Become a proficient user of MS Office 2007. Learn how to use MS Word, Excel, PowerPoint and Outlook, in this hands-on course. An expert BCIT instructor will lead the class with lectures, lab exercises and assignments. Students will create, manage and integrate documents, spreadsheets, presentations and email. Topics include: the new MS Office 2007 user interface with the Office Button, Quick Access Toolbar, the Ribbon and contextual tabs. Upon completion, participants will have mastered time-saving tips, techniques and learned shortcuts for the daily use in each of these business software applications.

- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Understand MS Office 2007 terminology.
- Use time saving techniques.
- Create, Save, Open, Close, Edit and Print files using MS Word, Excel, and PowerPoint.
- Navigate quickly and efficiently using the new Office button, Quick Access toolbar and Ribbon.
## MS Word 2007
- Create headers and footers in documents, workbooks and presentations.
- Apply font, paragraph and page formats to documents including borders and shading.
- Insert and modify clipart and pictures.
- Create and set custom tab stops with line leaders.
- Create and format text into table and column layouts.
## MS Excel 2007
- Create formulas using addition, subtraction, division, multiplication, and common statistical functions such as Sum, Average, Min, Max and Count.
- Use financial functions such as Payment (PMT).
- Format cells, rows, columns.
- Create a simple column chart and pie chart.
## MS PowerPoint 2007
- Create, format and modify slide elements for presentations.
- Apply bullets and numbering to a document or presentation.
- Use and format SmartArt Graphics.
- Apply an animation scheme.
- Run a slide show presentation.
## MS Outlook 2007
- Use the Office Outlook 2007 user interface including the To-Do Bar to organize your day.
- Work with email messages and attachments.
- Create and manage contacts.
- Schedule calendar appointments and create tasks.
## MS Office 2007 Integration
- Copy and link data from one MS Office application into another including updating links.
