## Java Programming 2 MMSD 3620
Multimedia Software Development Course
## Course Overview
Continues from MMSD 3610 . Addresses advanced Java Programming techniques for applications. Covers application GUI design through an in-depth examination of Swing API component models, JDBC, multithreading and thread synchronization, look and feel, drop and drag, and Java Media Framework. Advanced topics may include RMI, Servlets, JSP's, and JavaBeans.
### Prerequisite(s)
- 50% in COMP 3730 and 50% in MMSD 3610 or 50% in COMP 4409
