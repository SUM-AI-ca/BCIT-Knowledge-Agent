## Applied Google Analytics for Web Developers COMP 2250
Computer Systems Course
## Course Overview
This hands-on course follows on from COMP 1911 and COMP 1950 Applied Web Development Level 2 or those who already understand HTML, CSS and JavaScript. Beginning with fundamentals of Web and Digital Analytics, participants will gain an understanding of complex web ecosystems and how to use Google Analytics to collect and organize web data. Students uncover hidden intelligence in the data by setting up various Google Analytics reports and develop the confidence to promote data driven decision making. Labs and exercises are designed to reinforce best practices and how to translate business goals and objectives into web analytics language and define simple but meaningful Key Performance Indicators (KPIs). Assignments provide a working knowledge of data collection models and procedures for a better understanding of marketing channel performance, and online visitor’s interactions with a website. Students learn how to provide recommendations to improve usability and site performance. Topics include; Analytics Requirements Engineering, Web Data Collection Procedures, Set up Google Analytics, Data Analysis Techniques, Segmentation and Advanced Reporting. Students will examine opportunities for continued website improvement and learn how to optimize for better traffic acquisition. By the end of this course successful participants will be able to collect reliable and actionable web data using Google Analytics.
### Prerequisite(s)
- COMP 1911 and COMP 1950 or an equivalent understanding of web page design with HTML, CSS and JavaScript.

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Explain Web Analytics fundamentals and data collection methods and tools.
- Plan, Implement and Configure Web Data Collection Procedures.
- Identify timely and useful KPIs, define and track target values to drive action and achieve business objectives.
- Architect Google Analytics installation, and configuration.
- Conduct complex data analysis using Google Analytics reports and advanced data analysis techniques.
- Design and implement a standard to tag and measure incoming traffic, and identify channel performance.
- Measure and evaluate effectiveness of marketing efforts, including organic traffic through Search Engine Optimizations (SEO), paid traffic from Search Engine Marketing (SEM), Pay per Click (PPC), email newsletter, and Social Media traffic acquisition.
- Use data to understand visitors engagement with a website and provide recommendations to improve usability and site navigation.
- Implement an strategy to track and analyze conversions and evaluate against business goals and objectives.
- Explain what multi-channel analysis is, and design a basic attribution model.
