## GPS and TPS Data Processing (Leica) SURV 1005
Surveying Course
## Course Overview
Essential course for users familiar with LGO (SKI or SKI-Pro) GPS and TPS data processing and data validation techniques. Provides in-depth analysis of different GPS processing techniques and network adjustment procedures through practical case studies. Combining TPS (terrestrial) data with GPS (baseline vector) data is also presented with coordinate transformations. The course is directed towards engineers, surveyors, and all related professionals within the Geomatics community.
### Prerequisite(s)
- Basic GPS survey background and basic Windows and computer skills.

1.0

## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Post-process static and kinematic GPS raw data.
- Analyze GPS baseline results.
- Troubleshoot GPS baseline processing via site and satellite windowing.
- Adjust GPS static and RTK baselines with TPS measurements.
- Assess network adjustment results.
- Convert GPS coordinates to different coordinate systems.
