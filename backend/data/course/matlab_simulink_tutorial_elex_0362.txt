## Matlab/Simulink Tutorial ELEX 0362
Electrical and Computer Engineering Course
## Course Overview
This course introduces MatLab software and its use in electronics technology. The M programming language, MatLab graphics and the graphical user interface features of the language are used to solve problems and display results. Simulink is introduced for dynamic simulation in both continuous and discrete time. Students in the Electronics BTech program are advised to take this course if they have no previous MatLab experience.
### Prerequisite(s)
- No prerequisites are required for this course.
