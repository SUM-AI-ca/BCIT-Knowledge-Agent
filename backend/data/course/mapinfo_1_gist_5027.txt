## MapInfo 1 GIST 5027
Geographic Information Systems Course
## Course Overview
Introduces MapInfo Professional, a popular, user friendly GIS product that runs within Microsoft Windows. Learn how to navigate, label and query maps, create thematic maps, use images, geocode address and use basic GIS analysis techniques.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student should be able to:
- List elementary principles of GIS, database and desktop mapping.
- Describe with the concepts, organization and files of MapInfo Professional databases.
- Control the display (layers, projections) and views of MapInfo Professional databases.
- Query MapInfo Professional databases using geographic and attribute criteria.
- Perform geocoding and thematic mapping in MapInfo Professional.
- Create a MapInfo Professional layout.
- Import data into MapInfo Professional.
- Perform elementary buffering operations.
