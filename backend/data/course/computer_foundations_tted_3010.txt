## Computer Foundations TTED 3010
Technology Teacher Education Course
## Course Overview
Provides students with the computer skills to complete assigned work to the standard required in Technology Teacher Education courses and the public schools of British Columbia. Introduces BCIT lab procedures and regulations, the current Windows operating system, the detection and removal of viruses, file management strategies, the creation of web pages and the rudiments of the Microsoft Office suite.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Use BCIT networked lab facilities correctly and efficiently
- Demonstrate an understanding of the current Windows operating system
- Use Windows Explorer to manage computer files and directories
- Adopt measures to deal with computer viruses
- Use Microsoft Word to create text documents
- Use Microsoft Excel to create data tables and graph mathematical relationships
- Create a simple web page including links and pictures
