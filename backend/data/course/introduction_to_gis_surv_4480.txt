## Introduction to GIS SURV 4480
Surveying Course
## Course Overview
Covers fundamental GIS concepts and terminology including spatial data models, GIS databases, query and analysis, data input and editing. Students will learn how to use commercial GIS software.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
2.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe fundamental concepts of GIS and databases.
- Describe vector and raster data models.
- Perform attribute, spatial query operations.
- Utilize ArcGIS software to perform common analytical operations.
- Import and edit data in ArcGIS.
- Create a map layout.
