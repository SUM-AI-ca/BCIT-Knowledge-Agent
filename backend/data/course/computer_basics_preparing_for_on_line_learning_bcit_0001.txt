## Computer Basics-Preparing for On-line Learning BCIT 0001
BCIT Generic Course
## Course Overview
This enjoyable hands-on course will assist new computer users to develop all the skills needed to succeed with Internet based course environment. Upon successful completion of this course, you will have an understanding of: basic computer operations; file management; MS Windows; application software and file types; use of the Internet, e-mail, conferencing, and other on-line communication tools; on-line research and Web CT (BCIT's on-line learning environment).
