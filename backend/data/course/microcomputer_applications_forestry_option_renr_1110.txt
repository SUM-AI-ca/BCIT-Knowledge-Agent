## Microcomputer Applications (Forestry Option) RENR 1110
Renewable Resources Course
## Course Overview
Introduces various computer applications in resource management. Includes a review of computer hardware, software and operating systems. Assignments from other program courses will be used to introduce students to general word processing, spreadsheet, database management and file management skills. Students will also prepare a report involving the integration of word processor and spreadsheet tools to present statistical information.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
3.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Provide examples of word processing, spreadsheet, database, and CAD software typically used in the field of renewable resources.
- Use Windows XP to create, copy, move and delete files and folders.
- Use virus scanning software the check a computer for viruses.
- Send e-mail messages with attachments to other students and instructors.
- Use WinZip to compress, decompress and copy files.
- Use FTP software to move large files from one computer to another.
- Complete introductory word processing tasks necessary for resumes, memos, and reports.
- Create simple spreadsheets for resource management tasks.
- Use RoadEng to create plots based on field traverse notes.
- Collect point and line GPS data.
- Add RoadEng and GPS data to an existing map.
