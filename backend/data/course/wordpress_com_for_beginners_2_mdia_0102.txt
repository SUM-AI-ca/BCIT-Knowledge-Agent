## WordPress.com for beginners 2 MDIA 0102
Media Communications Course
## Course Overview
Receive instruction on how to make a professional looking website using the WordPress blogging platform with a minimum of coding required. In this hands-on half-day workshop you will delve into how to install the WordPress blogging engine/CMS yourself to build dynamic, elegant and professional looking websites quickly and easily. Learn the settings required to turn a WordPress blog into a website, how to tune it for search engines, how to install and configure plugins, how to choose the right theme for your website, and how to install the theme on the site. While not required, students not familiar with WordPress or blogging might find the Level 1 ( MDIA 0101 ) course helpful to give them a basis in how to use WordPress and its features.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Set up a WordPress-based blog or website via self-install on a server or local machine.
- Know how to organize informatin on a website.
- Using pages vs posts for the best fit to the content.
- Basics of blogging and posting.
- Adding links, images, and video to posts and pages.
- Choosing a theme for your site that matches your audience.
- Installing and configuring a theme on WordPress.
- Choosing plugins to expand WordPress' capabilities.
- Installing and configuring plugins.
- Use sidebar widgets to add interactivity and navigation to the blog/site.
- Making a blog theme look like a website through settings and basic theme editing.
- Basics of style sheet editing for theme customization.
