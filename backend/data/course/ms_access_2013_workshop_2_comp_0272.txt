## MS Access 2013 Workshop 2 COMP 0272
Computer Systems Course
## Course Overview
COMP 0271 , 0272 and 0279 have been replaced by COMP 0371 and COMP 0372 . Following on from COMP 0271 , participants are shown intermediate level Access 2013 in this intensive, hands-on seminar. Participants must already be familiar with managing files on a Windows PC and the basic functions of MS Access. Through lectures and exercises, students will learn more about relational database design and form and report design. Topics include: how to control field properties, change join types, create parameter queries and action queries, improve form and report designs, import data from Excel, text and csv files, and export data to Excel and Word. Successful participants will be prepared to move on to MS Access Workshop Level 3, COMP 0279 .
### Prerequisite(s)
- COMP 0271 or equivalent knowledge of MS Access.

## Learning Outcomes
- Upon successful completion of this course, the student will be able to:
- Control data entry by changing field properties
- Understand join types
- Create flexible queries
- Improve forms by changing control types, restricting data entry and adding command buttons
- Improve reports by changing report control properties, controlling report pagination and inserting a subreport
- Create mailing labels
- Integrate Access with Word and Excel. Specifically, publish Access data as a Word document, analyze Access data in Excel, merge Access Data with a Word Document
- Export data to a text file
