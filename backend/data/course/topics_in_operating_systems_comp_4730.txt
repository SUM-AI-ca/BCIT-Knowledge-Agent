## Topics in Operating Systems COMP 4730
Computer Systems Course
## Course Overview
This course is a continuation of Comp 3730. The topics covered are virtual memory, processor scheduling, input/output management, disk scheduling, file management, distributed systems and computer security. Each topic will conclude with a presentation regarding the implementation of the concepts in the modern operating systems (UNIX, Linux, Windows NT, and Windows 2000).
### Prerequisite(s)
- 50% in COMP 3730
