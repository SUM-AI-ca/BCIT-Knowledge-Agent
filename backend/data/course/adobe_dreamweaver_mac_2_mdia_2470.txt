## Adobe Dreamweaver MAC 2 MDIA 2470
Media Communications Course
## Course Overview
This Level 2 course builds upon the skills learned in Level 1. You will use some of the more advanced features of Dreamweaver including working with templates and libraries, cascading style sheets, dynamic HTML and JavaScript. The course will also cover working with forms and plug-ins.
### Prerequisite(s)
- 50% in MDIA 1470
### Credits
1.5
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Modify and update more complex multi-page Cascading Style Sheets
- Identify server side vs client side programming technology
- Describe popular plug-ins centered around jQuery.
- Determine web hosting needs, and navigate hosting packages
- Work with popular CMS systems such as wordpress
- Make changes or updates to CMS based sites
