## New Technologies and Cross-Media Applications GCOM 4250
Graphic Communications Course
## Course Overview
This course is an introduction to the many opportunities presented by e-commerce and online connectivity in the graphic communications industry. Students learn how to devise, select, implement, maintain, and grow an online website specific to graphic communications industry. Emphasis will be on using current technology for website creation with links to PDF workflow systems and online estimating and transaction services. Students will also learn about digital publishing, including interactive PDF’s, eBooks, tablet publishing, and augmented reality. Finally, students will learn about the applications of social media in cross-media marketing campaigns.​

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the necessary components of a graphic communications company’s online presence.
- Describe the criteria for a value-added web to print service.
- Categorize online needs based on the positioning of the graphic imaging company.
- Analyze an existing web presence for effectiveness.
- Outline needs for high-speed data communication.
- Identify criteria for choosing tech partners.
- Identify company stakeholders to be included in planning and development.
- Develop a business plan for implementing a complete online website for a mid-sized company.
- Create a functioning web page with links to virtual proofs.
- Distinguish between traditional publishing and digital publishing.
- Prepare files for various digital publishing methods.
- Describe augmented reality technologies and how to implement them in graphic communications.
- Identify the tools social media platforms provide and their uses in the Graphic Communications Industry.​
