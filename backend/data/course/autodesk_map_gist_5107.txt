## Autodesk Map GIST 5107
Geographic Information Systems Course
## Course Overview
Covers the basic technical skills required in spatial data collection and management within Autodesk Map. Topics include CAD issues, workflow, spatial data tools, GIS definitions, topology (spatial relationships), advanced queries, property alteration and spatial analysis.
### Prerequisite(s)
- 50% in AICO 1000
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Describe principles of GIS and the AutoCAD MAP product.
- Bring data into AutoCAD Map.
- Work with object data.
- Edit maps and cleanup drawings.
- Work with raster images.
- Create and use projects.
- Query Data.
- Edit multiple source drawings.
- Work with coordinate systems and external databases.
- Link objects to database records.
- Plot and view Map data and images.
- Create and use topologies.
