## Web Page Creation Level 1 COMP 0402
Computer Systems Course
## Course Overview
Have fun learning how to design, create, and upload your own web pages using a word-processing program, HTML and FrontPage. Topics include: how to add formatted text, lists, links, tables and images to web pages. By the end of the week, students will publish a small web site online to share with family and friends (Ages 10-13).
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Define basic web development related terms.
- Understand safe surfing techniques.
- Create web pages using open source tools like a text editor (notepad) or EditPlus.
- Create and add images, sounds, tables, and links to web pages.
- Utilize basic CSS to style web pages.
- Upload files to a web server.
- Build a five-page website by the end of the week.
