## MS Access 2007 Transitional Workshop COMP 0270
Computer Systems Course
## Course Overview
MS Office has a completely new interface for version 2007. It was developed to make these applications simpler to use. The menus and buttons from prior versions are gone. MS Access 2007 uses a new ribbon environment with a new Getting Started page. This intensive half-day transition workshop is targeted for students who already know how to use MS Access 2003 to design and manage databases. Topics include navigating the Ribbon, the Quick Access Toolbar, Categorized Templates, the Navigation Pane and how to create and save database objects in the appropriate file formats. Gain hands-on experience to create and manage databases using concepts and special techniques to increase efficiency.
### Prerequisite(s)
- COMP 0271 or working knowledge of MS Access and Windows PC and file management.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Download a database from the new Getting Started page.
- Create database objects by using Ribbon.
- Use the Navigation Pane for tables, forms, reports and queries.
- Save and share your data in appropriate formats.
