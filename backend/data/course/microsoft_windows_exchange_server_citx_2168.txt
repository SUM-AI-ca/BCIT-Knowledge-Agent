## Microsoft Windows Exchange Server CITX 2168
Computer Information Technology Electronics Course
## Course Overview
This course prepares students to implement and administer messaging and collaborative infrastructure solutions. Students will learn about installing, mapping and troubleshooting Microsoft Exchange 2003 Server.
### Prerequisite(s)
- CITX 2161 or CITX 2162 or CITX 2163
