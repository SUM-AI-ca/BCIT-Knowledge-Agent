## Windows SharePoint Services (WSS) for End-Users COMP 2969
Computer Systems Course
## Course Overview
This hands-on course is designed to allow end-users of MS Office 2007 to leverage Windows SharePoint Services (WSS) for effective information sharing and collaboration. Students who already know how to use MS Office 2007, will learn to create and manage SharePoint sites, and how to use and add content to the sites. They will also learn how to set up alerts when documents or content have been added or changed. Topics include: document libraries, lists, wikis, blogs, discussion boards and surveys. Successful participants will also learn how to integrate WSS with Microsoft Office 2007 applications and understand native SharePoint permissions and security. By the end of this course, they will be prepared to move on to COMP 3969 , SharePoint Designer.
### Prerequisite(s)
- COMP 1002 and COMP 2007

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Plan SharePoint Sites and Structures.
- Create document libraries, views, folders, out-of-the-box lists.
- Use wikis, blogs, calendars, discussion boards, and surveys.
- Change basic branding, themes, logos.
- Understand custom content types, site libraries and lists.
- Work with out-of-the-box web parts.
- Set up groups, users and permissions.
- Explore out-of-the-box workflows.
- Use Office Products (Word, Outlook, Excel, InfoPath, Access) with SharePoint.
