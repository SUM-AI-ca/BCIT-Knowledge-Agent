## Java Programming Language Level 1 COMP 4409
Computer Systems Course
## Course Overview
Provides a thorough introduction to the Java programming language and the Java distributed objects paradignm. Includes the Java language environment, creating user interfaces, developing multi-threaded applications, handling multimedia data types, and managing collections.
### Prerequisite(s)
- COMP 3670 and one level 2 programming language.
