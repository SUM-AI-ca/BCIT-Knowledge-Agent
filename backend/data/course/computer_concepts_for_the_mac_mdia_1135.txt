## Computer Concepts for the Mac MDIA 1135
Media Communications Course
## Course Overview
This course is intended for all levels of Mac users. We will take an In-depth look at Snow Leopard and the majority of it?s features. The course also provides a hands on journey as the student explores the depths of Mac OS X Snow Leopard. Topics include: introduction to the computer concepts of hardware and software, the Mac user interface, file management, components of the Mac OS X, free programs included with Mac OS X, networking/file sharing/ Screen Sharing, printing/fonts/graphics, troubleshooting, accounts/parental controls, networking/firewall and security. Gain a hands-on understanding of how to set up a home-based or small business network, and firewalls. Learn how to back-up data and systems, create and burn CDs and use USB drives. For those that require access to windows, Bootcamp and virtualization will be covered.
### Prerequisite(s)
- Basic hands-on knowledge of a Mac.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Explain how a Mac works, and understand the relationship between hardware and software.
- Classify and explain the function of different computer hardware components.
- Understand purpose and functions of an operating system (OS).
- Examine the history of Mac OS X operating systems and Unix basics.
- Identify Mac OS X GUI components, and understand their use.
- Learn efficient storage management, file maintenance and file organization.
- Use System Preferences to
- Customize keyboard, display and mouse functions.
- Manage network resources.
- Configure System Preferences to manage Time Machine, set the Startup Disk.
- Customize and manage User accounts.
- Understand the concepts behind compression and encryption via FileVault.
- Understand how to create users, groups and set login options.
- Understand basic networking principles, screen sharing and the internet.
- Understand Mac security, backup, malware, and firewalls.
- Understand Internet browsers and search engines.
- Troubleshoot basic operating system challenges and use "Help".
- Understand Bootcamp and virtualization options to run "Windows".
