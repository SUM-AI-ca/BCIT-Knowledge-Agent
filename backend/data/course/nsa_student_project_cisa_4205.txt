## NSA Student Project CISA 4205
Computer Info Systems Admin Course
## Course Overview
In this capstone course, students design, build, test and troubleshoot a complex computer network. The project requires the students to work in groups to complete the project within the allotted time. Specifications include the use of tools and applications used in previous levels, and configuration of multiple routers, switches, servers, firewalls, and clients in an enterprise organization, according to the project design requirements. Students will utilize all the skills they have accumulated during the program and develop teamwork skills, time management, report writing, presentation, and networking skills abilities.
### Prerequisite(s)
- Successful completion of CISA Level 3 (NSA option) with minimum 60% grade point average.
### Credits
8.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Demonstrate project management skills in planning and completing a team project
- Manage their time and deal with obstacles in completing their project
- Develop effective teamwork skills
- Demonstrate effective presentation skills
- Demonstrate ability for self-directed learning
- Configure and test network devices in accordance to the project requirements
- Monitor the network operation and services in accordance with the project requirements
- Install, configure, maintain software services required by the project
- Evaluate network security for the network created within the project
- Assess the overall operation of the network created within the project
- Present the project to a technical audience
- Develop project report that includes comprehensive documentation
