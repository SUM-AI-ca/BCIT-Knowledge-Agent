## Overview

Introduces basic principles of wood frame building construction. Develops skills to produce a basic set of construction working drawings. Topics; western platform wood frame construction; wall framing, floor framing and roof framing for a single family residence. Previous drafting experience or DRFT 1000 is recommended prior to taking this course.

## Credits

3.0

## Cost

## Prerequisites

- No prerequisites are required for this course.

## Learning Outcomes

- Identify architectural working drawing requirements.
- Size sawn timber components to part 9 code compliance.
- Prepare a partial set of architectural working drawings.
