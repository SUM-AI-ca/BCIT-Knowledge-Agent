## Architectural CAD Rendering BLDG 3405
Building Course
## Course Overview
Covers basic concepts involved in architectural rendering and animating 3D models. Uses advanced 3D rendering software (3D Studio Max) to explore the concepts of materials, lighting and form, and how they are combined to create high-quality presentation media.
### Prerequisite(s)
- 50% in BLDG 3400
### Credits
1.5
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Be competent and familiar with 3D Studio Max interface.
- Import/link Autocad data into these applications.
- Access the on-line help system and user documentation.
- Create basic and advanced geometric primitives in 3DS Max.
- Create and apply basic materials to 3D objects.
- Create accurate lighting systems, (daylight and artificial illumination).
- Use cameras and simple animation techniques to create images and movies to best visualize designs.
Effective as of Fall 2012
