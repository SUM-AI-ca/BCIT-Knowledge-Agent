## Leopard 101: Mac OS X Support Essentials v 10.5 MDIA 1011
Media Communications Course
## Course Overview
BCIT is an authorized Apple Training Centre. Mac OS X Support Essentials is a three-day, hands-on course that provides an in-depth exploration of troubleshooting on Mac OS X. This course is designed to give you a tour of the breadth of functionality of Mac OS X and the best methods for effectively supporting users of Mac OS X systems. The course is a combination of lectures and hands-on case study exercises that provide practical real-world experience.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Follow a troubleshooting process and become more efficient with available tools and resources.
- Prepare and partition the drive.
- Install Mac OS X.
- Use the installer log to verify installation.
- Configure Mac OS X with Setup Assistant.
- Update software with Update and Installer.
- Troubleshooting installation problems.
- Create and manage user accounts.
- Create and manage administer accounts.
- Demonstrate Security abilities.
- Create Password selections.
- Work with the FileVault.
- Work with file systems supported by Mac OS X.
- File and directory ownership and permissions.
- Disk Utility and file repair.
- Use the Command Line Interface.
- Applications supported in Mac OS X.
- Accessing network services.
- FTP and WebDav connections.
- Enabling network services on a Mac OS X client.
- Share files between Macs and Windows.
- Basic network configuration.
- TCP/IP networking.
- Airport.
- Connecting peripherals to a Mac.
- Troubleshooting boot issues with a Mac at start-up.
- Prepare for Apple Certified Support Professional certification.
