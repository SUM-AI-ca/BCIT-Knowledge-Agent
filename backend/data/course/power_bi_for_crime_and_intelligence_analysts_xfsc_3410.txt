## Power BI for Crime and Intelligence Analysts XFSC 3410
Forensics Microcredentials Course
## Course Overview
​This course is designed for analysts in law enforcement or regulatory agencies that have work experience using Excel and descriptive statistics. In this course you will learn how to use Power BI to analyze trends and patterns, apply statistical analysis and create dashboards for reporting and for subsequent intelligence analysis. Some background knowledge in data cleaning and data preparation, such as FSCT 8438 : Data Analytics and Visualization, is recommended for success in this course.​
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create comprehensive dashboards for reporting and analysis using Power-BI
- Analyze data using statistical tools within power BI, with the emphasis on the regulatory and law enforcement environment.
- Assess the inferences made from statistics one creates within Power BI​
