## Basic Stair Construction CARP 0125
Carpentry Course
## Course Overview
An ideal refresher for working carpenters. Topics include basic stair construction techniques pertaining to straight-line stairs and stairs with landings as well as related BC Building Code requirements.
### Prerequisite(s)
- No prerequisites are required for this course.
