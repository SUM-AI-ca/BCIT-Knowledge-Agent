## Human Factors for Interface Design MDIA 2530
Media Communications Course
## Course Overview
Examines the perceptual and cognitive foundations of multimedia production. Research in visual perception, cognitive models, sound, user feedback, and gender issues will be integrated with principles of interface design and navigation.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Recognize the main disciplines of web usability.
- Evaluate and critique web site interfaces under industry standards.
- Demonstrate user and task analysis processes.
- Identify principles of interface design and user experience.
- Conduct usability testing and web evaluations.
- Evaluate the elements of credibility and persuasion for Interactive media.
- Design and implement website prototypes.
