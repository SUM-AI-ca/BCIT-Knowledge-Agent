## Computer Aided Manufacturing MANU 3312
Mechanical Manufacturing Course
## Course Overview
Investigates programming and operating procedures of Computer Numerical Control (CNC) machine tools. Part and machine setup procedures will be examined and proved on BCIT's CNC equipment. Computer Aided Manufacturing (CAM) techniques for programming will be studied in depth.
### Prerequisite(s)
- 50% in MECH 1210 and 50% in MECH 2202
- MANU 3314 ‡ ( ‡ must be taken concurrently)
### Credits
5.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Set up and operate a Computer Numerical Control (CNC) milling machine.
- Perform CNC process planning.
- Create programs for CNC machine tools using manual G-code programming methods.
- Create and simulate milling toolpaths using Computer Aided Manufacturing software.
