## C Programming Language 1 COMP 2425
Computer Systems Course
## Course Overview
This second level programming course is designed for students who already know how to write structured code. It introduces the C language which is one of the principal foundations of computer software. The C syntax is also the basis for several higher level languages such as C++, Java, C# and Perl. Concepts taught in this course make it easier to understand other programming languages. Topics include: basic C language programming elements and the use of pointers, which are an essential construct of C. Students who successfully complete this course will be able to write simple C applications, as well as be able to understand C source code written by others. This course prepares students to move on to other higher level programming courses.
