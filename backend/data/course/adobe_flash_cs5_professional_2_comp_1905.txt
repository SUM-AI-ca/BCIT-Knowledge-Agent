## Adobe Flash CS5 Professional 2 COMP 1905
Computer Systems Course
## Course Overview
This hands-on course carries on from COMP 1904 and introduces students to advanced Flash programming and design techniques. Students learn to create advanced rich internet applications with interactive and dynamic content and greater functionality. Beginning with an introduction to of the basics of object oriented programming (OOP) in Flash, students learn to create and work with classes and variables in a Flash environment. Topics also include; functions, arrays, and conditional logic. Upon successful completion of this course, participants will be able to use Flash to make web sites more interesting with ActionScript. Please bring a pair of basic headphones to each class.
### Prerequisite(s)
- 50% in COMP 1904

## Learning Outcomes
Upon successful completion of this course, students will be able to:
- Utilize ActionScript 3.0.
- Integrate data with Flash.
- Construct rich internet applications.
- Build simple web based games.
- Plan a Flash based project.
- Discuss several methods for troubleshooting their code.
- Create and work with variables.
- Utilize conditional statements.
- Work with built in objects and create new objects.
- Load external movies and content.
- Discuss the basics of programming Flash from an OOP perspective.
- Apply ActionScript to create dynamic web based content.
- Demonstrate several ways to integrate data into Flash.
- Define arrays are and how to utilize them in applications.
