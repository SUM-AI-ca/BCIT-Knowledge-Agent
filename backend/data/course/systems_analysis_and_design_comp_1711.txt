## Systems Analysis and Design COMP 1711
Computer Systems Course
## Course Overview
This course introduces tools and techniques that are used for large-scale software development. Topics include: Systems Development Fundamentals, Systems Analysis, Systems Design, Data and Process Modelling, Systems Implementation and Support, Project Management. Student teams will work a case study through the full information system development cycle using project management and modelling tools. Note: COMP 2615 and COMP 3615 are the PTS equivalent to COMP 1711 .
### Prerequisite(s)
- No prerequisites are required for this course.

5.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Define the building blocks of an information system.
- Explain a systems development life cycle.
- Use data modeling and process modeling to design an information system to meet users' requirements.
- Gather and analyze user requirements.
- Use project management tools to plan and monitor projects.
- Prepare feasibility studies.
- Prepare detailed specifications for a system design.
- Plan systems implementation, including consideration of:
- System testing
- Preparing user manuals
- Systems delivery, maintenance, recovery, enhancements
- Training
