## Developing Web Applications ACIT 2520
Computer Information Technology Course
## Course Overview
​This course develops an understanding of the fundamental underpinnings of client-server interaction within the context of Web Applications. Topics covered include using modern javascript, building asynchronous non-blocking web servers, working with databases to persist data, creating RESTful Web Services, and application deployment.
### Prerequisite(s)
- 50% in ACIT 1515 and 50% in ACIT 1620
### Credits
4.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe client-server interaction as it applies to a web application.
- Develop server-side web applications.
- Use modern techniques for handling asynchronous IO in a web application.
- Deploy web applications.
- Access a database from a web site.
- Load and manipulate JSON documents.
- Create dynamic web pages.
- Develop web services.
