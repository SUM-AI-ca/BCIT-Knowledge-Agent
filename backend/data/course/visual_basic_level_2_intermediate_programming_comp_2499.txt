## Visual Basic Level 2 (Intermediate Programming) COMP 2499
Computer Systems Course
## Course Overview
Continuing from COMP 1499 , this course takes students to the next level of Visual Basic v6 programming using multi-form applications, list controls, collection objects, user-defined types, file access and error handling. Object oriented programming concepts introduced are: how to write class files with properties, methods and custom events; and how to create objects and collections of objects. Upon completion of this course, students will be able to write object oriented Windows applications using VB v6.
### Prerequisite(s)
- 50% in COMP 1499

3.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Design VB screens using the intrinsic, advanced controls and array of controls.
- Write VB code using the industry standards and expectations, inline documentation.
- Build functional medium complexity applications using data files.
- Use arrays, user defined types and collections.
- Understand the concepts of OOP, COM, OLE.
- Connect to a database using Data Bound controls.
- Design and implement simple VB classes, properties, methods and events.
