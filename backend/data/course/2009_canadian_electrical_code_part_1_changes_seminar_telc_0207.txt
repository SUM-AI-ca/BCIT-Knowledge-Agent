## 2009 Canadian Electrical Code Part 1 Changes Seminar TELC 0207
Electrical Trades Course
## Course Overview
This one day seminar will cover all the major changes to the 2009 Canadian Electrical Code Part 1. Special attention will be given to the key changes to Section 0, 10, 12, 18, 26, 32, 46 and 68.
### Prerequisite(s)
- No prerequisites are required for this course.
