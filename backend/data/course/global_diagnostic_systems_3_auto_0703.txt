## Global Diagnostic Systems 3 AUTO 0703
Automotive Mechanics Course
## Course Overview
Kia Course #TEC-ILT-GDS3-1EF. Provides technicians with the knowledge and skills to develop a methodical and consistent approach to apply VMI to effectively and efficiently diagnose, service and repair customer vehicles.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
0.0

## Learning Outcomes
Upon successful completion of this course, technicians will be able to:
- Apply all oscilloscope features and functions
- Correctly connect and test vehicle components
- Utilize the simulator function
- Perform various inspections and tests
