## Java Programming 1 COMP 3611
Computer Systems Course
## Course Overview
This course provides a thorough introduction to the Java programming language and core application framework. Starting with an introduction to Java and the Java Programming Environment, the course moves through fundamental programming structures to cover Objects and Classes. Event Handling and Swing provide the core understanding of how to build Graphical User Interfaces. Topics include: exceptions, debugging, streams and files. JAVA 1 is not an introduction to programming and you are expected to know how to write structured code.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Install and use the Java Developer Kit (JDK) Standard Edition to develop Java applications.
- Develop an understanding of the fundamental classes of the Java application framework.
- Build Java programs with proper exception handling.
- Build Java programs with proper event handling.
- Build Java programs that conform to the model-view-controller architecture, and demonstrate proper application of the observer-observable pattern.
- Build programs that use the basic Swing GUI components.
- Use the Java Collection Framework and serialization to manage and save your object data.
- Build Java programs that conform to Sun's Java coding style, naming, and documentation conventions.
