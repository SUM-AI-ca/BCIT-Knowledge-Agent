## AutoCAD for Interior Design INTD 2160
Interior Design Course
## Course Overview
Using the current release of AutoCAD for Windows, students will become familiar with and use the drawing, editing, and view manipulation commands of the program. They will also be introduced to layouts, blocks, dimensioning, and text commands. The students will complete a dimensioned floor plan, a furniture plan, elevations, and details. Overall emphasis will be on using AutoCAD for designing a residential project.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create new drawings without the use of templates, using drawing and editing commands found in the current release of AutoCAD.
- Draw residential floor plans, elevations and details using different line types.
- Create blocks of furniture, fixtures and architectural details for use within drawings.
- Create various text styles for different applications such as title blocks, room names, construction and detail notes.
- Create various dimension styles for plans, elevations, and details.
- Apply the External Reference command to create elevation drawings.
- Use Attributes for symbols in referencing.
- Create a standard title block template for a drawing sheet.
- Layout drawings in paper space to produce different viewports at various scales.
- Plot drawings using appropriate line weights for interior design applications.
Effective as of Winter 2025
