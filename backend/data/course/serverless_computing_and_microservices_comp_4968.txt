## Serverless Computing and Microservices COMP 4968
Computer Systems Course
## Course Overview
In this course students learn to how design and develop software natively for cloud computing platforms. This course is tightly integrated with COMP 4964 (DevOps Engineering - Cloud). Topics include software application patterns and architectures, fundamentals of distributed processing, re-architecting (refactoring) applications for the cloud, migrating applications to the cloud, hybrid architecture development (on-premises and cloud), cloud application services, cloud development tools, containerization, container orchestration, serverless computing platforms and microservices (event-driven) architecture. Students will build their skills by participating in in-class interactive lectures, hands-on lab activities and working on comprehensive assignments.

## Learning Outcomes
Upon successful compleltion of this course, the student will be able to:
- Articulate the differences between varieties of software application architectures using diagrams.
- Describe how to use the various cloud-based development tools and application services available on the leading public cloud computing platforms.
- Design, build and deploy cloud-based applications using cloud-based development tools and application services.
- Create and deploy applications with Docker containers.
- Configure and utilize cloud-based and third-party container management and orchestration tools.
- Define serverless computing and the serverless computing frameworks on the leading public cloud computing platforms.
- Design, build and deploy a variety of serverless applications, including web applications, on public cloud computing platforms.
