## Unix/Linux Security, Ethics & Privacy CITX 2183
Computer Information Technology Electronics Course
## Course Overview
This course provides students with proven techniques for protecting information stored in organizations networks from intruders, while allowing authorized users access to the internet and other outside resources. Course intended for technicians.
### Prerequisite(s)
- CITX 2182
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Describe the relevant components of Linux security.
- Secure Network Servers and User Workstations.
- Secure Public Web Servers.
- Deploy Firewalls.
- Detect Intrusions.
- Respond to Intrusions.
- Deal with other security related issues.
