## Imaging Technologies for Web Publishing MDIA 3205
Media Communications Course
## Course Overview
This course covers all aspects of preparing images for publication on the Internet, including image file formats, browser-safe colours, transparency, tiling, typography, scanning, animations, image mapping, and graphical layout using image slices. The course will be offered entirely on the Internet.
### Prerequisite(s)
- (50% in MDIA 1205 or 50% in MDIA 1206 ) and MDIA 2205
