## CCTV and Access Control Systems TELC 2230
Electrical Trades Course
## Course Overview
This is a mostly hands-on course in surveillance cameras and personnel access control. The unifying factor in both these systems is the use of IP technology for remote access and viewing. Students will work with routers and switches and investigate the workings of the internet. The course includes hands-on time connecting and configuring different camera types, digital video recorders, and card access systems.
### Prerequisite(s)
- TELC 2210

8.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Install a simple network.
- Select and install closed circuit television components.
- Select and install access control system components.
