## Adobe Illustrator PC 1 MDIA 1260
Media Communications Course
## Course Overview
The Adobe Illustrator level 1 course provides students the opportunity to complete three vector artwork projects that introduces illustrator’s user interface, main toolsets and the core concepts of creating vector artwork. The course examines artwork view modes, rulers, guides, and selection, drawing, painting, shaping and type tools. Students work with layers, paint objects, apply custom colors and gradient fills, draw straight lines and curves with the pen tool, convert points, and use primitives to create basic art elements. Students also work with type and change type attributes.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Define Illustrators work environment including, workspaces and preferences
- Demonstrate knowledge of terminology used in vector graphic creation
- Navigate Adobe illustrators interface
- Create basic shapes such as rectangles, circles, and polygons
- Draw and adjust bezier paths with the pen tool
- Assign objects to layers and groups for greater control over artwork
- Create solid color fills and gradient fills
- Save fills as swatches to the swatches panel for convenient retrieval and reuse
- Change an objects path using techniques that include the selection, transform, direct selection or convert direction point tools
- Apply type and change its attributes and alignment with basic typography controls
- Prepare Adobe Illustrator files for different uses including print, web and pdf distribution
