## CSS, DHTML and AJAX MDIA 4321
Media Communications Course
## Course Overview
This course begins with an overview of the basic and advanced CSS functions necessary for writing DHTML and AJAX scripts. Other topics include DHTML basics, the DHTML environment, using objects and events, integrating dynamic CSS with DHTML, AJAX basics, and using CSS, DHTML and AJAX for page layout, content, navigation, and page controls.
### Prerequisite(s)
- MDIA 1205 and MDIA 2205 and MDIA 3201 and MDIA 3207
### Credits
3.0

## Learning Outcomes
Upon successful completion of this course, students will be able to:
- Outline basic and advanced CSS declarations.
- Describe the nature and structure of the Document Object Model (DOM).
- Explain the interaction between objects and events in DHTML functionality.
- Detect aspects of the user environment using DHTML.
- Illustrate the interaction between objects and events using DHTML.
- Explain how to employ CSS for dynamic page styling.
- Summarize the relationship between CSS and DHTML in the AJAX environment.
- Outline techniques for dynamic page functionality using CSS, DHTML, and AJAX scripting.
- Illustrate how to dynamically control page data.
- Describe how to create dynamic navigation tools.
- Outline how to create dynamic page controls.
