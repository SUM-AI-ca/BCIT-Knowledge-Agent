## Preflight for Printers GTEC 2145
Graphic Communications Technology Course
## Course Overview
This course covers the strategies and procedures to check customer generated prepress files, and recognize issues that will cause problems and delays later on in the production cycle. Focusing mostly on portable document format (PDF) based prepress workflows, students will be able to troubleshoot and fix common mistakes found in customer supplied files
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5

## Learning Outcomes
Upon successful completion, the student will be able to:
- Jump from a pre-flight report to a problem highlighted on a pdf page.
- Perform a wide range of fixes for common pdf prepress errors.
- Add or remove logos, page headers or convert colors from different color spaces.
- Embed action lists into pdf files for test and modification options.
- Track changes to files and roll back to previous versions.
- Select and edit pdf elements such as text, vector objects, raster images and color profiles.
- Change properties such as fonts, font embedding and outlining, color spaces, size and position.
- Change image resolution and ICC profiles.
- Pick a color engine from a range of industry standard CMS solutions for maximum color fidelity.
