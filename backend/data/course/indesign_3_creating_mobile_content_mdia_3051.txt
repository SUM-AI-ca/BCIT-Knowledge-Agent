## InDesign 3 Creating Mobile Content MDIA 3051
Media Communications Course
## Course Overview
This course provides instruction to students on how to author content for mobile devices that allows viewers to engage with interactive media. Students will explore different features of Adobe InDesign including authoring designs in both horizontal and vertical formats with interactivity including; hand gestures, video and audio, image panoramas and zooms for playback on tablets and smartphones. Techniques for visual composition and layout will be applied to the content developed. The course will cover creating and building folio files for uploading to a Content Viewer. Upon completion of the course students will have interactive content ready for uploading to an App store such as the Apple Store or the Android Market.
### Prerequisite(s)
- MDIA 1049 and MDIA 2049

## Learning Outcomes
At the end of this course the student will be able to:
- Create base layouts in Adobe InDesign for digital content in both horizontal and vertical formats.
- Add interactive objects using the Overlay Creator panel including hand gestures, swipe, pinch and zoom.
- Apply the principles of visual composition and layout to each page.
- Apply paragraph styles, character styles and object styles to help ensure content consistency.
- Create custom libraries for storing multiple pictures, graphics, video and sound files.
- Create hyperlinks that jump to websites and other articles.
- Use the Folio Builder to create folio and article content pages.
- Share the Folio with others for previewing in a Content Viewer.
