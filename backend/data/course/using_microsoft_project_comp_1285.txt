## Using Microsoft Project COMP 1285
Computer Systems Course
## Course Overview
This hands-on course teaches experienced Project Managers how to use the MS Project software application package. Project Managers learn to use MS Project to develop plans and manage resources in order to deliver projects on time and on budget. Case studies are used to practice PM skills by developing plans and schedules over various phases of their projects in the MS Project application. Topics include: how to create schedules, assign resources, analyse workloads and detail tasks and materials required. Students will work in teams to complete a project plan from start to finish and understand how to track deliverables. They will learn to input and access project information, set milestones, track progress and make trade off decisions between cost, schedule and scope. Those taking this course for credit will have access to download MS Project 2013 Professional software for use at home during this course.This course is offered once a year in the fall term.
### Prerequisite(s)
- COMP 1002 or equivalent knowledge of a Windows PC, and file management.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Develop project scope statements from conception, sign-off, implementation, and formal completion.
- Build rapport with stake-holders and to communicate effectively with other team members.
- Divide a specific project into various phases.
- Create a new project plan file and enter project information.
- Estimate time duration in order to accurately forecast project scheduling demand and costs.
- Manage project resources, update project plans, and manage project costs.
- Manage project activities by organizing tasks and determining task relationships.
- Level resources when they are over allocated (or not available) in order to satisfy project demands.
- Identify critical and non-critical tasks that are required to get a project in on time and to employ relevant crashing techniques.
- Report project data visually, reuse project plan information, finalize project plans, and exchange project plan data with other applications.
