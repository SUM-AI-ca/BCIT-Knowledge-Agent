## Technical Communication 3 for Geomatics COMM 2452
Communication Course
## Course Overview
This course expands the scope and the complexity of communication skills learned in COMM 1135 and COMM 2252 . Students learn how to write proposals, progress reports and formal reports. Emphasis throughout the course is placed on using effective writing and editing techniques to prepare professional and functional workplace reports.
### Prerequisite(s)
- 50% in COMM 2252
### Credits
2.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Assess the audience and purpose of a report and plan the report appropriately for the intended audience and purpose.
- Structure, write and format a project proposal.
- Structure, write and format a progress report.
- Structure, write and format a formal report.
- Produce, format and integrate suitable graphics for technical reports.
- Write clear, concise sentences and paragraphs.
- Edit and revise your writing to an acceptable industry standard.
- Make documents easily accessible by using headings, lists, and white space.
- Plan, develop, and present a group technical presentation using PowerPoint.
- Use online collaboration tools to produce group documents.
- Work effectively in teams.
- Critically evaluate information to determine if it is accurate, relevant, and complete, and to use critical thinking to develop strong arguments.
