## Computer Hardware Setup Configuration and Maintenance CITX 0120
Computer Information Technology Electronics Course
## Course Overview
This hands-on course will familiarize the student with the internal hardware construction of a PC. The course covers the various components that make up a multimedia PC platform, troubleshooting and the resolution of configuration issues.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
0.0

## Learning Outcomes
Upon successful completion, the student will:
- Have a basic understanding of the internal hardware construction of a PC; processors, bus structures, floppy and fixed disk drives, video cards, CD ROM and DVD drives, scanners, sound cards, modems and printers.
- Be able to install and trouble shoot standard operating system software.
- Be able to trouble shoot standard hardware components.
- Be able to connect and configure common external devices.
