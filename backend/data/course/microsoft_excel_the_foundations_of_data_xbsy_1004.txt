## Microsoft Excel: The Foundations of Data XBSY 1004
Business Systems Course
## Course Overview
In this course, participants take a deeper look at how to use Microsoft Excel and key functionality such as creating tables and charts in addition to using formulas such as SUM, AVERAGE, MAX, MIN and ROUND that all help to improve calculations for decision-making. Participants will also walk through the different ways to format the file depending on if you are printing or sending it electronically.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create, edit, arrange, and print spreadsheets.
- Create and import graphics into spreadsheets; including picture files, SmartArt and WordArt.
- Describe default settings for graphics in MS Excel.
- Apply the order of mathematical operations in MS Excel.
- Manage worksheets by inserting, hiding, deleting, and adjusting rows and columns.
- Apply functions such as the SUM, AVERAGE, MAX, MIN and ROUND functions using Excel.
- Create and modify charts in MS Excel.
