## Campus Network Project CISA 2390
Computer Info Systems Admin Course
## Course Overview
​Students leverage the knowledge and skills they have accumulated during the first 33 weeks of the program to design, build, test, and troubleshoot a computer network. The students work in teams, develop a report and presentation on their project, and exercise project management procedures. The computer network is deployed across the classrooms using real equipment interconnected in a hierarchy that lends the design to multiple subnets, sites & services, issues with bandwidth, and issues with security. This provides a real-world experience.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Determine the requirements to deploy a computer network based on criteria supplied in a request for proposal (RFP)
- Design an IPv4 and IPv6 addressing scheme, device naming scheme, company naming conventions for users and groups, and domain name system (DNS)
- Create a project management report with timelines and accomplishments
- Create a project document that clearly outlines the proposed computer network design, lists the inventory (software and hardware), and indicates critical configurations
- Create a presentation and present their project
- Build the infrastructure to support the network connections and services for the project
- Interconnect computers and configure software services required by the project
- Monitor and verify network operation and services in accordance with the project requirements
- Work effectively within a small team
- Develop strategies for efficient use of time within a team environment
