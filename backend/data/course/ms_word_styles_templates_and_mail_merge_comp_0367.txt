## MS Word Styles, Templates and Mail Merge COMP 0367
Computer Systems Course
## Course Overview
In this one-day workshop participants will gain hands-on experience using time saving features in MS Word to increase document consistency by using Styles and automate document creation using Building Blocks, Templates, and Mail Merge to personalize correspondence. Students must be familiar with managing files on a Windows PC and the common features in Word including the user interface, and creating and editing documents. Students will understand the benefits in using styles, building blocks, and templates for document creation and appreciate the mail merge process for preparing customized letters. Workshop topics include applying, creating and modifying styles in documents or templates. Using building blocks or quick parts to insert frequently used content and objects into documents or templates; creating, saving and using templates; performing a mail merge to create letters, envelopes, and labels. Advanced mail merge topics include sorting and filtering data, and using rules to customize the merge are also covered. For working with Reports and Collaboration features please see COMP 0368 .
### Prerequisite(s)
- COMP 1002 or equivalent knowledge of managing files on a Windows PC and experience with MS Word.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the benefits of using styles.
- Demonstrate formatting text using the style gallery.
- Create, modify and update styles in documents or templates.
- Create and insert contents or objects using quick parts or building blocks.
- Explain the benefits of using templates.
- Create, save and use a template to generate commonly used documents.
- Customize template content.
- Create a merged document using the Mailings tab and/or Mail Merge wizard.
- Sort and filter data for the merge.
- Use mail merge rules to tailor merged results.
