## Data Analytics Bootcamp BTCW 0190
Business Workshops Course
## Course Overview
Data analytics allow organizations to gain data-driven insights and make better decisions faster. This is an introductory 1-day course that provides knowledge and skills required to effectively use business data for decision-making. The course includes a series of hands-on workshops using the latest release of Microsoft Excel. Whether you are tracking sales, planning inventory, or developing competitive strategies, this course will provide important skills needed to effectively work with data.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Effectively manipulate large amounts of data using advanced spreadsheet techniques.
- Identify how to capture, clean, and format data from multiple sources.
- Identify how to perform data mining and visualization using tables and graphs.
- Create data models from large corporate data sources.
- Prepare interactive reports to unearth customer behavior and preferences.
- Discuss forecasting methods and develop interactive dashboards.
