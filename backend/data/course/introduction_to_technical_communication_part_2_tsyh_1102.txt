## Introduction to Technical Communication Part 2 TSYH 1102
Transystems Course
## Course Overview
Applies the techniques learned in TSYH 1101 to specific forms of written communication.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
2.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
Upon successful completion, the student will be able to:
## Module 7 - Writing Technical Instructions
- Identify the requirements for effective instructions.
- Define the three-part format for instructions.
- Explain when to use cautions and warnings, command style and illustrations.
- Follow guidelines for writing instructions.
- Write an effective set of instructions.
## Module 8 - Writing Technical Descriptions
- Describe technical descriptions.
- Describe the differences between instructions and descriptions.
- Distinguish between process descriptions and mechanism descriptions.
- Organize technical descriptions.
- Use guidelines for writing technical descriptions.
- Write a practice technical description.
## Module 9 - Writing Effective Memos
- Explain the general characteristics of memos.
- Recognize the parts of a memo and explain the function of each part.
- Use appropriate presentation strategies for memos.
- Write an effective memo.
## Module 10 - Writing Effective Letters
- Explain the general characteristics of routine letters.
- Recognize the parts of a letter and explain the function of each part.
- Use appropriate presentation strategies for letters.
- Use a reader-friendly style in your letters.
- Write an effective routine letter.
## Module 11 - Writing Difficult Messages
- Use three general guidelines for writing difficult messages.
- Use the direct approach for difficult messages.
- Use the indirect approach for difficult messages.
- Select the appropriate approach in a given situation.
- Apply the guidelines and approaches to difficult requests, complaints and refusals.
- Write an effective letter in a difficult situation.
