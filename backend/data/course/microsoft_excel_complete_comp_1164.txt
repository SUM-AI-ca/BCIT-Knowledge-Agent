## Microsoft Excel Complete COMP 1164
Computer Systems Course
## Course Overview
COMP 1164 has been replaced by COMP 2364 . This hands-on course is the combination of MS Excel Level 1 and 2. Students progress from a beginner to an expert in just 12 sessions. With a combination of lectures, labs and project assignments, this course provides students with the practical skills needed to create and manage a variety of spreadsheets. As an added bonus, successful completion of this course helps in the preparation for challenging a Microsoft Office Specialist (MOS) exam.
### Prerequisite(s)
- 50% in COMP 1002

3.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Explore the Excel Workspace.
- Understand the Impact of Application Errors and Crashes.
- Enter and edit Data.
- Saving a Workbook.
- Modify a Worksheet.
- Format and improve the appearance of a Worksheet.
- Relative and Absolute Cell References.
- Use Basic Formulae and Functions.
- Working with Date and Time Functions.
- Working with Decision Making Functions (ie IF, VLOOKUP).
- Using Financial Functions.
- Sorting, Filtering and Editing Lists.
- Finding and Fixing Formula Errors.
- Creating, Editing and Formatting Charts.
- Combination Charts.
- Protecting Workbooks, Worksheets and Ranges.
- Import and Export Data.
- More on Templates and Styles.
- Analyze Data.
- Use the Scenario Manager, Solver, Goal Seek.
- Link Worksheets and Workbooks.
- Consolidate Data by Position and Category.
- Create Pivot Tables.
- Trace Dependents, Precedents and Trace Errors.
- Use data validation techniques.
- Create and Modify Worksheet Outlines.
- Create and Customize Toolbars.
- Use Database Lists and Filters to Manage and Summarize Data.
