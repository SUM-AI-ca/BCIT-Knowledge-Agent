## Script Supervision: The Full Picture XBST 1012
Broadcast and Media Communications Course
## Course Overview
​From pencil and paper to digital format, you will learn a basic understanding of how to navigate through the ScriptE program. Transferring Script Supervising skills into a finished digital version is key for efficient distribution as you advance in your Script Supervising career. You will gain basic knowledge of ​the software while learning to oversee the living Script Supervising elements onset.
### Prerequisite(s)
- S in XBST 1009 and S in XBST 1010 and 50% in XBST 1011
### Credits
1.0

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Discern how the Script Supervisor interacts with all other departments.
- Review and amalgamate key components of Script Supervising and Continuity.
- Apply basic concepts of the ScriptE program workflow to complete the work digitally
