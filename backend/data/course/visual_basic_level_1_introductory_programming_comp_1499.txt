## Visual Basic Level 1 (Introductory Programming) COMP 1499
Computer Systems Course
## Course Overview
This course is designed for students with no previous programming experience and builds on what they have learned in COMP 1409 . Using a task-driven approach, students will learn how to use the VB6 Integrated Development Environment in order to design VB6 screens and write functional VB6 code. Topics include: data types, variables and constants, programming structures, subs and functions, GUI design, using VB6 intrinsic controls, implementing event procedures, tracing and debugging.
### Prerequisite(s)
- 50% in COMP 1002 and 50% in COMP 1409
### Credits
3.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Identify the components of Visual Basic language.
- Build user interfaces, with dialogs and windows, using the GUI components.
- Build the shell of a Visual Basic application with menu support.
- Build Visual Basic programs that conform to Microsoft's Visual Basic coding style, naming, and documentation conventions.
