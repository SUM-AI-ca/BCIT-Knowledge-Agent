## ASP.NET Core MVC for Web Apps COMP 4514
Computer Systems Course
## Course Overview
This hands-on course builds upon COMP 3514 in the Full Stack Web Development Diploma. ASP.NET MVC (Model View Controller) allows students to build scalable and secure web applications to industry standards. Following on from COMP 2523 and COMP 3514 , web developers build on their experience with C# in the .NET Framework in this hands on course. Participants use patterns to script dynamic MVC websites in an alternate approach to ASP.NET Forms. Students learn to use both C# and Razor with the ASP.NET MVC framework to develop powerful data driven web applications with HTML5, jQuery and AJAX for full control over mark-up. Homework, exercises and labs focus on best practices in ASP.NET MVC. By the end of this course successful participants will be able to design, create and deploy sophisticated web applications with the latest ASP MVC tools.
### Prerequisite(s)

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explain the Model-View-Controller Architecture.
- Use Visual Studio to build ASP.NET MVC Core applications using the latest framework.
- Integrate ASP.NET MVC applications with popular JavaScript libraries.
- Develop responsive ingle Page Applications (SPAs).
- Implement Test Driven Development best practices.
- Integrate MVC applications with a variety of data sources.
- Secure MVC web applications.
- Use C#, Razor and Tag Helpers for building MVC pages.
- Deploy ASP.NET MVC applications into the cloud.
- Leverage the ASP.NET infrastructure.
- Explain how an ASP.NET Core application participates in the build & release processes along the CI/CD pipeline.
- Validate user input.
- Produce and consume API services.
- Develop cross-platform web applications.
