## Process Control GTEC 4467
Graphic Communications Technology Course
## Course Overview
Students will gain a basic understanding of several digital technologies and produce colour-managed contract proofs for large format signage and variable data digital print work flows. Students will get hands-on implementation of several process controls to integrate all the digital equipment in the facility. Particular attention will be paid to digital print as a proofing technology for offset and flexographic print workflows.
### Prerequisite(s)
- GTEC 3467 and GTEC 3464 and MDIA 2140
### Credits
2.0

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Correct file formats for digital workflows.
- Use Raster Image Processing (RIP) software on internal and external PC or Mac.
- Set up input and output ICC profiles—adjusting and/or substituting manufacturer’s profiles.
- Create colour-managed print production jobs that match across two different imaging technologies.
- Create output profiles using industry standard profile creation software.
- Convert colour spaces LAB and RGB to CMYK.
- Compare and describe inkjet RIP technologies.
- Compare and describe digital press RIP technologies.
- Describe industry-standard colour management routines to manage cross media production in a manufacturing environment.
- Implement proper digital press and inkjet calibration in standard RIP software.
- Implement colour proofing for digital print, inkjet, lithographic offset print, and flexographic print technologies.
