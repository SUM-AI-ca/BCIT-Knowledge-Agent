## Security Awareness MSEC 1001
Marine Security Course
## Course Overview
This course provides security awareness for vessel’s personnel without security responsibilities, and is in accordance with regulation VI/6 of STCW convention and section A-VI/6 of the STCW code.
### Prerequisite(s)
- A valid marine medical, 18 years of age, and proof of citizenship or permanent residence of Canada.
### Credits
0.5
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Contribute to the enhancement of maritime security through heightened awareness.
- Recognize security threats.
- Explain the need for and methods of maintaining security awareness and vigilance.
- Recognize security responsibilities of the contracting governments.
- Report security incidents.
- Explain the importance of the ship security exercises and drills.
- Explain MARSEC levels 1, 2, and 3.
