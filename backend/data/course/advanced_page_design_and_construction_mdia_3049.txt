## Advanced Page Design and Construction MDIA 3049
Media Communications Course
## Course Overview
This course introduces an advanced page layout workflow with features like nested frames, anchored objects, smart text handling, snippets and libraries for moving items of a page between documents and dragging and dropping external design elements on a page. The course focuses on integrating advanced features into page design while working with multiple applications with bridge software. Students will create a series of projects complete with a set of packaged files ready for output to different postscript devices.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Precisely control the positioning of anchored objects and apply text wrap settings.
- Create regular and irregular text wraps with varying positive and negative offsets.
- Apply smart text handling techniques.
- Use traditional typesetting features such as optical margin alignment and Opentype fonts.
- Place native file formats and create snippets from parts of a page.
- Create, format and edit tables with alternating screen tints.
- Use color controls, the color palette, apply colors and gradients and create spot color tint builds.
- Draw paths with Bezier curves and create compound paths.
- Anchor callouts, pull quotes, margin notes and graphics to text.
- Work with multiple layers blending mode effects.
- Work with clipping paths and threshold settings.
