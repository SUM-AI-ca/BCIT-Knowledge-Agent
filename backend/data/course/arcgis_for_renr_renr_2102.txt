## ArcGIS for RENR RENR 2102
Renewable Resources Course
## Course Overview
Introduces the latest versions of the ArcGIS software family and ArcGIS data models. Students use ArcMap, ArcCatalog and ArcToolbox to create and edit GIS data, and perform mapping. Successful completion of this course will give you a background in GIS concepts, help you to operate the basic components of ArcGIS software.
### Prerequisite(s)
- RENR 1118
### Credits
3.0

## Learning Outcomes
Upon successful completion, the student should be able to:
- Describe fundamental concepts of GIS and databases.
- Describe vector and raster data models.
- Perform attribute, spatial query operations.
- Utilize ArcGIS software to perform common analytical operations.
- Import and edit data in ArcGIS.
