## PageMaker PC 1 MDIA 1050
Media Communications Course
## Course Overview
Teaches design, layout and production of professional publications, using the Adobe PageMaker assembly software program. Students will learn to create numerous publishing projects including advertisements, brochures, bulletins, flyers and forms. Students will have their own workstation.
### Prerequisite(s)
- No prerequisites are required for this course.
### Credits
1.5
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to perform the following tasks in PageMaker 7 on the PC:
- Create, open and size documents.
- Create master pages and creating, moving and deleting pages.
- Understand the concept of grids and columns when constructing pages.
- Create, import and manipulate text.
- Understand and be able to use all the tools in the toolbox.
- Understand and be able to use all the functions in the control palette.
- Be able to format text and paragraphs, including: setting tabs and hanging indents.
- Be able to import graphics created in other software.
- Be able to draw rudimentary objects using PageMaker's drawing tools.
- Understand the use of layering objects.
- Understand the colour palette and how to apply colour to objects and test.
- Understanding and being able to image from the print dialogue box.
