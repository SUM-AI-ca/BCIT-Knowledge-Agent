## Using ASP in Web Publishing MDIA 4315
Media Communications Course
## Course Overview
This course will introduce you to the fundamentals of creating dynamic, interactive Web pages using Active Server Pages (ASP) technology. Topics will include: an introduction to ASP, ASP syntax, an introduction to VBScript, the request, response, server, application, and session objects, working with components, and connecting databases to ASP pages. Projects for the course will include creating an interactive guest book, a virtual radio station, a chat room, a classified ads database, and a restaurant menu database.
### Prerequisite(s)
- Completion of the Associate Certificate Web Technologies.
