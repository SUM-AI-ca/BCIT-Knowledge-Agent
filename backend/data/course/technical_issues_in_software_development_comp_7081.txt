## Technical Issues in Software Development COMP 7081
Computer Systems Course
## Course Overview
This course focuses on the technical issues of software development. This includes software development methodologies, software requirements analysis, software architecture and user interface design, version control, quality assurance, and maintenance. The course will also focus on applying patterns in all phases of software development. Students will also learn how to create essential artifacts throughout the entire software development cycle.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion, the student will be able to critically evaluate and apply:
- Software modelling techniques.
- Software costing models.
- Tasks and scheduling.
- Object-oriented analysis.
- Object-oriented design.
- Software test planning.
- Software maintenance concepts.
- Software quality assurance.
- Software configuration management.
