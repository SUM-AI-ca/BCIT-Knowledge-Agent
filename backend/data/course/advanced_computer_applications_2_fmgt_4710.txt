## Advanced Computer Applications 2 FMGT 4710
Financial Management Course
## Course Overview
​​​​​​This course is divided into two parts: One part builds on the learning from FMGT 3720 and continues to develop Data and Analytics skills using various tools including Excel, Power BI and Tableau. In the other part, Excel is used to analyze data and to build a Financial Model.​
### Prerequisite(s)
- 50% in FMGT 3720
### Credits
5.0

International fees are typically 3.4 times the domestic tuition. Exact cost will be calculated upon completion of registration.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Perform processes to extract, transform and load data for analysis
- Apply critical thinking principles to decision-making
- Use various tools including Excel, Power BI and Tableau for visual presentation of analysis results
- Create a Pivot table in Excel to analyze Payroll information.
- Create Monthly and Annual Budget Income Statement, Balance Sheet and Cash Flow reports using an Excel model.
- Change the projection data and have the budget reports update to reflect these changes in this model.
- Use appropriate excel functions to link the data in the model.
- Update this model to deal with changes to the underlying assumptions.​
Effective as of Winter 2024
