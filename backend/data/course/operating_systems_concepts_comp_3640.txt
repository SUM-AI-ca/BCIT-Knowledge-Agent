## Operating Systems Concepts COMP 3640
Computer Systems Course
## Course Overview
Introduces basic principles of operating systems design and implementation. Topics include memory management, processor scheduling, disk organization, and file systems. Students must have a programming and systems background. JAVA will be used to illustrate the concepts studied.
### Prerequisite(s)
- 50% in COMP 1450 and 50% in COMP 2610
