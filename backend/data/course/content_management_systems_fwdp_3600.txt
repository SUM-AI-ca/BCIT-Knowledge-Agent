## Content Management Systems FWDP 3600
Front-End Web Developer Course
## Course Overview
This course covers the fundamental features of dynamic websites and the creation of custom-coded websites built with a Content Management System (CMS). Students will learn the basics of dynamic websites, how they are used to create a CMS, and how to work with a CMS to build websites. Students will create, configure, and migrate websites built using a CMS. Once they understand the basic features, students will create custom code to extend functionality, edit and create templates, and build a basic web app or website on a CMS. To prepare them for their Capstone Project, students will also create a development plan for a mock client website. Evaluation will include lab assignments and projects.
### Prerequisite(s)
- FWDP 2000 and FWDP 1400 and FWDP 2400

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe the difference between static websites and dynamic websites.
- Create, configure, and customize websites built with a CMS.
- Migrate dynamic websites between both local and live servers.
- Create custom content types and blocks and custom content taxonomies.
- Write code to customize the output of content.
- Edit and create templates to modify front-end layout and functionality.
- Write custom code to modify and extend the back-end functionality of the CMS.
- Build a basic web app or website on top of the CMS REST API.
- Use the documentation of the CMS to find solutions to problems or tasks.
- Build a CMS development plan based on a website requirement list.
