## InDesign Mobile for iOS and Android MDIA 1058
Media Communications Course
## Course Overview
This course and has been designed specifically for the Mobile App Tools program. Students in this section must supply their own Mac notebook installed with the current OS X, a tablet, a SmartPhone, an Adobe Creative Cloud subscription, and an Apple iOS Developer Program membership in order to participate. The course will focus on creating mobile content using the digital publishing workflow, UI/UX design, adding interactivity and creating and deploying mobile apps. Students start by creating a UI/UX design flowchart conveying a mobile app user flow, as well as organizing, documenting and illustrating wire frames to match their mobile design. Labs and projects focus on creating and managing digital content to build and deploy articles and folios. Topics include: Creating icons and splash screens, adding smooth scrolling text, adding slide shows, creating multi-state object buttons, adding hyperlinks, creating scrollable frames, creating image sequences and importing video and music. Students will set-up and configure a Digital Publishing Suite (DPS) account, provision iOS and Android mobile devices, create an App ID, create Apple development and distribution certificates, submit a mobile provision file and use DPS App Builder to create and test iOS and Android apps in iTunes and Google Play.

## Learning Outcomes
At the end of this course the student will be able to:
- Setup and configure a Digital Publishing Suite account.
- Develop mobile specific design templates.
- Develop mobile flowcharts for UI/UX designs.
- Develop properly arranged mobile UI/UX wireframes based on designs.
- Develop version control of working files for mobile design iterations.
- Add user information, highlights and notes to wireframes.
- Add page/screen control for changes from one screen layout to another.
- Add iconography to mobile specific areas with information.
- Create interactive content with Folio Overlay tools.
- Create multi-state objects and device controls for viewer interaction.
- Design and create different mobile navigation systems with buttons and sliding menus.
- Preview and test an app on a mobile device with an Adobe Content viewer.
- Optimize video files for fast efficient downloads with Adobe Media encoder.
- Build articles and folios.
- Use a Folio Builder panel to upload content to the Creative Cloud.
- Use a Folio Producer dashboard to check mobile analytics.
- Follow a checklist for building an App.
- Provision mobile devices and create development and distribution certificates.
- Use DPS App Builder to create and test an app for both iOS and Android devices.
- Test an app on iTunes
