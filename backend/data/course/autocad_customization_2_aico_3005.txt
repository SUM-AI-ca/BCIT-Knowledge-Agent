## AutoCAD Customization 2 AICO 3005
Computer Aided Design & Engineering Course
## Course Overview
Introduces the AutoLISP programming environment. Includes AutoLISP programming concepts, development of applications in parameterized drawings, user defined commands, and interfacing with the drawing file database.
### Prerequisite(s)
- AICO 0050 or familiarity with Microsoft Windows and AICO 2000 ( AICO 2020 recommended).

3.0
