## Vector Works for Interior Design INTD 3345
Interior Design Course
## Course Overview
This course will introduce students to Vector Works software focusing on its use specific to Interior Design. Students will create 2D and 3D drawings concentrating on interior, modelling, lighting and rendering. This is an introduction course.
### Prerequisite(s)
- Entrance Requirements for Diploma.
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
At the end of this course the student will be able to:
- Set up a drawing file in Vector Works.
- Create a plan and elevation using 2D and 3D object creation, layers and snap constaints.
- Create drawings of walls, windows, doors and roofs in 2D and 3D.
- Create drawings using 3D modelling and rendering.
- Convert Vector Work files to AutoCAD and vice versa.
- Plot a 2D and 3D Vector Work drawing.
