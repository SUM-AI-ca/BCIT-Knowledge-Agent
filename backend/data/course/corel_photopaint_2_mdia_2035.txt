## Corel Photopaint 2 MDIA 2035
Media Communications Course
## Course Overview
Covers the advanced features of Corel Photopaint. Students will learn how to use special effects including edge effects for compositing text and images. use Photopaint's Recorder to record and play back command sequences. Learn how to use alpha channels and merge modes. Adjust tone, brightness contrast, color balance and gamma to color correct photos and images. Use Corel Photopaint's Movie feature to create and play back 2D animations. Projects will focus on quality art work to be used in a portfolio presentation.
### Prerequisite(s)
- MDIA 1035
