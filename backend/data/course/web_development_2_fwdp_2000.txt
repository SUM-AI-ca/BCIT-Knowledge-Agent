## Web Development 2 FWDP 2000
Front-End Web Developer Course
## Course Overview
This course explores advanced mobile-first responsive layout techniques and team-based web development process techniques. Students will develop an understanding of web development processes as part of a team of developers and project stake holders and will review modern CSS which provides a multitude of tools for creating advanced mobile-first responsive layouts. Practical applications will be demonstrated and reviewed including creating animated user interfaces using standards compliant HTML and CSS. Sharing and version controlling code, automating tasks using task runners and improving CSS development using the latest CSS pre-processors will be discussed and practiced. The web development process will include publishing a finished website for public consumption as a major step. Evaluation will include lab assignments and projects.
### Prerequisite(s)
- FWDP 1000

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create advanced mobile-first layouts using modern CSS layout techniques.
- Create animated user interface elements using CSS.
- Write CSS using a CSS preprocessor.
- Use Version Control to manage code and collaborate with other developers.
- Automate web development tasks using modern task runner tools.
- Develop small- and medium-sized multi-page web sites as part of a team of developers.
