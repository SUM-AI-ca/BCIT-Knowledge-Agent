## Cargo and Stability Software NAUT 1204
Ocean Navigation Course
## Course Overview
This course involves planning stowage for marine bulk containers and liquid bulk cargoes on board vessels using a software application. The stowage planning incorporates criteria for stability conditions to the requirements of IMO standards. This course also explains calculation method of longitudinal stresses on ships.
### Prerequisite(s)
- Successful completion of Term 3 and Ship Stability 3
### Credits
1.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion of the course, the student will be able to:
- Use computer software for planning a vessel’s passage on ballast to meet specified stability condition.
- Use computer software for stowage of bulk cargo on bulk vessel to meet specified stability condition.
- Use computer software for container stowage on container vessel to meet specified stability condition.
- Use computer software for planning stowage of liquid cargo on tanker to meet specified stability condition.
