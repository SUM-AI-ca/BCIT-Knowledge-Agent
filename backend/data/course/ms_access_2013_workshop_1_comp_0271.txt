## MS Access 2013 Workshop 1 COMP 0271
Computer Systems Course
## Course Overview
COMP 0271 , 0272 and 0279 have been replaced by COMP 0371 and COMP 0372 . In one day participants are shown how to create a simple database with multiple tables using MS Access 2013 in this intensive, hands-on seminar. Participants must already be familiar with managing files on a Windows PC and the MS Office interface, version 2010 or higher. Topics include: how to create Access tables and fields, generate queries and identify criteria, and create basic forms and reports using Wizards. Successful participants will be prepared for MS Access Workshop Level 2, COMP 0272
### Prerequisite(s)
- COMP 1002 and COMP 2010 or equivalent knowledge.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Understand database terminology, and the basic principles of normalization to create a functional database
- Create multiple tables and establish relationships between tables
- Modify table data and properties
- Sort and filter table data
- Create select queries using the Query by Example window
- Add criteria to a query
- Add a calculated field to a query
- Create basic forms using the Form Wizard
- View data using an Access form
- Apply basic changes to a form using Layout View
- Effectively use the report generator to create reports
- Add a calculated field to a report
- Apply basic formatting to a report using Layout View
