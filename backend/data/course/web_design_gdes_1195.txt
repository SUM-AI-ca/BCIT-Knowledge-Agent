## Web Design GDES 1195
Graphic Design Course
## Course Overview
​Graphic designers require web design skills as well as traditional media skills. In this course, students will be introduced to the foundation of front-end development and code management and become familiar with the basic tools of web design, including coding concepts to translate web design into code. Focusing on web standards as outlined by the World Wide Web Consortium (W3C), students will learn to hand code HTML 5, CSS3 (Cascading Styles Sheets) to control overall hierarchy, structure, functionality, layout and appearance of websites​.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Hand-code HTML and CSS to current web standards and create simple, deployable websites.
- Identify, utilize, and position HTML5 elements with CSS positioning in webpage layouts.
- Select and use HTML layout tags to create appropriate website layouts with consideration of visual design principles and web SEO optimization standards.
- Demonstrate and optimize images as web page assets.
- Learn the basics foundations of responsive website practices including Flexbox
- Integrate effective web design principles and web accessibility considerations.
- Analyze and troubleshoot error code messages in web browser de-bugging tools
- Introduce process of website implementation with hosting/domain services
- Provide a showcase of alternative website building solutions such as WordPress, Wix, and Web flow​
Effective as of Spring/Summer 2025
