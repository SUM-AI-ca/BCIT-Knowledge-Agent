## Game Level Design 2 MDIA 2080
Media Communications Course
## Course Overview
This course explores advanced features of the Unity 3D game engine software. Topics include; creating additional assets, refining elements from third party sources used to incorporate into a game, techniques for achieving a higher visual quality, better interface design and a smoother workflow. At the end of the course students are expected to deliver at least one working game level that a user can play through, interact with objects and see the results as scores or other types of user feedback.
### Prerequisite(s)
- MDIA 1080

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create or refine assets for the game project.
- Follow the game project plan and meet the deadlines.
- Design, test, evaluate and troubleshoot the game-play.
- Design and create feedback elements for user interactions.
- Optimize the assets and environment for smoother runtime experience.
- Layout and create a user friendly user interface.
- Properly setup camera angles and shots inside the game engine.
- Setup lighting and atmosphere for the game.
- Test, refine and regress the game level in action.
- Create a final working demo and prototype of the game concept.
