## SSP MS NT Enterprise COMP 2656
Computer Systems Course
## Course Overview
Shows students with experience supporting MS Windows NT Server how to design, implement and support a multi-domain enterprise environment. The content is organized into four different unit areas, Implementing MS Win NT Server Directory Services, NT Server Analysis and Optimization, NT Network Analysis and Optimization, Troubleshooting NT Server in the Enterprise Environment.
### Prerequisite(s)
- No prerequisites are required for this course.
