## MS Word Workshop 1 COMP 0266
Computer Systems Course
## Course Overview
In one day participants are shown Word principles and how to produce well formatted documents in this intensive, hands-on seminar. This one day workshop starts with the Word user interface components - Backstage view, Tabs, the Ribbon, Quick Access Toolbar, Mini-Toolbar, Live Preview, and Galleries. Topics include: using Word navigation and selection techniques, shortcuts; modifying text; find and replace; font and paragraph formatting – applying styles; tabs, paragraph alignment, line spacing, borders, shading, bulleted and numbered lists; document formatting – margins, page orientation, page and section breaks, headers and footers, watermarks and tables. MS Word interface illustrations - graphics, SmartArt diagrams, WordArt; and Word’s proofing tools are also discussed. Successful participants will be prepared for MS Word Workshop Level 2, COMP 0267 .
### Prerequisite(s)
- COMP 1002 , or equivalent knowledge of managing files on a Windows PC or equivalent.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Explore and identify the MS Word interface components - Backstage view, Tabs, the Ribbon, Quick Access Toolbar, Mini-Toolbar, Live Preview, and Galleries.
- Create, save, and print documents.
- Work efficiently in Word using navigation and selection techniques and shortcuts.
- Modify text using copy, cut, paste and find / replace.
- Apply font and paragraph formatting – styles; alignment, line spacing, borders, shading.
- Create and format bulleted and numbered lists.
- Set tabs using the ruler and dialog box , format tabs with line leaders.
- Create and format tables.
- Apply document formatting – change margins, page orientation, insert page and section breaks, watermarks, create and format headers and footers.
- Insert and format illustrations - graphics, SmartArt diagrams or organization charts, WordArt.
- Use Word’s proofing tools - spelling and grammar, contextual spelling, and the thesaurus.
