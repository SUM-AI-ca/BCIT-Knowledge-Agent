## MS PowerPoint 2007 Transitional Workshop COMP 0280
Computer Systems Course
## Course Overview
MS Office has a completely new interface for version 2007. It was developed to make these applications simpler to use. The menus and buttons from prior versions are gone. MS PowerPoint 2007 uses a new ribbon environment with contextual tabs to get to commands. This intensive half-day transition workshop is targeted for students who already know how to use MS PowerPoint 2003 to build and style presentations. Topics include navigating the Ribbon, the Quick Access Toolbar, Cut, Copy, Paste, Format, Style, Insert Pictures, Tables, Diagrams, Charts, Add Sounds, Animations and how to save presentations in the appropriate file formats. Gain hands-on experience using concepts and special techniques to increase efficiency.
### Prerequisite(s)
- COMP 0282 or working knowledge of MS PowerPoint, a Windows PC and file management.
