## Adobe InDesign PC 1 MDIA 1048
Media Communications Course
## Course Overview
Adobe InDesign enables designers to realize their creative vision by incorporating text, graphics and images into a finished fully designed page. InDesign allows you to work smoothly with Adobe Photoshop, Illustrator, Acrobat, InCopy and Dreamweaver and enjoys consistency by using shared presets and color settings and work more efficiently while using native file formats. InDesign moves beyond just print with support for publishing multiple media.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Demonstrate an understanding of the InDesign work area & basic manoeuvres.
- Understand Raster vs. Vector.
- Integrate and flow text from column to column.
- Assemble and produce visually appealing layouts.
- Pull down ruler guides and use different units of measurement.
- Create and store colours in a Swatches palette.
- Create and modify text and paragraphs.
- Create linear and radial gradients and modify their direction.
- Add and Delete pages of a multi-page document.
- Import other file formats into an InDesign document.
- Use the Links Palette for modifying and updating external links.
- Understand and apply the Preflight and Package features.
- Create layers and move objects between various layers.
- Apply fills and strokes to different objects.
- Understand and apply the Transform Tools.
- Create type on a path, and inside closed paths.
- Create and use Master Pages.
