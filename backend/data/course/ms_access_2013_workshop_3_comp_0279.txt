## MS Access 2013 Workshop 3 COMP 0279
Computer Systems Course
## Course Overview
COMP 0271 , 0272 and 0279 have been replaced by COMP 0371 and COMP 0372 . Following on from COMP 0271 plus COMP 0272 , participants are shown advanced MS Access 2013 topics in this intensive, hands-on seminar. Participants must already be familiar with managing files on a Windows PC and intermediate functions of MS Access. Topics include: advanced queries, crosstab queries, pivot tables, pivot charts, and basic macros. Lectures and exercises focus on how to import data, enhance form designs with the calendar control and tab pages, basic security for MS Access 2013 databases and introduction on macros to automate routine tasks. Successful participants in all three One Day Access workshops will acquire an understanding of how to use MS Access 2013 for a variety of tasks.
### Prerequisite(s)
- COMP 0271 and COMP 0272 or equivalent knowledge of MS Access 2013.

## Learning Outcomes
- Upon successful completion of this course, the student will be able to:
- Import data from other sources
- Create find unmatched and find duplicate queries
- Create crosstab queries
- Create a pivot chart and pivot table
- Create basic macros and attach them to command buttons on forms
- Display a calendar on a form, and organize information with tab pages
- Maintain an Access database by implementing a database password, compact and repair a database, and analyze the performance of a database
