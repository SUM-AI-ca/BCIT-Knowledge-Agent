## Network Cyber Security Workshop for Biomedical Engineering 2 BMET 0927
Biomedical Engineering Course
## Course Overview
​This 2-day on-campus workshop is the second part of the cybersecurity workshop to reinforce the concepts introduced in BMET 0926 (Network Cybersecurity Workshop for Biomedical Engineering I). Students will get hands-on exercise to solidify the concepts and skills using packet sniffers and other network monitoring tools. ​
### Prerequisite(s)
- ATT in BMET 0926
### Credits
0.0

## Learning Outcomes
​Upon successful completion of this course, the student will be able to:
- Practice using TCP/IP utilities to carry basic network troubleshooting
- Explore common healthcare industry cybersecurity vulnerabilities and threats
- Apply the BMET cybersecurity best practices in healthcare​
