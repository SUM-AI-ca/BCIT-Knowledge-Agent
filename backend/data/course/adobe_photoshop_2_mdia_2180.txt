## Adobe Photoshop 2 MDIA 2180
Media Communications Course
## Course Overview
This course covers advanced compositing techniques, including painting with the mixer brush, adding a background, matching colour schemes across images, and blending multiple pictures to create a panorama. Students will select different brush settings and create a custom brush preset. The course also covers applying layer styles, adding adjustment layers, using layer effects and blending modes. Students will manipulate an image with Puppet Warp, create type on a path, warp point type, design with paragraphs of type and work with type styles. Other topics covered in the course include straightening and cropping images, using the spot healing and brush tools, repairing areas of an image using the clone stamp tool, applying gradients to layers, and working with masks and channels. Students will also prepare files for the web by creating slices and export HTML and images.

## Learning Outcomes
At the end of this course the student will be able to:
- Mix colours with the mixer brush.
- Create a custom brush preset.
- Use wet and dry brushes to blend colour.
- Create seamless patterns from images.
- Use vector drawing techniques to create and edit paths.
- Control type and positioning using advanced features.
- Merge type with other layers.
- Apply and edit smart filters.
- Apply colour effects to selected areas of an image.
- Manipulate an image with Puppet Warp.
- Create a clipping mask from type.
- Match colour schemes across images.
- Blend images together to create a panorama.
- Prepare files for the web by creating slices and exporting HTML and images.
