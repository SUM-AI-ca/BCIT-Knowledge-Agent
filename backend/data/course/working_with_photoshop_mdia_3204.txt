## Working with Photoshop MDIA 3204
Media Communications Course
## Course Overview
This course proves a basic introduction to the Adobe Photoshop interface and tools. Topics covered will include the basics of colour and images; painting and editing tools; making selections; using layers; working with type, using paths, channels and masks; correcting digital colour; and using filters. The course will end with the process of optimizing images for delivery on the Internet.
### Prerequisite(s)
- ( MDIA 1205 or MDIA 1206 ) and MDIA 2205

2.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Describe the basic function of each of the Photoshop tools.
- Outline the basics of digital colour and list the digital colour formats and their applications.
- Describe how print colour differs from Web colour.
- Illustrate how the Photoshop painting tools may be used to create digital imagery.
- Demonstrate how the Photoshop tools may be used to edit digital images.
- Explain how using layers, paths, and channels can simplify digital image editing.
- Show how masks and filters can enhance the creation of digital images.
- Indicate how working with digital type differs from other digital imagery.
- Illustrate the tools and techniques available for correcting colour aberrations in digital images.
- Demonstrate how to optimize images for delivery on the Web.
