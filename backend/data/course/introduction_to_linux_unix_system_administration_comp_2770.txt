## Introduction to Linux/Unix System Administration COMP 2770
Computer Systems Course
## Course Overview
This course is the second level in a series of core Linux/Unix courses, and introduces system administration using the GNU/Linux operating system. Topics include custom installation, file system, software, service, and local account management under Linux/Unix. Fundamental system administration principles and basic security concepts are also covered.
### Prerequisite(s)
- 50% in COMP 2765
### Credits
3.0

## Learning Outcomes
Upon successful completion, the student will be able to:
- Perform custom installation.
- Understand Intel boot configuration.
- Manage file systems.
- Manage software packages.
- Manage services.
- Manage local user accounts.
- Utilize backup tools.
- Understand system recovery.
