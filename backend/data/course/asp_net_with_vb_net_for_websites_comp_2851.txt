## ASP.NET with VB.NET for Websites COMP 2851
Computer Systems Course
## Course Overview
This introductory course discusses the main elements in creating and deploying a dynamic data driven website using Active Server Pages (ASP.Net) and VB.Net. Topics include: introduction to web database programming, HTML basic concepts, web servers, processing ASP.Net web forms and server controls, retrieving and displaying data in web forms using the DataGrid, and DataList controls and an introduction to XML and web services.
### Prerequisite(s)
- COMP 1850 or COMP 1820 and one programming language (ie. VB, C or Java).

## Learning Outcomes
Upon successful completion, the student will be able to:
- Learn the basics the .Net framework and how it applies to ASP.Net.
- Learn basic database concepts.
- Understand how an ASP.net page interacts with a Web server.
- Learn about with client-side scripts and server-side processing.
- Retrieve and display data in an ASP.Net Web Form.
- Create and manage a basic ASP.Net intranet site.
