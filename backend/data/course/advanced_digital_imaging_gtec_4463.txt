## Advanced Digital Imaging GTEC 4463
Graphic Communications Technology Course
## Course Overview
This course concentrates on checking documents before they are printed by application programs used for preflighting including native application and PDF files. Students will also set up Colour Management settings within the application programs using ICC profiles to help ensure consistent colour reproduction from the monitor to final digital output. Students will perform all of the tasks using a high capacity digital printer including setting up routines for running calibration and registrations tests. A database will be utilized to create a variable data print run for a personalized print marketing campaign. Students will impose a four-colour brochure with bleeds and trim marks and produce final output. The final exam will be to produce a complex job from creation through to completion.
### Prerequisite(s)
- GTEC 2463 and MDIA 2140

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Perform manual preflighting for identifying potential output problems.
- Build a job using various application files.
- Prepare pre-flight documents to create a report identifying potential problems.
- Work with native application files.
- Create PDF files from various applications.
- Implement ICC colour profiles for colour management consistency.
- Work with Colour Management software and RIP settings for colour management consistency.
- Use calibration software to ensure consistent colour output.
- Recognize consistency, verification, calibration, characterization and conversion issues.
- Troubleshoot a file and correct either on the fly or on demand.
- Set up and prepare a digital printer for four-colour digital output.
- Assess PDF files to ensure they have been through the pre-flight process.
- Customize a print job with variable data, including variable customer specifications.
- Set up jobs to merge database for a personalized media campaign
- Run a variable data client job.
- Impose the job for the printer.
