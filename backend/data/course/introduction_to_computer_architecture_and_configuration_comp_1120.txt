## Introduction to Computer Architecture and Configuration COMP 1120
Computer Systems Course
## Course Overview
This course introduces students to typical PC architecture and organization. It gives an overview of the hardware organization and how operating system and application software interact with the hardware. The course covers PC system configuration, hardware and software installation as well as basic PC preventative maintenance and troubleshooting.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Identify the hardware components of a PC typical of a LAN workstation.
- Identify the software components of the operating system for such a PC.
- Describe the assembly and upgrading of such a PC and its components.
- Describe troubleshooting for such a PC.
- Describe common problems for such a PC.
- Describe preventive maintenance measures for such a PC.
- Demonstrate the installation and configuration of Microsoft Windows.
- Demonstrate basic usage of Windows from both the GUI and the command line.
- Demonstrate the installation and configuration of Linux.
- Demonstrate basic usage of Linux.
