## PV Installation CESA 0125
Centre for Energy Systems Applications Course
## Course Overview
Participants will be taught the appropriate equipment, materials and techniques for installing, commissioning, maintaining and operating a Photovoltaic System. Participants will apply their skills and training while assisting in the installation of a functional grid-interactive, battery back-up PV system.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, students will be able to:
- Install PV Modules:
- Attach modules to racks.
- Install power and bonding conductors.
- Install combiner and conductors between PV modules and combiner.
- Install Charge Controller:
- Install charge controller and charge controller disconnect.
- Install conductors between combiner, charge controller disconnect, charge contoller and battery.
- Install Conductors for Battery Interconnection and Connection of Equipment to Battery.
- Commission a Grid-interactive, Battery Back-up Photovoltaic System.
- Set up, commission, troubleshoot and operate the Xantrex SW 4024 inverter.
- Perform basic battery maintenance.
