## Understanding TCP/IP CITX 1151
Computer Information Technology Electronics Course
## Course Overview
Provides students with a thorough understanding of the TCP/IP protocol suite. Key topics include Internetworking, Internet protocol, sub-networking the Internet layer, routing protocols, TCP and UDP, and application layer protocols.
### Prerequisite(s)
- CITX 1145
### Credits
3.0
Not offered this term: This course is not offered this term. Notify me to receive email notifications when the course opens for registration next term.
## Learning Outcomes
Upon successful completion, the student will be able to:
- Understand the fundamentals of routing in IP networks.
- Be familiar with the RIP routing protocol.
- Be familiar with the OSPF routing protocol.
- Understand TCP/IP based applications, and the protocols they use.
- Understand and be able to implement security in an IP-based network.
- Be familiar with network management using SNMP.
