## Architectural Desktop 1 AICO 3042
Computer Aided Design & Engineering Course
## Course Overview
Describes how to use the features of AutoCAD Architectural Desktop software in a typical architectural design project. File and project management, 2D drawing layout and annotations are covered. Course emphasis is on the new features relating to the object-based architectural elements of the software.
### Prerequisite(s)
- 50% in AICO 2000
- AICO 2000 or equivalent.
