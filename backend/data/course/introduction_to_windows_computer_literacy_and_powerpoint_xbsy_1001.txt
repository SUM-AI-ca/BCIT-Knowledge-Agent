## Introduction to Windows, Computer Literacy and PowerPoint XBSY 1001
Business Systems Course
## Course Overview
​In this course, participants get introduced to an essential tool in business today. This course provides an introduction of computer terminology, operating systems and how to use popular business software to create content and professional-looking presentations to deliver them to an audience. In addition, we will discuss up to date technology issues and challenges that affect and impact the business environment.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Open, save, create, move, copy, delete, and rename files in a Windows environment.
- Define target audiences for a PowerPoint presentation and select designs, themes, and content appropriate to those audiences.
- Apply transitions, animation, and sounds to a PowerPoint presentation.
- Create, edit, arrange, and print presentations.
- Create and import graphics into presentations; including picture files, SmartArt and WordArt.
- Create presentations with tables, images, hyperlinks, and watermarks.
- Describe default settings for graphics in MS PowerPoint.
- Create and modify charts in MS PowerPoint.
- Integrate elements of the internet, MS Word, MS Excel, and MS PowerPoint across all three applications.
