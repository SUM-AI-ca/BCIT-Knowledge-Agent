## Cloud Computing Platforms COMP 3962
Computer Systems Course
## Course Overview
In this course students learn how to utilize a wide variety of resources and services available on cloud computing platforms. Topics include characteristics of cloud computing; cloud deployment models; cloud platform architectures; cloud computing platforms and comparative analysis; cloud compute resources including virtual machine instances, load balancers, auto scaling groups, and snapshots; cloud networking, with an emphasis on virtual private clouds (VPCs); cloud storage and content delivery, cloud-hosted databases, and cloud security models including user identity, access management, and resource security. Students will build their skills by participating in in-class interactive lectures, hands-on lab activities, and working on comprehensive assignments.
### Prerequisite(s)

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Differentiate the different types of cloud deployment and service models.
- Describe the advantages and disadvantages of cloud computing.
- Analyze the platform architectures of a variety of public cloud computing platforms.
- Configure and deploy virtual machines (instances), load balancers, and auto scaling groups.
- Design and implement VPCs.
- Implement security policies on users and resources, including VPCs and instances.
- Select storage options for resources and applications, including instances, databases and websites.
- Design and deploy cloud-based websites.
- Deploy and configure a variety of database instances.
- Remotely configure and monitor deployed resources.
- Install, configure and use both integrated development environments and command line interfaces to configure and manage resources on public clouds.
