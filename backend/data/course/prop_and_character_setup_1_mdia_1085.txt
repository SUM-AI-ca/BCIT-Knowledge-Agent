## Prop and Character Setup 1 MDIA 1085
Media Communications Course
## Course Overview
This course introduces Unity 3D which is one of the most popular game engines for preparing and setting up characters and props for video games across multiple platforms. Topics include; the essentials of character creation, prop setup, concept design and project needs for a low to intermediate scale game project. Students will be introduced to industry standard techniques required for preparing, optimizing, designing and creating proper game characters and props for a game project. Other topics will include; different methods for creating animation pieces for different actions and interactions inside the game engine. Students who attend the course must have basic knowledge of Autodesk Maya, 3ds Max, or Blender.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Describe and transform an idea into a game prop or character.
- Properly plan and manage a low-level game project.
- Design and explain a prop and character concept.
- Prepare and optimize images for texturing the game props.
- Create compelling character textures quickly and efficiently.
- Animate realistic game props inside the game engine.
- Create action-based animations for characters inside the game engine.
- Trigger prop and character animations based on user input.
- Create and discuss a preliminary working prototype.
