## Advanced Flash Web Design MDIA 4310
Media Communications Course
## Course Overview
With over 4 hours of video notes spread across 21 movies, this course teaches you all of the skills required to push your animation to the next level and use ActionScript 3.0 to make your Flash websites, animations, and games more interesting and interactive. You will explore some advanced animation techniques and tricks to streamline your work, as well as more complex IK animation, and the basics of using 3D animation in Flash. Moving on to the scripting, you start with basic buttons, then work on multiple timeline control, manipulating movie clip properties, working with variables, draggable movies, collision detection, and Preloaders. You also focus on multiple ways to mount your Flash content on your website.

## Learning Outcomes
Upon successful completion, the student will be able to:
- Control multiple timelines
- Demonstrate 3D animation in Flash, using Swift 3D
- Work with more complex Inverse Kinematic animations
- Manipulate movie clip properties
- Work with variables and apply those variables to dynamic text
- Use conditional statements
- Create a complex Preloaders
- Set up drag and drop movies
- Dynamically control an object's depth
- Use collision detection to see if objects are touching
- Mount your Flash content on a website, and integrate Flash components with existing HTML
- Demonstrate how to use AS3.0 to make your Flash content more interactive
- Combine multiple AS3.0 actions together, to create larger, more complex scripts
