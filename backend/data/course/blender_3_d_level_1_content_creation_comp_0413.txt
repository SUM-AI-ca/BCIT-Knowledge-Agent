## Blender 3-D, Level 1 - Content Creation COMP 0413
Computer Systems Course
## Course Overview
Jump into the world of 3-D modeling in this hands-on course that introduces content creation with Blender 3-D. Students with no prior knowledge will learn basic modeling skills, in this open source software package. Topics include: mesh modeling, textures, lighting and rendering techniques. Learn to build basic 3-D images and be prepared to move on to Blender Part 2 and explore animation.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create basic mesh models.
- Apply modifiers to the models.
- Create and apply textures to models.
- Apply different lighting to the scenes.
- Render scenes to different web ready formats.
