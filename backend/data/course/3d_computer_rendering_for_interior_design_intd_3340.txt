## 3D Computer Rendering for Interior Design INTD 3340
Interior Design Course
## Course Overview
This course will introduce students to 3D drawing using the current release of AutoCAD. Students will draw 3D furniture and 3D spaces in isometric and perspective views. Emphasis is to use the AutoCAD skills and techniques learned in Construction Drawings 2, and further develop them to work in conjunction with new 3D commands and to apply them to design applications for presentation.
### Prerequisite(s)
- 65% or better in INTD 2500 and all bridging courses.
### Credits
3.0
Retired: This course has been retired and is no longer offered. Find other Flexible Learning courses that may interest you.
## Learning Outcomes
At the end of this course, the student will be able to:
- Use Autocad Hatch, Gradient and Images to render 2D Plans and Elevations.
- Create 3D drawings from 2D AutoCAD Plans for interior design applications.
- Create 3D furniture and accessories.
- Render 3D objects and spaces using AutoCAD and custom materials.
- Apply lighting to a 3D interior drawing.
- Plot a professional looking 3D rendered drawing.
