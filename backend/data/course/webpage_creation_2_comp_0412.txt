## Webpage Creation 2 COMP 0412
Computer Systems Course
## Course Overview
Continuing on from COMP 0402 , this hands-on course shows students how to create more complex, content- rich web pages that contain audio, video an animations. Topics include: how to add dynamic JavaScript animations, plus image and text-rollovers, an image gallery and a thumbnailer. Students learn some basic PHP to add forms, a BLOG and how to password-protect their site. Recommended for aspiring web developers (Ages 10-13).
### Prerequisite(s)
- COMP 0402 or equivalent knowledge.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Create richer content to web pages with:
- Dynamic image galleries using HTML, CSS and JavaScript.
- Add images, sounds and animation.
- Use basic PHP.
- Build a BLOG.
- Learn how to setup password protection.
