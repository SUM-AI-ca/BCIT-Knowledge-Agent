## Adobe InDesign 2 MDIA 2049
Media Communications Course
## Course Overview
This hands-on course expands on the skills and knowledge that you gained in Adobe InDesign 1 by using different tools, drop-down menus, and panels to create a more complex series of projects. You will create multiple master pages with different columns and grids, create a digital imposition, add video with sound controls, precisely position pictures, text, and graphics, and transform digital graphics. As well, you will use step and repeat to create a background pattern, span text columns, and smart link InDesign with Photoshop. You will use a pen tool to create advanced computer graphics with compound paths.

## Learning Outcomes
Upon successful completion of this course the student will be able to:
- Set up multiple master facing pages so that items appear consistently on each page of a document.
- Apply consistent formatting to objects through using paragraph and character styles.
- Create tables with formatting specifically set for rows, columns, stroke weights, and colours.
- Apply different transparency settings to objects on different layers for visual design effects.
- Apply different layers to assign text, graphics and pictures.
- Demonstrate use of filling frames proportionally with pictures.
- Integrate Photoshop smart objects into InDesign for painting effects by applying layer masks.
- Create an interactive PDF file with layers to view in Adobe Acrobat.
- Create interactive buttons that control picture placements, videos, and audio.
- Use a pathfinder panel to intersect different objects on a page.
- Use scissors to cut different part of computer graphics.
- Practice using a pen tool to hand draw and rotate letters around to create headlines.
