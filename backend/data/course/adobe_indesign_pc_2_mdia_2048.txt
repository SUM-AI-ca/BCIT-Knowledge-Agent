## Adobe InDesign PC 2 MDIA 2048
Media Communications Course
## Course Overview
This course covers multi-page documents, multiple master pages and book features. Students will work with transparency, object styles, paragraph styles, tables with screen tints, managing links from imported files, importing Photoshop files, creating a library and managing objects, and apply transparency settings. The course will be centred around creating documents for professional printing with a concentration on creating pdf files.
### Prerequisite(s)
- MDIA 1048
### Credits
1.5

## Learning Outcomes
Upon successful completion, the student will be able to:
- Use advanced Character and Paragraph styles to automate formatting across multiple pages.
- Review Thread and Unthread text in multiple columns.
- Mark section of pages for document control.
- Generate form elements using advanced tables and tab control.
- Create and apply an InDesign library while managing objects.
- Apply transparency through opacity changes, drop shadows and feathers.
- Create Object Styles to automate graphics across multiple pages.
- Review Preflight and Package a file for print production.
- Review Linked and Embedded Images.
- Understand and use the Hidden Characters.
- Understand and insert some Special Characters.
- Create Automatic Page Numbering.
- Modify spreads and create island spreads.
- Create and modify Books.
- Understand the concept of printers? vs. readers? spread and their application.
- Automate work through Quick Apply feature of CS4.
