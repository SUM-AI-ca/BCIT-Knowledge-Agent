## SSP Netware COMP 2631
Computer Systems Course
## Course Overview
Shows students by providing lectures and hands-on, how to install NetWare clients, describe the virtual load-able modules, define NDS naming conventions, map drives and create NDS objects. Further topics include how to manage users and groups, describe the 3 levels of security, define objects/property rights, create login scripts and menus and use the RCONSOLE to access a file server console.
### Prerequisite(s)
- No prerequisites are required for this course.
