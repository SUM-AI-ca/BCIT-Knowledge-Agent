## MS Office 2010 Upgrade Workshop COMP 1004
Computer Systems Course
## Course Overview
Upgrade to MS Office 2010 with this intensive, hands-on workshop, learn new features to be productive and save time. The aim of this course is to cover the version changes and requires that the students have prior knowledge of word processing, spreadsheets and presentation applications. MS Office 2010 has new navigation and uses a context sensitive ribbon with tabs which lead specific related commands. This workshop is designed for end users who already know how to use; MS Word, MS Excel and MS PowerPoint, from the previous version of MS Office 2003. Topics include an overview of MS Office 2010, understanding, navigating and using the new interface for typical commands. Successful participants will be productive in routine tasks, and gain confidence to use many of the new features of MS Office 2010.
### Prerequisite(s)
- COMP 1200 or equivalent knowledge of MS Word, MS Excel and MS PowerPoint.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Navigate and identify the components within the new User Interface.
- Use the Ribbon, tabs and Dialogue Launcher to find commonly used commands and features.
- Customize the Quick Access Toolbar.
- Display Key Tip badges and efficient use of keyboard shortcuts.
- Save using the new file format.
- Work with older files using compatibility mode and/or convert older files.
