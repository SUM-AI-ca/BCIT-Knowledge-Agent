## InDesign Fastrack MDIA 1043
Media Communications Course
## Course Overview
This Adobe InDesign course explores how to use the drawing tools, the gap tool, layers, tables, control typographical settings, span columns, flow columns and pages together within the same document. Students use the Adobe Bridge and import graphics from Adobe Illustrator and images from Photoshop. You will also learn some useful techniques to create attractive projects for your work in an efficient way by applying some of the automating tools of InDesign such as Paragraph Styles, character styles, object styles and Master Pages. The course will be provided in a lecture/lab format with in-class exercises providing hands-on experience.
### Prerequisite(s)
- MDIA 1170 or MDIA 1180

## Learning Outcomes
Upon successful completion, the student will be able to:
- Demonstrate use of the InDesign work area by performing basic manoeuvres when assembling a page
- Describe the differences between Raster objects and Vector Graphics
- Draw and Modify Basic Shape Objects with different InDesign tools
- Assemble and produce layouts using both text and graphics
- Flow text from column to column and show text threads
- Use horizontal and vertical ruler guides with different units of measurement
- Create and store colours in a Swatches panel
- Create and Modify linear and radial gradients
- Create and modify text and paragraphs with character and paragraph style sheets
- Add and Delete pages of a multi-page document
- Import different file formats into an InDesign document with the Adobe Bridge
- Use the Links Palette to keep track of supporting files
- Apply the Pre-flight and Package features of InDesign for troubleshooting files
- Create Layers and assign objects between different layers
- Apply Fills and Strokes to different objects
- Execute different Transform Tools including scale, rotate, shear and reflect
- Create and use Master Pages with multiple page documents
- Create and apply Paragraph Styles to automate formatting
