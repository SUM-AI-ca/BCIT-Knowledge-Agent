## Computer Applications in Construction BLDT 2061
Construction Operations/Supervision Course
## Course Overview
Presents practical computer applications with an emphasis on construction documentation, economic problems, estimating and scheduling associated with project and construction management of construction projects. Topics include use of MS Excel and MS Project software.
### Prerequisite(s)
- Successful completion of Construction Operations program or departmental approval and a background in a Windows and Excel environments.
### Credits
3.0
### Domestic fees
$564.42 - $620.01 See individual course offerings below for actual costs.
International fees are typically 3.4 times the domestic tuition. Exact cost will be calculated upon completion of registration.
## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Identify various forms of construction documents.
- Produce Change Order forms.
- Apply appropriate MS Excel features to insure document accuracy and efficiently produce documents.
- Apply appropriate financial functions in MS Excel for calculations related to the construction process.
- Create Application for Payment forms.
- Generate sequence of applications for payment.
- Create a project plan by using MS Project software.
- Analyze a project plan and implement scheduling techniques to improve efficiency.
- Add resources and cost components to a project plan in MS Project.
- Resolve potential scheduling issues.
- Generate relevant reports in different project phases.
- Track project progress and update a project plan.
Effective as of Spring/Summer 2015
