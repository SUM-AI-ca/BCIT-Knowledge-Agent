## Microsoft Windows Architectures for Developers COMP 2651
Computer Systems Course
## Course Overview
Presents the architectures and related services of the Microsoft's Windows Operating systems. Provides the framework required to develop solutions for the Windows 95 and Windows NT operating systems. Prpares you to write the Microsoft Windows Architecture exam. Prereq: Comp 1261,1266, 1270 and 2495 or equivalent, and understanding of the Internet.
### Prerequisite(s)
- No prerequisites are required for this course.
