## Electronic Prepress 1 GTEC 2005
Graphic Communications Technology Course
## Course Overview
This course introduces the mechanisms and protocols of electronic prepress production through the workflow application 'Prinergy'. It focuses on the requirements for setting work up in Prinergy and exposes the student to the Refine and Trapping functions that produce single page PDFs. Fundamentals of imposed form work for printing production is also covered through industry standard applications Preps and Prinergy. Students will have an opportunity to process a project from input through to plate ready status.
### Prerequisite(s)
- No prerequisites are required for this course.

## Learning Outcomes
Upon successful completion of this course, the student will be able to:
- Articulate the primary components and functional modules of the Prinergy application in the context of the modern electronic prepress workflow.
- Create a job and the requisite supporting folder structure in the Prinergy workflow.
- Construct a Master Template job for recurring parameters.
- Differentiate between acceptable and unacceptable file formats for input to Prinergy.
- Effectively navigate the online help system that is built into the application.
- Import input files both through menu commands and the graphic interface.
- Transform files with the Refine function into PDF format required for all subsequent actions in Prinergy.
- Describe the settings for Trapping in Prinergy.
- Use the Trap Editor plug-in for Acrobat to identify and revise trap characteristics.
- Process a job from input to single page output.
- Create templates and jobs in the application Preps to provide imposition instructions to Prinergy.
- Import the Preps job and its associated marks pdf into the appropriate location in Prinergy.
- Manipulate page sets for correct linking to Imposition plans.
- Process a multi-page project from input through to the output of correctly imposed forms.
